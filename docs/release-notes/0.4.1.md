Ferret 0.4.1

- Install: the Windows installer installs and starts Ferret in one step, without choosing a folder. An earlier copy installed for all users is removed during the update.
- Review targets can be marked as app, design or doc. Figma, Google Docs, Notion and similar URLs are recognized, and findings recorded on a design or a document tell your agent to change the design or the document rather than the code.
- The built-in browser completes "Sign in with Google" and other sign-in pop-ups, and presents itself like Chrome so sign-ins are accepted.
- Record the other side too: the voices of other people in Google Meet, Zoom, Teams and other meeting apps are recorded from the computer's audio and transcribed as "Other".
- File tree: create files and folders, rename (F2) and move to Trash, with an in-app confirmation.
- Terminal: Shift+Enter inserts a new line for agents, Ctrl+C / Ctrl+V copy and paste on Windows and Linux, programs can copy to the clipboard (OSC 52), multi-line paste reaches agents as one block on Windows, and closing a tab whose agent is still working asks first.
- Updates: Check for Updates downloads the new installer itself and checks it against the signed SHA256SUMS before saving it. The download page verifies files in the browser as well.
- Security: agent and sign-in commands on Windows are only taken from folders outside the project, project files cannot be redirected outside the project with symbolic links, and large folders and long review histories load within limits.
- Input methods: the Enter that confirms a conversion no longer submits name and title fields, and repeated Korean syllables are kept.
- Network: transcription and organize requests use the system proxy and certificates.
- The window reloads by itself if its page crashes, and macOS has a Window menu with Minimize (Cmd+M).
- Docs are available in 14 languages, show shortcuts for macOS and for Windows / Linux, and work with any coding agent.
