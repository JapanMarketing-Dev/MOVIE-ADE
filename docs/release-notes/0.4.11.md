Ferret 0.4.11

- The footer shows the project's branch and how far it is behind or ahead of GitHub, GitLab or any other remote. Ferret fetches when you open a folder and every few minutes after that.
- From the footer you can get the latest code (fast-forward only: it never merges, and it keeps your uncommitted changes) or sync, which gets the latest and then pushes your commits after you confirm.
- On Windows, adding a second Claude Code or Codex account no longer fails to share skills, plugins and other folders when symlinks need administrator rights.
- Fewer false crash reports when process sampling briefly fails (for example, right after a display is disconnected).
- Imported files are checked more strictly: a file that is replaced or changed after Ferret measures it is no longer copied.
