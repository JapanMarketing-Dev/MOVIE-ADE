Ferret 0.4.2

- Updates: new versions download in the background, are checked against the signed SHA256SUMS, and install when you restart Ferret.
- Agents keep going at usage limits: when an account reaches its limit, Ferret switches to another account or the next agent in your order (Settings → Accounts), and the next agent continues from .ferret/handoff.md in the project.
- Claude Code starts with --dangerously-skip-permissions and Claude in Chrome, and Codex without approval prompts, by default. The launch command and arguments can be changed in Settings, and the permission skip can be turned off there.
- Projects whose agents have finished show a done mark, and with notifications on, Ferret tells you when all agents are done or when one is waiting for you.
- Markdown files can be edited directly in the preview; parts you do not touch keep their original text.
- File tree: create, rename, cut, copy, paste, duplicate, drag to move or copy, copy path, open in terminal, and undo. An empty folder shows where to start.
- Drag and drop: drop files and folders from the desktop onto the terminal (including agents), the project list (adds a project) and the editor, and drag rows from the file tree into the terminal or the editor.
- Terminal: Shift+Enter inserts a new line in each agent with that agent's own keys, and Japanese input with live conversion no longer repeats text when the input method commits part of a sentence.
- Crash reports: crashes are reported from macOS, Windows and Linux, and the remaining reported problems are fixed.
