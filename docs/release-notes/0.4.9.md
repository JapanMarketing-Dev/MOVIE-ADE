Ferret 0.4.9

- Findings awaiting your review are listed first by default, so you can check them and answer right away. This changes only the display order; numbers, feedback.md and the order sent to the agent stay the same.
- The status chips now filter: click a status to show only that status, and click it again to remove it.
- BEFORE and AFTER screenshots are shown large and side by side across the card, with the text below, so you can compare them without opening them.
- The decision model judges each finding once. From that one result, the agent improves the change at most once more, then hands it to you for review. It no longer loops.
- Findings recorded on external sites (such as a competitor's site) are treated as reference. The agent never edits that site; it adopts or avoids the pattern in your app, or notes that no change is needed. Targets named with words like "competitor" or "reference" become reference automatically.
- The Organize selector lets you choose the model as well as the service, and switch it in place.
- When settings.json has errors, a new button copies a request you can paste to Claude Code or Codex to fix them, with the file paths and each error's line.
- In the Markdown preview, type / to insert headings, lists, checklists, tables, code blocks, quotes and dividers. Inside a table, / adds or deletes rows and columns.
- The footer always stays at the bottom; the option to move it was removed. The URL filter row and the "nothing to send" line above the findings were removed.
