Ferret 0.4.3

- Windows: Ferret no longer pauses for a second or more at startup while it looks for installed agents and command-line tools, and finding tools such as Whisper no longer holds up the window.
- Editor: the buttons above the editor stay inside a narrow pane, shrinking to icons with tooltips, and Save no longer overlaps the terminal.
- Crash reports no longer carry a location derived from the connection.
- Install: the docs say that the Linux AppImage needs FUSE 2 and which package provides it on each distribution.
