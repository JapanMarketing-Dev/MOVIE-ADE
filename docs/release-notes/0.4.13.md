Ferret 0.4.13

- Terminals come back after a restart: the same tabs, splits and folders, with their earlier screen text above a "continued from" line. Claude Code and Codex tabs pick up their last conversation in that folder (Claude Code with --continue when one exists, Codex with resume --last).
- Reopen a closed terminal from the Terminal menu, or with Cmd/Ctrl+Shift+T while a terminal has focus. The last ten closed terminals are kept, with their text.
- The saved terminal text stays in Ferret's own data folder, readable only by you, and is capped in size. Turn it off, or delete what was saved, in Settings → Agent.
- Fixed an error when quitting while the review list was being refreshed.
