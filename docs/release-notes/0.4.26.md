Ferret 0.4.26

- All projects: the top of the sidebar now has "All projects", the agent for the whole editor. Start Claude Code there and ask; every registered project works as a subagent, in parallel where possible. Projects are included automatically as you add or remove them, and you never have to manage folders. Requests (Settings > Requests) and reviews sent from All projects go to every project.
- Creating an orchestrator by hand (added in 0.4.25) is replaced by All projects. An orchestrator you already made can be turned off from its right-click menu.
