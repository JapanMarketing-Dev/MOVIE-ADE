Ferret 0.6.9

- Search from the address bar: type words instead of a URL (or start with ?) and the built-in browser searches Google. URLs, host names, localhost and IP addresses still open directly.
- Sign in once, use it everywhere: sign-ins in the built-in browser (Google, Gmail, GitHub and so on) are shared by every project. Google accepts the built-in browser's sign-in, so you can read Gmail and work in signed-in sites inside Ferret.
- Keep a client apart when you need to: in Settings > Browser sign-ins, give a project a group name. Projects with the same name share their own sign-ins and are kept apart from everything else. Leave it empty to share again.
- Extension buttons next to the address bar: extensions you load (for example Google Translate) now show their icons right of the address bar, like in Chrome. Click one to open its popup.
