Ferret 0.4.10

- In the enlarged BEFORE / AFTER view you can mark a finding OK, NG or Comment. After each mark the next finding awaiting review opens, and you can move back and forth with the buttons or the arrow keys.
- Type a comment on a finding awaiting review and press Enter (or Cmd/Ctrl+Enter) to mark it NG and send it to the agent right away; there is also a Send to agent button. The Enter that confirms Japanese input does not send, and Shift+Enter adds a new line.
- Chrome extensions can be added to the built-in browser in Settings → Browser extensions (an unpacked folder, or imported from Chrome, Edge, Brave or Chromium). An extension's popup is included in recordings.
- One recording can capture up to four views at once (the built-in browser, app windows and screens). Switch between them with the chips in the recording bar; every view keeps recording.
- A review target can wait for an app window that isn't open yet: when it opens during a recording, Ferret records it too, and can switch to it.
- The feedback screen's right panel has a Terminal tab showing the editor's own terminal, so you can talk to Claude Code or Codex while recording (for example, to say localhost isn't running).
- The Review targets list shows every registered URL first, and each target's visited pages five at a time with "Show more". The filter still searches everything.
- The pen, frames and text notes work over dialogs opened by the page, over extension popups, and in sign-in popups such as Google login. While recording, a sign-in popup is recorded as its own video.
- Opening the version popover checks for updates right away. Ferret also checks after waking from sleep, and when you return to the window if the last check was over an hour ago.
- The project list in the sidebar always stays open; the close button, the title bar toggle and Cmd/Ctrl+B were removed.
- feedback.md explains the format of transcript.jsonl, so agents read the times and speakers correctly.
- Security fixes for the decision relay, saved provider addresses, organizer command lookup, file imports and the feedback relay. If you use your own transcription, organizing or decision endpoint, press "Test connection" once after updating to approve it; until then, requests that use its saved key are blocked.
- Fewer false "main process blocked" crash reports (while quitting for an update, in the background, or right after sleep).
