Ferret 0.6.17

- Agents ask each other in terminals you can see (on by default). Tell Claude Code "have Codex run a security check and fix what it finds", and it runs `ferret-agent send codex "..."`: Ferret pastes the request into the Codex terminal, or opens Codex below the sender when none is running. Codex writes its result to `.ferret/agent-mail/` in the project and replies with `ferret-agent reply`, and Ferret pastes the reply back into Claude Code, so the work goes back and forth without you. It works between any agents Ferret can start (Claude Code, Codex, Gemini CLI, …), also inside Codex's sandbox. Ferret installs the ferret-agent-mail skill for Claude Code and Codex; turn it off in Settings > Agents.
- Fixed: adding an account that signs in to the same login as an account you already used could delete the older account (its folder and saved sign-in). Now only the account you just added is removed as a duplicate.
- Several orchestras. Create one from + > "Create an orchestra" (for example one per client). In the sidebar each orchestra is a parent folder with its projects under it, like subfolders; collapse it with the arrow. Drag a project onto another orchestra (or between its projects) to move it, and drag orchestras to reorder them. New projects join the orchestra you have open. Everything an orchestra does (subagents, one recording across products, rounds, the checklist and answers, costs) covers only its own projects.
- Build each orchestra's dashboard yourself in `.ferret/dashboard.json`: choose and order the built-in sections (checklist, stats, composer, actions, requests, projects, costs) and add your own: metrics, a note from a text file, links and tables. Ask your agent to build it; the ferret-settings skill explains the format. Without the file, the dashboard looks as before.
