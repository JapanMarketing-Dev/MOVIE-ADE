Ferret 0.4.24

- Accounts: the same Claude Code or Codex login can no longer be added twice. If you add an account and sign in with a login you already have (or the one your system uses by default), Ferret removes the new entry and tells you. Duplicates added with earlier versions are cleaned up the same way, keeping the selected account.
- The account list in the footer shows one row per login.
- The account notes now say that running agent tabs also switch after they finish their current work.
