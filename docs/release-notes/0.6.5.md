Ferret 0.6.5

Orchestra: build many products at once. This release also includes 0.6.3 and 0.6.4, which were not published separately.

- One recording across products. In All products, start one recording and switch products with the tabs above the page; you no longer stop and start for each product. When you send it, each finding goes to the product whose page was open: products with their own agent get their findings directly, the rest go to the orchestra agent for that product's subagent, all in parallel. The text box in the strip sends typed feedback to the open product. The round that moved to the next product on its own is gone; Check pending items in turn only moves on Next.
- Prompts from the orchestra run in parallel: one subagent per product at the same time, and independent work inside each product in parallel too.
- The dashboard puts what people must check at the top, including approvals, keys to provide and decisions without a URL. Have the agent write it all sends a request that collects everything from every product into human.md.
- Requests to the agent moved from Settings to the dashboard. Hide one-time requests such as Sentry or Search Console setup once they are done. Scheduled sending was removed.
- Costs for this month, this year and in total now include infrastructure, services and subscriptions from .ferret/costs.json (in each product folder and the All products folder), broken down by product, category, item, model and token type. The Record every cost request has the agent fill it in.
- In the All products feedback view, the terminal and review targets stay behind small buttons at the bottom right, like the editor.
- The ferret-settings skill explains the orchestra to Claude Code and Codex: the human.md format, costs.json, products in or out, shared and per-product rules and the requests list, so you can ask the agent to change any of them.
- Long requests resume. If Ferret quits while an agent is working, reopening Ferret reopens the conversation and asks the agent to continue from where it stopped. After the computer sleeps, agents that stopped are asked to continue.
- Lighter with many products: the dashboard reads only the new part of conversation records, hidden terminals send output every 250 ms instead of every 16 ms, agent states are checked in one request (background projects every 4 seconds), terminal restore data is saved every minute without blocking, hidden terminals release their GPU context, background projects' terminals start two at a time, and git status and view-size updates run less often.
- Password import syncs. Importing a new export from the same browser replaces what you imported from it before, so passwords you deleted or changed there follow. Exports in Downloads or on the Desktop are listed for one-click import, and the CSV can be moved to the Trash right after. The key button updates as soon as you import, passwords saved for http work on the https page, and logins from another subdomain of the same site are offered (you pick them from the menu).
- Build a Chrome extension in a project and run it in Ferret's built-in browser from the terminal: the agent registers the folder, changes the reload number after each build, and removes or turns it off the same way (from 0.6.4).
- The strip above the page in All products feedback has two levels: products on top, and that product's pages and checklist items below (from 0.6.3).
- Crash fixes: no error when the orchestrator syncs the same folder twice at once; a PATH printed by your login shell is kept even if the shell exits with an error; helper processes stopped from outside are no longer reported as crashes; crash reports keep the crash location; a closing extension popup can no longer crash the layout on Windows (from 0.6.3).
