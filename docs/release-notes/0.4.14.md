Ferret 0.4.14

- Markdown files open in preview, and HTML files open in the built-in browser instead of the code editor. "Open source" is still there when you need it.
- Right-click a file tab to close it, close the others, close the tabs to the right, close saved tabs or close all.
- The "/" menu in Markdown preview works with the keyboard: arrow keys move, Enter or Tab applies, Esc closes. Typing "/#", "/-", "/1." and so on picks that format, and Markdown shortcuts such as "## " or "- [ ] " (also in full-width characters) convert as you type.
- The file tree shows icons for well-known folders and files, colors files and folders changed in git, dims files ignored by .gitignore, and hides .env, .DS_Store and .git (right-click to show them).
- Panel toggles live next to the Record button: the project list, the file tree, and a button that hides everything but the browser. Dragging panels to other places is gone; terminal tabs still reorder and split.
- The browser toolbar has "Open in external browser". The start screen lists the project's URLs (dev, prd, local…) and the URLs you opened recently.
- The footer shows microphone, transcription, API usage, GitHub branch and more while they fit; the rest go into "…", which no longer overflows.
- Copies from terminal programs (OSC 52) go straight to the clipboard without the confirmation bar.
- Recording: every connected display is listed, apps that are not open yet can be chosen by name (Ferret opens them and selects the window), and up to four screens or windows can be recorded together into one video. The picker explains why windows on other macOS desktops are not listed.
- The ferret-settings skill for Claude Code and Codex now lists every setting, including nested ones.
- After waking from sleep, Ferret waits for the network before checking for updates.
