Ferret 0.4.25

- Orchestrator: choose "Create an orchestrator" in Add project to make a main folder for several products and put existing projects under it. Their folders are not moved; they appear as subfolders (links) of the main folder, and each gets a subagent. In the sidebar, products are listed under their orchestrator; right-click a project to put it under an orchestrator or take it out.
- The main folder gets a README.md for people and CLAUDE.md / AGENTS.md. People write shared rules and per-product rules in CLAUDE.md. Ferret's part tells the agent to settle shared work once, keep infrastructure and other per-product things separate, run each product's part in parallel through its subagent, and set up connections and permissions (Chrome, computer use, MCP, logins) once at the top.
- Settings > Requests: ready-made requests to send to the agent of the open project — tidy up memory (dream), compact the instructions, a security check from every angle, SEO, analytics, Sentry errors and crashes, performance, accessibility and dependency updates — plus your own. Edit any text, send several together, or repeat them daily or weekly. From an orchestrator, a request goes to every product in parallel.
- New review opens the feedback view even when no page is open yet, instead of showing a warning. Enter the URL there.
- The sidebar no longer shows "Recordings appear here" under the open project. In Japanese, "mtg" is now written "MTG".
