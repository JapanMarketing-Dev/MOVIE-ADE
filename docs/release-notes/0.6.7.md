Ferret 0.6.7

- Fixes changes to settings.json made by an agent (or your editor) being lost when Ferret saved its own settings a moment later. Ferret now merges the outside change before saving: keys Ferret changed keep Ferret's value, everything else keeps the outside value. For example, turning off or removing a browser extension you are building from the terminal now always sticks.
- Checked end to end in the app: registering an unpacked extension through settings.json, rebuilding it and changing its reload number (the open page reloads with the new version), turning it off and removing it.
