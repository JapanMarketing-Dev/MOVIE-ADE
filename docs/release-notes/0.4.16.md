Ferret 0.4.16

- Paste into the file tree: copy files, videos, folders or an image (such as a screenshot) in Finder or Explorer, select a folder in Ferret's file tree and press Cmd/Ctrl+V. Images are saved as pasted-<date>.png.
- Project HTML opens in the built-in browser as ade-page://project/… and can no longer reach other sites by itself: scripts, styles and images load only from the project, and the page cannot navigate or open tabs to other sites (type an address to go there). The address bar no longer opens file:// URLs.
- Background Git checks run only for a remote you allow: the Git popover in the footer asks once per project and remote ("Check automatically"). Projects cloned in Ferret are allowed from the start. Automatic Git commands never run repository hooks or fsmonitor commands.
- Security fixes from a review: terminal paste no longer lets the app screen read the clipboard; changing an API key ends relay tokens that used the old key; the decision-model relay reserves each request's worst-case cost before sending; API and update requests no longer follow redirects; review media is served from the checked file; ripgrep and whisper.cpp are found only outside the project; the release workflow holds no signing key.
