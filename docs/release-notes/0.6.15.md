Ferret 0.6.15

- Hands off before the usage limit so work keeps going overnight. When the account a running Claude Code or Codex tab uses reaches 98% (Settings > Accounts > "Hand off before the limit at"), Ferret waits until the agent is idle, has it write its progress to `.ferret/handoff.md`, and continues in a new tab with the next account or agent in your order. Nobody has to open a new session.
- Clicking a link in the Markdown preview opens it in your browser.
