Ferret 0.5.0 — Orchestra

Ferret is now an ADE for developing several products in parallel. You work from the whole editor, not one folder at a time. Voice and pen feedback work as before; the difference is that you move through many products in one go.

- All products opens by default. Ask the agent there and every product's agent works on it, in parallel where possible.
- Review round: "Review every product in turn" opens each product's page and starts recording. When you stop, that review goes to the agent and the next product opens, so agents fix one product while you review the next. A product without its own agent hands its review to the All products agent, which passes it to that product's subagent.
- Check round: "Check pending items in turn" goes through every product's before/after checks, moving to the next product once a review has nothing left to check.
- Settings > Orchestra: write shared rules for all products (security, conventions, design, docs) and rules for each product (infrastructure, tags, instances, deployment). Ferret puts them into the All products agent's instructions and each product's subagent.
- New built-in requests set up Sentry, Google Analytics, Search Console and infrastructure: connect once for everything, then configure each product separately without mixing their values. Sending the Sentry, security and other requests from All products covers every product.
- Fixes a crash when the feedback view opened before the microphone list had loaded.
