Ferret 0.6.12

- Answer the orchestra's questions right on the All products dashboard. Each item in human.md (screens to check, approvals, things to provide, decisions) gets an answer box: pick a numbered option, with the recommended one marked, or write your own answer, just like Claude Code's questions. Agents can write questions with choices as `### Q1 [product] question` followed by numbered options. "Use the recommended answers" fills the rest, and "Send all answers to the agent" hands every answer to the All products agent in one message. Answers are kept under "## Answers" in human.md.
- Allowed without asking: list on the dashboard what agents may do without a person's check (for example, deploying to the dev environment). The list goes into the All products CLAUDE.md / AGENTS.md and every product's subagent, and agents leave those things out of human.md. "Always allow this" on an approval adds it in one click.
- Requests from the orchestra always run as parallel subagents, one per product, browser work included: each product uses its own browser tab at the same time instead of waiting for the others.
- Share links, reworked: send a link and the person opens the real page and records feedback with the same tools as Ferret (pen, box, text notes and voice), shares their screen, or uploads a screen recording from their phone, with no sign-in. Pressing Share copies the link for the open page. Everyone with the link sees the feedback that arrived, and links are deleted after 7 days. Add a memo, and a password when the memo holds sign-in details: the password never reaches the server and the memo is stored encrypted. Import an arrived recording to turn it into findings, like an MTG import, with the sender's name.
- Stops reporting a helper process that was stopped while still starting up on macOS as a crash (FERRET-1W).
