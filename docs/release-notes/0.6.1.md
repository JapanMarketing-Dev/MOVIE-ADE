Ferret 0.6.1

- Codex security audit in one click: the All products dashboard has a "Codex security audit" button. It opens Codex with Daybreak Blue at Extra high reasoning and asks it to audit every product at every layer (application, database, infrastructure, CI/CD, secrets, dependencies, privacy, and how the products connect). Codex reports findings only, inspects cloud and databases read-only, writes a dated report to .ferret/security/, and adds what you need to decide to human.md. The same request is in Settings > Requests, where you can edit it.
