Ferret 0.6.10

- Paste images and videos straight into the terminal: press ⌘V (Ctrl+V on Windows and Linux) in a terminal with a screenshot, or with files you copied in Finder or Explorer, on the clipboard. Ferret puts a copy in the project's .ferret/pasted/ folder (kept out of git) and types the path into the terminal, just like dropping the file from the desktop, so Claude Code and Codex receive the image or video. Plain text pastes work as before.
