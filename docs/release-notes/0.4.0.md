Ferret 0.4.0

- Windows and Linux are fully supported. On Ubuntu and Debian, install the .deb; on other distributions, use the AppImage.
- Security: agents now start with their permission prompts on. Skip-permission flags saved in earlier versions are removed: to let agents skip prompts in a project you trust, turn it on again for that project in Settings > Agent.
- Security: SHA256SUMS is signed with a release key kept apart from the download server, and Check for Updates verifies the signature before offering a version.
- Security: the Markdown preview blocks remote images until you load them, crash reports drop IP addresses, and the feedback relay checks its limits before reading a request.
- GitLab: clone from GitLab and send review findings to GitLab issues or merge request comments through glab.
- Projects: add a project from this computer, by cloning from GitHub or GitLab, or over SSH.
- CLI tools: install and sign in to 16 service CLIs (gh, glab, wrangler, Ollama, Vercel, Netlify, Supabase, Firebase, Fly.io, Railway, Heroku, Stripe, gcloud, AWS, Azure, Docker) from a new terminal tab.
- File viewer: images (zoom), video, audio, PDF and a hex view for other binary files open in the editor area.
- Findings: filter by status. The sidebar shows which projects have an agent running.
- Decision model and Organize findings default to a local Ollama model chosen from this PC's memory (clef / clef-flash for the decision model).
- Setup and review prompts for your agent follow the interface language.
- Send Feedback can attach a screenshot of the Ferret window, including the built-in browser.
- Terminal: text committed from a Japanese, Chinese or Korean input method is sent once, not twice.
- Windows: agents are detected in the terminal again, and agent arguments with backslashes (C:\...) are passed as written. Linux: watching a large project no longer runs out of inotify watches.
