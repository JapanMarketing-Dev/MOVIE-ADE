Ferret 0.4.6

- Desktop apps, phone simulators and games: choose a review target with a window (a desktop app, iOS Simulator, Android Emulator, or a Unity, Unreal or Godot editor) and Ferret shows that window live where the built-in browser is. While you record a screen or window, you can draw with the pen and boxes on it, and the images in findings show your marks in the right place. Opening a URL goes back to the browser.
- Text feedback in the editor: click Text feedback in the browser toolbar, draw a box on the page or the mirrored window, type the instruction and press Enter. It becomes a finding with the image, URL and element, without recording, and you can add several in a row.
- The window picker shows thumbnails for always-on-top windows such as an app's setup window.
- Let agents change Ferret settings: install the ferret-settings skill for Claude Code and Codex from onboarding, the setup checklist or Settings, then ask your agent to change Ferret. It edits settings.json for the whole app or only for the current project, and Ferret keeps the skill in line with its settings when it starts.
- Markdown: the editor has one Preview, and it is always editable. Drag images and videos into a Markdown file from Finder, the desktop or the file tree; files outside the project are copied next to it, and videos play in the preview.
- See your transcript while you record: the right panel in feedback mode has a Transcript tab next to Review targets, and Ferret warns you early when speech is not being transcribed or the microphone hears nothing. You can hide the tab in Settings; the warnings stay.
- The recording bar shows which microphone is connected; click it to test the input level or switch microphones. Back to Editor is now the first button and uses a code icon; the review targets toggle is the last one.
- Service CLIs: the CLI section lists more common services (Vercel, Netlify, Firebase, Fly.io, AWS, Google Cloud, Azure, Supabase, Sentry, Stripe, Docker, kubectl, mobile tools, UTM and other VMs...) with a link to each website. Installing them is optional.
- Review target buttons (local, dev, prd...) can be reordered by drag and drop. Switching projects goes back to the built-in browser as the recording target.
- Findings leave out speech that carries no meaning, such as "Shh.", "Thank you." picked up from silence, or fillers like "um". It goes to Excluded speech, where you can restore it.
- Send to Agent lists only the agent tabs of the open project, numbered within that project.
- Removed: sending reviews to GitHub or GitLab issues and pull request comments, the Needs check and Merge with next buttons on findings, the + button next to Record more (Cmd/Ctrl+Shift+R still starts a new review), the file tree button on the center tabs, and the Organize item in the footer.
- Terminal: right-click a terminal to split it right or down, or to close a split pane.
- Terminal: closing a terminal no longer reports an error from the WebGL renderer.
