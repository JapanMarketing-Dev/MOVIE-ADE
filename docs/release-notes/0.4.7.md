Ferret 0.4.7

- Your agent no longer asks you questions. The decision model is the agent's own check: it judges its fix, improves the fix or the screenshot and tries again, and when it stops it hands the finding to you as Waiting for review with BEFORE and AFTER. You only press OK or NG (with a comment to send it back).
- When a finding does not match the current app (an old recording, a missing element, conflicting findings), the agent implements the most reasonable reading of your request and leaves a one-line note on what it assumed, instead of stopping to ask.
- Findings that an older agent marked as needing your answer are shown as Waiting for review, so you can decide them with OK or NG. The reply box, the "Questions from the agent" counts and the Needs you filter are gone.
- Quitting with unsaved files shows which project each file belongs to, and offers Save and Quit, Quit Without Saving, and Open Project (switches to that project and opens the file). Files of projects you are not looking at are saved too, and Ferret stays open if any file cannot be saved.
