Ferret 0.6.14

- Every item on the All products dashboard can be answered by choice. The recommended option is always on top, items without options get sensible ones (approve / reject, OK / needs a fix, done / later / can't do it, go ahead / hold / don't), and you can add a note to the option you pick or write your own answer. Items are grouped by product, IDs like DESIGN-6 can be answered too, and "Send all answers to the agent" sends them grouped by product.
- Claude in Chrome stays connected: the extension only works with Claude Code signed in to the same claude.ai account, so Ferret now prefers that account when switching on usage limits and moves new and idle tabs back to it as soon as it has room again.
- Ferret and its docs are now in English and Japanese only. If you had picked another language, Ferret shows English; old docs links in other languages open the English page.
