Ferret 0.6.6

- Fixes the app pausing for a second or more when it lists your agent accounts (Settings, the footer, after waking): Ferret no longer reads and parses Claude Code's whole .claude.json, which grows to many megabytes with conversation history; it reads only the signed-in account part, without blocking.
- Opening many agents at once (for example reopening the orchestra after a restart) no longer reads .claude.json again for every agent: a folder trusted once stays trusted for the rest of the session.
- Starts up faster on Windows: the memory and terminal numbers in the footer are measured a few seconds after the window is ready, instead of starting PowerShell while the app is still loading.
- Fixes trusted folders being written again on every launch because the result of the write was not awaited.
