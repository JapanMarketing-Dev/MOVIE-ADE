Ferret 0.6.3

- The strip above the page in All products feedback now has two levels: the top row is one tab per product, and the row below switches between that product's pages (prd, local and the like) and its items from the checklist (B1 and so on). Checklist items go to the product with the same URL or address, or with a matching name. Choosing a product returns to the page you last opened in it, and the tabs follow the page you are on.
- Prevents a possible crash on Windows when the layout changes (for example dragging a divider) just as a browser extension's popup is closing.
- Crash reports from Windows and other systems now include where the crash happened (module and offset only). An earlier filter removed it, so recent native crashes arrived without it.
- The All products dashboard shows the estimated cost for this month, this year and in total, for the whole orchestra and for each product. The cost section breaks the chosen period down by product, by model and by type (input, output, cache reads and cache writes). Total covers the Claude Code records still on disk; Claude Code deletes records older than 30 days unless you change cleanupPeriodDays.
