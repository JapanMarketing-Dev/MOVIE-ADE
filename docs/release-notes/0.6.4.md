Ferret 0.6.4

- Build a Chrome extension in a project and run it in Ferret's built-in browser from the terminal alone. Ask the agent to register the extension's folder; after each fix, the agent rebuilds and changes the entry's reload number in Ferret's settings, and Ferret loads the extension again and reloads the open page. Removing or turning it off works the same way. The ferret-settings skill explains the steps to Claude Code and Codex, and Settings > Requests has a ready-made request ("Run this Chrome extension in Ferret's browser").
