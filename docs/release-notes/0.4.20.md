Ferret 0.4.20

- Share links for feedback without sign-in. Click Share in the built-in browser toolbar to capture the page and copy a link. Anyone with the link can drop a pin, draw a box or a line on the screenshot and write a note, with an optional name, or open the live page and pin notes on it. Ferret lists the notes; decline the ones you don't want and import the rest as findings, which then go to your agent with the usual BEFORE/AFTER check. Links expire after 30 days.
- Import a meeting from the sidebar. It takes a recording, a transcript (Google Meet/Gemini, Circleback, Zoom VTT, SRT or plain text, as a file or pasted), or both. Ferret turns the requests in the conversation into candidate findings with the speaker, the quote and a frame from the video at that moment. With a decision model set up, each candidate gets a likelihood that it is a concrete request; low ones start unselected. Check and edit them, then send them to your agent.
- Create a private GitHub repository from a project: right-click it in the sidebar and choose Create private GitHub repo. Ferret runs git init if needed, offers a first commit (files that look like secrets, such as `.env` and keys, are left out and listed), creates the private repository with `gh` under your account or an organization, and sets it as the folder's `origin`. Choose the default owner in Settings.
- Mermaid diagrams in Markdown show as diagrams by default. Click Code (or double-click the diagram) to edit the source.
- Type feedback is now also next to the Record button at the top right, and in feedback mode.
- Send to Agent works while the agent is busy. Claude Code and Codex read the message after the current task. Ferret only holds back while the agent is asking for a permission or an answer.
- Windows: terminals open in PowerShell (PowerShell 7 when installed) instead of cmd.exe, so the Up arrow recalls commands from earlier tabs and sessions. Settings > Agent > Terminal shell switches back to cmd.exe.
- Windows: fixes a crash when Ferret closed to install an update. The installer now starts only after Ferret has finished closing its terminals.
- Fixes a crash on Windows after switching projects and then opening a file: browser tabs closed by the switch are now hidden and detached before they are destroyed, and nothing touches a tab that is closing.
- The first terminal no longer shows a stray `%` line, and the browser toolbar no longer spills over the terminal in a narrow window.
- Crash reports now include where the crash happened (module and offset) so it can be traced, still without sending the crash dump. A slow first launch right after installing or updating, caused by the system scanning the new app, is no longer reported.
