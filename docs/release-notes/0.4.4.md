Ferret 0.4.4

- Updates install when you close Ferret: a downloaded and verified update is applied on quit, without relaunching, and Restart to update still installs right away.
- Projects can be reordered by drag and drop or Alt+Up/Down, sorted by manual, active, recently used, name or added order, starred, and filtered to starred projects.
- Findings can be reordered by drag and drop or the keyboard, and sorted by manual, time or progress order; numbers, feedback.md and the order sent to agents follow it.
- Recording desktop apps, games and phone simulators: always-on-top and panel windows appear in the window list on macOS with their app names, a Phone tab lists iOS Simulator and Android Emulator windows, and feedback.md names the app, window or device instead of a URL.
- Ask an agent to set up: the instructions use the model currently selected, and Ollama explains how to pull a model that is not installed yet.
- Security: capture, screenshots and clipboard writes need your own action; programs in the terminal ask before copying to the clipboard unless you allow it; built-in agents start from a trusted absolute path, and permission-skip flags come only from Settings; saved keys go only to origins you approved; decision relay requests have request and spend limits; project file changes stay inside the project even if a folder is swapped; release checksums are signed from locally hashed files.
- Code scanning findings are fixed, including HTML comments that showed in release note excerpts on the download page.
