Ferret 0.4.23

- Orchestrator: keep several projects as subfolders of one folder and work from the parent. Right-click the parent project in the sidebar and choose "Use as orchestrator". Ferret writes one Claude Code subagent per project in a subfolder (git repositories or registered projects) to `.claude/agents/ferret-<name>.md`, and keeps them in sync when the project is opened. Ask the Claude Code in the parent folder and it hands the work to the right project. Reviews sent from the parent tell the agent which subagent owns which project. Your own files in `.claude/agents` are left alone, and turning it off removes only the files Ferret wrote.
- Terminal: while you scroll up to read earlier output, a button at the bottom right jumps back to the latest line in one click, even while an agent keeps printing. The keyboard focus stays in the terminal.
