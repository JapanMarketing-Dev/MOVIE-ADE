Ferret 0.4.17

- Install Chrome extensions from the Chrome Web Store: paste a store link or extension ID in Settings → Browser extensions, or open the store page in the built-in browser and choose "Add this extension from the Chrome Web Store" from the Extensions button. Ferret downloads the package from Google and installs it only if its signature matches that extension, and the extension keeps its store ID.
- Add a packed extension (.crx) from a file, with the same signature check.
- The Extensions button in the built-in browser toolbar is shown even before any extension is installed.
