Ferret 0.6.8

- Choose a version to install: the update popover in the status bar now lists recent releases. Pick one (including an older one) and Ferret downloads it, checks it against the signed SHA256SUMS like any update, and installs it when you restart. Choosing an older version keeps you on it and turns automatic updates off until you turn them back on.
- The terminal now sits behind the small button at the bottom right in every project, not only in All products, in both the editor and the feedback screen. The feedback target gets the whole width until you open it.
- The file tree on the left remembers which folders you opened, per project, so updating or restarting Ferret no longer collapses it.
- The "Codex security audit" request now checks against CIS Benchmarks and CIS Controls v8, OWASP (Top 10, API, ASVS, MASVS, LLM), CWE Top 25, NIST CSF 2.0 / SP 800-53, SLSA and the OpenSSF Scorecard, runs the matching scanners (Semgrep, CodeQL, gitleaks, osv-scanner, Trivy, Checkov, Prowler, kube-bench, Docker Bench, testssl.sh, a ZAP baseline on localhost and development only), and writes a pass/fail table per standard with the standard IDs on every finding. It still only reports and never changes anything.
