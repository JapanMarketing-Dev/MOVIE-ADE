С чего начать

Установка

Скачайте Ferret для своего компьютера и откройте его. Он работает на macOS, Windows и Linux.

#Скачивание

На странице загрузки предлагается подходящий файл для вашего компьютера. Нажмите кнопку загрузки.

#macOS

Откройте .dmg, перетащите Ferret в Applications и запустите его оттуда.

#Windows

Запустите скачанный .exe. Ferret установится и откроется, ничего выбирать не нужно. В следующий раз открывайте его из меню «Пуск» или ярлыком на рабочем столе.

Если Windows покажет Система Windows защитила ваш компьютер, нажмите Подробнее, затем Выполнить в любом случае.

#Linux

Ubuntu / Debian: дважды щёлкните .deb, чтобы установить его через центр приложений, или выполните:

sudo apt install ./Ferret-<version>-linux-amd64.deb

Затем откройте Ferret из меню приложений или выполните ferret.

Другие дистрибутивы: используйте .AppImage. AppImage работает через FUSE 2, поэтому сначала установите его пакет, если его нет в системе: fuse-libs в Fedora, fuse2 в Arch, libfuse2 в openSUSE и системах на основе Debian. Затем разрешите запускать .AppImage как программу (щелчок правой кнопкой → Свойства или chmod +x) и откройте его.

#Дальше

  • Быстрый старт: откройте проект и запишите первый фидбэк.
  • Что-то пошло не так? См. Устранение неполадок.
  • Как проверить подпись загрузки, собрать из исходного кода или получить старую версию, см. в разделе Расширенная установка.
