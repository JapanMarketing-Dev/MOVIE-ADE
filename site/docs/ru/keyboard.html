Сочетания клавиш

Сочетания показаны для ОС, в которой вы читаете эту страницу; чтобы увидеть другую, воспользуйтесь переключателем ниже. В большинстве сочетаний на macOS используется Command там, где в Windows и Linux — Ctrl, и Option там, где — Alt. Некоторые отличаются сильнее, и в таблицах приведены оба варианта. Источник: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts, а также обработка клавиш в терминале.

Сочетания клавиш для

#Запись

ДействиеmacOSWindows / Linux
Начать / остановить запись⌘⇧RCtrlShiftR
Сменить режим (редактор / фидбэк)⌘⇧MCtrlShiftM
Перо, пока клавиша удерживается⌥Alt

#Рисование во время записи

ДействиеmacOSWindows / Linux
ПероPP
ПрямоугольникB / RB / R
Работать со страницей (прекратить рисование)V / EscV / Esc
Следующий цветCC
Отменить последнюю пометку⌘ZCtrlZ
Повторить⌘⇧ZCtrlShiftZ / CtrlY

Эти клавиши работают, когда вы записываете встроенный браузер и фокус находится на странице. Пока вы печатаете в поле на странице, они игнорируются, а буквенные клавиши работают только без клавиш-модификаторов, поэтому собственные сочетания клавиш страницы продолжают работать.

#Файлы

ДействиеmacOSWindows / Linux
Открыть папку проекта…⌘OCtrlO
Перейти к файлу…⌘PCtrlP
Сохранить⌘SCtrlS
Переименовать в дереве файловF2 / EnterF2

Клавиши дерева файлов работают, когда фокус находится на элементе в разделе Файлы.

#Терминал

ДействиеmacOSWindows / Linux
Новый терминал⌘TCtrlT
Закрыть панель / вкладку⌘WCtrlW
Разделить вправо⌘DCtrlShiftD
Разделить вниз⌘⇧DAltShiftD
Копировать выделенное⌘CCtrlShiftC / CtrlC
Вставить⌘VCtrlV / CtrlShiftV / ShiftInsert
Новая строка в запросе агенту⇧EnterShiftEnter
Начало / конец строки⌘← / ⌘→—
Удалить до начала строки⌘⌫—

Эти сочетания работают, когда фокус находится в терминале. В Windows и Linux Ctrl+C копирует, если выделен текст, и останавливает выполняемую команду, если ничего не выделено. ⇧Enter / ShiftEnter начинает новую строку, пока работает агент, например Claude Code или Codex; в обычной оболочке он выполняет команду, как Enter. В полноэкранной программе, которая использует мышь (vim, tmux, агент), на macOS удерживайте Option при перетаскивании, чтобы выделить текст.
