Ferret の使い方

録画

内蔵ブラウザ、画面全体、ほかのウインドウ、デスクトップアプリ、ゲーム、スマホのシミュレータを録画します。ページを操作しながら、話し、囲み、入力します。

ショートカットの表示

#録画の対象を選ぶ

フィードバックモードで 録画の対象を選ぶ を押します。録画の対象 ダイアログでは次から選べます。

対象記録するもの
内蔵ブラウザ（最初の設定）動画、声、ペンに加えて、URL、要素のセレクタ、クリック、スクロール。OS の許可は要りません。
画面全体動画、声、ペン。URL、要素、操作の記録はありません（そのことを feedback.md に書きます）。
ウインドウ上と同じです。各ウインドウはアプリ名つきで一覧に出ます。Ferret 自身のウインドウは一覧に出ません。
スマホ上と同じです。一覧には iOS Simulator と Android Emulator のウインドウだけが出ます。

選んだものは覚えておきます。macOS では、画面とウインドウの録画に画面収録の許可が要ります（許可のしかた）。

#デスクトップアプリ、ゲーム、モバイルアプリ

作っているデスクトップアプリ（Electron、Tauri、ネイティブアプリ）をレビューするには、開発中いつもするようにアプリを起動し、ウインドウ からそのウインドウを選びます。ウインドウはアプリ名つきで一覧に出るので、Electron アプリの開発ビルドは Electron の名前で出ます。小さなウインドウや、ほかのウインドウより手前に出続けるウインドウも一覧に出ます。macOS では、手前に出続けるウインドウはプレビューの代わりにアプリ名とタイトルで表示します。

選んだものはアプリについていきます。アプリを起動し直してウインドウが戻ると、次の録画では同じタイトルのウインドウを使います。タイトルが変わっていれば、そのアプリの唯一のウインドウを使います。

モバイルアプリでは、iOS Simulator（Xcode、macOS）か Android Emulator（Android Studio）を起動し、スマホ からそのデバイスを選びます。エミュレータが Android Studio の中で動いているときは、独立したウインドウで開くと一覧に出ます（Android Studio の設定の Tools → Emulator で、Running Devices ツールウインドウ内で起動する設定をオフにします）。

feedback.md は URL の代わりに、録画したものから始まります。アプリ名とウインドウのタイトル、シミュレータやエミュレータならデバイス名と OS のバージョン、Android では手前に出ているアプリも書きます。そのアプリのソースコードを直すよう Agent に伝える文も入ります。Ferret は録画を始めるときに、xcrun simctl と adb（ANDROID_HOME、ANDROID_SDK_ROOT、または Android Studio の SDK フォルダにあるもの）でデバイスの情報を読みます。画像には選んだウインドウだけが写るので、何を指しているかを話しながら説明してください。

ゲームも同じように録画できます。ゲームビューを表示した Unity、Unreal Engine、Godot のエディタのウインドウか、ビルドしたゲームのウインドウ（ボーダーレスのウインドウモードを含む）を選びます。排他的フルスクリーンのゲームは、画面全体 からそのディスプレイを選びます。ウインドウがこれらのエディタのときは、feedback.md にエンジン名を書き、ゲームのコード、シーン、アセットを直すよう Agent に伝えます。ファイルを小さく保つため動画は毎秒 10 フレームまでで記録し、指摘の画像も同じ動画から取り出すので、タイムライン上のその瞬間と一致します。

レビュー対象の 録画するウインドウ は、ウインドウのタイトルだけでなくアプリ名にも一致します。そのため Simulator と書けば、どのデバイスを表示していても iOS Simulator のウインドウを選びます。

#タブで複数のページを開く

内蔵ブラウザにはタブがあります。エディタモードではブラウザのツールバーの上、フィードバックモードでは URL 欄の横です。新しいタブ（⌘T / CtrlT）で空のタブを開き、URL を入れます。たとえばログインのコードを見るために Web メールを開けます。タブを押すか ⌘1 / Ctrl1〜⌘9 / Ctrl9、⌃Tab / CtrlTab で切り替え、タブの × か ⌘W / CtrlW で閉じます。⌘T / CtrlT と ⌘W / CtrlW がタブに効くのは、ページ・タブ・URL 欄に焦点があるときと、フィードバックモードのときです。ターミナルでは今までどおりターミナルを開く・閉じるです。新しいタブで開くリンク（target="_blank"）と、大きさを指定しない window.open は新しいタブで開きます。大きさを指定するログインのポップアップは、今までどおり別のウインドウで開きます。

どのタブもログインと Cookie を共有し、あるタブでコピーしたものを別のタブに貼れます。タブは 20 枚まで開けます。ページがタブを開けるのは、そのページをクリック・キー入力した直後だけです。そうでなければリンクは同じタブで開きます。

内蔵ブラウザを録画している間にタブを切り替えると、切り替えた先のタブを別の映像として録ります（複数のウインドウを同時に録画する）。操作ログに切り替えとページが残るので、指摘はどのページの話かと結びついたままです。ペンと四角の枠はどのタブでも使えます。空のタブは、ページを読み込むと録り始めます。

タブはプロジェクトごとです。プロジェクトを切り替えると、開いているタブを閉じ、切り替え先のプロジェクトのタブを開きます。元のプロジェクトに戻すとタブが戻り、Ferret を開いている間は戻る・進むの履歴も戻ります（再起動後はページだけが戻り、その履歴は戻りません）。フィードバックモードで確認先の下に出る、開いたページの一覧もプロジェクトごとです。ログインと Cookie は今までどおり全プロジェクトで共有します。

サイトが Cloudflare の確認（Verify you are human）を返したときは、Electron であることを名乗る UA でそのページを1回だけ開き直し、Ferret を閉じるまでそのサイトではその UA を使います。それ以外のサイトでは、Google などのログイン画面が使えるように、内蔵ブラウザは Chrome と同じ形で名乗ります。

#ブラウザからパスワードと履歴を取り込む

ふだん使っているブラウザのログインと履歴を、設定 → ブラウザから取り込む で取り込めます。

  • パスワード: ブラウザの機能でパスワードを CSV に書き出し、パスワードの CSV を取り込む… で選びます。Chrome・Edge: パスワード マネージャー → 設定 → パスワードをエクスポート。Safari: ファイル → 書き出す → パスワード。Firefox: パスワード → ⋯ → パスワードをエクスポート。Ferret はブラウザの暗号化された保存場所を読みません。書き出した CSV にはパスワードが平文で入っているので、取り込んだら削除してください（ゴミ箱も空にします）。
  • 保存したパスワードがあるサイトのページでは、エディタモードのブラウザのツールバーに鍵のボタンが出ます。押すとユーザー名とパスワードを入れます（アカウントが複数あれば選びます）。入れるのは、保存したものとオリジンが一致するページ（スキーム・ホスト・ポートが同じ。www. の有無は問いません）の一番上のフレームだけで、iframe の中のログインフォームには入れません。
  • 履歴: ブラウザを探す で、この PC の Chrome・Edge・Brave・Chromium・Arc（macOS）・Safari（macOS）のプロフィールを一覧にし、履歴を取り込む でその履歴を URL 欄の候補に取り込みます。取り込んだ履歴は全プロジェクトで共有し、候補にだけ使います。Safari の履歴を読むには、Ferret にフルディスクアクセスが必要です（システム設定 → プライバシーとセキュリティ）。

パスワードは Electron の safeStorage で暗号化して <userData>/browser-import/passwords.bin に、取り込んだ履歴は browser-import/history.json に保存します。すべて削除 と 取り込んだ履歴を削除 で消せます。開発用のビルドと safeStorage が使えない環境では、取り込んだパスワードは Ferret を閉じるまでしか残りません。

#ブラウザ拡張機能

設定 → ブラウザ拡張機能 で、内蔵ブラウザに Chrome の拡張機能を入れられます。manifest.json があるフォルダは 展開済みのフォルダを追加…、Chrome・Edge・Brave・Chromium に入っている拡張は Chrome から取り込む… で写して使います。拡張が動くのは内蔵ブラウザの中だけで、Ferret 自身の画面には入りません。拡張はそこで開いたすべてのページを読み書きでき、そのログインのまま通信できるので、信用できる拡張だけを入れてください。

拡張のポップアップは、ブラウザのツールバーかフィードバックのツールバーの 拡張機能 から開きます。ページの右上に開き、ほかの場所を押すか Esc で閉じます。内蔵ブラウザ を録画すると、拡張がページの中で変えたものも、開いているポップアップも、動画と画像に入ります。Electron が対応する拡張の API は一部だけです。サイドパネル・右クリックメニュー・通知・キーボードショートカット・拡張が開く新しいタブやウインドウは動かず、パッケージ化した .crx は読み込めません。

ポップアップの上にも書き込めます。録画中はツールバーを押しても拡張のポップアップは閉じません。ペンか枠を選んでいるとき、または 文字で指摘 が入のときは、ページを押しても閉じず、Esc はポップアップを閉じる代わりに道具を切ります。ポップアップの中に描くと、その書き込みはポップアップの位置で動画と画像に入ります。使えるのは、録画か 文字で指摘 を始めてから開いたポップアップです。ページが別のウインドウで開くログインのポップアップ（Google でログインなど）は、開いている間、別の動画として録画します。そのウインドウが前に出るとペンと枠はその中に描け、ページを押すと元に戻ります。ログインが終われば、これまでどおり自動で閉じます。

#複数のウインドウを同時に録画する

1回の録画で、内蔵ブラウザ・デスクトップアプリのウインドウ・画面を最大 4 つまで同時に録れます。それぞれを録画を止めるまで別の動画に録るので、Web アプリからデスクトップアプリを開いてまた戻る、のように行き来する流れも最初から最後まで残ります。

  1. 録画中に、録画の帯の +（ほかのウインドウも同時に録る） を押し、ウインドウ・画面・内蔵ブラウザを選びます。レビュー対象 パネルでウインドウの対象を押しても同じです。
  2. 録画の帯のチップを押すと、映すものが切り替わります。ペンと指摘の画像は映しているものに付き、ほかは裏で毎秒 5 フレームまで録り続けます。

まだ開いていないウインドウを待つこともできます。プロジェクトを編集… で対象に 録画するウインドウ（アプリ名、ウインドウのタイトルの一部、com.example.MyApp のような macOS のバンドル ID、またはアプリのパス）を入れ、録画中に開いたら を 一緒に録る か 録って切り替える にします。settings.json では "watch": "record" か "watch": "switch" です。録画中、Ferret は 1 秒ごとにウインドウの一覧を見ます。ウインドウが開くまでは対象が点線のチップで出て、アプリを閉じてまた開いたときも録り直します。

切り替えはすべて操作ログに残るので、指摘ごとにどれを映していたかが分かります。アプリのウインドウを映していた間の指摘には URL・要素の情報が付かず、指摘 と feedback.md ではそのウインドウの下にまとまり、Agent にもアプリのウインドウだと伝わります。足した動画はレビューのフォルダの tracks/ に、始まりと終わりの時刻は tracks.jsonl に保存します。Windows と Linux ではウインドウのタイトルしか分からないので、名前はタイトルと照らし合わせます。Linux の Wayland ではウインドウの一覧を取るたびに選択を求められるため、ウインドウを待つことはできません。開いたあとで + から足してください。

#開始・一時停止・停止

  1. レビューするページを内蔵ブラウザで開きます。
  2. タイトルバーの 録画 か、⌘⇧R / CtrlShiftR を押します。
  3. 一時停止 で描画とタイマーが止まります。再開 で続けます。
  4. 停止 か、もう一度 ⌘⇧R / CtrlShiftR を押します。

サイドバーでは、プロジェクトごとに 新しいレビュー があります（その行の +、「<name>」で新しいレビュー でも同じです）。別のプロジェクトのものを押すと、先にそのプロジェクトに切り替えてから録画を始めます。ほかの録画が動いている間は始まりません。

1回の録画は90分までです。上限が近づくと警告が出て、上限に達すると録画は自動で止まり、保存されます。

#ペン

  • ペン: 選ぶか、⌥ / Alt を押している間だけ描けます（入力欄で文字を打っている間は無視します）。
  • 消去: いまの書き込みを消します。

話しながらその場所を囲むと、言葉と書き込みが同じ指摘に入ります。ペンは録画中だけ使えます。録画中に文字を書く道具はありません。声で伝えるか、あとで文字で指摘で打ってください。ペン、四角の枠、色のキーはキーボードショートカットに載っています。

#話す代わりに文字で指摘する

話しにくいときは、指摘を文字で打てます。エディタモードでもフィードバックモードでも、録画していないときに使えます。

  1. 文字で指摘 を押します。右上の録画ボタンの右、ブラウザのツールバー、フィードバックモードのツールバーのどれからでも押せます。エディタモードでは先に ブラウザ タブへ移り、フィードバックモードではペンと枠を切ります。
  2. ページの直したい場所をドラッグして枠で囲みます。要素をクリックすると、その要素を枠で囲みます。
  3. どう直すかを打ちます。Enter で追加、⇧Enter / ShiftEnter で改行、Esc で枠を取り消します。日本語入力の変換を確定する Enter では追加しません。

1件ずつが、ページと枠の画像、URL、囲んだ要素の付いた指摘になります（録画した指摘と同じ形です）。指摘 で開いているレビューに足し、開いていなければ新しいレビューを作ります。ブラウザは前に出たままなので、続けて何件も足せます。枠が無いときの Esc か、もう一度ボタンを押すとやめます。ブラウザの場所に映したデスクトップアプリやシミュレータのウインドウでも同じように使えます（URL は付きません）。

#共有リンクで誰からでも指摘をもらう

Ferret を使っていない人（お客さん・デザイナー・チームの人）から指摘をもらうには、共有リンクを送ります。相手はアカウントもアプリも要りません。ブラウザでリンクを開き、ページの静止画に印を付けて、直してほしいことを書きます。名前は任意です。

  1. 内蔵ブラウザでページを開き（http か https のページだけ）、ブラウザのツールバーの 共有 を押します。
  2. 必要なら題名を付け（無ければページの題名）、送った人どうしでほかの人の指摘も見えるようにする をオンにします。このページで共有リンクを作る を押すと、Ferret がページの見えている部分を撮って上げ、リンク（https://share.ferretade.dev/s/…）をコピーします。
  3. 同じリンクにページを足すには、別のページを開いてその共有の このページを足す を押します（20 ページまで）。

リンクを開いた人は、静止画の上にピンを打つ・枠を引く・ペンで描くことができ、文を書いて送ります（2,000 字まで）。ライブで操作 では元のページを枠の中で開いて触れ、ライブに注釈 でその上にピンを打てます。そのとき見ていた URL も一緒に送られます。枠の中で開けないサイトもあり、その場合は新しいタブで開いて文だけで送れます。相手の画面は、相手のブラウザに合わせて日本語か英語で出ます。

届いた指摘は同じ 共有 の画面に出ます。指摘を選んで 選んだ指摘を取り込む を押すか、要らないものは 断る を押します（戻す で戻せます）。取り込んだ指摘は、文字で指摘 と同じように新しいレビューの指摘になります。相手の印を重ねた静止画が BEFORE の画像になり、ページの URL と相手の名前・文が付きます。ライブのページに打ったピンは、スクロールの位置が静止画と合わないことがあるので、静止画全体を囲む枠になります。あとはいつもどおりエージェントへ送り、BEFORE と AFTER を確かめます。

  • リンクを知っている人は誰でも静止画を見て指摘を送れるので、見られて困るものが写ったページは共有しないでください。リンクは 30 日で切れます。消す を押すと、リンク・静止画・指摘がすぐ消えます。
  • 1つのリンクで受けられる指摘は 500 件までで、指摘とリンクを送れる頻度にもサーバー側で上限があります。サーバーは IP アドレスを保存しません。
  • 共有リンクはプロジェクトごとに覚えます。Ferret がリンクを読んで管理するための持ち主のトークンは、Electron の safeStorage で暗号化して <userData>/feedback-share/shares.bin に保存します。開発用のビルドと safeStorage が使えない環境では Ferret を閉じるまでしか残りません（リンク自体は期限まで使えます）。
  • サーバーのコードはリポジトリの workers/feedback-share にあります。

#mtg を取り込む

製品についての mtg を指摘にできます。サイドバーで開いているプロジェクトの下の mtg を取り込む を押し、録画・文字起こし・その両方を入れます。

  • 録画: 動画・音声を選ぶ…（MP4・M4V・MOV・WebM・MKV・M4A・MP3・WAV・OGG・AAC）。新しいレビューのフォルダへ写します。
  • 文字起こし: 文字起こしのファイルを開く…（.txt・.md・.vtt・.srt・.docx）か、貼り付け。WebVTT・SRT の字幕（Zoom・Google Meet）、時刻の行のあとに 名前: 本文 の行が続くもの（Google Meet・Gemini）、[00:12:34] 名前: 本文 の行、名前 0:05 の行のあとに本文が続くもの（Circleback・Otter）、名前: 本文 だけの行、ただの段落を読めます。Ferret はこれらのサービスとは連携せず、渡した文だけを読みます。

取り込む を押します。文字起こしが無ければ、文字起こし の設定で録画の音声を文字にします（3 時間までの録画）。続けて 整理 のモデルが、話された内容から指摘の候補を作ります。録画に映像があり、文字起こしに時刻があれば、発言の時刻のコマが指摘の BEFORE の画像になります。時刻の無い文字起こしでも取り込めますが、コマは付きません。

判定モデルを有効にしていれば、Ferret は候補ごとに1回、mtg で製品への具体的な変更が求められたかを問い、画像を読めるモデルでコマがあれば、そのコマが話題の画面を写しているかも問います。候補には 確からしさ が百分率で付き、50% 未満の候補は外した状態で始まります。この呼び出しは、エージェントの確認と同じローカルの中継を通り、同じ回数と費用の枠に入ります。候補を確かめるまで、エージェントには何も送りません。直す・外す・残すを決めてから、いつもどおり送ります。

#書き込みが消えるとき

書き込みは、描いたときの画面に属します。次のときには、いまの指摘に記録してから消します。

  • ページが移動したとき: ページ全体の読み込み、または SPA のルート変更で新しいパスやクエリになったとき。ハッシュだけの変更では消えません。
  • ページをスクロールしたとき
  • 話したひとまとまりが終わったとき

#マイク

マイクは最初の設定で ON です。フッター（マイクをオフにする / マイクをオンにする）か、設定の 自分の声を録る で切り替えます。使う機器は マイク で選びます。

#文字起こしされた内容を見る

録画中は、フィードバック画面の右パネルの上にある 文字起こし タブを開くと、話したことが話した時刻つきの文字で読めます（会議の相手の声も録っているときは、誰が話したかも出ます）。文字は話して少し間を空けると数秒で出るので、話したことが取れているかを早めに確かめられます。上の行には 文字起こし中、待っている区切りの数、または止まった理由が出ます。

文字起こしが失敗したとき、モデルやキーが無いとき、2分ほど声が入っているのに文字にならないとき、マイクに音が届いていないときは、タブを閉じていても Ferret が1回だけ知らせ、右パネルのボタンに印を付けます。録画は続き、音声も残ります。タブを出さないようにするには、設定 → 文字起こし の 録画中に文字起こしを表示する（フィードバック画面の右パネル） を OFF にします。警告はそれでも出ます。

#録画しながら Agent に伝える

フィードバック画面の右パネルには ターミナル タブもあります。新しいシェルではなく、エディタモードと同じターミナルです。同じタブ、動いている同じ Agent（たとえば Claude Code や Codex）とその履歴がそのまま出ます。上でタブを選んで打てば、たとえば localhost が起動していないことを Agent に伝えられます。エディタモードへ戻っても、ターミナルは同じ状態です。内蔵ブラウザやほかのアプリのウインドウを録画しても、ターミナルは写りません。

#会議の相手の声も録る

通話をしながら一緒にページをレビューするときは、マイクに加えて、パソコンから聞こえる音も Ferret に録らせます。Ferret が録るのはアプリではなくパソコンの音声なので、どの会議アプリ（Zoom、Google Meet、Microsoft Teams など）でも使えます。2つは分けて扱い、マイクは 自分、パソコンの音声は 相手 として文字起こしするので、どの指摘を誰が求めたかが分かります。マイクをオフにしていても使えます。

  1. いつもどおり会議アプリで通話に入ります。マイクとスピーカーの設定は、その会議アプリのものをそのまま使います。
  2. 設定の 相手の声も録る か、フッターのマイクのメニューの 相手の声も録る をオンにします。録画中は変えられません。
  3. 録るものを選びます。レビューするページなら 内蔵ブラウザ、共有された画面を見ているなら 画面全体 / ウインドウ です。
  4. 録画 を押し、相手と話しながらページを見て、気になる所をペンで囲みます。
  5. 停止 を押します。両方の声が文字起こしされ、指摘になります。

ほかの参加者には録画していることを伝えてください。クラウドの文字起こしを使っている場合は、相手の声もその事業者に送られます。

#OS ごとのシステム音声

OS必要なもの許可
macOSmacOS 14.2 以降。それより前の版では、マイクだけを録ります。初めて相手の声を録るときに、Ferret にシステムの音声の録音を許すか macOS が尋ねます。断った場合は、システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音 で Ferret をオンにし、Ferret を終了して開き直します。このために画面が録られることはありません。
Windows設定 → システム → サウンド で有効になっている再生デバイス（スピーカーかヘッドホン）。不要。既定の再生デバイスの音を録ります。
LinuxPulseAudio、または pipewire-pulse を入れた PipeWire（多くのデスクトップの既定）。不要。既定の出力の音を録ります。

相手の声を録れないときは、Ferret が警告で理由を示し、マイク・映像・ペンの記録は続けます。トラブルシューティングを見てください。

#会議で使うときのコツ

  • ヘッドホンを使う。 スピーカーだと、マイクが相手の声も拾います。Ferret は相手の声を録るときにマイクのエコーキャンセルをオンにし、両方で聞こえた発言を除きますが、いちばんきれいに文字起こしできるのはヘッドホンです。
  • パソコンで鳴る音はすべて録られます。 通知音や動画も含みます。レビューの間は、要らないものを消音してください。
  • 録画の途中で音声の機器を切り替えない。 出力の機器が変わったり外れたりすると、相手の声の録音は警告を出して止まります。マイク・映像・ペンの記録は続きます。残りはあとで 追加で録る で録ってください。
