はじめに

キーボードショートカット

ショートカットは、いま読んでいる OS のものを表示します。もう一方は下の切り替えで見られます。たいていは、Windows と Linux の Ctrl が macOS では Command に、Alt が Option になるだけです。それ以上に違うものもいくつかあり、表には両方を載せています。出典: src/main/menu.ts、src/shared/browserNav.ts、src/shared/annotation.ts、ターミナルのキー処理。

ショートカットの表示

#録画

操作macOSWindows / Linux
録画を開始 / 停止⌘⇧RCtrlShiftR
モードを切り替える（エディタ / フィードバック）⌘⇧MCtrlShiftM
押している間だけペン⌥Alt

#録画中に描く

操作macOSWindows / Linux
ペンPP
四角の枠B / RB / R
ページを操作する（描くのをやめる）V / EscV / Esc
次の色CC
最後の書き込みを取り消す⌘ZCtrlZ
やり直す⌘⇧ZCtrlShiftZ / CtrlY

これらのキーは、内蔵ブラウザを録画していて、ページにフォーカスがあるときに効きます。ページの入力欄で文字を打っている間は無視されます。また、文字のキーは修飾キーなしのときだけ効くので、ページ自身のショートカットはそのまま使えます。

#ブラウザと表示

操作macOSWindows / Linux
URL欄へ移動⌘LCtrlL
ページを再読込⌘RCtrlR
戻る⌘[Alt←
進む⌘]Alt→
PC幅 / スマホ幅を切り替える⌘⇧VCtrlShiftV
サイドバーの表示を切り替える⌘BCtrlB
ファイルツリーの表示を切り替える⌘⇧ECtrlShiftE
レビュー対象の表示を切り替える⌘⇧KCtrlShiftK

#ファイル

操作macOSWindows / Linux
プロジェクトフォルダを開く…⌘OCtrlO
ファイルを名前で開く…⌘PCtrlP
保存⌘SCtrlS
ファイルツリーで名前を変更F2 / EnterF2
ファイルツリーで削除⌘⌫ / DeleteDelete

#ターミナル

操作macOSWindows / Linux
新しいタブ⌘TCtrlT
閉じる（ペイン／タブ）⌘WCtrlW
右に分割⌘DCtrlShiftD
下に分割⌘⇧DAltShiftD
選択範囲をコピー⌘CCtrlShiftC / CtrlC
ペースト⌘VCtrlV / CtrlShiftV / ShiftInsert
エージェントへの入力で改行⇧EnterShiftEnter
行頭 / 行末へ⌘← / ⌘→—
行頭まで削除⌘⌫—

どれもターミナルにフォーカスがあるときに効きます。Windows と Linux では、文字を選んでいるときの Ctrl+C はコピーになり、何も選んでいないときは実行中のコマンドを止めます。⇧Enter / ShiftEnter は、Claude Code や Codex などのエージェントが動いている間は改行になり、ふつうのシェルでは Enter と同じくコマンドを実行します。マウスを使う全画面のプログラム（vim、tmux、エージェント）の中で文字を選ぶには、macOS では Option を押しながらドラッグします。

#ウィンドウと設定

操作macOSWindows / Linux
設定…⌘,Ctrl,
ウィンドウを閉じる⌘⇧W—
しまう⌘M—

Windows と Linux にはウィンドウを閉じるショートカットがありません。ファイル → 終了 でアプリを終了します。
