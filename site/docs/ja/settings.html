設定

設定の一覧

設定 はタイトルバーの歯車から開きます。録画中は設定を変えられません。

#マイク

設定既定値
自分の声を録るオン
マイクシステムの既定
相手の声も録る（会議）オフ

#文字起こし

設定既定値
言語（話す言語）自動
処理この端末（無料）
モデル（端末内）large-v3-turbo（おすすめ）
接続先の Base URL / モデル（互換）空
OpenAIのAPIキー / 接続先のAPIキー（省略可）未設定
費用の上限1回のレビューにつき $1 まで

文字起こしと費用を見てください。

#保管

設定既定値
録画の保管: 7日 / 30日 / ずっと7日
停止後もフィードバック画面のままオフ

#Agent

設定既定値
プロジェクトを開いたら起動Claude Code、Codex（対応しているエージェントから好きなものを選べます。選ばなくてもかまいません）
<agent> をメニューに出すすべてのエージェントでオン
権限確認を省いて起動するオン: Claude Code は --dangerously-skip-permissions、Codex は --dangerously-bypass-approvals-and-sandbox を付けて起動します（詳細）
Agent の作業が終わったときと、確認が必要なときに通知するオフ（詳細）
コマンド / 引数（エージェントごと）そのエージェントのコマンド（たとえば claude、codex、gemini）/ Claude Code は --chrome、ほかはなし
カスタムエージェントなし（カスタムエージェントを追加 で任意の CLI を登録できます）
Agentへの指示組み込みの文面（変数）
ターミナルのシェル（Windows）PowerShell: PowerShell 7（pwsh）が入っていればそれ、無ければ Windows PowerShell。コマンドの履歴をタブと再起動をまたいで残します。もう1つの選択肢は cmd.exe（settings.json の agents.windowsShell）。あとから開くタブに効きます

#上限での自動切り替え

設定既定値
上限に達したら自動で切り替えるオン
上限とみなす使用量95%
先に同じ Agent の別のアカウントへ切り替えるオン
Agent の順番Claude Code、Codex、Gemini CLI
上限が戻ったら、順番が上の Agent に戻すオフ

設定 → アカウント にあります。作業はプロジェクトの .ferret/handoff.md を通して引き継ぎます。利用上限に達しても作業を続ける を参照してください。

#アカウント、よく使うサービスの CLI、外観、言語

  • アカウント: アカウントと使用量を見てください。
  • よく使うサービスの CLI: 各サービスの CLI のインストールとサインイン。よく使うサービスの CLIを見てください。
  • ブラウザから取り込む: パスワード（書き出した CSV から）と履歴を内蔵ブラウザに取り込みます。パスワードと履歴を取り込むを見てください。
  • 外観 → 配色: システム（既定）、ライト、ダーク。
  • 言語 → 画面: システム（既定。Ferret がその言語を持っていれば OS の言語に合わせ、無ければ英語）か、14言語のどれか: English、日本語、简体中文、繁體中文、한국어、Español、Français、Deutsch、Italiano、Português (Brasil)、Русский、हिन्दी、Bahasa Indonesia、Tiếng Việt。

フッターからは、ターミナルの位置（右 / 下）とマイクのオン・オフを切り替えられます。

#settings.json

ここまでの設定はすべて ~/.ferret/settings.json（どの OS でも同じパス）に保存され、隣に JSON Schema があります。アプリの起動中でも、手で直したりコーディングエージェントに編集させたりでき、変更はすぐ反映されます。settings.json で設定するを見てください。
