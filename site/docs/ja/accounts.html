設定

アカウントと使用量

Claude Code や Codex の複数のログインを切り替え、レート制限の枠をフッターで見られます。どちらの機能も今のところ Claude Code と Codex だけで使えます。ほかのエージェントはいつもどおり自分のログインを使います。

#複数のアカウント

アカウントの登録は任意です。複数を切り替えるときだけ追加してください。

  1. 設定 → アカウント を開くか、フッターの使用量のメニューから Manage Accounts… を開きます。
  2. アカウントを追加 を押すと、内蔵のターミナルのタブでエージェントのログインが始まります。
  3. 使うアカウントを選びます。動いているタブはそのアカウントのままで、新しいタブから選んだアカウントを使います。

しくみ: 追加したアカウントごとに専用の設定フォルダ <userData>/accounts/<agent>/<id>/ ができます。Ferret は CLAUDE_CONFIG_DIR（Claude Code）か CODEX_HOME（Codex）をそこに向けてエージェントを起動します。システムの既定 は、いつもの ~/.claude / ~/.codex をそのまま使います。

アカウントを削除すると、その設定フォルダが消えます。サーバー側でログアウトされるわけではありません。

#フッターの使用量

フッターには、レート制限の枠ごとにどれだけ使ったかが出ます。5時間の枠と週の枠、Claude ではモデルごとの週の枠もあります。60% で黄色、80% で赤になります。値は15分ごとか、使用量を再読み込み を押したときに更新されます。

どこまで表示するかは、フッターの空きで変わります。余裕があればバー、枠の名前、割合を出します。フッターが狭くなるにつれて重要度の低いものから省き、最後はエージェントごとに割合1つだけになります。使用量を押すと、ポップオーバーですべてを見られます。

使用量は、ログインしているアカウント自身の認証情報で、Anthropic（api.anthropic.com/api/oauth/usage）と ChatGPT（chatgpt.com/backend-api/wham/usage）から直接取得します。

#利用上限に達しても作業を続ける

エージェントが利用上限に達すると、Ferret は同じプロジェクトのフォルダで同じ作業を続けます。長い作業が上限で止まりません。最初からオンになっていて、設定 → アカウント → 上限での自動切り替え で設定します。

作業はプロジェクト内の1つのファイル .ferret/handoff.md を通して引き継ぐので、アカウントの間でも、別のエージェントの間でも同じように働きます。Agentへ送信 の指示は、区切りごとと利用上限が近づいたときに、このファイルを更新するようエージェントに頼みます。書くのは、目的、終わったこと、残りの作業のチェックリスト、変更したファイル、次の一歩、関係する feedback.md とレビューのパス、注意すべきことです。.ferret/ は git に入りません（.gitignore ではなく .git/info/exclude に追加します）。

  1. Ferret は、ターミナルに出るエージェント自身のメッセージ（たとえば Claude Code の 5-hour limit reached ∙ resets 3pm、Codex の You've hit your usage limit）か、フッターの使用量がしきい値（既定は 95%。5時間・週・モデルごとの枠のうち最も高いもの）に達したことから、上限に気づきます。
  2. 切り替える前に、Ferret は今のエージェントに .ferret/handoff.md を更新するよう頼みます。エージェントがそれに取りかからないとき（たとえばすでに上限に達しているとき）は、Ferret が分かっていることをファイルに書き足します。最後の依頼、feedback.md の場所、git status から分かる変更したファイルです。
  3. そのあと Ferret は、同じエージェントでサインインしている別のアカウントのうち、使用量が最も少ないものに切り替えます。そのエージェントのアカウントがすべて上限に達しているときは、Agent の順番（既定: Claude Code → Codex → Gemini CLI）の次のエージェントへ作業を移します。
  4. 新しいエージェントは同じプロジェクトの新しいタブで開き、アプリの表示言語で、まず .ferret/handoff.md を読んで残りの作業を続けるよう伝えられます。
  5. フッターに <agent> で作業中 と出て、何が変わったかを通知で知らせます（たとえば Codex の利用上限のため、Claude Code に切り替えました。）。上限に達したタブは閉じるので、その上限が戻ったときに同じ作業をまた始めることはありません。
設定既定値
上限に達したら自動で切り替えるオン
上限とみなす使用量95%
先に同じ Agent の別のアカウントへ切り替えるオン
Agent の順番Claude Code、Codex、Gemini CLI。一覧にないエージェントは使いません。
上限が戻ったら、順番が上の Agent に戻すオフ（今のエージェントで作業を続けます）。オンにすると、タブが入力待ちの間に作業を戻します。

切り替えはプロジェクトの中だけで行い、1時間に6回まで、間隔は1分以上あけます。認証情報はそれぞれのアカウントの設定ディレクトリに置いたままで、コピーしません。settings.json では limitFailover の下にあります。
