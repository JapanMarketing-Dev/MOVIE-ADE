파일과 환경

Ferret이 자체 파일을 보관하는 위치와, 읽거나 설정하는 환경 변수입니다.

#userData 폴더

앱 데이터는 Electron의 userData 폴더에 있습니다. 폴더 이름은 제품 이름이 아니라 ade-movie로 고정되어 있으므로, 이름이 바뀌어도 데이터가 유지됩니다. --user-data-dir=<path>로 바꿀 수 있습니다.

OS경로
macOS~/Library/Application Support/ade-movie/
Windows%APPDATA%\ade-movie\
Linux~/.config/ade-movie/(또는 $XDG_CONFIG_HOME/ade-movie/)
 
settings.json       # settings before 0.1.1, kept as a backup (now ~/.ferret/settings.json)
stt-keys.bin        # API keys, encrypted with safeStorage
models/             # downloaded whisper models (ggml-*.bin)
accounts/claude/<id>/   # CLAUDE_CONFIG_DIR for added accounts
accounts/codex/<id>/    # CODEX_HOME for added accounts

설정은 이 폴더에 없습니다. 설정은 ~/.ferret/에 있습니다(settings.json으로 설정하기 참고).

직접 고른 모델은 어디에 있어도 됩니다. 예전 기본 위치인 ~/.cache/ade-movie/models/ggml-small.bin도 여전히 확인합니다.

#환경 변수

변수효과
CLAUDE_CONFIG_DIR, CODEX_HOME추가한 계정을 선택하면 Ferret이 에이전트 탭에 설정합니다
GH_TOKEN, GITHUB_TOKENgh가 자체 로그인보다 먼저 사용합니다. 둘 중 하나가 설정되어 있으면 Ferret이 경고합니다
FERRET_CONFIG_DIR(또는 예전의 MOVIE_ADE_CONFIG_DIR)~/.ferret 대신 settings.json, state.json, settings.schema.json을 두는 폴더
apiKeyEnv에 적은 이름settings.json에서 가리키는 API 키. 프로젝트의 .env와 ~/.ferret/.env에서도 읽습니다
ADE_PROJECT_DIR실행할 때 이 폴더를 프로젝트로 열고 등록합니다
ADE_INITIAL_URL실행할 때 내장 브라우저에서 이 URL을 로드합니다
ADE_WHISPER_MODEL기기 내 음성 인식에 사용할 GGML 모델의 절대 경로. 내려받은 기본 모델 대신 사용합니다
FERRET_SENTRY_DSN(또는 예전의 MOVIE_ADE_SENTRY_DSN)충돌 보고서를 보낼 곳. 비어 있으면 보내지 않습니다(충돌 보고서 참고)
OPENAI_API_KEY개발 중(pnpm dev)에만 .env에서 읽으며, 패키지된 빌드에서는 읽지 않습니다
PATH에이전트의 명령(claude, codex, gemini…), gh, git, whisper-cli를 찾는 데 사용합니다. macOS와 Linux에서는 Homebrew, linuxbrew, snap 위치가 추가됩니다

#프로젝트 안

  • .ferret/reviews/<id>/: 리뷰(데이터와 개인정보 참고). .ade-movie/reviews/에 있는 예전 리뷰도 계속 읽습니다
  • .git/info/exclude: 처음 녹화할 때 .ferret/ 한 줄이 추가됩니다
