Ferret 사용하기

에디터와 미리 보기

프로젝트 파일을 열고 편집하며, Markdown과 Mermaid를 미리 봅니다. 내장 브라우저에서 연 미리 보기는 일반 웹 페이지처럼 녹화하고 리뷰할 수 있습니다.

단축키 표시

#파일 열기와 편집

  • 파일(파일 트리): ⌘⇧E / CtrlShiftE. 파일 이름으로 필터, 새로고침, 모두 접기가 있습니다.
  • 파일로 이동…: ⌘P / CtrlP.
  • Finder(Windows에서는 파일 탐색기, Linux에서는 파일 관리자)에서 파일을 탭 표시줄이나 에디터로 드래그하면 열립니다. 프로젝트 안의 파일은 에디터나 뷰어에서 열립니다. 프로젝트 밖의 파일을 가져오려면 파일에 놓으세요. 프로젝트로 복사됩니다. 여기에 놓은 폴더는 프로젝트로 열립니다. 파일에서 드래그한 파일도 같은 방식으로 열립니다. 열려 있는 Markdown 파일에 놓은 이미지와 동영상은 대신 그 파일에 삽입됩니다(Markdown에 이미지와 동영상 삽입하기 참고).
  • ⌘S / CtrlS로 저장합니다. 수정한 파일을 닫으면 <name>의 변경 사항을 저장할까요?라고 묻고 저장, 저장 안 함, 취소 중에서 고릅니다.
  • 저장하지 않은 편집이 있는 동안 디스크의 파일이 바뀌면 디스크에서 다시 불러오기 또는 내 변경 사항 유지를 고릅니다.

에디터는 Monaco입니다. 텍스트가 아닌 파일은 대신 뷰어로 열립니다. 이미지(확대와 축소. SVG는 코드로도 표시 가능), 탐색 막대가 있는 동영상과 오디오, PDF, 그리고 그 밖의 바이너리 파일은 크기와 앞부분 바이트의 16진수 보기를 보여 줍니다. 뷰어는 읽기 전용이며, 프로젝트 폴더 밖의 파일이나 폴더 밖으로 나가는 심볼릭 링크를 통해 닿는 파일은 표시되지 않습니다.

#파일 트리에서 파일 다루기

VS Code에서처럼 파일에서 바로 파일을 다룹니다. 항목을 마우스 오른쪽 버튼으로 클릭하세요. 프로젝트 맨 위에서 작업하려면 트리 아래의 빈 공간을 마우스 오른쪽 버튼으로 클릭합니다. 이름은 트리 안에서 직접 입력합니다.

  • 새 파일 / 새 폴더: 트리 위의 버튼 또는 마우스 오른쪽 버튼 클릭. 새 항목은 선택한 폴더 안, 선택한 파일 옆, 또는 프로젝트의 맨 위에 만들어집니다. src/routes/index.ts처럼 슬래시가 들어간 이름을 입력하면 중간의 폴더도 함께 만들어집니다. 새 파일은 에디터에서 열립니다. 빈 폴더에서는 파일에 이 폴더는 비어 있습니다와 새 파일, 새 폴더 버튼이 표시됩니다.
  • 잘라내기, 복사, 붙여넣기: ⌘X / CtrlX, ⌘C / CtrlC, ⌘V / CtrlV 또는 마우스 오른쪽 버튼 클릭. 폴더는 안의 내용까지 모두 복사됩니다. 복제는 원본 옆에 사본을 만듭니다. 이름이 이미 있으면 사본의 이름은 name copy, 그다음은 name copy 2가 됩니다.
  • 항목을 폴더 위(프로젝트 맨 위로 옮기려면 빈 공간)로 드래그하면 이동합니다. 놓을 때 ⌥ / Ctrl를 누르고 있으면 대신 복사합니다. Finder(Windows에서는 파일 탐색기)에서 드래그해 온 파일과 폴더는 프로젝트로 복사되며, 원본은 원래 자리에 그대로 남습니다.
  • 이름 바꾸기: F2 / Enter / F2 또는 마우스 오른쪽 버튼 클릭.
  • 삭제: ⌘⌫ / Delete / Delete 또는 마우스 오른쪽 버튼 클릭. Ferret이 먼저 확인한 뒤 항목을 휴지통으로 옮기므로 복원할 수 있습니다. 삭제한 파일의 탭은 닫히며, 저장하지 않은 편집이 있던 탭이 있으면 확인 화면에 그렇게 표시됩니다.
  • 실행 취소: ⌘Z / CtrlZ로 마지막 새 항목 만들기, 이름 바꾸기, 이동, 붙여넣기, 복제를 되돌립니다. 삭제한 항목은 휴지통에서 복원됩니다.
  • 경로 복사(⌥⌘C / ShiftAltC)와 상대 경로 복사(⌥⇧⌘C / CtrlShiftAltC)는 경로를 클립보드에 넣습니다.
  • Finder에서 보기(Windows에서는 파일 탐색기에서 보기, Linux에서는 포함된 폴더 열기): ⌥⌘R / ShiftAltR. 터미널에서 열기는 그 폴더(파일이면 그 파일이 있는 폴더)에서 새 터미널 탭을 엽니다.
  • 파일의 경우 열기는 에디터에서 열고, 기본 앱으로 열기는 OS가 그 유형의 파일에 사용하는 앱에서 엽니다.
  • ⌘ / Ctrl-클릭이나 ⇧ / Shift-클릭으로 여러 항목을 선택해 한꺼번에 잘라내기, 복사, 이동, 삭제를 할 수 있습니다.
  • Esc는 입력 중인 이름을 취소합니다.

열린 탭은 이름을 바꾸거나 이동한 파일을 따라가며 저장하지 않은 편집도 유지됩니다. Ferret은 같은 이름의 기존 파일이나 폴더를 덮어쓰지 않으며, 모든 것을 프로젝트 폴더 안에 둡니다. .., 절대 경로, 밖을 가리키는 심볼릭 링크, .git 안의 것, 폴더를 자기 자신 안으로 옮기는 것, 그리고 일부 OS에서 쓸 수 없는 이름(/ \ < > : " | ? *, 제어 문자, 끝의 공백이나 점, CON이나 NUL 같은 Windows 예약 이름)은 거부합니다. 한 번의 복사나 놓기로 다룰 수 있는 것은 최대 10,000개 항목, 1 GB입니다.

#Markdown과 Mermaid 미리 보기

미리 보기는 .md, .markdown, .mdx, .mmd, .mermaid에서 사용할 수 있습니다. Mermaid는 앱에 포함되어 있으므로 다이어그램이 오프라인에서도 렌더링됩니다.

Markdown 파일은 에디터 위쪽에 소스와 미리보기 두 가지 보기가 있습니다. 미리 보기는 항상 편집할 수 있으므로 바로 입력할 수 있으며, 텍스트로 돌아가려면 소스를 클릭합니다. 둘 다 같은 내용을 보여 주며, 저장, 저장하지 않음 표시, 닫을 때의 확인도 똑같이 작동합니다.

  • 제목, 단락, 목록, 체크박스, 표, 링크, 굵게, 기울임꼴, 인라인 코드에 바로 입력할 수 있습니다. 줄 처음에 #, -, 1., >와 공백을 입력하면 제목, 목록, 인용이 시작됩니다.
  • 줄 처음(또는 공백 뒤)에 /를 입력하면 목록에서 블록을 고를 수 있습니다. 제목, 글머리 기호·번호·체크 목록, 표, 코드 블록, 인용, 구분선입니다. 각 항목에는 무엇을 만드는지와 Markdown에서 쓰는 방법이 나옵니다. 계속 입력하면 걸러지고, ↑ ↓와 Enter로 고르거나 Esc를 눌러 /를 글자로 남깁니다. 표는 머리글 행이 있는 3 × 3으로 시작하며, Tab은 다음 셀로 이동하고 마지막에서는 행을 추가합니다. 표 안에서 /를 입력하면 행과 열을 추가·삭제하거나 표를 삭제할 수 있습니다.
  • 코드 블록은 소스 그대로 편집하며 모서리에 언어를 표시합니다. Mermaid 코드 블록(mermaid 또는 mmd)은 기본으로 다이어그램을 보여 줍니다. 오른쪽 위의 코드를 누르거나 다이어그램을 더블클릭하면 소스를 편집할 수 있고, 커서가 블록 밖으로 나가면 다시 다이어그램이 나옵니다. 소스에 오류가 있으면 메시지와 코드 고치기가 나옵니다. 다이어그램은 샌드박스 프레임 안에서 그리며, 저장하는 Markdown은 쓴 그대로입니다.
  • 프런트 매터(맨 위의 --- 블록)는 문서 위에 텍스트로 표시되며 그곳에서 편집할 수 있습니다.
  • 바꾸지 않은 부분은 제목 스타일, 목록 기호, 빈 줄, 표 정렬, 줄 끝 문자까지 쓰인 그대로 저장됩니다. 편집한 블록은 가능한 한 원래 스타일을 유지하며, 그럴 수 없으면 그 블록은 표준 Markdown 형식(목록은 -, 제목은 #)으로 쓰입니다.
  • 프로젝트 안의 이미지와 동영상은 표시됩니다. 다른 사이트의 이미지는 불러오지 않고 대신 호스트 이름을 표시합니다. 파일 안의 그 밖의 HTML은 텍스트로 표시됩니다.

.mdx 파일(소스로만 편집), .mmd, .mermaid 파일에는 대신 읽기 전용 미리 보기가 있습니다.

  • 옆에 미리 보기 열기: 에디터 옆에 엽니다
  • 미리 보기 열기: 내장 브라우저(ade-preview://)에서 열리므로 녹화하고 리뷰할 수 있습니다

#Markdown에 이미지와 동영상 삽입하기

이미지(PNG, JPEG, GIF, WebP, SVG, AVIF)나 동영상(MP4, WebM, MOV)을 소스 또는 미리보기의 Markdown 파일로 드래그하면 놓은 위치에 삽입됩니다.

  • 파일에서 드래그한 것을 포함해 이미 프로젝트 안에 있는 파일은 Markdown 파일 기준의 상대 경로로 링크됩니다. 아무것도 복사되지 않습니다.
  • 프로젝트 밖의 파일(Finder, 데스크톱, Windows의 파일 탐색기)은 먼저 Markdown 파일 옆의 폴더로 복사됩니다. assets, images, media, img 중 이미 있는 폴더를 쓰고, 없으면 새 assets 폴더를 만듭니다. 이름의 공백은 -가 되며, 이름이 이미 있으면 사본의 이름은 name-2가 됩니다. 원본은 원래 자리에 그대로 남습니다.
  • 이미지는 ![name](assets/name.png), 동영상은 <video src="assets/name.mp4" controls></video>로 쓰이며, 동영상은 GitHub에서도 재생됩니다. 둘 다 미리보기에 표시됩니다.
  • 이미지는 최대 50 MB, 동영상은 최대 500 MB이며, 한 번 놓을 때 최대 50개 파일, 1 GB까지 복사합니다. 함께 놓은 다른 파일은 평소처럼 에디터에서 열립니다.

#녹화로 문서 리뷰하기

  1. 리뷰 대상 패널의 파일에서 Markdown 파일을 엽니다. 내장 브라우저에서 미리 보기로 열립니다.
  2. 평소처럼 녹화합니다. 사양서나 설계 문서를 읽어 가며 말하고, 잘못된 부분을 동그라미로 표시합니다.
  3. 중지합니다. 지적 사항에는 URL 대신 프로젝트 기준의 파일 상대 경로가 들어갑니다.
  4. 에이전트에게 보내기로 문서를 고치게 합니다.
