#저장

설정기본값

중지 후에도 피드백 화면에 머무르기꺼짐

#에이전트

설정기본값
프로젝트를 열 때 시작Claude Code, Codex(지원하는 에이전트 중 원하는 것을 고르거나 고르지 않을 수 있음)
메뉴에 <agent> 표시모든 에이전트에서 켜짐
권한 확인 없이 에이전트 시작켜짐: Claude Code는 --dangerously-skip-permissions, Codex는 --dangerously-bypass-approvals-and-sandbox로 시작(자세히)
에이전트 작업이 끝나거나 확인이 필요할 때 알림 받기꺼짐(자세히)
명령 / 인수(에이전트별)에이전트 자체의 명령(예: claude, codex, gemini) / Claude Code는 --chrome, 나머지는 없음
사용자 지정 에이전트없음(사용자 지정 에이전트 추가로 어떤 CLI든 등록)
에이전트에게 보낼 지시기본 제공 텍스트(변수)
터미널 셸 (Windows)PowerShell: PowerShell 7(pwsh)이 설치되어 있으면 그것, 없으면 Windows PowerShell. 명령 기록을 탭과 재시작을 넘어 남깁니다. 다른 선택지는 cmd.exe(settings.json의 agents.windowsShell). 이후에 여는 탭에 적용됩니다

#사용 한도에서 자동 전환

설정기본값
사용 한도에 도달하면 자동으로 전환켜짐
계정을 한도로 보는 사용량95%
먼저 같은 에이전트의 다른 계정으로 전환켜짐
에이전트 순서Claude Code, Codex, Gemini CLI
한도가 돌아오면 순서가 위인 에이전트로 되돌리기꺼짐

설정 → 계정에 있습니다. 작업은 프로젝트의 .ferret/handoff.md를 통해 인계됩니다. 사용 한도에 도달해도 작업 계속하기를 참고하세요.

#계정, 자주 쓰는 서비스 CLI, 모양, 언어

  • 계정: 계정과 사용량을 참고하세요.
  • 자주 쓰는 서비스 CLI: 서비스 CLI를 설치하고 로그인합니다. 자주 쓰는 서비스 CLI를 참고하세요.
  • 브라우저에서 가져오기: 비밀번호(내보낸 CSV에서)와 기록을 내장 브라우저로 가져옵니다. 비밀번호와 기록 가져오기를 보세요.
  • 모양 → 테마: 시스템(기본값), 라이트, 다크.
  • 언어 → 인터페이스: 시스템(기본값. Ferret이 OS 언어를 지원하면 그 언어를, 아니면 영어를 사용) 또는 14개 언어 중 하나: English, 日本語, 简体中文, 繁體中文, 한국어, Español, Français, Deutsch, Italiano, Português (Brasil), Русский, हिन्दी, Bahasa Indonesia, Tiếng Việt.

푸터에서는 터미널 위치(오른쪽 / 아래)와 마이크 켜기/끄기를 바꿀 수 있습니다.

#settings.json

위의 모든 설정은 ~/.ferret/settings.json(모든 OS에서 같은 경로)에 저장되며, 그 옆에 JSON Schema가 있습니다. 앱이 실행 중일 때 직접 또는 코딩 에이전트로 편집할 수 있고, 변경 사항은 바로 적용됩니다. settings.json으로 설정하기를 참고하세요.
