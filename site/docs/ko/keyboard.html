키보드 단축키

단축키는 지금 보고 있는 OS에 맞춰 표시됩니다. 다른 OS의 단축키를 보려면 아래 전환 버튼을 사용하세요. 대부분은 Windows와 Linux의 Ctrl 대신 macOS에서 Command를, Alt 대신 Option을 사용합니다. 그보다 더 다른 몇 가지는 표에 두 가지를 모두 적었습니다. 출처: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts, 터미널의 키 처리.

단축키 표시

#녹화

동작macOSWindows / Linux
녹화 시작 / 중지⌘⇧RCtrlShiftR
모드 전환(에디터 / 피드백)⌘⇧MCtrlShiftM
누르고 있는 동안 펜⌥Alt

#녹화 중 그리기

동작macOSWindows / Linux
펜PP
사각형B / RB / R
페이지 조작(그리기 중지)V / EscV / Esc
다음 색CC
마지막 표시 실행 취소⌘ZCtrlZ
다시 실행⌘⇧ZCtrlShiftZ / CtrlY

이 키는 내장 브라우저를 녹화하는 중이고 페이지에 포커스가 있을 때 작동합니다. 페이지의 입력란에 입력하는 동안에는 무시되며, 문자 키는 보조 키 없이 누를 때만 작동하므로 페이지 자체의 단축키는 그대로 쓸 수 있습니다.

#브라우저와 보기

동작macOSWindows / Linux
URL 표시줄에 포커스⌘LCtrlL
페이지 새로고침⌘RCtrlR
뒤로⌘[Alt←
앞으로⌘]Alt→
데스크톱 / 모바일 너비 전환⌘⇧VCtrlShiftV
사이드바 표시/숨기기⌘BCtrlB
파일 트리 표시/숨기기⌘⇧ECtrlShiftE
리뷰 대상 표시/숨기기⌘⇧KCtrlShiftK

#파일

동작macOSWindows / Linux
프로젝트 폴더 열기…⌘OCtrlO
파일로 이동…⌘PCtrlP
저장⌘SCtrlS
파일 트리에서 이름 바꾸기F2 / EnterF2
파일 트리에서 삭제⌘⌫ / DeleteDelete
파일 트리에서 잘라내기 / 복사 / 붙여넣기⌘X / ⌘C / ⌘VCtrlX / CtrlC / CtrlV
파일 트리에서 실행 취소⌘ZCtrlZ
경로 복사⌥⌘CShiftAltC
상대 경로 복사⌥⇧⌘CCtrlShiftAltC
Finder / 파일 탐색기에서 보기⌥⌘RShiftAltR

파일 트리 키는 파일의 항목에 포커스가 있을 때 작동합니다.

#터미널

동작macOSWindows / Linux
새 터미널⌘TCtrlT
창 / 탭 닫기⌘WCtrlW
오른쪽으로 분할⌘DCtrlShiftD
아래로 분할⌘⇧DAltShiftD
선택 영역 복사⌘CCtrlShiftC / CtrlC
붙여넣기⌘VCtrlV / CtrlShiftV / ShiftInsert
에이전트 프롬프트에서 줄 바꿈⇧EnterShiftEnter
줄의 처음 / 끝으로⌘← / ⌘→—
줄의 처음까지 삭제⌘⌫—

이 단축키는 터미널에 포커스가 있을 때 작동합니다. Windows와 Linux에서 Ctrl+C는 텍스트가 선택되어 있으면 복사하고, 선택된 것이 없으면 실행 중인 명령을 멈춥니다. ⇧Enter / ShiftEnter는 Claude Code나 Codex 같은 에이전트가 실행 중일 때 새 줄을 시작하고, 일반 셸에서는 Enter처럼 명령을 실행합니다. 마우스를 쓰는 전체 화면 프로그램(vim, tmux, 에이전트)에서 macOS의 경우 Option을 누른 채 드래그하면 텍스트를 선택할 수 있습니다.

#창과 설정

동작macOSWindows / Linux
설정…⌘,Ctrl,
창 닫기⌘⇧W—
최소화⌘M—

Windows와 Linux에는 창을 닫는 단축키가 없습니다. 파일 → 종료로 앱을 종료합니다.
