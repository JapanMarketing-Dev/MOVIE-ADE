시작하기

빠른 시작

Ferret을 설치하고, 프로젝트와 개발 서버 URL을 열고, 피드백을 한 번 녹화해 코딩 에이전트에게 전달합니다. 5분 정도 걸립니다.

단축키 표시

#시작하기 전에

  • 터미널에서 실행되는 코딩 에이전트(설치하고 로그인한 상태). 예를 들어 Claude Code(claude), Codex(codex), Gemini CLI(gemini) 등입니다. Ferret은 내장 터미널에서 이를 실행합니다. 지원 목록에 있는 에이전트라면 무엇이든 사용할 수 있고, 직접 추가한 다른 CLI도 사용할 수 있습니다.
  • URL로 열 수 있는 웹 앱. 예: http://localhost:3000의 개발 서버.
  • 마이크. 피드백은 음성과 펜으로 전달합니다. 마이크가 없어도 펜으로 표시한 부분은 지적 사항이 되지만, 말은 포함되지 않습니다.

#1. 설치

다운로드 페이지에서 사용하는 OS용 빌드를 받아 엽니다. macOS 빌드는 Developer ID로 서명되고 Apple의 공증을 받았으므로 다른 앱처럼 열 수 있습니다. Windows와 Linux 빌드는 아직 코드 서명이 없어 처음 실행할 때 단계가 하나 더 필요합니다. Windows SmartScreen, Linux, 소스에서 빌드하는 방법은 설치를 참고하세요.

#2. 프로젝트와 URL 열기

  1. 파일 → 프로젝트 폴더 열기…(⌘O / CtrlO)에서 저장소의 루트를 선택합니다.
  2. 브라우저의 URL 표시줄(⌘L / CtrlL)에 개발 서버 URL을 입력하고 Enter를 누릅니다.
  3. 선택 사항: +(현재 URL 저장)를 눌러 local, dev, prd처럼 한 번의 클릭으로 열 수 있는 프리셋으로 저장합니다.

프로젝트를 열면 그 폴더에서 터미널 탭으로 에이전트도 시작됩니다. 기본값은 Claude Code와 Codex입니다. 사용할 에이전트는 설정 → 에이전트 → 프로젝트를 열 때 시작에서 고릅니다(설정 참고).

#3. 녹화하기

  1. 제목 표시줄의 녹화를 클릭하거나 ⌘⇧R / CtrlShiftR을 누릅니다. 창이 피드백 모드로 전환됩니다.
  2. 평소처럼 페이지를 사용하면서 바뀌어야 할 점을 말합니다.
  3. ⌥ / Alt를 누른 채로(또는 펜을 선택하고) 드래그해, 말하고 있는 위치를 동그라미로 표시합니다.
  4. 중지를 클릭하거나 ⌘⇧R / CtrlShiftR을 다시 누릅니다.

말하거나 표시한 순간마다 지적 사항이 하나씩 만들어집니다. 지적 사항 하나에는 펜 자국이 들어간 스크린샷, 요청, 말한 원문, URL, 가리킨 요소가 담깁니다.

#4. 지적 사항 확인하기

중지하면 창이 에디터 모드로 돌아가고 지적 사항 탭이 열립니다.

  • 제목이나 요청은 그 자리에서 수정할 수 있습니다.
  • 지적 사항마다 보내기 / 보내지 않음을 전환하거나, 다음과 병합, 삭제를 할 수 있습니다.
  • 실행 취소는 마지막 편집을 되돌립니다.

#5. 에이전트에게 보내기

  1. 에이전트에게 보내기를 클릭합니다. 현재 터미널 탭의 에이전트나 실행 중인 에이전트에게 전달됩니다. 버튼 옆의 화살표로 특정 에이전트나 탭을 고를 수 있습니다.
  2. 아직 실행 중인 에이전트가 없으면 Ferret이 먼저 하나를 시작하고, 준비되는 대로 보냅니다.

Ferret은 에이전트의 입력란에 지시를 하나 입력하고 제출합니다. 기본 지시는 다음과 같이 시작합니다.

"{{path}}"와 같은 폴더에 있는 각 지적 사항의 이미지를 읽고, 전송 대상으로 표시된 모든 지적 사항을 구현하세요. …

이어지는 부분에서는 바뀐 화면을 실제로 보고 확인할 것, 지적 사항별 진행 상태를 기록할 것, 마지막에 완료 / 미완료 목록으로 보고할 것을 요청합니다. 에이전트는 .ferret/reviews/<timestamp>/feedback.md와 그 옆의 PNG를 읽습니다. 동영상은 보내지 않습니다. Ferret 밖에서 실행되는 에이전트를 사용한다면 에이전트용으로 복사를 클릭해 붙여 넣으세요.

기본 지시는 표시 언어를 따릅니다. 설정에서 바꿀 수도 있습니다. 지시 바꾸기를 참고하세요.
