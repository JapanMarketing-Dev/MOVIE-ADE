क्विक स्टार्ट

Ferret इंस्टॉल करें, अपना प्रोजेक्ट और उसके dev server का URL खोलें, एक feedback रिकॉर्ड करें, और उसे अपने coding agent को सौंप दें। इसमें लगभग पाँच मिनट लगते हैं।

शॉर्टकट दिखाएँ

#शुरू करने से पहले

  • टर्मिनल में चलने वाला एक coding agent, जो इंस्टॉल हो और जिसमें साइन इन किया हो: जैसे Claude Code (claude), Codex (codex) या Gemini CLI (gemini)। Ferret उसे अपने बिल्ट-इन टर्मिनल में चलाता है। समर्थित सूची का कोई भी agent काम करता है, और आपका खुद जोड़ा गया कोई भी दूसरा CLI भी।
  • एक वेब ऐप जिसे URL से खोला जा सके, जैसे http://localhost:3000 पर चलता dev server।
  • एक माइक्रोफ़ोन। Feedback आपकी आवाज़ और पेन से मिलकर बनता है। माइक के बिना भी पेन से घेरी गई जगहें findings बनती हैं, पर उनमें शब्द नहीं होते।

#1. इंस्टॉल करें

डाउनलोड पेज से Ferret डाउनलोड करें और खोलें। हर OS के कदम इंस्टॉल करें में दिए गए हैं।

#2. प्रोजेक्ट और URL खोलें

  1. फ़ाइल → प्रोजेक्ट फ़ोल्डर खोलें… (⌘O / CtrlO) चुनें और अपनी repository का root चुनें।
  2. ब्राउज़र के URL बार (⌘L / CtrlL) में अपने dev server का URL लिखें और Enter दबाएँ।
  3. चाहें तो + (मौजूदा URL सेव करें) पर क्लिक करके इसे local, dev या prd जैसे एक-क्लिक preset के रूप में रख लें।

प्रोजेक्ट खोलने पर उसी फ़ोल्डर में टर्मिनल टैब में आपके agents भी शुरू हो जाते हैं। शुरुआती सेटिंग में ये Claude Code और Codex हैं; जिन्हें आप इस्तेमाल करते हैं, उन्हें Settings → Agents → प्रोजेक्ट खुलने पर शुरू करें में चुनें (सेटिंग्स देखें)।

#3. रिकॉर्ड करें

  1. टाइटल बार में रिकॉर्ड पर क्लिक करें, या ⌘⇧R / CtrlShiftR दबाएँ। विंडो Feedback मोड में बदल जाती है।
  2. पेज को हमेशा की तरह इस्तेमाल करें और बोलें कि क्या बदलना चाहिए।
  3. ⌥ / Alt दबाए रखें (या पेन चुनें) और जिस जगह के बारे में बोल रहे हैं, उसे drag करके घेरें।
  4. रोकें पर क्लिक करें या फिर से ⌘⇧R / CtrlShiftR दबाएँ।

जिस भी पल आप बोलते हैं या घेरते हैं, वह एक finding बन जाता है: पेन के निशानों वाला screenshot, अनुरोध, आपके मूल शब्द, URL, और वह element जिसकी ओर आपने इशारा किया।

#4. Findings जाँचें

रोकने के बाद विंडो Editor मोड में लौट आती है और Findings टैब खुल जाता है।

  • शीर्षक या अनुरोध को वहीं संपादित करें।
  • हर finding के लिए भेजें / न भेजें बदलें, अगले के साथ मर्ज करें, या हटाएँ।
  • पूर्ववत करें पिछला संपादन वापस ले लेता है।

#5. Agent को भेजें

  1. Agent को भेजें पर क्लिक करें। यह मौजूदा टर्मिनल टैब के agent को, या किसी चल रहे agent को जाता है। बटन के बगल का तीर किसी खास agent या टैब को चुनता है।
  2. अगर अभी कोई agent नहीं चल रहा, तो Ferret पहले एक शुरू करता है और तैयार होते ही भेज देता है।

Ferret agent के prompt में एक निर्देश लिखकर उसे submit करता है। डिफ़ॉल्ट रूप से वह ऐसे शुरू होता है:

"{{path}}" और साथ की इमेज पढ़ें, फिर भेजने के लिए चिह्नित हर finding लागू करें। …

बाकी हिस्सा agent से कहता है कि हर बदलाव को असली स्क्रीन पर जाँचे, हर finding की प्रगति दर्ज करे, और अंत में "पूरा / पूरा नहीं" की सूची दे। Agent .ferret/reviews/<timestamp>/feedback.md और उसके बगल की PNG फ़ाइलें पढ़ता है। वीडियो कभी नहीं भेजा जाता। Ferret के बाहर चलने वाला agent इस्तेमाल कर रहे हैं? Agent के लिए कॉपी करें पर क्लिक करें और paste करें।

डिफ़ॉल्ट निर्देश इंटरफ़ेस की भाषा के अनुसार बदलता है। आप इसे Settings में बदल सकते हैं: निर्देश बदलें देखें।

#आगे क्या पढ़ें

  • ट्रांसक्रिप्शन और खर्च: मुफ़्त on-device whisper मॉडल डाउनलोड करें, या अपना endpoint इस्तेमाल करें
