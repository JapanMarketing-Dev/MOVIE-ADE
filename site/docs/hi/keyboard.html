कीबोर्ड शॉर्टकट

शॉर्टकट उसी OS के लिए दिखाए जाते हैं जिस पर आप यह पढ़ रहे हैं; दूसरे OS के शॉर्टकट देखने के लिए नीचे का स्विच इस्तेमाल करें। ज़्यादातर शॉर्टकट में जहाँ Windows और Linux पर Ctrl होता है, वहाँ macOS पर Command होता है, और जहाँ Alt होता है वहाँ Option। कुछ शॉर्टकट इससे ज़्यादा अलग हैं, और तालिकाओं में दोनों दिए गए हैं। स्रोत: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts, और टर्मिनल की key handling।

शॉर्टकट दिखाएँ

कामmacOSWindows / Linux

आख़िरी निशान पूर्ववत करें⌘ZCtrlZ
फिर से करें⌘⇧ZCtrlShiftZ / CtrlY

ये keys तब काम करती हैं जब आप बिल्ट-इन ब्राउज़र रिकॉर्ड कर रहे हों और पेज पर focus हो। पेज के किसी field में टाइप करते समय इन्हें अनदेखा किया जाता है, और अक्षर वाली keys सिर्फ़ modifier keys के बिना काम करती हैं, ताकि पेज के अपने शॉर्टकट काम करते रहें।

#टर्मिनल

कामmacOSWindows / Linux
नया Terminal⌘TCtrlT
Pane / टैब बंद करें⌘WCtrlW
दाईं ओर विभाजित करें⌘DCtrlShiftD
नीचे विभाजित करें⌘⇧DAltShiftD
चुना हुआ टेक्स्ट कॉपी करें⌘CCtrlShiftC / CtrlC
पेस्ट करें⌘VCtrlV / CtrlShiftV / ShiftInsert
Agent के prompt में नई लाइन⇧EnterShiftEnter
लाइन की शुरुआत / अंत⌘← / ⌘→—
लाइन की शुरुआत तक हटाएँ⌘⌫—

ये शॉर्टकट तब काम करते हैं जब किसी टर्मिनल पर focus हो। Windows और Linux पर Ctrl+C, टेक्स्ट चुना हो तो कॉपी करता है, और कुछ भी चुना न हो तो चल रही command को रोक देता है। ⇧Enter / ShiftEnter तब नई लाइन शुरू करता है जब Claude Code या Codex जैसा कोई agent चल रहा हो; सामान्य shell में यह Enter की तरह command चला देता है। माउस इस्तेमाल करने वाले full-screen program (vim, tmux, कोई agent) में macOS पर टेक्स्ट चुनने के लिए drag करते समय Option दबाए रखें।
