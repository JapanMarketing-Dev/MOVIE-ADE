#Agents

सेटिंगडिफ़ॉल्ट
प्रोजेक्ट खुलने पर शुरू करेंClaude Code, Codex (कोई भी समर्थित agents चुनें, या कोई नहीं)
मेन्यू में <agent> दिखाएँहर agent के लिए चालू
अनुमति पूछे बिना Agents शुरू करेंचालू: Claude Code --dangerously-skip-permissions के साथ, Codex --dangerously-bypass-approvals-and-sandbox के साथ शुरू होता है (विवरण)
एजेंट का काम पूरा होने या मेरी ज़रूरत होने पर सूचना देंबंद (विवरण)
कमांड / आर्ग्युमेंट्स (हर agent के लिए)agent का अपना command (जैसे claude, codex, gemini) / Claude Code के लिए --chrome, बाक़ी के लिए कोई नहीं
Custom Agentsकोई नहीं (Custom Agent जोड़ें कोई भी CLI रजिस्टर करता है)
Agent के लिए निर्देशबिल्ट-इन टेक्स्ट (variables)

#उपयोग सीमा पर बदलाव

सेटिंगडिफ़ॉल्ट
उपयोग सीमा पर पहुँचने पर अपने-आप बदलेंचालू
अकाउंट को सीमा पर मानें, जब उपयोग हो95%
पहले उसी Agent का कोई दूसरा अकाउंट आज़माएँचालू
Agent का क्रमClaude Code, Codex, Gemini CLI
सीमा लौटने पर ऊपर वाले Agent पर वापस जाएँबंद

Settings → अकाउंट में। काम प्रोजेक्ट की .ferret/handoff.md के ज़रिए सौंपा जाता है। उपयोग सीमा पर भी काम जारी रखें देखें।

#अकाउंट, सेवाओं के CLI, रूप-रंग, भाषा

  • अकाउंट: अकाउंट और usage देखें।
  • सेवाओं के CLI: सेवाओं के CLI इंस्टॉल करें और उनमें साइन इन करें। सेवाओं के CLI देखें।
  • रूप-रंग → थीम: सिस्टम (डिफ़ॉल्ट), लाइट, डार्क।
  • भाषा → इंटरफ़ेस: सिस्टम (डिफ़ॉल्ट; अगर Ferret में OS की भाषा उपलब्ध है तो वही, वरना अंग्रेज़ी) या 14 भाषाओं में से एक: English, 日本語, 简体中文, 繁體中文, 한국어, Español, Français, Deutsch, Italiano, Português (Brasil), Русский, हिन्दी, Bahasa Indonesia, Tiếng Việt।

फ़ुटर से: टर्मिनल की जगह (दाईं ओर / नीचे) और माइक्रोफ़ोन टॉगल।

#settings.json

ऊपर की सारी सेटिंग्स ~/.ferret/settings.json (हर OS पर यही path) में सेव होती हैं, और उसके बगल में एक JSON Schema होता है। ऐप चलते समय आप इसे हाथ से या अपने coding agent से संपादित कर सकते हैं; बदलाव तुरंत लागू होते हैं। settings.json से कॉन्फ़िगर करें देखें।
