Primeros pasos

Instalación

Descarga Ferret para tu ordenador y ábrelo. Funciona en macOS, Windows y Linux.

#Descarga

La página de descarga te ofrece el archivo adecuado para tu ordenador. Haz clic en el botón de descarga.

#macOS

Abre el .dmg, arrastra Ferret a Applications y ábrelo desde ahí.

#Windows

Ejecuta el .exe que descargaste. Ferret se instala y se abre sin que tengas que elegir nada. Las próximas veces, ábrelo desde el menú Inicio o desde el acceso directo del escritorio.

Si Windows muestra Windows protegió su PC, haz clic en Más información y luego en Ejecutar de todas formas.

#Linux

Ubuntu / Debian: haz doble clic en el .deb para instalarlo con tu centro de software, o ejecuta:

sudo apt install ./Ferret-<version>-linux-amd64.deb

Después abre Ferret desde el menú de aplicaciones o ejecuta ferret.

Otras distribuciones: usa el .AppImage. Permite que se ejecute como programa (clic derecho → Propiedades, o chmod +x) y ábrelo.

#Siguientes pasos

  • Guía rápida: abre un proyecto y graba tu primer feedback.
  • ¿Algo ha fallado? Consulta Solución de problemas.
  • Para comprobar la firma de una descarga, compilar desde el código fuente u obtener una versión anterior, consulta Instalación avanzada.
