Atajos de teclado

Los atajos se muestran para el sistema operativo desde el que lees; usa el selector de abajo para ver los del otro. La mayoría usan Command en macOS donde Windows y Linux usan Ctrl, y Option donde usan Alt. Unos pocos difieren más, y las tablas muestran ambos. Fuente: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts y la gestión de teclas de la terminal.

Atajos para

#Grabación

AcciónmacOSWindows / Linux
Iniciar / detener grabación⌘⇧RCtrlShiftR
Cambiar modo (Editor / Feedback)⌘⇧MCtrlShiftM
Lápiz mientras se mantiene pulsado⌥Alt

#Dibujar mientras grabas

AcciónmacOSWindows / Linux
LápizPP
RecuadroB / RB / R
Usar la página (dejar de dibujar)V / EscV / Esc
Siguiente colorCC
Deshacer el último trazo⌘ZCtrlZ
Rehacer⌘⇧ZCtrlShiftZ / CtrlY

Estas teclas funcionan mientras grabas el navegador integrado y la página tiene el foco. Se ignoran mientras escribes en un campo de la página, y las teclas de letras solo funcionan sin teclas modificadoras, así que los atajos propios de la página siguen funcionando.

Enfocar barra de URL⌘LCtrlL
Recargar página⌘RCtrlR

Adelante⌘]Alt→

#Archivos

AcciónmacOSWindows / Linux
Abrir carpeta de proyecto…⌘OCtrlO

#Terminal

AcciónmacOSWindows / Linux
Nueva terminal⌘TCtrlT
Cerrar panel / pestaña⌘WCtrlW
Dividir a la derecha⌘DCtrlShiftD
Dividir hacia abajo⌘⇧DAltShiftD

Los atajos de división funcionan mientras una terminal tiene el foco.

#Ventana y ajustes

AcciónmacOSWindows / Linux

Cerrar ventana⌘⇧W—
