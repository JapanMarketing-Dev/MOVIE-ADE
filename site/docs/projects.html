Using Ferret

Projects and URLs

A project is a folder (usually your repo root). Each project keeps its own saved URLs, so local, dev, and production are one click apart.

#Add a project

  1. File → Open Project Folder… (⌘O / CtrlO), Add Project in the sidebar, or Add Project… in the title bar project menu.
  2. Pick the folder and click Open.

The name defaults to the folder name. Adding a folder that is already registered opens it instead (paths are compared case-insensitively on macOS and Windows). From the sidebar menu you can Rename a project or Remove from List. Removing never deletes the folder.

Terminals open in the project folder, and reviews are saved under <project>/.ferret/.

#Save URLs

  1. Open the page in the built-in browser.
  2. Click + (Save current URL) in the browser toolbar. The current URL is pre-filled.
  3. Enter a Name and click Save.

Only http:// and https:// URLs are accepted. The name is guessed from the host if you leave it as suggested:

HostName
localhost, 127.*, ::1, 0.0.0.0, *.localhostlocal
contains dev, develop, developmentdev
contains stg, stage, stagingstg
anything elseprd

#Review targets panel

In Feedback mode, the Review targets panel on the right lists everything you can review for the current project. Switching targets doesn't stop the recording. Toggle the panel with View → Toggle Review Targets (⌘⇧K / CtrlShiftK) or Hide panel.

  • Targets: the project's saved URLs. Under each one is a tree of the pages you have visited on that site. Sites you visited that aren't saved appear as their own groups.
  • Files: the project folder. A file opens as a preview (Markdown and Mermaid rendered, other text read-only), so you can review docs too. The pencil (Open in editor) opens it in the editor.

Filter targets filters targets, pages, and files together, with the same fuzzy matching as Go to File…. In the list, ↑ ↓ Enter or 1–9 switch targets. Open URL… opens a one-off URL, and Save to project URLs keeps it.

Targets come from projects[].urls in settings.json (see the example). Each entry needs a url, a launchCommand (run in a terminal, e.g. to start a desktop app), or a windowMatch (the window to record). Picking a window target sets it as the recording source, so it can't be done while recording. Visited pages are remembered per project, on this machine only (up to 200).

#Open and switch environments

Click a saved URL to open it. If the current page is under another saved URL, Ferret keeps the path, query, and hash and swaps only the origin. For example, on http://localhost:3000/pricing?plan=pro, clicking prd opens https://example.com/pricing?plan=pro.

The chip matching the current page (longest prefix) is highlighted. Right-click a chip or use its pencil icon to edit or Delete it. When a project opens and there is no previous URL, its first saved URL loads.
