Inizia qui

Guida rapida

Installa Ferret, apri il tuo progetto e l'URL del suo server di sviluppo, registra un feedback e consegnalo al tuo coding agent. Circa cinque minuti.

Scorciatoie per

#Prima di iniziare

  • Un coding agent che gira in un terminale, installato e con accesso effettuato: per esempio Claude Code (claude), Codex (codex) o Gemini CLI (gemini). Ferret lo esegue nel suo terminale integrato. Funziona qualsiasi agent dell'elenco di quelli supportati, e anche qualsiasi altra CLI che aggiungi tu.
  • Una web app che puoi aprire tramite URL, ad es. un server di sviluppo su http://localhost:3000.
  • Un microfono. Il feedback è la tua voce più la penna. Senza microfono i cerchi tracciati con la penna diventano comunque segnalazioni, ma senza parole.

#1. Installa

Scarica Ferret dalla pagina di download e aprilo. I passaggi per ogni sistema operativo sono in Installazione.

#2. Apri un progetto e un URL

  1. File → Apri cartella progetto… (⌘O / CtrlO) e scegli la radice del tuo repository.
  2. Digita l'URL del server di sviluppo nella barra degli URL del browser (⌘L / CtrlL) e premi Enter.
  3. Facoltativo: fai clic su + (Salva URL corrente) per conservarlo come preimpostazione apribile con un clic, ad esempio local, dev o prd.

Aprire un progetto avvia anche i tuoi agent in schede del terminale in quella cartella. Di base sono Claude Code e Codex; scegli quelli che usi in Impostazioni → Agent → Avvia all'apertura di un progetto (vedi Impostazioni).

#3. Registra

  1. Fai clic su Registra nella barra del titolo, oppure premi ⌘⇧R / CtrlShiftR. La finestra passa alla modalità Feedback.
  2. Usa la pagina come al solito e di' cosa dovrebbe cambiare.
  3. Tieni premuto ⌥ / Alt (o scegli Penna) e trascina per cerchiare il punto mentre ne parli.
  4. Fai clic su Ferma o premi di nuovo ⌘⇧R / CtrlShiftR.

Ogni momento in cui parli o cerchi qualcosa diventa una segnalazione: uno screenshot con i segni della penna, la richiesta, le parole originali, l'URL e l'elemento che hai indicato.

#4. Controlla le segnalazioni

Quando fermi la registrazione, la finestra torna alla modalità Editor e apre la scheda Segnalazioni.

  • Modifica direttamente un titolo o una richiesta.
  • Per ogni segnalazione alterna Invia / Non inviare, oppure usa Unisci con la successiva o Elimina.
  • Annulla annulla l'ultima modifica.

#5. Invia a un agent

  1. Fai clic su Invia all'Agent. Il feedback va all'agent nella scheda del terminale attuale, oppure a uno in esecuzione. La freccia accanto al pulsante permette di scegliere un agent o una scheda precisi.
  2. Se non c'è ancora nessun agent in esecuzione, Ferret ne avvia uno e invia appena è pronto.

Ferret scrive un'istruzione nel prompt dell'agent e la invia. Per impostazione predefinita inizia così:

Leggi "{{path}}" e l'immagine di ogni segnalazione nella stessa cartella, poi implementa ogni segnalazione contrassegnata per l'invio. …

Il resto chiede all'agent di verificare ogni modifica sulla schermata reale, di registrare l'avanzamento di ogni segnalazione e di concludere con un elenco Fatto / Non fatto. L'agent legge .ferret/reviews/<timestamp>/feedback.md e i PNG accanto. Il video non viene mai inviato. Usi un agent fuori da Ferret? Fai clic su Copia per l'Agent e incolla.

L'istruzione predefinita segue la lingua dell'interfaccia. Puoi sostituirla nelle Impostazioni: vedi Personalizzare l'istruzione.
