File e ambiente

Dove Ferret conserva i propri file, e le variabili d'ambiente che legge o imposta.

#Cartella userData

I dati dell'app si trovano nella cartella userData di Electron. Il suo nome è fissato su ade-movie (non sul nome del prodotto), così i dati sopravvivono ai cambi di nome. Puoi sovrascriverla con --user-data-dir=<path>.

Sistema operativoPercorso
macOS~/Library/Application Support/ade-movie/
Windows%APPDATA%\ade-movie\
Linux~/.config/ade-movie/ (oppure $XDG_CONFIG_HOME/ade-movie/)
 
settings.json       # settings before 0.1.1, kept as a backup (now ~/.ferret/settings.json)
stt-keys.bin        # API keys, encrypted with safeStorage
browser-import/     # imported passwords (passwords.bin, encrypted with safeStorage) and history (history.json)
feedback-share/     # share links you made (shares.bin; owner tokens encrypted with safeStorage)
login-shell-path.json  # your login shell's PATH from the last launch, so agent tabs start without waiting
models/             # downloaded whisper models (ggml-*.bin)
accounts/claude/<id>/   # CLAUDE_CONFIG_DIR for added accounts
accounts/codex/<id>/    # CODEX_HOME for added accounts

Le tue impostazioni non sono in questa cartella: si trovano in ~/.ferret/ (vedi Configurare con settings.json).

Un modello scelto da te può trovarsi ovunque. Viene ancora controllato il vecchio percorso predefinito ~/.cache/ade-movie/models/ggml-small.bin.

#Variabili d'ambiente

VariabileEffetto
CLAUDE_CONFIG_DIR, CODEX_HOMEImpostate da Ferret per le schede degli agent quando è selezionato un account aggiunto
GH_TOKEN, GITHUB_TOKENUsate da gh prima del proprio accesso. Ferret avvisa quando una delle due è impostata
FERRET_CONFIG_DIR (o il vecchio MOVIE_ADE_CONFIG_DIR)Cartella per settings.json, state.json e settings.schema.json al posto di ~/.ferret
Nomi indicati in apiKeyEnvChiavi API a cui fai riferimento da settings.json. Vengono lette anche dal .env del progetto e da ~/.ferret/.env
ADE_PROJECT_DIRApre (e registra) questa cartella come progetto all'avvio
ADE_INITIAL_URLCarica questo URL nel browser integrato all'avvio
ADE_WHISPER_MODELPercorso assoluto di un modello GGML da usare per la trascrizione sul dispositivo, al posto di quello predefinito scaricato
ADE_TERMINAL_PREWARM0 impedisce a Ferret di tenere una shell pronta in background. Per impostazione predefinita la usa la successiva scheda di shell semplice, così il suo prompt compare subito
FERRET_SENTRY_DSN (o il vecchio MOVIE_ADE_SENTRY_DSN)Dove vanno i report sugli arresti anomali. Se è vuota non viene inviato nulla (vedi Report sugli arresti anomali)
OPENAI_API_KEYLetta da .env solo in sviluppo (pnpm dev), mai nelle build pacchettizzate
PATHUsata per trovare i comandi dei tuoi agent (claude, codex, gemini…), gh, git, whisper-cli. Su macOS e Linux vengono aggiunti i percorsi di Homebrew, linuxbrew e snap

#Dentro il tuo progetto

  • .ferret/reviews/<id>/: le revisioni (vedi Dati e privacy). Le revisioni precedenti in .ade-movie/reviews/ vengono ancora lette
  • .git/info/exclude: una riga, .ferret/, aggiunta alla prima registrazione
