Atalhos de teclado

Os atalhos são exibidos para o sistema em que você está lendo; use o seletor abaixo para ver o outro. A maioria usa Command no macOS onde o Windows e o Linux usam Ctrl, e Option onde eles usam Alt. Alguns diferem mais do que isso, e as tabelas mostram os dois. Fonte: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts, e o tratamento de teclas do terminal.

Atalhos para

#Gravação

AçãomacOSWindows / Linux
Iniciar / parar gravação⌘⇧RCtrlShiftR
Alternar modo (Editor / Feedback)⌘⇧MCtrlShiftM
Caneta enquanto pressionada⌥Alt

#Desenhar durante a gravação

AçãomacOSWindows / Linux
CanetaPP
CaixaB / RB / R
Usar a página (parar de desenhar)V / EscV / Esc
Próxima corCC
Desfazer a última marca⌘ZCtrlZ
Refazer⌘⇧ZCtrlShiftZ / CtrlY

Essas teclas funcionam enquanto você grava o navegador integrado e a página está em foco. Elas são ignoradas enquanto você digita em um campo da página, e as teclas de letras só funcionam sem teclas modificadoras, para que os atalhos da própria página continuem funcionando.

#Navegador e exibição

AçãomacOSWindows / Linux
Focar na barra de URL⌘LCtrlL
Recarregar página⌘RCtrlR
Voltar⌘[Alt←
Avançar⌘]Alt→
Alternar largura desktop / mobile⌘⇧VCtrlShiftV
Alternar barra lateral⌘BCtrlB
Alternar árvore de arquivos⌘⇧ECtrlShiftE
Alternar alvos de revisão⌘⇧KCtrlShiftK

#Arquivos

AçãomacOSWindows / Linux
Abrir pasta do projeto…⌘OCtrlO
Ir para arquivo…⌘PCtrlP

#Terminal

AçãomacOSWindows / Linux
Novo terminal⌘TCtrlT
Fechar painel / aba⌘WCtrlW
Dividir à direita⌘DCtrlShiftD
Dividir abaixo⌘⇧DAltShiftD

Os atalhos de divisão funcionam enquanto um terminal está em foco.

#Janela e configurações

AçãomacOSWindows / Linux
Configurações…⌘,Ctrl,
Fechar janela⌘⇧W—

No Windows e no Linux, não há atalho para fechar a janela: Arquivo → Sair encerra o app.
