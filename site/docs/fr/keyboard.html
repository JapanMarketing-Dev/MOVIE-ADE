Raccourcis clavier

Les raccourcis sont affichés pour l'OS sur lequel vous lisez ; utilisez le sélecteur ci-dessous pour voir l'autre. La plupart utilisent Commande sur macOS là où Windows et Linux utilisent Ctrl, et Option là où ils utilisent Alt. Quelques-uns diffèrent davantage, et les tableaux indiquent alors les deux. Source : src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts et la gestion des touches du terminal.

Raccourcis pour

ActionmacOSWindows / Linux
Démarrer / arrêter l'enregistrement⌘⇧RCtrlShiftR
Changer de mode (Éditeur / Retours)⌘⇧MCtrlShiftM

#Dessiner pendant l'enregistrement

ActionmacOSWindows / Linux
StyloPP
CadreB / RB / R
Utiliser la page (arrêter de dessiner)V / EscV / Esc
Couleur suivanteCC
Annuler le dernier trait⌘ZCtrlZ
Rétablir⌘⇧ZCtrlShiftZ / CtrlY

Ces touches fonctionnent pendant l'enregistrement du navigateur intégré, lorsque la page a le focus. Elles sont ignorées pendant la saisie dans un champ de la page, et les touches de lettre ne fonctionnent que sans touche de modification : les raccourcis propres à la page continuent donc de fonctionner.

#Terminal

ActionmacOSWindows / Linux
Nouveau terminal⌘TCtrlT
Fermer le panneau / l'onglet⌘WCtrlW
Diviser à droite⌘DCtrlShiftD
Diviser en bas⌘⇧DAltShiftD
Copier la sélection⌘CCtrlShiftC / CtrlC
Coller⌘VCtrlV / CtrlShiftV / ShiftInsert
Nouvelle ligne dans le prompt d'un agent⇧EnterShiftEnter
Début / fin de ligne⌘← / ⌘→—
Supprimer jusqu'au début de la ligne⌘⌫—

Ces raccourcis fonctionnent lorsqu'un terminal a le focus. Sous Windows et Linux, Ctrl+C copie quand du texte est sélectionné et arrête la commande en cours quand rien n'est sélectionné. ⇧Enter / ShiftEnter commence une nouvelle ligne pendant qu'un agent comme Claude Code ou Codex s'exécute ; dans un shell simple, il exécute la commande comme Entrée. Dans un programme plein écran qui utilise la souris (vim, tmux, un agent), maintenez Option en faisant glisser pour sélectionner du texte sur macOS.

#Fenêtre et réglages

ActionmacOSWindows / Linux
