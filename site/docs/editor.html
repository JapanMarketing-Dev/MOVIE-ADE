Using MOVIE-ADE

Editor and preview

Open and edit project files, and preview Markdown and Mermaid. A preview opened in the built-in browser can be recorded and reviewed like any web page.

#Open and edit files

  • Files (the file tree): ⌘⇧E / CtrlShiftE, with Filter by file name, Refresh, and Collapse All.
  • Go to File…: ⌘P / CtrlP.
  • Save with ⌘S / CtrlS. Closing a modified file asks Save changes to <name>? with Save, Don't Save, and Cancel.
  • If the file changes on disk while you have unsaved edits, choose Reload from Disk or Keep My Changes.

The editor is Monaco.

#Markdown and Mermaid preview

Preview works for .md, .markdown, .mdx, .mmd, and .mermaid. Mermaid is bundled with the app, so diagrams render offline.

  • Open Preview to the Side: next to the editor
  • Open Preview: in the built-in browser (ade-preview://), so you can record and review it

#Review docs by recording

  1. Open a Markdown file and click Open Preview.
  2. Record as usual. Talk through the spec or design doc and circle what's wrong.
  3. Stop. Findings reference the file's project-relative path instead of a URL.
  4. Send to Agent to have the doc fixed.
