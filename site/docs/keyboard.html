Keyboard shortcuts

Shortcuts are shown for the OS you are reading on; use the switch below to see the other one. Most use Command on macOS where Windows and Linux use Ctrl, and Option where they use Alt. A few differ more than that, and the tables list both. Source: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts, and the terminal's key handling.

#Terminal

ActionmacOSWindows / Linux
New Terminal⌘TCtrlT
Close Pane / Tab⌘WCtrlW
Split Right⌘DCtrlShiftD
Split Down⌘⇧DAltShiftD
Copy Selection⌘CCtrlShiftC / CtrlC
Paste⌘VCtrlV / CtrlShiftV / ShiftInsert
New Line in an Agent's Prompt⇧EnterShiftEnter
Start / End of Line⌘← / ⌘→—
Delete to Start of Line⌘⌫—

These work while a terminal has focus. On Windows and Linux, Ctrl+C copies when text is selected and stops the running command when nothing is selected. ⇧Enter / ShiftEnter starts a new line while an agent such as Claude Code or Codex is running; in a plain shell it runs the command like Enter. In a full-screen program that uses the mouse (vim, tmux, an agent), hold Option while dragging to select text on macOS.
