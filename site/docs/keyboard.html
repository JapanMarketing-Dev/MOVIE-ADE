Keyboard shortcuts

Menu shortcuts use ⌘ on macOS and Ctrl on Windows and Linux. Source: src/main/menu.ts and src/renderer/lib/shortcut.ts.

#Recording

ActionmacOSWindows / Linux
Start / Stop Recording⌘⇧RCtrlShiftR
Switch Mode (Editor / Feedback)⌘⇧MCtrlShiftM
Pen while held⌥Alt
Text: confirmEnterEnter
Text: new line⇧EnterShiftEnter
Text: cancelEscEsc

#Browser and view

ActionmacOSWindows / Linux
Focus URL Bar⌘LCtrlL
Reload Page⌘RCtrlR
Toggle Desktop / Mobile Width⌘⇧VCtrlShiftV
Toggle Sidebar⌘BCtrlB
Toggle File Tree⌘⇧ECtrlShiftE

#Files

ActionmacOSWindows / Linux
Open Project Folder…⌘OCtrlO
Go to File…⌘PCtrlP
Save⌘SCtrlS

#Terminal

ActionmacOSWindows / Linux
New Terminal⌘TCtrlT
Close Pane / Tab⌘WCtrlW
Split Right⌘DCtrlShiftD
Split Down⌘⇧DAltShiftD

Split shortcuts work while a terminal has focus.

ActionmacOSWindows / Linux
Close Window⌘⇧W—
