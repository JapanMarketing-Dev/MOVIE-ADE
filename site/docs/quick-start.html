Quick start

Install MOVIE-ADE, open your project and its dev server URL, record one piece of feedback, and hand it to Claude Code or Codex. About five minutes.

#Before you start

  • Claude Code (claude) or Codex (codex) installed and signed in. MOVIE-ADE runs them in its built-in terminal.
  • A web app you can open by URL, e.g. a dev server on http://localhost:3000.
  • A microphone is optional. You can leave feedback with the pen and text only.

#1. Install

Download the build for your OS from the download page and open it. Builds are unsigned, so the first launch needs one extra step. See Install for macOS Gatekeeper, Windows SmartScreen, Linux, and building from source.

#2. Open a project and a URL

  1. File → Open Project Folder… (⌘O / CtrlO) and pick your repository root.
  2. Type your dev server URL into the browser's URL bar (⌘L / CtrlL) and press Enter.
  3. Optional: click + (Save current URL) to keep it as a one-click preset such as local, dev, or prd.

Opening a project also starts Claude Code and Codex in terminal tabs in that folder (configurable in Settings).

#3. Record

  1. Click Record in the title bar, or press ⌘⇧R / CtrlShiftR. The window switches to Feedback mode.
  2. Use the page as usual and say what should change.
  3. Hold ⌥ / Alt and drag to circle the spot. Or pick Text, click the page, type a request, and press Enter.
  4. Click Stop or press ⌘⇧R again.

Each moment you speak, circle, or type becomes one finding: a screenshot with your pen marks, the request, the original words, the URL, and the element you pointed at.

#4. Check the findings

After you stop, the window returns to Editor mode and opens the Findings tab.

  • Edit a title or request in place.
  • Toggle Send / Don't send per finding, Merge with Next, or Delete.
  • Undo reverts the last edit.

#5. Send to an agent

  1. Make sure a Claude Code or Codex tab is running in the built-in terminal.
  2. Click Send to Agent.

MOVIE-ADE types one instruction into the agent's prompt and submits it. By default the instruction is:

Read "{{path}}", check the image for each finding in the same folder, and address the findings marked for sending.

The agent reads .ade-movie/reviews/<timestamp>/feedback.md and the PNGs next to it. The video is never sent. Using an agent outside MOVIE-ADE? Click Copy for Agent and paste.

The default follows the display language. You can replace it in Settings: see Customize the instruction.
