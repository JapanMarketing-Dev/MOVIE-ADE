Settings reference

Open Settings from the gear in the title bar. Settings can't be changed while recording.

#Microphone

Record my voiceOn
MicrophoneSystem Default
Record the other side too (beta)Off

#Accounts, GitHub, appearance, language

  • Accounts: see Accounts and usage.
  • GitHub: gh sign-in. See Send to GitHub.
  • Appearance → Theme: System (default), Light, Dark.
  • Language → Interface: System (default; follows the OS language: Japanese on a Japanese OS, English otherwise), English, or Japanese.

From the footer: terminal position (right / bottom) and the microphone toggle.

#settings.json

Everything above is stored in ~/.ferret/settings.json (same path on every OS), with a JSON Schema next to it. You can edit it while the app is running, by hand or with your coding agent; changes apply immediately. See Configure with settings.json.
