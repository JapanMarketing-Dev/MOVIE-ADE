Configure

Accounts and usage

Switch between several Claude Code or Codex logins, and watch your rate-limit windows in the footer.

#Multiple accounts

Accounts are optional. Add them only if you switch between several.

  1. Open Settings → Accounts, or Manage Accounts… from the footer usage menu.
  2. Add Account starts the agent's login in a built-in terminal tab.
  3. Pick the account to use. Running tabs keep their account. New tabs use the selected one.

How it works: each added account gets its own config directory, <userData>/accounts/<agent>/<id>/. MOVIE-ADE launches the agent with CLAUDE_CONFIG_DIR (Claude Code) or CODEX_HOME (Codex) pointing there. System Default uses your usual ~/.claude / ~/.codex unchanged.

Removing an account deletes its config directory. It does not sign you out on the server.

#Usage in the footer

The footer shows how much of each rate-limit window is used: the 5-hour window and the weekly window, plus the per-model weekly window for Claude. Colors turn yellow at 60% and red at 80%. Values refresh every 15 minutes, or on Refresh usage.

Display: Detailed (bars, window names, and percentages) or Compact (one value per agent).

Usage is fetched directly from Anthropic (api.anthropic.com/api/oauth/usage) and ChatGPT (chatgpt.com/backend-api/wham/usage) with the signed-in account's own credentials.
