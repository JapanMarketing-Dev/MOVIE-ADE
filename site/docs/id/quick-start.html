Mulai cepat

Instal Ferret, buka proyek Anda beserta URL dev server-nya, rekam satu umpan balik, lalu serahkan ke agent coding Anda. Sekitar lima menit.

Pintasan untuk

#Sebelum mulai

  • Agent coding yang berjalan di terminal, sudah terinstal dan sudah masuk (sign in): misalnya Claude Code (claude), Codex (codex), atau Gemini CLI (gemini). Ferret menjalankannya di terminal bawaannya. Agent mana pun dalam daftar yang didukung bisa dipakai, begitu juga CLI lain yang Anda tambahkan sendiri.
  • Aplikasi web yang bisa dibuka lewat URL, misalnya dev server di http://localhost:3000.
  • Mikrofon. Umpan balik terdiri dari suara Anda ditambah pena. Tanpa mikrofon, lingkaran pena tetap menjadi temuan, tetapi tanpa kata-kata.

#1. Instal

Unduh Ferret dari halaman unduhan, lalu buka. Langkah untuk setiap OS ada di Instalasi.

#2. Buka proyek dan URL

  1. Pilih File → Buka Folder Proyek… (⌘O / CtrlO), lalu pilih root repositori Anda.
  2. Ketik URL dev server Anda di bilah URL browser (⌘L / CtrlL), lalu tekan Enter.
  3. Opsional: klik + (Simpan URL saat ini) untuk menyimpannya sebagai preset sekali klik, misalnya local, dev, atau prd.

Membuka proyek juga menjalankan agent Anda di tab terminal pada folder tersebut. Secara bawaan, agent tersebut adalah Claude Code dan Codex; pilih yang Anda pakai di Pengaturan → Agent → Jalankan Saat Proyek Dibuka (lihat Pengaturan).

#3. Rekam

  1. Klik Rekam di bilah judul, atau tekan ⌘⇧R / CtrlShiftR. Jendela beralih ke mode Umpan Balik.
  2. Gunakan halaman seperti biasa dan sebutkan apa yang perlu diubah.
  3. Tahan ⌥ / Alt (atau pilih Pena) lalu seret untuk melingkari bagian yang sedang Anda bicarakan.
  4. Klik Berhenti atau tekan ⌘⇧R / CtrlShiftR lagi.

Setiap momen Anda berbicara atau melingkari menjadi satu temuan: screenshot dengan coretan pena Anda, permintaannya, kata-kata asli Anda, URL, dan elemen yang Anda tunjuk.

#4. Periksa temuan

Setelah Anda berhenti, jendela kembali ke mode Editor dan membuka tab Temuan.

  • Edit judul atau permintaan langsung di tempat.
  • Alihkan Kirim / Jangan kirim per temuan, Gabung dengan Berikutnya, atau Hapus.
  • Urungkan membatalkan edit terakhir.

#5. Kirim ke agent

  1. Klik Kirim ke Agent. Temuan dikirim ke agent di tab terminal saat ini, atau ke agent yang sedang berjalan. Panah di samping tombol memilih agent atau tab tertentu.
  2. Jika belum ada agent yang berjalan, Ferret menjalankannya terlebih dahulu dan mengirim begitu agent siap.

Ferret mengetik satu instruksi ke prompt agent lalu mengirimkannya. Secara bawaan, instruksinya diawali dengan:

Baca "{{path}}" dan gambar untuk setiap temuan di folder yang sama, lalu implementasikan setiap temuan yang ditandai untuk dikirim. …

Bagian selanjutnya meminta agent memeriksa setiap perubahan di layar yang sebenarnya, mencatat progres per temuan, dan menutup dengan daftar Selesai / Belum selesai. Agent membaca .ferret/reviews/<timestamp>/feedback.md dan file PNG di sebelahnya. Videonya tidak pernah dikirim. Memakai agent di luar Ferret? Klik Salin untuk Agent lalu tempel.

Instruksi bawaan mengikuti bahasa tampilan. Anda bisa menggantinya di Pengaturan: lihat Menyesuaikan instruksi.
