Pemecahan masalah

Masalah umum dan cara mengatasinya. Pesan yang dikutip adalah teks yang ditampilkan aplikasi dalam bahasa Indonesia.

#Perekaman layar atau jendela gagal (macOS)

Pesan: Merekam seluruh layar atau jendela lain memerlukan izin Perekaman Layar macOS.

  1. Di dialog Target Perekaman, klik Buka Pengaturan Sistem.
  2. Privasi & Keamanan → Perekaman Layar & Audio Sistem: aktifkan Ferret.
  3. Mulai ulang aplikasi, lalu klik Periksa Lagi.

Merekam Browser Bawaan tidak memerlukan izin.

Saat menjalankan dari kode sumber di macOS, pnpm dev meluncurkan salinan Electron yang sudah diganti namanya dan ditandatangani ad-hoc, yang juga bernama Ferret (scripts/prepare-dev-electron.mjs), sehingga muncul sebagai entri Ferret terpisah di daftar ini. Saat pertama kali dijalankan, macOS meminta lagi akses Perekaman Layar dan Mikrofon. Setelah itu tidak ditanyakan lagi. Build pengembangan memakai keychain tiruan (--use-mock-keychain), sehingga tidak ada permintaan Keychain: cookie dan key yang disimpan di build dev dienkripsi dengan kunci tetap, bukan Keychain yang sebenarnya. Atur ADE_DEV_REAL_KEYCHAIN=1 untuk memakai Keychain yang sebenarnya.

#Mikrofon tidak terbuka

Pesan: Tidak dapat membuka mikrofon. Periksa izin di pengaturan OS Anda.

  • macOS: Pengaturan Sistem → Privasi & Keamanan → Mikrofon, lalu aktifkan Ferret.
  • Windows: Pengaturan → Privasi & keamanan → Mikrofon, lalu izinkan aplikasi desktop.

Tanpa mikrofon, lingkaran pena tetap membuat temuan, tetapi tanpa permintaan lisan.

#Tidak ada model di perangkat / whisper-cli tidak ditemukan

Pesan: Model transkripsi di perangkat tidak ditemukan. Audio akan disimpan, dan hanya temuan pena yang diproses.

Unduh model di Pengaturan, atau pilih ggml-*.bin yang sudah ada. Jika Pengaturan menampilkan whisper.cpp (whisper-cli) tidak ditemukan, instal (petunjuk), pastikan berada di PATH, lalu buka kembali Pengaturan. Aplikasi terpaket yang diluncurkan dari Finder atau Explorer mungkin tidak melihat PATH shell Anda, jadi instal ke lokasi standar seperti milik Homebrew.

Unduhan model yang gagal dalam pemeriksaan sha256 akan dibuang. Coba lagi.

#Terminal: node-pty tidak dapat dimuat

Hal ini terjadi saat menjalankan dari kode sumber dan node-pty di-build untuk ABI Node atau Electron yang berbeda.

pnpm rebuild:native

#Agent tidak ditemukan / Kirim ke Agent tidak terkirim

  • command not found: claude (atau codex, gemini, atau perintah agent lain) di terminal: CLI belum terinstal atau tidak ada di PATH. Ferret menampilkan error dari shell itu sendiri tanpa menambahkan petunjuk. Pastikan perintahnya berfungsi di terminal biasa Anda, gunakan Instal di Pengaturan → Agent, atau atur path absolut sebagai Perintah untuk agent tersebut.
  • Agent sedang menunggu konfirmasi. Tanggapi di terminal, lalu kirim. Jawab prompt agent terlebih dahulu.
  • Input agent belum siap. Tunggu sampai agent selesai dijalankan.
  • Teks sudah dimasukkan tetapi belum terkirim. Tekan Enter di terminal.
  • Buka terminal terlebih dahulu.
  • Tidak dapat mengurai argumen peluncuran: Tanda kutip tidak ditutup. Perbaiki tanda kutip di argumen agent.

#Perekaman tidak dimulai

  • Buka folder proyek terlebih dahulu.
  • Buka URL yang ingin ditinjau terlebih dahulu.
  • Halaman tidak dimuat. Buka URL yang dapat ditampilkan, lalu rekam. Pastikan dev server berjalan. Tidak dapat terhubung ke server berarti tidak ada yang mendengarkan di port tersebut.

#Key OpenAI atau endpoint belum diatur

API key OpenAI belum diatur… atau Endpoint transkripsi (Base URL / model) belum diatur…: tambahkan di Pengaturan, atau beralih ke Di perangkat (gratis). Audio dari rekaman tersebut sudah tersimpan.

#Error GitHub

  • GitHub CLI (gh) tidak ditemukan. Instal gh.
  • Belum masuk ke GitHub Pengaturan → GitHub / GitLab → Masuk di Terminal.
  • Tidak ada remote origin. atau origin bukan repositori GitHub. Periksa git remote -v.
  • Repositori tidak ditemukan, atau Anda tidak memiliki akses. Periksa gh auth status dan GH_TOKEN.

#Melaporkan bug

Buka issue di github.com/JapanMarketing-Dev/ferret/issues (terbuka di tab baru) dengan menyertakan OS Anda, versi aplikasi (footer → Pembaruan), dan langkah untuk mereproduksi masalahnya. Jangan lampirkan isi .ferret/ yang memuat layar pribadi.
