Install

MOVIE-ADE is a desktop app for macOS, Windows, and Linux. Builds are not code-signed yet, so each OS asks you to confirm the first launch.

#Download

Get the file for your OS and CPU from the Download page. Files are served from Cloudflare R2, not GitHub Releases, and only the 10 most recent versions are kept.

OSFiles
macOS (Apple silicon / Intel)MOVIE-ADE-<version>-mac-arm64.dmg, MOVIE-ADE-<version>-mac-x64.dmg
Windows (x64 / arm64)MOVIE-ADE-<version>-win-x64.exe, MOVIE-ADE-<version>-win-arm64.exe (NSIS installer)
Linux (x64)MOVIE-ADE-<version>-linux-x86_64.AppImage, MOVIE-ADE-<version>-linux-amd64.deb

MOVIE-ADE is tested on macOS (Apple silicon). The Windows and Linux builds are marked Preview: they are built and published, but not yet validated on real machines.

#Verify the download (sha256)

There is no SHA256SUMS file. Each release has releases/<version>/manifest.json on the download server, and its files[].sha256 field holds the expected hash of every file. versions.json lists the available versions.

# the download server (currently the R2 public URL; it may move to a custom domain)
BASE=https://pub-588d93b3e875464f98d6cf98dc711a0c.r2.dev
VERSION=0.1.1

# expected hashes
curl -s $BASE/releases/$VERSION/manifest.json | jq -r '.files[] | "\(.sha256)  \(.name)"'

# macOS
shasum -a 256 MOVIE-ADE-<version>-mac-arm64.dmg
# Linux
sha256sum MOVIE-ADE-<version>-linux-x86_64.AppImage
# Windows (PowerShell)
Get-FileHash .\MOVIE-ADE-<version>-win-x64.exe -Algorithm SHA256

Compare the output with the manifest. A match only proves the file is what was uploaded. The builds are not code-signed.

#macOS

  1. Open the .dmg and drag MOVIE-ADE.app to /Applications.
  2. Launch it. macOS says the developer cannot be verified. Close the dialog.
  3. Open System Settings → Privacy & Security, scroll down, and click Open Anyway next to the MOVIE-ADE message.
  4. Confirm with Open. Later launches work normally.

If macOS says the app "is damaged", remove the quarantine attribute:

xattr -dr com.apple.quarantine /Applications/MOVIE-ADE.app

#Windows (Preview)

  1. Run MOVIE-ADE-<version>-win-<arch>.exe.
  2. When SmartScreen shows "Windows protected your PC", click More info, then Run anyway.
  3. Choose the install folder. The installer creates a desktop shortcut.

#Linux (Preview)

AppImage:

chmod +x MOVIE-ADE-<version>-linux-x86_64.AppImage
./MOVIE-ADE-<version>-linux-x86_64.AppImage

Debian / Ubuntu:

sudo apt install ./MOVIE-ADE-<version>-linux-amd64.deb

The deb installs the movie-ade package and command.

#Build from source

Requires Node.js 20+ (CI and local development use 22), pnpm, and git.

git clone https://github.com/JapanMarketing-Dev/MOVIE-ADE.git
cd MOVIE-ADE
pnpm install          # postinstall prepares node-pty for Electron
pnpm dev              # run in development mode

To package installers (output in dist/release/, config in electron-builder.config.cjs). The Linux build only runs on Linux.

pnpm dist:mac     # dmg (arm64, x64)
pnpm dist:win     # NSIS installers (x64, arm64)
pnpm dist:linux   # AppImage + deb (x64)

The build:<os>:dev scripts produce an unpacked app only (--dir), which is faster for local testing.

On Windows, pnpm install uses node-pty's bundled prebuilt binaries instead of rebuilding (that would need the Visual Studio C++ build tools). Set ADE_FORCE_NATIVE_REBUILD=1 to force a rebuild.

If the terminal reports that node-pty could not be loaded, run pnpm rebuild:native.

#Updates

MOVIE-ADE does not auto-update. In the footer, open Updates and click Check for Updates. It fetches latest.json from the download server (R2), compares versions, and links to the download page. Nothing is checked until you click, and nothing is installed automatically.
