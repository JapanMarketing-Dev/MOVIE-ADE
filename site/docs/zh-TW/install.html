從這裡開始

安裝

下載適用於你電腦的 Ferret 並開啟。它可在 macOS、Windows 與 Linux 上執行。

#下載

下載頁面會提供適合你電腦的檔案。按一下下載按鈕即可。

#macOS

開啟 .dmg，將 Ferret 拖到 Applications，然後從那裡開啟。

#Windows

執行下載的 .exe。Ferret 會完成安裝並開啟，過程中不需要做任何選擇。之後請從「開始」功能表或桌面捷徑開啟。

如果 Windows 顯示 Windows 已保護您的電腦，請按一下 其他資訊，再按 仍要執行。

#Linux

Ubuntu / Debian：按兩下 .deb，用軟體中心安裝，或執行：

sudo apt install ./Ferret-<version>-linux-amd64.deb

接著從應用程式選單開啟 Ferret，或執行 ferret。

其他發行版：請使用 .AppImage。AppImage 需要 FUSE 2 才能執行，若系統尚未安裝，請先安裝對應的套件：Fedora 為 fuse-libs，Arch 為 fuse2，openSUSE 與以 Debian 為基礎的系統為 libfuse2。接著允許 .AppImage 以程式執行（按右鍵 → 內容，或使用 chmod +x），然後開啟。
