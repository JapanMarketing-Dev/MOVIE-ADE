設定

設定參考

從標題列的齒輪圖示開啟 設定。錄製期間無法變更設定。

#麥克風

設定預設值
錄下我的聲音開啟
麥克風系統預設
也錄下對方的聲音（會議）關閉

#轉錄

設定預設值
語言（說話的語言）自動
引擎本機（免費）
模型（本機）large-v3-turbo（建議）
端點 Base URL / 模型（相容端點）空白
OpenAI API 金鑰 / Endpoint API key（選填）未設定
費用上限每份審查最多 $1

請參閱轉錄與費用。

#儲存

設定預設值
保留錄影：7 天 / 30 天 / 永久7 天
停止後停留在意見畫面關閉

#Agent

設定預設值
開啟專案時啟動Claude Code、Codex（可選擇任何支援的 Agent，或都不選）
在選單中顯示 <agent>所有 Agent 皆開啟
啟動 Agent 時略過權限確認開啟：Claude Code 以 --dangerously-skip-permissions 啟動，Codex 以 --dangerously-bypass-approvals-and-sandbox 啟動（詳細說明）
Agent 完成或需要我確認時通知我關閉（詳細說明）
指令 / 參數（每個 Agent）該 Agent 本身的指令（例如 claude、codex、gemini）/ Claude Code 為 --chrome，其他為無
自訂 Agent無（新增自訂 Agent 可登錄任何 CLI）
給 Agent 的指示內建文字（變數）

#達到用量上限時自動切換

設定預設值
達到用量上限時自動切換開啟
帳號用量達到此值即視為上限95%
先切換到同一個 Agent 的其他帳號開啟
Agent 順序Claude Code、Codex、Gemini CLI
上限恢復後切回順序較前的 Agent關閉

位於 設定 → 帳號。工作會透過專案中的 .ferret/handoff.md 交接。請參閱達到用量上限時繼續工作。

#帳號、GitHub、外觀、語言

  • 帳號：請參閱帳號與用量。
  • GitHub / GitLab：gh 與 glab 的登入。請參閱傳送到 GitHub 或 GitLab。
  • CLI 工具：安裝並登入各服務的 CLI。請參閱 CLI 工具。
  • 外觀 → 主題：跟隨系統（預設）、淺色、深色。
  • 語言 → 介面：跟隨系統（預設；Ferret 支援作業系統的語言時就使用該語言，否則使用英文），或 14 種語言之一：English、日本語、简体中文、繁體中文、한국어、Español、Français、Deutsch、Italiano、Português (Brasil)、Русский、हिन्दी、Bahasa Indonesia、Tiếng Việt。

從頁尾可以設定：終端機的位置（右側 / 下方）以及麥克風開關。

#settings.json

以上所有設定都儲存在 ~/.ferret/settings.json（所有作業系統都是相同路徑），旁邊附有 JSON Schema。你可以在 App 執行時手動編輯，或交給你的程式設計 Agent 編輯；變更會立即生效。請參閱用 settings.json 設定。
