使用 Ferret

編輯器與預覽

開啟並編輯專案檔案，以及預覽 Markdown 與 Mermaid。在內建瀏覽器中開啟的預覽，可以像任何網頁一樣錄製並審查。

快速鍵顯示為

#開啟並編輯檔案

  • 檔案（檔案樹）：⌘⇧E / CtrlShiftE，提供 依檔名篩選、重新整理 與 全部收合。
  • 前往檔案…：⌘P / CtrlP。
  • 從 Finder（Windows 上為檔案總管，Linux 上為檔案管理員）把檔案拖到分頁列或編輯器上即可開啟。專案中的檔案會在編輯器或檢視器中開啟。若要把專案外的檔案帶進來，請把它放到 檔案 上，它會被複製到專案中。放到這裡的資料夾會以專案開啟。從 檔案 拖出的檔案也以相同方式開啟。圖片與影片放到已開啟的 Markdown 檔案上時，則會改為嵌入該檔案（請參閱在 Markdown 中嵌入圖片與影片）。
  • 按 ⌘S / CtrlS 儲存。關閉已修改的檔案時，會詢問 要儲存對 <name> 的變更嗎？，並提供 儲存、不儲存 與 取消。
  • 如果在你有未儲存的編輯時，檔案在磁碟上被變更，請選擇 從磁碟重新載入 或 保留我的變更。

編輯器使用 Monaco。非文字檔案會改用檢視器開啟：圖片（可放大縮小；SVG 也能以程式碼顯示）、附播放進度列的影片與音訊、PDF，其他二進位檔案則顯示檔案大小與開頭位元組的十六進位檢視。檢視器為唯讀，專案資料夾外的檔案，或經由指向資料夾外的符號連結才能到達的檔案，都不會顯示。

#在檔案樹中操作檔案

可以直接在 檔案 中操作檔案，就像在 VS Code 中一樣。在項目上按右鍵；若要在專案最上層操作，請在樹狀結構下方的空白處按右鍵。名稱直接在樹狀結構中輸入。

  • 新增檔案 / 新增資料夾：使用樹狀結構上方的按鈕，或按右鍵。新項目會建立在選取的資料夾中、選取的檔案旁，或專案的最上層。輸入含斜線的名稱（例如 src/routes/index.ts）會一併建立途中的資料夾。新檔案會在編輯器中開啟。在空的資料夾中，檔案 會顯示 此資料夾是空的，以及 新增檔案 和 新增資料夾 按鈕。
  • 剪下、複製 與 貼上：⌘X / CtrlX、⌘C / CtrlC、⌘V / CtrlV，或按右鍵。資料夾會連同其中的所有內容一起複製。製作副本 會在原項目旁建立一份副本。如果名稱已被使用，副本會命名為 name copy，接著是 name copy 2。
  • 把項目拖到資料夾上（拖到空白處則移到專案最上層）即可移動。放下時按住 ⌥ / Ctrl 則改為複製。從 Finder（Windows 上為檔案總管）拖入的檔案和資料夾會被複製到專案中，原始檔案保留在原處。
  • 重新命名：F2 / Enter / F2，或按右鍵。
  • 刪除：⌘⌫ / Delete / Delete，或按右鍵。Ferret 會先詢問，再把項目移到垃圾桶（Windows 上為資源回收筒），因此可以復原。已刪除檔案的分頁會關閉；如果其中有未儲存的編輯，確認訊息會提到這點。
  • 復原：⌘Z / CtrlZ 會復原上一次的新增、重新命名、移動、貼上或製作副本。已刪除的項目會從垃圾桶還原。
  • 複製路徑（⌥⌘C / ShiftAltC）與 複製相對路徑（⌥⇧⌘C / CtrlShiftAltC）會把路徑放到剪貼簿。
  • 在 Finder 中顯示（Windows 上為 在檔案總管中顯示，Linux 上為 開啟所在的資料夾）：⌥⌘R / ShiftAltR。在終端機中開啟 會在該資料夾（若是檔案，則為其所在資料夾）開啟新的終端機分頁。
  • 對於檔案，開啟 會在編輯器中開啟，用預設應用程式開啟 會以作業系統為該類型檔案指定的 App 開啟。
  • 用 ⌘ / Ctrl-按一下或 ⇧ / Shift-按一下選取多個項目，即可一起剪下、複製、移動或刪除。
  • Esc 會取消正在輸入的名稱。

已開啟的分頁會跟著重新命名或移動的檔案，並保留未儲存的編輯。Ferret 不會覆寫同名的現有檔案或資料夾，並會把一切都限制在專案資料夾內：它會拒絕 ..、絕對路徑、指向外部的符號連結、.git 內的任何項目、把資料夾移到自身之中，以及某些作業系統無法使用的名稱：/ \ < > : " | ? *、控制字元、結尾的空格或句點，以及 CON 或 NUL 等 Windows 保留名稱。一次複製或拖放最多可包含 10,000 個項目、1 GB。

#Markdown 與 Mermaid 預覽

預覽支援 .md、.markdown、.mdx、.mmd 與 .mermaid。Mermaid 已內建於 App 中，因此離線也能繪製圖表。

Markdown 檔案在編輯器上方有兩種檢視：原始碼 與 預覽。預覽隨時都可以編輯，因此可以直接在其中輸入；按一下 原始碼 即可回到文字。兩者顯示相同的內容，儲存、未儲存標記與關閉時的確認也都相同。

  • 可以直接在標題、段落、清單、核取方塊、表格、連結，以及粗體、斜體或行內程式碼中輸入。在行首輸入 #、-、1. 或 > 再加一個空格，即可開始標題、清單或引言。
  • 在行首（或空格之後）輸入 /，即可從清單中選擇區塊：標題、項目符號清單、編號清單或核取清單、表格、程式碼區塊、引用或分隔線。每一項都會說明它產生什麼，以及在 Markdown 中如何撰寫。繼續輸入可以篩選，用 ↑ ↓ 和 Enter 選擇，或按 Esc 將 / 保留為文字。表格一開始是帶標題列的 3 × 3；Tab 移到下一個儲存格，在最後會新增一列。在表格中輸入 / 可以新增或刪除列與欄，或刪除整個表格。
  • 程式碼區塊以原始碼編輯，並在角落顯示語言。Mermaid 程式碼區塊（mermaid 或 mmd）預設顯示圖表。點選右上角的 程式碼 或雙擊圖表即可編輯原始碼；游標移出區塊後會再顯示圖表。原始碼有錯誤時，會顯示錯誤訊息和 修改程式碼。圖表在沙箱框架中繪製，儲存的 Markdown 保持原樣。
  • 前置資料（最上方的 --- 區塊）會以文字顯示在文件上方，並可在那裡編輯。
  • 未變更的部分會照原樣儲存，包括標題樣式、清單符號、空行、表格對齊與換行字元。編輯過的區塊會盡量保留原本的樣式；無法保留時，該區塊會以標準 Markdown 形式寫出，清單用 -，標題用 #。
  • 專案中的圖片與影片會顯示。不會載入其他網站的圖片，而是改為顯示其主機名稱。檔案中的其他 HTML 會以文字顯示。

.mdx 檔案（僅以原始碼編輯）、.mmd 與 .mermaid 檔案則改為提供唯讀預覽：

  • 在側邊開啟預覽：在編輯器旁邊
  • 開啟預覽：在內建瀏覽器中（ade-preview://），因此可以錄製並審查

#在 Markdown 中嵌入圖片與影片

把圖片（PNG、JPEG、GIF、WebP、SVG、AVIF）或影片（MP4、WebM、MOV）拖到 Markdown 檔案上（原始碼 或 預覽 皆可），即可嵌入到放下的位置。

  • 已在專案中的檔案（包括從 檔案 拖出的檔案）會以相對於該 Markdown 檔案的路徑連結，不會複製任何內容。
  • 專案外的檔案（來自 Finder、桌面，或 Windows 上的檔案總管）會先複製到 Markdown 檔案旁的資料夾：若已有 assets、images、media 或 img，就複製到其中，否則建立新的 assets 資料夾。名稱中的空格會變成 -，如果名稱已被使用，副本會命名為 name-2。原始檔案保留在原處。
  • 圖片寫成 ![name](assets/name.png)，影片寫成 <video src="assets/name.mp4" controls></video>，GitHub 也能播放。兩者都會在 預覽 中顯示。
  • 單一圖片最大 50 MB，單一影片最大 500 MB，一次拖放最多複製 50 個檔案、共 1 GB。一起放下的其他檔案會照常在編輯器中開啟。

#用錄製來審查文件

  1. 在 審查目標 面板中，從 檔案 開啟 Markdown 檔案。它會在內建瀏覽器中以預覽開啟。
  2. 照常錄製。一邊說明規格書或設計文件，一邊圈出有問題的地方。
  3. 停止。意見會以檔案相對於專案的路徑來參照，而不是 URL。
  4. 按 傳送給 Agent，讓 Agent 修正文件。
