鍵盤快速鍵

快速鍵會依你目前閱讀所用的作業系統顯示；可用下方的切換開關查看另一種。大多數快速鍵在 Windows 與 Linux 上使用 Ctrl 的地方，macOS 改用 Command；使用 Alt 的地方，macOS 改用 Option。少數快速鍵差異更大，表格中會同時列出兩者。來源：src/main/menu.ts、src/shared/browserNav.ts、src/shared/annotation.ts，以及終端機的按鍵處理。

快速鍵顯示為

#錄製

動作macOSWindows / Linux
開始 / 停止錄製⌘⇧RCtrlShiftR
切換模式（編輯器 / 意見）⌘⇧MCtrlShiftM
按住時使用畫筆⌥Alt

#錄製時繪圖

動作macOSWindows / Linux
畫筆PP
方框B / RB / R
操作頁面（停止繪圖）V / EscV / Esc
下一個顏色CC
復原上一個標記⌘ZCtrlZ
重做⌘⇧ZCtrlShiftZ / CtrlY

這些按鍵在錄製內建瀏覽器且頁面取得焦點時有效。在頁面上的欄位中輸入文字時會被忽略，而字母鍵只有在未按修飾鍵時才有效，因此頁面本身的快速鍵仍可照常使用。

#瀏覽器與檢視

動作macOSWindows / Linux
聚焦網址列⌘LCtrlL
重新載入頁面⌘RCtrlR
上一頁⌘[Alt←
下一頁⌘]Alt→
切換桌面 / 行動版寬度⌘⇧VCtrlShiftV
切換側邊欄⌘BCtrlB
切換檔案樹⌘⇧ECtrlShiftE
切換審查目標⌘⇧KCtrlShiftK

#檔案

動作macOSWindows / Linux
開啟專案資料夾…⌘OCtrlO
前往檔案…⌘PCtrlP
儲存⌘SCtrlS
在檔案樹中重新命名F2 / EnterF2
在檔案樹中刪除⌘⌫ / DeleteDelete
在檔案樹中剪下 / 複製 / 貼上⌘X / ⌘C / ⌘VCtrlX / CtrlC / CtrlV
在檔案樹中復原⌘ZCtrlZ
複製路徑⌥⌘CShiftAltC
複製相對路徑⌥⇧⌘CCtrlShiftAltC
在 Finder / 檔案總管中顯示⌥⌘RShiftAltR

檔案樹的快速鍵在 檔案 中的某個項目取得焦點時可用。

#終端機

動作macOSWindows / Linux
新增終端機⌘TCtrlT
關閉窗格 / 分頁⌘WCtrlW
向右分割⌘DCtrlShiftD
向下分割⌘⇧DAltShiftD
拷貝選取的文字⌘CCtrlShiftC / CtrlC
貼上⌘VCtrlV / CtrlShiftV / ShiftInsert
在 Agent 的提示中換行⇧EnterShiftEnter
移到行首 / 行尾⌘← / ⌘→—
刪除到行首⌘⌫—

這些快速鍵在終端機取得焦點時有效。在 Windows 與 Linux 上，有選取文字時 Ctrl+C 會拷貝，沒有選取時則會停止正在執行的指令。執行 Claude Code 或 Codex 等 Agent 時，⇧Enter / ShiftEnter 會換行；在一般的 shell 中，它會像 Enter 一樣執行指令。在使用滑鼠的全螢幕程式（vim、tmux、Agent）中，macOS 上請按住 Option 鍵再拖曳來選取文字。

#視窗與設定

動作macOSWindows / Linux
設定…⌘,Ctrl,
關閉視窗⌘⇧W—
縮到最小⌘M—

Windows 與 Linux 沒有關閉視窗的快速鍵：檔案 → 結束 會結束 App。
