使用 Ferret

錄製

錄製內建瀏覽器、整個螢幕、其他視窗、桌面應用程式、遊戲或手機模擬器。一邊操作頁面，一邊說話、圈選與輸入。

快速鍵顯示為

#選擇要錄製的內容

在意見模式中，按一下 選擇錄製目標。錄製目標 對話框提供以下選項：

目標擷取的內容
內建瀏覽器（預設）影像、語音與畫筆，以及 URL、元素選擇器、點擊與捲動。不需要作業系統權限。
整個螢幕影像、語音與畫筆。沒有 URL、元素與操作記錄（feedback.md 中會註明這一點）。
視窗同上。每個視窗都會連同其應用程式名稱一起列出。Ferret 本身的視窗不會列出。
手機同上，只列出 iOS Simulator 與 Android Emulator 的視窗。

你的選擇會被記住。在 macOS 上，擷取螢幕與視窗需要螢幕錄製權限（授予方式）。

#桌面應用程式、遊戲與行動應用程式

若要審查你正在開發的桌面應用程式（Electron、Tauri 或原生應用程式），請像平常開發時一樣啟動它，然後在 視窗 下選擇它的視窗。視窗會連同應用程式名稱一起列出，因此 Electron 應用程式的開發版本會顯示為 Electron。小視窗與始終顯示在其他視窗之上的視窗也會列出；在 macOS 上，始終置頂的視窗會以應用程式名稱與標題顯示，而不是預覽圖。

所選內容會跟著應用程式走。重新啟動應用程式、它的視窗再次出現後，下一次錄製會使用標題相同的視窗；若標題已改變，則使用該應用程式唯一的視窗。

行動應用程式請啟動 iOS Simulator（Xcode，macOS）或 Android Emulator（Android Studio），然後在 手機 下選擇裝置。若模擬器在 Android Studio 內執行，請讓它在獨立視窗中開啟（在 Android Studio 的設定中，於 Tools → Emulator 下關閉在 Running Devices 工具視窗中啟動），這樣它就會列出。

feedback.md 開頭寫的不是 URL，而是你錄製的內容：應用程式與視窗標題；若是模擬器，則是裝置名稱與作業系統版本，在 Android 上還包括前景中的應用程式。它也會告訴 Agent 去修改該應用程式的原始碼。Ferret 在錄製開始時透過 xcrun simctl 與 adb（來自 ANDROID_HOME、ANDROID_SDK_ROOT 或 Android Studio 的 SDK 資料夾）讀取裝置資訊。影像中只會顯示所選的視窗，所以請邊說邊講清楚你指的是什麼。

遊戲的用法相同。選擇顯示著遊戲檢視的 Unity、Unreal Engine 或 Godot 編輯器視窗，或你建置的遊戲視窗（包括無邊框視窗模式）。若遊戲為獨占全螢幕，請在 整個螢幕 下選擇它所在的顯示器。當視窗是這些編輯器之一時，feedback.md 會寫明引擎，並請 Agent 修改遊戲的程式碼、場景或素材。為了讓檔案保持精簡，影像最多以每秒 10 格錄製；問題的圖片也取自同一段影像，因此與時間軸上的那一刻一致。

審查目標的 要錄製的視窗 除了視窗標題，也會比對應用程式名稱，因此填入 Simulator 時，無論顯示的是哪個裝置，都會選到 iOS Simulator 的視窗。

#用分頁開啟多個頁面

內建瀏覽器支援分頁：編輯器模式下位於瀏覽器工具列上方，回饋模式下位於 URL 欄旁邊。點選新分頁（⌘T / CtrlT）開啟空白分頁，再輸入 URL，例如開啟網頁郵件查看登入驗證碼。點選分頁或按 ⌘1 / Ctrl1 到 ⌘9 / Ctrl9、⌃Tab / CtrlTab 切換，點選分頁上的 × 或按 ⌘W / CtrlW 關閉。焦點在頁面、分頁或 URL 欄時，以及在回饋模式下，⌘T / CtrlT 與 ⌘W / CtrlW 會作用於分頁；在終端機中仍用於開啟與關閉終端機。在新分頁開啟的連結（target="_blank"）和未指定大小的 window.open 會在新分頁中開啟。指定大小的登入彈出視窗仍會在獨立的視窗中開啟。

所有分頁共用相同的登入狀態與 Cookie，可以在一個分頁複製、在另一個分頁貼上。最多可開啟 20 個分頁。頁面只有在你剛點選或在其中輸入後才能開啟分頁，否則連結會在目前的分頁中開啟。

錄製內建瀏覽器時切換分頁，會把切換到的分頁錄成獨立的影片（請參閱同時錄製多個視窗），操作記錄會記下切換與頁面，因此每則回饋都與其頁面相連。畫筆與方框在每個分頁都能使用。空白分頁會在載入頁面後開始錄製。

分頁依專案區分。切換專案時，會關閉目前開啟的分頁，並開啟目標專案的分頁；切換回來時分頁會還原，在 Ferret 未關閉期間，上一頁和下一頁的紀錄也會還原（重新啟動後只還原頁面，不還原這些紀錄）。回饋模式中審查目標下列出的已造訪頁面也依專案保存。登入狀態和 Cookie 仍由所有專案共用。

如果網站回傳 Cloudflare 的驗證（Verify you are human），Ferret 會用表明自己是 Electron 的使用者代理重新載入該頁面一次，並在 Ferret 結束前對該網站一直使用它。在其他網站上，內建瀏覽器以與 Chrome 相同的方式標識自己，讓 Google 等登入頁面能正常運作。

#從瀏覽器匯入密碼和瀏覽紀錄

在 設定 → 從瀏覽器匯入 中，可以把常用瀏覽器的登入資訊和瀏覽紀錄匯入進來。

  • 密碼：先用瀏覽器內建的功能把密碼匯出為 CSV，再點選 匯入密碼 CSV… 並選擇它。Chrome / Edge：密碼管理工具 → 設定 → 匯出密碼。Safari：檔案 → 輸出 → 密碼。Firefox：密碼 → ⋯ → 匯出密碼。Ferret 不會讀取瀏覽器加密儲存的密碼。匯出的 CSV 中密碼是明文，匯入後請刪除它（並清空垃圾桶）。
  • 在有已儲存密碼的網站頁面上，編輯模式的瀏覽器工具列會出現一個鑰匙按鈕。點選它即可填入使用者名稱和密碼（有多個帳號時可選擇）。只會填入來源與儲存的一致的頁面（通訊協定、主機和連接埠相同；www. 可以不同），而且只填入最上層的框架，不會填入 iframe 中的登入表單。
  • 瀏覽紀錄：尋找瀏覽器 會列出這台電腦上 Chrome、Edge、Brave、Chromium、Arc（macOS）和 Safari（macOS）的設定檔，匯入瀏覽紀錄 會把它們的瀏覽紀錄匯入為 URL 列的建議。匯入的瀏覽紀錄由所有專案共用，只用於建議。讀取 Safari 瀏覽紀錄需要為 Ferret 開啟完整磁碟取用權限（系統設定 → 隱私權與安全性）。

密碼用 Electron 的 safeStorage 加密，儲存在 <userData>/browser-import/passwords.bin；匯入的瀏覽紀錄儲存在 browser-import/history.json。用 全部刪除 和 刪除匯入的瀏覽紀錄 可以刪除它們。在開發版本和無法使用 safeStorage 的系統上，匯入的密碼只保留到 Ferret 結束為止。

#瀏覽器擴充功能

在 設定 → 瀏覽器擴充功能 中為內建瀏覽器加入 Chrome 擴充功能：含有 manifest.json 的資料夾用 加入已解壓縮的資料夾…，已安裝在 Chrome、Edge、Brave 或 Chromium 中的擴充功能用 從 Chrome 匯入… 複製過來。擴充功能只在內建瀏覽器中執行，不會進入 Ferret 自身的視窗。擴充功能可以讀取與修改你在其中開啟的所有頁面，並使用其中的登入狀態，所以請只加入你信任的擴充功能。

用瀏覽器工具列或回饋工具列中的 擴充功能 開啟擴充功能的彈出視窗。它在頁面右上角開啟，點擊其他地方或按 Esc 即關閉。錄製 內建瀏覽器 時，擴充功能在頁面中造成的變化和開啟的彈出視窗都會出現在影片和圖片中。Electron 只支援部分擴充功能 API：側邊面板、右鍵選單、通知、鍵盤快捷鍵，以及擴充功能開啟的分頁或視窗都無法使用，也無法載入封裝的 .crx 檔案。

彈出視窗上也可以標註。錄製時點選工具列不會關閉擴充功能的彈出視窗。選取畫筆或方框時，或 文字回饋 開啟時，點選頁面也不會關閉它，Esc 會關閉工具而不是關閉彈出視窗。在彈出視窗裡畫的標註會依彈出視窗的位置出現在影片和圖片中。僅適用於開始錄製或 文字回饋 之後開啟的彈出視窗。頁面在獨立視窗中開啟的登入彈出視窗（例如使用 Google 登入）在開啟期間會錄製為獨立的影片。它來到前景時，畫筆和方框會畫在其中；點選頁面即切換回來。登入完成後它仍會自動關閉。

#同時錄製多個視窗

一次錄製可以同時錄下最多 4 個畫面：內建瀏覽器、桌面應用程式的視窗與螢幕。每個畫面都各自錄成一個影片，直到停止錄製，因此在它們之間來回切換的流程（例如 Web 應用程式開啟桌面應用程式後再回來）也能從頭到尾錄下。

  1. 錄製中，點選錄製列中的 +（同時錄製另一個視窗），然後選擇一個視窗、螢幕或內建瀏覽器。在 審查目標 面板中點選視窗目標也一樣。
  2. 點選錄製列中的標籤即可切換顯示的畫面。畫筆與意見的圖片會跟著目前顯示的畫面；其他畫面在背景繼續以每秒最多 5 格錄製。

也可以等待尚未開啟的視窗。在 編輯專案… 中為目標填入 要錄製的視窗（應用程式名稱、視窗標題的一部分、com.example.MyApp 這類 macOS bundle ID，或應用程式的路徑），並把 錄製中開啟時 設為 一起錄製 或 錄製並切換過去。在 settings.json 中對應 "watch": "record" 或 "watch": "switch"。錄製中，Ferret 每秒檢查一次視窗清單。視窗開啟前，目標會以虛線標籤顯示；應用程式關閉後再次開啟時也會重新錄製。

每次切換都會寫入操作記錄，因此每則意見都知道它針對哪個畫面。顯示應用程式視窗期間的意見不帶 URL 與元素資訊，在 意見 與 feedback.md 中歸到該視窗之下，並告訴 Agent 這是應用程式視窗。額外的影片存放在審查資料夾的 tracks/ 下，開始與結束時間記錄在 tracks.jsonl。在 Windows 與 Linux 上只能得知視窗標題，所以用名稱去比對標題。在 Linux 的 Wayland 下無法等待視窗，因為每次列出視窗都會要求你選擇一個；請在視窗開啟後用 + 加入。

#開始、暫停、停止

  1. 在內建瀏覽器中開啟要審查的頁面。
  2. 按標題列中的 錄製，或按 ⌘⇧R / CtrlShiftR。
  3. 暫停 會停止繪圖與計時器。繼續 會接著錄製。
  4. 按 停止，或再按一次 ⌘⇧R / CtrlShiftR。

在側邊欄中，每個專案都有自己的 新增審查（或該列上的 +，即 在 <name> 中新增審查）。在其他專案上使用時，會先切換到該專案，再開始錄製。如果有其他錄製正在進行，則不會開始。

每次錄製的上限為 90 分鐘。接近上限時會出現警告，達到上限時會自動停止並儲存。

#畫筆

  • 畫筆：選取它，或按住 ⌥ / Alt，只在按住時繪圖（在欄位中輸入文字時會被忽略）。
  • 清除：移除目前的標記。

一邊談論某個位置，一邊把它圈起來：話語與標記會歸入同一則意見。畫筆只在錄製時可用。錄製時沒有文字工具：請直接用說的，或之後用文字回饋輸入。畫筆、方框與顏色的按鍵列在鍵盤快速鍵中。

#不用說的，改用文字回饋

不方便說話時，可以改用文字輸入回饋。在編輯模式和回饋模式下都可以使用，但不能在錄製時使用。

  1. 點選 文字回饋：它位於右上角錄製按鈕的右側、瀏覽器工具列，以及回饋模式的工具列中。在編輯模式下會先切換到 瀏覽器 分頁；在回饋模式下會關閉畫筆和框。
  2. 在頁面上拖曳，框住要修改的位置；也可以點選某個元素，直接把它框起來。
  3. 輸入要怎麼改。Enter 新增，⇧Enter / ShiftEnter 換行，Esc 取消方框。用輸入法選字時按下的 Enter 不會新增。

每一則都會成為一則意見，附上頁面與方框的圖片、URL 以及框住的元素，和錄製得到的意見一樣。它會加入 意見 中開啟的審查；沒有開啟的審查時會建立新的。瀏覽器維持在前面，可以連續新增多則；在沒有方框時按 Esc，或再按一次按鈕即可結束。在瀏覽器位置顯示的桌面應用程式或模擬器視窗上也能同樣使用（不附 URL）。

#用分享連結收集任何人的回饋

想從不使用 Ferret 的人（客戶、設計師、同事）那裡取得回饋，就把分享連結傳給他們。對方不需要帳號，也不需要安裝 App：在瀏覽器中開啟連結，在頁面截圖上做標記，並寫下需要修改的地方。名字可以不填。

  1. 在內建瀏覽器中開啟頁面（僅限 http 或 https），然後點選瀏覽器工具列中的 分享。
  2. 可以填寫標題（不填則使用頁面標題），並開啟 允許回饋者互相看到彼此的意見。點選 為此頁面建立分享連結，Ferret 會擷取頁面的可見部分並上傳，然後複製連結（https://share.ferretade.dev/s/…）。
  3. 要在同一個連結加入更多頁面，開啟另一個頁面，然後在該分享上點選 加入此頁面（最多 20 個頁面）。

開啟連結的人可以在截圖上放置圖釘、畫框或用畫筆繪製，並輸入意見（最多 2,000 個字元）。Live page 會在框架中開啟原始頁面供對方操作，Annotate live 可以在上面放置圖釘；當時查看的 URL 會隨意見一起傳送。有些網站拒絕在框架中載入，此時對方可以在新分頁中開啟頁面，只用文字傳送意見。對方的頁面會依其瀏覽器顯示為日文或英文。

收到的意見會顯示在同一個 分享 視窗中。選擇意見後點選 匯入所選，或對不需要的意見點選 拒絕（復原 可以恢復）。匯入的意見會像 文字回饋 一樣成為新審查中的發現：帶有對方標記的截圖成為 BEFORE 圖片，並附上頁面 URL 以及對方的名字和意見。在即時頁面上放置的圖釘會顯示為圍住整張截圖的框，因為即時頁面的捲動位置可能與截圖不同。之後照常傳送給代理程式，並檢查 BEFORE 和 AFTER。

  • 任何拿到連結的人都能看到截圖並傳送意見，所以不要分享顯示私密資料的頁面。連結 30 天後過期。刪除 會立即刪除連結、截圖和意見。
  • 一個連結最多接收 500 則意見，伺服器也會限制傳送意見和建立連結的頻率。伺服器不儲存 IP 位址。
  • 分享連結依專案保存。Ferret 用來讀取和管理連結的擁有者權杖會用 Electron 的 safeStorage 加密，儲存在 <userData>/feedback-share/shares.bin。在開發版本和無法使用 safeStorage 的系統上，它只保留到 Ferret 結束為止（連結本身在過期前仍可使用）。
  • 伺服器的程式碼位於儲存庫的 workers/feedback-share。

#匯入會議

可以把關於產品的會議變成發現。在側邊欄中點選目前專案下的 匯入會議，然後加入錄製、逐字稿或兩者：

  • 錄製：選擇影片或音訊…（MP4、M4V、MOV、WebM、MKV、M4A、MP3、WAV、OGG 或 AAC）。它會被複製到新審查的資料夾中。
  • 逐字稿：開啟逐字稿檔案…（.txt、.md、.vtt、.srt 或 .docx），或直接貼上。Ferret 能讀取 WebVTT 和 SRT 字幕（Zoom、Google Meet）、時間列後接 名字: 內容 列的逐字稿（Google Meet、Gemini）、[00:12:34] 名字: 內容 列、名字 0:05 列後接內容（Circleback、Otter）、只有 名字: 內容 的列，或一般段落。Ferret 不連接這些服務，只讀取你提供的文字。

點選 匯入。沒有逐字稿時，Ferret 會依 轉錄 設定轉錄錄製的音訊（最長 3 小時的錄製）。接著由 整理 模型根據會議內容寫出候選發現。如果錄製有影片且逐字稿帶時間，每次發言時刻的畫面會成為該發現的 BEFORE 圖片。沒有時間的逐字稿也能匯入，但沒有畫面。

如果開啟了判定模型，Ferret 會對每個候選詢問一次會議是否要求對產品做具體修改；在使用能讀圖片的模型且有畫面時，還會詢問畫面是否顯示了所討論的畫面。每個候選會顯示 可能性 百分比，低於 50% 的候選開始時為未勾選。這些呼叫從 Ferret 經過與代理程式檢查相同的本機中繼，並計入相同的呼叫和費用上限。在你檢查候選之前，不會傳送任何內容給代理程式：編輯、取消勾選或保留它們，然後照常傳送。

#標記何時消失

標記屬於繪製當時的畫面。在下列情況下，標記會記錄到目前的意見中，然後清除：

  • 頁面導覽時：完整載入，或 SPA 路由變更到新的路徑或查詢字串。只變更雜湊時會保留標記。
  • 捲動頁面時
  • 一段語音結束時

#麥克風

麥克風預設為開啟。可從頁尾（關閉麥克風 / 開啟麥克風）或設定中的 錄下我的聲音 切換。在 麥克風 中選擇裝置。

#查看轉錄內容

錄製時，開啟回饋模式右側面板頂端的 轉錄 分頁，就能以文字查看你說的話與說話的時間（同時錄製會議對方的聲音時，也會顯示是誰說的）。說完稍作停頓，幾秒後就會出現文字，因此能及早確認所說的內容有被記錄下來。頂端一行會顯示 正在轉錄、等待中的段數，或轉錄停止的原因。

若轉錄失敗、未設定模型或金鑰、約 2 分鐘的語音沒有轉成文字，或麥克風沒有收到聲音，即使分頁已關閉，Ferret 也會提示一次，並在右側面板按鈕上加上標記。錄製會繼續，音訊也會保留。若要隱藏該分頁，請在 設定 → 轉錄 中關閉 錄製時顯示即時轉錄（回饋模式的右側面板）。警告仍會顯示。

#錄製時向 Agent 說明

回饋模式的右側面板還有一個 終端機 分頁。它不是新的 shell，而是與編輯器模式相同的終端機：同樣的分頁、同樣正在執行的 Agent（例如 Claude Code 或 Codex）及其歷史。在頂端選擇一個分頁並輸入，例如告訴 Agent localhost 沒有啟動。回到編輯器模式後，終端機維持同樣的狀態。錄製內建瀏覽器或其他應用程式的視窗時，不會錄進終端機。

#錄下會議中對方的聲音

在通話中一起審查頁面時，可以讓 Ferret 除了麥克風之外，也錄下你從電腦聽到的聲音。這適用於任何會議 App（Zoom、Google Meet、Microsoft Teams 等），因為 Ferret 錄的是電腦的音訊，而不是會議 App 本身。兩者會分開處理：麥克風會轉錄為 我，電腦的音訊則轉錄為 對方，因此每則意見都能看出是誰提出的要求。即使關閉麥克風也能使用。

  1. 照常在會議 App 中加入通話，麥克風與喇叭沿用該 App 自己的設定。
  2. 在設定中開啟 也錄下對方的聲音，或在頁尾的麥克風選單中開啟 也錄下其他人的聲音。錄製期間無法變更。
  3. 選擇要錄製的內容：要審查頁面時選 內建瀏覽器，觀看共用畫面時選 整個螢幕 / 視窗。
  4. 按 錄製，然後和其他人一起邊說明頁面、邊用畫筆圈出位置。
  5. 按 停止。雙方的聲音都會被轉錄並整理成意見。

請告知其他參與者你正在錄音。使用雲端轉錄服務時，他們的聲音也會傳送到該服務。

#各作業系統的系統音訊

作業系統需求權限
macOSmacOS 14.2 或更新版本。在較早的版本上，只會錄下你的麥克風。第一次錄製對方的聲音時，macOS 會詢問是否允許 Ferret 錄製系統音訊。如果你拒絕了，請在 系統設定 → 隱私權與安全性 → 螢幕與系統錄音 中開啟 Ferret，然後結束並重新開啟 Ferret。這不會錄下你的螢幕。
Windows在 設定 → 系統 → 音效 中有已啟用的播放裝置（喇叭或耳機）。不需要。會錄下預設的播放裝置。
LinuxPulseAudio，或裝有 pipewire-pulse 的 PipeWire（大多數桌面環境的預設）。不需要。會錄下預設的輸出。

如果無法錄下對方的聲音，Ferret 會在警告中說明原因，並繼續錄製你的麥克風、影片與畫筆。請參閱疑難排解。

#會議中的訣竅

  • 請使用耳機。使用喇叭時，你的麥克風也會收到對方的聲音。Ferret 在錄製對方聲音時會為麥克風開啟回音消除，並捨棄雙方都錄到的語句，但使用耳機能得到最乾淨的逐字稿。
  • 電腦播放的所有聲音都會被錄下，包括通知音效與影片。審查期間請把不需要的聲音靜音。
  • 錄製途中請勿切換音訊裝置。如果輸出裝置變更或被拔除，對方聲音的錄製會停止並顯示警告。麥克風、影片與畫筆會繼續錄製。之後可用 繼續錄製 補錄其餘部分。
