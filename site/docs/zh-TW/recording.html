使用 Ferret

錄製

錄製內建瀏覽器、整個螢幕、其他視窗、桌面應用程式、遊戲或手機模擬器。一邊操作頁面，一邊說話、圈選與輸入。

快速鍵顯示為

#選擇要錄製的內容

在意見模式中，按一下 選擇錄製目標。錄製目標 對話框提供以下選項：

目標擷取的內容
內建瀏覽器（預設）影像、語音與畫筆，以及 URL、元素選擇器、點擊與捲動。不需要作業系統權限。
整個螢幕影像、語音與畫筆。沒有 URL、元素與操作記錄（feedback.md 中會註明這一點）。
視窗同上。每個視窗都會連同其應用程式名稱一起列出。Ferret 本身的視窗不會列出。
手機同上，只列出 iOS Simulator 與 Android Emulator 的視窗。

你的選擇會被記住。在 macOS 上，擷取螢幕與視窗需要螢幕錄製權限（授予方式）。

#桌面應用程式、遊戲與行動應用程式

若要審查你正在開發的桌面應用程式（Electron、Tauri 或原生應用程式），請像平常開發時一樣啟動它，然後在 視窗 下選擇它的視窗。視窗會連同應用程式名稱一起列出，因此 Electron 應用程式的開發版本會顯示為 Electron。小視窗與始終顯示在其他視窗之上的視窗也會列出；在 macOS 上，始終置頂的視窗會以應用程式名稱與標題顯示，而不是預覽圖。

所選內容會跟著應用程式走。重新啟動應用程式、它的視窗再次出現後，下一次錄製會使用標題相同的視窗；若標題已改變，則使用該應用程式唯一的視窗。

行動應用程式請啟動 iOS Simulator（Xcode，macOS）或 Android Emulator（Android Studio），然後在 手機 下選擇裝置。若模擬器在 Android Studio 內執行，請讓它在獨立視窗中開啟（在 Android Studio 的設定中，於 Tools → Emulator 下關閉在 Running Devices 工具視窗中啟動），這樣它就會列出。

feedback.md 開頭寫的不是 URL，而是你錄製的內容：應用程式與視窗標題；若是模擬器，則是裝置名稱與作業系統版本，在 Android 上還包括前景中的應用程式。它也會告訴 Agent 去修改該應用程式的原始碼。Ferret 在錄製開始時透過 xcrun simctl 與 adb（來自 ANDROID_HOME、ANDROID_SDK_ROOT 或 Android Studio 的 SDK 資料夾）讀取裝置資訊。影像中只會顯示所選的視窗，所以請邊說邊講清楚你指的是什麼。

遊戲的用法相同。選擇顯示著遊戲檢視的 Unity、Unreal Engine 或 Godot 編輯器視窗，或你建置的遊戲視窗（包括無邊框視窗模式）。若遊戲為獨占全螢幕，請在 整個螢幕 下選擇它所在的顯示器。當視窗是這些編輯器之一時，feedback.md 會寫明引擎，並請 Agent 修改遊戲的程式碼、場景或素材。為了讓檔案保持精簡，影像最多以每秒 10 格錄製；問題的圖片也取自同一段影像，因此與時間軸上的那一刻一致。

審查目標的 要錄製的視窗 除了視窗標題，也會比對應用程式名稱，因此填入 Simulator 時，無論顯示的是哪個裝置，都會選到 iOS Simulator 的視窗。

#開始、暫停、停止

  1. 在內建瀏覽器中開啟要審查的頁面。
  2. 按標題列中的 錄製，或按 ⌘⇧R / CtrlShiftR。
  3. 暫停 會停止繪圖與計時器。繼續 會接著錄製。
  4. 按 停止，或再按一次 ⌘⇧R / CtrlShiftR。

在側邊欄中，每個專案都有自己的 新增審查（或該列上的 +，即 在 <name> 中新增審查）。在其他專案上使用時，會先切換到該專案，再開始錄製。如果有其他錄製正在進行，則不會開始。

每次錄製的上限為 90 分鐘。接近上限時會出現警告，達到上限時會自動停止並儲存。

#畫筆

  • 畫筆：選取它，或按住 ⌥ / Alt，只在按住時繪圖（在欄位中輸入文字時會被忽略）。
  • 清除：移除目前的標記。

一邊談論某個位置，一邊把它圈起來：話語與標記會歸入同一則意見。畫筆只在錄製時可用。沒有文字工具，請直接用說的。畫筆、方框與顏色的按鍵列在鍵盤快速鍵中。

#標記何時消失

標記屬於繪製當時的畫面。在下列情況下，標記會記錄到目前的意見中，然後清除：

  • 頁面導覽時：完整載入，或 SPA 路由變更到新的路徑或查詢字串。只變更雜湊時會保留標記。
  • 捲動頁面時
  • 一段語音結束時

#麥克風

麥克風預設為開啟。可從頁尾（關閉麥克風 / 開啟麥克風）或設定中的 錄下我的聲音 切換。在 麥克風 中選擇裝置。

#錄下會議中對方的聲音

在通話中一起審查頁面時，可以讓 Ferret 除了麥克風之外，也錄下你從電腦聽到的聲音。這適用於任何會議 App（Zoom、Google Meet、Microsoft Teams 等），因為 Ferret 錄的是電腦的音訊，而不是會議 App 本身。兩者會分開處理：麥克風會轉錄為 我，電腦的音訊則轉錄為 對方，因此每則意見都能看出是誰提出的要求。即使關閉麥克風也能使用。

  1. 照常在會議 App 中加入通話，麥克風與喇叭沿用該 App 自己的設定。
  2. 在設定中開啟 也錄下對方的聲音，或在頁尾的麥克風選單中開啟 也錄下其他人的聲音。錄製期間無法變更。
  3. 選擇要錄製的內容：要審查頁面時選 內建瀏覽器，觀看共用畫面時選 整個螢幕 / 視窗。
  4. 按 錄製，然後和其他人一起邊說明頁面、邊用畫筆圈出位置。
  5. 按 停止。雙方的聲音都會被轉錄並整理成意見。

請告知其他參與者你正在錄音。使用雲端轉錄服務時，他們的聲音也會傳送到該服務。

#各作業系統的系統音訊

作業系統需求權限
macOSmacOS 14.2 或更新版本。在較早的版本上，只會錄下你的麥克風。第一次錄製對方的聲音時，macOS 會詢問是否允許 Ferret 錄製系統音訊。如果你拒絕了，請在 系統設定 → 隱私權與安全性 → 螢幕與系統錄音 中開啟 Ferret，然後結束並重新開啟 Ferret。這不會錄下你的螢幕。
Windows在 設定 → 系統 → 音效 中有已啟用的播放裝置（喇叭或耳機）。不需要。會錄下預設的播放裝置。
LinuxPulseAudio，或裝有 pipewire-pulse 的 PipeWire（大多數桌面環境的預設）。不需要。會錄下預設的輸出。

如果無法錄下對方的聲音，Ferret 會在警告中說明原因，並繼續錄製你的麥克風、影片與畫筆。請參閱疑難排解。

#會議中的訣竅

  • 請使用耳機。使用喇叭時，你的麥克風也會收到對方的聲音。Ferret 在錄製對方聲音時會為麥克風開啟回音消除，並捨棄雙方都錄到的語句，但使用耳機能得到最乾淨的逐字稿。
  • 電腦播放的所有聲音都會被錄下，包括通知音效與影片。審查期間請把不需要的聲音靜音。
  • 錄製途中請勿切換音訊裝置。如果輸出裝置變更或被拔除，對方聲音的錄製會停止並顯示警告。麥克風、影片與畫筆會繼續錄製。之後可用 繼續錄製 補錄其餘部分。
