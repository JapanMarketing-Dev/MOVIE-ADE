使用 Ferret

录制

录制内置浏览器、整个屏幕、其他窗口、桌面应用、游戏或手机模拟器。一边使用页面，一边说话、圈画和打字。

#选择录制内容

在反馈模式下，点击 选择录制对象。录制对象 对话框提供以下选项：

对象录制内容
内置浏览器（默认）视频、语音和画笔，以及 URL、元素选择器、点击和滚动。不需要操作系统权限。
整个屏幕视频、语音和画笔。没有 URL、元素或操作记录（这一点会在 feedback.md 中注明）。
窗口同上。每个窗口都会连同其应用名称一起列出。Ferret 自己的窗口不会列出。
手机同上，只列出 iOS Simulator 和 Android Emulator 的窗口。

你的选择会被记住。在 macOS 上，录制屏幕和窗口需要“屏幕录制”权限（如何授予）。

#桌面应用、游戏和移动应用

要审查你正在开发的桌面应用（Electron、Tauri 或原生应用），像平时开发时那样启动它，然后在 窗口 下选择它的窗口。窗口会连同应用名称一起列出，因此 Electron 应用的开发版本会显示为 Electron。小窗口和始终显示在其他窗口之上的窗口也会列出；在 macOS 上，始终置顶的窗口会以应用名称和标题显示，而不是预览图。

所选内容会跟随应用。重新启动应用、它的窗口再次出现后，下一次录制会使用标题相同的窗口；如果标题变了，则使用该应用唯一的窗口。

对于移动应用，启动 iOS Simulator（Xcode，macOS）或 Android Emulator（Android Studio），然后在 手机 下选择设备。如果模拟器运行在 Android Studio 内部，请让它在独立窗口中打开（在 Android Studio 的设置中，于 Tools → Emulator 下关闭在 Running Devices 工具窗口中启动），这样它就会被列出。

feedback.md 开头写的不是 URL，而是你录制的内容：应用和窗口标题；如果是模拟器，则是设备名称和操作系统版本，在 Android 上还包括前台的应用。它还会告诉 Agent 去修改该应用的源代码。Ferret 在录制开始时通过 xcrun simctl 和 adb（来自 ANDROID_HOME、ANDROID_SDK_ROOT 或 Android Studio 的 SDK 文件夹）读取设备信息。图像中只显示所选的窗口，所以请边说边讲清你指的是什么。

游戏的用法相同。选择显示着游戏视图的 Unity、Unreal Engine 或 Godot 编辑器窗口，或者你构建的游戏的窗口（包括无边框窗口模式）。对于独占全屏的游戏，请在 整个屏幕 下选择它所在的显示器。当窗口是这些编辑器之一时，feedback.md 会写明引擎，并让 Agent 修改游戏的代码、场景或资源。为了让文件保持较小，视频最多以每秒 10 帧录制；问题的图像也取自同一段视频，因此与时间轴上的那一刻一致。

审查对象的 要录制的窗口 既匹配窗口标题，也匹配应用名称，因此填写 Simulator 时，无论显示的是哪台设备，都会选中 iOS Simulator 的窗口。

#用标签页打开多个页面

内置浏览器支持标签页：编辑器模式下在浏览器工具栏上方，反馈模式下在 URL 栏旁边。点击新标签页（⌘T / CtrlT）打开一个空标签页，然后输入 URL，例如打开网页邮箱查看登录验证码。点击标签页或按 ⌘1 / Ctrl1 到 ⌘9 / Ctrl9、⌃Tab / CtrlTab 切换，点击标签页上的 × 或按 ⌘W / CtrlW 关闭。当焦点在页面、标签页或 URL 栏上时，以及在反馈模式下，⌘T / CtrlT 和 ⌘W / CtrlW 作用于标签页；在终端中它们仍然用于打开和关闭终端。在新标签页中打开的链接（target="_blank"）和未指定大小的 window.open 会在新标签页中打开。指定了大小的登录弹窗仍在单独的窗口中打开。

所有标签页共享相同的登录状态和 Cookie，可以在一个标签页中复制、在另一个标签页中粘贴。最多可打开 20 个标签页。页面只有在你刚点击或在其中输入后才能打开新标签页，否则链接会在当前标签页中打开。

录制内置浏览器时切换标签页，会把切换到的标签页录制为单独的视频（参见同时录制多个窗口），操作日志会记录切换和页面，因此每条反馈都与其页面关联。画笔和方框在每个标签页中都可用。空标签页会在加载页面后开始录制。

标签页按项目区分。切换项目时，会关闭当前打开的标签页，并打开目标项目的标签页；切换回来时标签页会恢复，在 Ferret 未关闭期间，后退和前进的历史也会恢复（重启后只恢复页面，不恢复这些历史）。反馈模式中审查目标下列出的已访问页面也按项目保存。登录状态和 Cookie 仍由所有项目共用。

如果网站返回 Cloudflare 的验证（Verify you are human），Ferret 会用表明自己是 Electron 的用户代理重新加载该页面一次，并在 Ferret 退出前对该网站一直使用它。在其他网站上，内置浏览器以与 Chrome 相同的方式标识自己，以便 Google 等登录页面正常工作。

#从浏览器导入密码和历史记录

在 设置 → 从浏览器导入 中，可以把常用浏览器的登录信息和历史记录导入进来。

  • 密码：先用浏览器自带的功能把密码导出为 CSV，再点击 导入密码 CSV… 并选择它。Chrome / Edge：密码管理器 → 设置 → 导出密码。Safari：文件 → 导出 → 密码。Firefox：密码 → ⋯ → 导出密码。Ferret 不会读取浏览器加密保存的密码。导出的 CSV 中密码是明文，导入后请删除它（并清空废纸篓）。
  • 在有已保存密码的网站页面上，编辑模式的浏览器工具栏会出现一个钥匙按钮。点击它即可填入用户名和密码（有多个账号时可选择）。只会填入来源与保存的一致的页面（协议、主机和端口相同；www. 可以不同），并且只填入顶层框架，不会填入 iframe 中的登录表单。
  • 历史记录：查找浏览器 会列出这台电脑上 Chrome、Edge、Brave、Chromium、Arc（macOS）和 Safari（macOS）的配置文件，导入历史记录 会把它们的历史记录导入为 URL 栏的建议。导入的历史记录由所有项目共用，只用于建议。读取 Safari 历史记录需要为 Ferret 开启完全磁盘访问权限（系统设置 → 隐私与安全性）。

密码用 Electron 的 safeStorage 加密，保存在 <userData>/browser-import/passwords.bin；导入的历史记录保存在 browser-import/history.json。用 全部删除 和 删除导入的历史记录 可以删除它们。在开发版本和无法使用 safeStorage 的系统上，导入的密码只保留到 Ferret 退出为止。

#浏览器扩展

在 设置 → 浏览器扩展 中为内置浏览器添加 Chrome 扩展：包含 manifest.json 的文件夹用 添加已解压的文件夹…，已安装在 Chrome、Edge、Brave 或 Chromium 中的扩展用 从 Chrome 导入… 复制过来。扩展只在内置浏览器中运行，不会进入 Ferret 自身的窗口。扩展可以读取和修改你在其中打开的所有页面，并使用其中的登录状态，所以请只添加你信任的扩展。

用浏览器工具栏或反馈工具栏中的 扩展 打开扩展的弹出窗口。它在页面右上角打开，点击其他地方或按 Esc 即关闭。录制 内置浏览器 时，扩展在页面中做出的变化和打开的弹出窗口都会出现在视频和图片中。Electron 只支持部分扩展 API：侧边栏、右键菜单、通知、键盘快捷键，以及扩展打开的标签页或窗口都无法使用，也无法加载打包的 .crx 文件。

弹出窗口上也可以标注。录制时点击工具栏不会关闭扩展的弹出窗口。选中画笔或方框时，或 文字反馈 打开时，点击页面也不会关闭它，Esc 会关闭工具而不是关闭弹出窗口。在弹出窗口里画的标注会按弹出窗口的位置出现在视频和图片中。仅适用于开始录制或 文字反馈 之后打开的弹出窗口。页面在单独窗口中打开的登录弹出窗口（例如使用 Google 登录）在打开期间会录制为单独的视频。它来到前台时，画笔和方框会画在其中；点击页面即切换回来。登录完成后它仍会自动关闭。

#同时录制多个窗口

一次录制可以同时录下最多 4 个画面：内置浏览器、桌面应用的窗口和屏幕。每个画面都单独录成一个视频，直到停止录制，因此在它们之间来回切换的流程（例如 Web 应用打开桌面应用后再返回）也能从头到尾录下来。

  1. 录制中，点击录制栏中的 +（同时录制另一个窗口），然后选择一个窗口、屏幕或内置浏览器。在 审查对象 面板中点击窗口类目标也一样。
  2. 点击录制栏中的标签即可切换显示的画面。画笔和反馈的图片跟随当前显示的画面；其他画面在后台继续以每秒最多 5 帧录制。

也可以等待尚未打开的窗口。在 编辑项目… 中为目标填写 要录制的窗口（应用名、窗口标题的一部分、com.example.MyApp 这样的 macOS bundle ID，或应用的路径），并把 录制中打开时 设为 一起录制 或 录制并切换过去。在 settings.json 中对应 "watch": "record" 或 "watch": "switch"。录制中，Ferret 每秒检查一次窗口列表。窗口打开前，目标显示为虚线标签；应用关闭后再次打开时也会重新录制。

每次切换都会写入操作日志，因此每条反馈都知道它针对的是哪个画面。显示应用窗口期间做出的反馈不带 URL 和元素信息，在 反馈 和 feedback.md 中归到该窗口下，并告诉 Agent 这是一个应用窗口。额外的视频保存在审查文件夹的 tracks/ 下，开始和结束时间记录在 tracks.jsonl 中。在 Windows 和 Linux 上只能得知窗口标题，所以用名称去匹配标题。在 Linux 的 Wayland 下无法等待窗口，因为每次列出窗口时都会要求你选择一个；请在窗口打开后用 + 添加。

#开始、暂停、停止

  1. 在内置浏览器中打开要审查的页面。
  2. 点击标题栏中的 录制，或按 ⌘⇧R / CtrlShiftR。
  3. 暂停 会停止绘制和计时。继续 会接着录制。
  4. 点击 停止，或再按一次 ⌘⇧R / CtrlShiftR。

在侧边栏中，每个项目都有自己的 新建审查（或其所在行上的 +，即 在 <name> 中新建审查）。在其他项目上使用时，会先切换到该项目，再开始录制。另一段录制正在进行时不会开始。

每段录制最长 90 分钟。接近上限时会收到警告，达到上限时录制会自动停止并保存。

#画笔

  • 画笔：选中它，或按住 ⌥ / Alt，仅在按住期间绘制（在输入框中打字时会被忽略）。
  • 清除：移除当前的标记。

一边讲解一边圈出位置：话语和标记会进入同一条反馈。画笔仅在录制时可用。录制时没有文字工具：请直接说出来，或之后用文字反馈输入。画笔、方框和颜色的按键见键盘快捷键。

#不说话，用文字反馈

不方便说话时，可以改为输入反馈。在编辑模式和反馈模式下都可以使用，但不能在录制时使用。

  1. 点击 文字反馈：它位于右上角录制按钮的右侧、浏览器工具栏，以及反馈模式的工具栏中。在编辑模式下会先切换到 浏览器 标签页；在反馈模式下会关闭画笔和框。
  2. 在页面上拖动，框住要改的位置；也可以点击某个元素，直接把它框住。
  3. 输入要怎么改。Enter 添加，⇧Enter / ShiftEnter 换行，Esc 取消方框。使用输入法选字时按下的 Enter 不会添加。

每一条都会成为一条反馈，附带页面和方框的图片、URL 以及框住的元素，和录制得到的反馈一样。它会添加到 反馈 中打开的评审；没有打开的评审时会新建一个。浏览器保持在前面，可以连续添加多条；在没有方框时按 Esc，或再次点击按钮即可结束。在浏览器位置显示的桌面应用或模拟器窗口上也能同样使用（不带 URL）。

#用分享链接收集任何人的反馈

想从不使用 Ferret 的人（客户、设计师、同事）那里获得反馈，就把分享链接发给他们。对方不需要账号，也不需要安装应用：在浏览器中打开链接，在页面截图上做标记，并写下需要修改的地方。名字可以不填。

  1. 在内置浏览器中打开页面（仅限 http 或 https），然后点击浏览器工具栏中的 分享。
  2. 可以填写标题（不填则使用页面标题），并打开 允许反馈者互相看到彼此的意见。点击 为此页面创建分享链接，Ferret 会截取页面的可见部分并上传，然后复制链接（https://share.ferretade.dev/s/…）。
  3. 要向同一个链接添加更多页面，打开另一个页面，然后在该分享上点击 添加此页面（最多 20 个页面）。

打开链接的人可以在截图上放置图钉、画框或用画笔绘制，并输入意见（最多 2,000 个字符）。Live page 会在框架中打开原始页面供对方操作，Annotate live 可以在上面放置图钉；当时查看的 URL 会随意见一起发送。有些网站拒绝在框架中加载，此时对方可以在新标签页中打开页面，只用文字发送意见。对方的页面会根据其浏览器显示为日语或英语。

收到的意见会显示在同一个 分享 窗口中。选择意见后点击 导入所选，或对不需要的意见点击 拒绝（撤销 可以恢复）。导入的意见会像 文字反馈 一样成为新审查中的发现：带有对方标记的截图成为 BEFORE 图片，并附上页面 URL 以及对方的名字和意见。在实时页面上放置的图钉会显示为围住整张截图的框，因为实时页面的滚动位置可能与截图不同。之后照常发送给智能体，并检查 BEFORE 和 AFTER。

  • 任何拿到链接的人都能看到截图并发送意见，所以不要分享显示私密数据的页面。链接 30 天后过期。删除 会立即删除链接、截图和意见。
  • 一个链接最多接收 500 条意见，服务器还会限制发送意见和创建链接的频率。服务器不保存 IP 地址。
  • 分享链接按项目保存。Ferret 用来读取和管理链接的所有者令牌会用 Electron 的 safeStorage 加密，保存在 <userData>/feedback-share/shares.bin。在开发版本和无法使用 safeStorage 的系统上，它只保留到 Ferret 退出为止（链接本身在过期前仍可使用）。
  • 服务器的代码位于仓库的 workers/feedback-share。

#导入会议

可以把关于产品的会议变成发现。在侧边栏中点击当前项目下的 导入会议，然后添加录制、文字记录或两者：

  • 录制：选择视频或音频…（MP4、M4V、MOV、WebM、MKV、M4A、MP3、WAV、OGG 或 AAC）。它会被复制到新审查的文件夹中。
  • 文字记录：打开文字记录文件…（.txt、.md、.vtt、.srt 或 .docx），或直接粘贴。Ferret 能读取 WebVTT 和 SRT 字幕（Zoom、Google Meet）、时间行后接 名字: 内容 行的文字记录（Google Meet、Gemini）、[00:12:34] 名字: 内容 行、名字 0:05 行后接内容（Circleback、Otter）、只有 名字: 内容 的行，或普通段落。Ferret 不连接这些服务，只读取你提供的文字。

点击 导入。没有文字记录时，Ferret 会按 转写 设置转写录制的音频（最长 3 小时的录制）。然后由 整理 模型根据会议内容写出候选发现。如果录制有视频且文字记录带时间，每次发言时刻的画面会成为该发现的 BEFORE 图片。没有时间的文字记录也能导入，但没有画面。

如果打开了判定模型，Ferret 会对每个候选询问一次会议是否要求对产品做具体修改；在使用能读图片的模型且有画面时，还会询问画面是否显示了所讨论的界面。每个候选会显示 可能性 百分比，低于 50% 的候选开始时为未勾选。这些调用从 Ferret 经过与智能体检查相同的本地中继，并计入相同的调用和费用上限。在你检查候选之前，不会向智能体发送任何内容：编辑、取消勾选或保留它们，然后照常发送。

#标记何时消失

标记属于绘制时所在的画面。在以下情况下，它们会被记录到当前反馈中，然后清除：

  • 页面发生跳转：完整载入，或 SPA 路由变更到新的路径或查询参数。仅哈希变化时会保留标记。
  • 你滚动了页面
  • 一段语音结束

#麦克风

麦克风默认开启。可以在底栏中切换（关闭麦克风 / 打开麦克风），也可以在设置中使用 录制我的语音。在 麦克风 下选择设备。

#查看转写内容

录制时，打开反馈模式右侧面板顶部的 转写 标签，就能以文字形式查看你说的话及其时间（同时录制会议对方的声音时，还会显示是谁说的）。说完稍作停顿，几秒后就会出现文字，因此可以尽早确认所说的内容是否被记录下来。顶部一行显示 正在转写、等待中的段数，或转写停止的原因。

如果转写失败、没有设置模型或密钥、约 2 分钟的语音没有转成文字，或麦克风没有收到声音，即使标签已关闭，Ferret 也会提示一次，并在右侧面板按钮上做标记。录制会继续，音频也会保留。要隐藏该标签，请在 设置 → 转写 中关闭 录制时显示实时转写（反馈模式的右侧面板）。警告仍会显示。

#录制时向 Agent 发话

反馈模式的右侧面板还有一个 终端 标签。它不是新的 shell，而是与编辑器模式相同的终端：同样的标签、同样正在运行的 Agent（例如 Claude Code 或 Codex）及其历史。在顶部选择一个标签并输入，例如告诉 Agent localhost 没有启动。回到编辑器模式后，终端保持同样的状态。录制内置浏览器或其他应用的窗口时，不会录进终端。

#录制会议中对方的声音

如果要在通话中和他人一起审查页面，可以让 Ferret 在录制麦克风的同时，也录制你电脑中听到的声音。这适用于任何会议应用（Zoom、Google Meet、Microsoft Teams 等），因为 Ferret 录制的是电脑的音频，而不是某个应用。两路声音分开处理：麦克风转写为 我，电脑音频转写为 其他人，因此每条反馈都能看出是谁提出的。关闭麦克风时同样可用。

  1. 照常在会议应用中加入通话。继续使用会议应用自己的麦克风和扬声器设置。
  2. 在设置中打开 同时录制对方的声音，或在底栏的麦克风菜单中打开 同时录制其他人的语音。录制过程中无法更改。
  3. 选择录制内容：审查页面时选 内置浏览器；查看共享屏幕时选 整个屏幕 / 窗口。
  4. 点击 录制，然后和其他人一起讨论页面，并用画笔圈出位置。
  5. 点击 停止。双方的声音都会被转写并整理成反馈。

请告知其他参与者你正在录制。如果使用云端转写服务，他们的声音也会发送给该服务。

#各操作系统的系统音频

操作系统要求权限
macOSmacOS 14.2 或更高版本。在更早的版本上只会录制你的麦克风。第一次录制对方的声音时，macOS 会询问是否允许 Ferret 录制系统音频。如果你拒绝了，请在 系统设置 → 隐私与安全性 → 录屏与系统录音 中打开 Ferret，然后退出并重新打开 Ferret。这不会录制你的屏幕。
Windows在 设置 → 系统 → 声音 中有一个已启用的播放设备（扬声器或耳机）。无。录制的是默认播放设备。
LinuxPulseAudio，或带有 pipewire-pulse 的 PipeWire（大多数桌面环境的默认配置）。无。录制的是默认输出。

如果无法录制对方的声音，Ferret 会在警告中说明原因，并继续录制你的麦克风、视频和画笔标注。请参阅故障排除。

#会议录制技巧

  • 使用耳机。使用扬声器时，你的麦克风也会收进对方的声音。Ferret 在录制对方声音时会为麦克风开启回声消除，并去掉双方都录到的语句，但使用耳机得到的转写最干净。
  • 电脑播放的所有声音都会被录制，包括通知音和视频。审查期间请把不需要的声音静音。
  • 录制过程中不要切换音频设备。如果输出设备发生变化或被拔出，对方声音的录制会停止并显示警告。你的麦克风、视频和画笔标注会继续录制。之后可以用 继续录制 补录剩下的内容。
