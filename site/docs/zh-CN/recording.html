使用 Ferret

录制

录制内置浏览器、整个屏幕或其他窗口。一边使用页面，一边说话、圈画和打字。

快捷键显示为

#选择录制内容

在反馈模式下，点击 选择录制对象。录制对象 对话框提供以下选项：

对象录制内容
内置浏览器（默认）视频、语音和画笔，以及 URL、元素选择器、点击和滚动。不需要操作系统权限。
整个屏幕视频、语音和画笔。没有 URL、元素或操作记录（这一点会在 feedback.md 中注明）。
窗口同上。Ferret 自己的窗口不会列出。

你的选择会被记住。在 macOS 上，录制屏幕和窗口需要“屏幕录制”权限（如何授予）。

#开始、暂停、停止

  1. 在内置浏览器中打开要审查的页面。
  2. 点击标题栏中的 录制，或按 ⌘⇧R / CtrlShiftR。
  3. 暂停 会停止绘制和计时。继续 会接着录制。
  4. 点击 停止，或再按一次 ⌘⇧R / CtrlShiftR。

在侧边栏中，每个项目都有自己的 新建审查（或其所在行上的 +，即 在 <name> 中新建审查）。在其他项目上使用时，会先切换到该项目，再开始录制。另一段录制正在进行时不会开始。

每段录制最长 90 分钟。接近上限时会收到警告，达到上限时录制会自动停止并保存。

#画笔

  • 画笔：选中它，或按住 ⌥ / Alt，仅在按住期间绘制（在输入框中打字时会被忽略）。
  • 清除：移除当前的标记。

一边讲解一边圈出位置：话语和标记会进入同一条反馈。画笔仅在录制时可用。没有文字工具，请直接说出来。画笔、方框和颜色的按键见键盘快捷键。

#标记何时消失

标记属于绘制时所在的画面。在以下情况下，它们会被记录到当前反馈中，然后清除：

  • 页面发生跳转：完整载入，或 SPA 路由变更到新的路径或查询参数。仅哈希变化时会保留标记。
  • 你滚动了页面
  • 一段语音结束

#麦克风

麦克风默认开启。可以在底栏中切换（关闭麦克风 / 打开麦克风），也可以在设置中使用 录制我的语音。在 麦克风 下选择设备。

#录制会议中对方的声音

如果要在通话中和他人一起审查页面，可以让 Ferret 在录制麦克风的同时，也录制你电脑中听到的声音。这适用于任何会议应用（Zoom、Google Meet、Microsoft Teams 等），因为 Ferret 录制的是电脑的音频，而不是某个应用。两路声音分开处理：麦克风转写为 我，电脑音频转写为 其他人，因此每条反馈都能看出是谁提出的。关闭麦克风时同样可用。

  1. 照常在会议应用中加入通话。继续使用会议应用自己的麦克风和扬声器设置。
  2. 在设置中打开 同时录制对方的声音，或在底栏的麦克风菜单中打开 同时录制其他人的语音。录制过程中无法更改。
  3. 选择录制内容：审查页面时选 内置浏览器；查看共享屏幕时选 整个屏幕 / 窗口。
  4. 点击 录制，然后和其他人一起讨论页面，并用画笔圈出位置。
  5. 点击 停止。双方的声音都会被转写并整理成反馈。

请告知其他参与者你正在录制。如果使用云端转写服务，他们的声音也会发送给该服务。

#各操作系统的系统音频

操作系统要求权限
macOSmacOS 14.2 或更高版本。在更早的版本上只会录制你的麦克风。第一次录制对方的声音时，macOS 会询问是否允许 Ferret 录制系统音频。如果你拒绝了，请在 系统设置 → 隐私与安全性 → 录屏与系统录音 中打开 Ferret，然后退出并重新打开 Ferret。这不会录制你的屏幕。
Windows在 设置 → 系统 → 声音 中有一个已启用的播放设备（扬声器或耳机）。无。录制的是默认播放设备。
LinuxPulseAudio，或带有 pipewire-pulse 的 PipeWire（大多数桌面环境的默认配置）。无。录制的是默认输出。

如果无法录制对方的声音，Ferret 会在警告中说明原因，并继续录制你的麦克风、视频和画笔标注。请参阅故障排除。

#会议录制技巧

  • 使用耳机。使用扬声器时，你的麦克风也会收进对方的声音。Ferret 在录制对方声音时会为麦克风开启回声消除，并去掉双方都录到的语句，但使用耳机得到的转写最干净。
  • 电脑播放的所有声音都会被录制，包括通知音和视频。审查期间请把不需要的声音静音。
  • 录制过程中不要切换音频设备。如果输出设备发生变化或被拔出，对方声音的录制会停止并显示警告。你的麦克风、视频和画笔标注会继续录制。之后可以用 继续录制 补录剩下的内容。
