配置

设置参考

点击标题栏中的齿轮图标打开 设置。录制期间无法更改设置。

#麦克风

设置默认值
录制我的语音开
麦克风系统默认
同时录制对方的声音（会议）关

#转写

设置默认值
语言（说话语言）自动
引擎本机（免费）
模型（本机）large-v3-turbo（推荐）
端点 Base URL / 模型（兼容 OpenAI）空
OpenAI API 密钥 / Endpoint API key（可选）未设置
费用上限每次审查最多 $1

参见转写与费用。

#存储

设置默认值
保留录制内容：7 天 / 30 天 / 永久7 天
停止后停留在反馈界面关

#Agent

设置默认值
打开项目时启动Claude Code、Codex（可选择任意支持的 Agent，也可以都不选）
在菜单中显示 <agent>所有 Agent 均为开
启动 Agent 时跳过权限确认开：Claude Code 以 --dangerously-skip-permissions 启动，Codex 以 --dangerously-bypass-approvals-and-sandbox 启动（详情）
Agent 完成或需要我确认时通知我关（详情）
命令 / 参数（每个 Agent）该 Agent 自己的命令（例如 claude、codex、gemini）/ Claude Code 为 --chrome，其他为无
自定义 Agent无（添加自定义 Agent 可登记任意 CLI）
给 Agent 的指令内置文本（变量）

#达到用量上限时自动切换

设置默认值
达到用量上限时自动切换开
账户用量达到此值即视为上限95%
先切换到同一 Agent 的其他账户开
Agent 顺序Claude Code、Codex、Gemini CLI
上限恢复后切回顺序更靠前的 Agent关

位于 设置 → 账户。工作通过项目中的 .ferret/handoff.md 交接。参见达到用量上限时继续工作。

#账户、GitHub、外观、语言

  • 账户：参见账户与用量。
  • GitHub / GitLab：gh 和 glab 的登录。参见发送到 GitHub 或 GitLab。
  • CLI 工具：安装并登录各服务的 CLI。参见CLI 工具。
  • 外观 → 主题：跟随系统（默认）、浅色、深色。
  • 语言 → 界面：跟随系统（默认；Ferret 支持操作系统的语言时跟随该语言，否则使用英语），或 14 种语言之一：English、日本語、简体中文、繁體中文、한국어、Español、Français、Deutsch、Italiano、Português (Brasil)、Русский、हिन्दी、Bahasa Indonesia、Tiếng Việt。

在底部栏中：终端位置（右侧 / 底部）和麦克风开关。

#settings.json

以上所有设置都保存在 ~/.ferret/settings.json（所有操作系统路径相同），旁边还有一个 JSON Schema。应用运行时也可以编辑它，手动编辑或让你的编码 Agent 编辑都可以；更改会立即生效。参见用 settings.json 配置。
