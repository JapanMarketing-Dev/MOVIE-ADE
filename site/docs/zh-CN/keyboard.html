键盘快捷键

快捷键按你当前阅读所用的操作系统显示；可用下方的开关查看另一种。大多数快捷键在 macOS 上用 Command，对应 Windows 和 Linux 上的 Ctrl；用 Option 对应 Alt。少数快捷键差别更大，表中会同时列出两种。来源：src/main/menu.ts、src/shared/browserNav.ts、src/shared/annotation.ts 以及终端的按键处理。

快捷键显示为

#录制

操作macOSWindows / Linux
开始 / 停止录制⌘⇧RCtrlShiftR
切换模式（编辑器 / 反馈）⌘⇧MCtrlShiftM
按住时使用画笔⌥Alt

#录制时绘制

操作macOSWindows / Linux
画笔PP
方框B / RB / R
操作网页（停止绘制）V / EscV / Esc
下一个颜色CC
撤销上一个标记⌘ZCtrlZ
重做⌘⇧ZCtrlShiftZ / CtrlY

这些按键在录制内置浏览器且页面获得焦点时有效。在页面的输入框中打字时它们会被忽略，而且字母键只在不按修饰键时有效，因此页面自身的快捷键仍可正常使用。

#浏览器与视图

操作macOSWindows / Linux
聚焦 URL 栏⌘LCtrlL
重新载入页面⌘RCtrlR
后退⌘[Alt←
前进⌘]Alt→
切换桌面 / 移动端宽度⌘⇧VCtrlShiftV
显示 / 隐藏侧边栏⌘BCtrlB
显示 / 隐藏文件树⌘⇧ECtrlShiftE
显示 / 隐藏审查对象⌘⇧KCtrlShiftK

#文件

操作macOSWindows / Linux
打开项目文件夹…⌘OCtrlO
转到文件…⌘PCtrlP
保存⌘SCtrlS

#终端

操作macOSWindows / Linux
新建终端⌘TCtrlT
关闭窗格 / 标签页⌘WCtrlW
向右拆分⌘DCtrlShiftD
向下拆分⌘⇧DAltShiftD

拆分快捷键在终端获得焦点时有效。

#窗口与设置

操作macOSWindows / Linux
设置…⌘,Ctrl,
关闭窗口⌘⇧W—

Windows 和 Linux 没有关闭窗口的快捷键：文件 → 退出 会退出应用。
