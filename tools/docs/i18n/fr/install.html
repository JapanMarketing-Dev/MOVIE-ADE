Installation Téléchargez Ferret pour votre ordinateur et ouvrez-le. Il fonctionne sous macOS, Windows et Linux. ## Téléchargement

La page de téléchargement propose le fichier adapté à votre ordinateur. Cliquez sur le bouton de téléchargement.

## macOS

Ouvrez le .dmg, faites glisser Ferret dans Applications, puis ouvrez-le depuis ce dossier.

## Windows

Exécutez le .exe téléchargé. Ferret s'installe et s'ouvre, sans rien à choisir. Les fois suivantes, ouvrez-le depuis le menu Démarrer ou le raccourci du bureau.

Si Windows affiche Windows a protégé votre ordinateur, cliquez sur Informations complémentaires, puis sur Exécuter quand même.

## Linux

Ubuntu / Debian : double-cliquez sur le .deb pour l'installer avec votre logithèque, ou exécutez :

sudo apt install ./Ferret-<version>-linux-amd64.deb

Ouvrez ensuite Ferret depuis le menu des applications, ou exécutez ferret.

Autres distributions : utilisez le .AppImage. Les AppImage fonctionnent avec FUSE 2 : installez d'abord son paquet si votre système ne l'a pas (fuse-libs sur Fedora, fuse2 sur Arch, libfuse2 sur openSUSE et les systèmes basés sur Debian). Autorisez ensuite l'exécution du .AppImage comme programme (clic droit → Propriétés, ou chmod +x), puis ouvrez-le.
