Projets et URL Un projet est un dossier (en général la racine de votre dépôt). Chaque projet garde ses propres URL enregistrées : local, dev et production sont ainsi à un clic l'un de l'autre. ## Ajouter un projet
  1. Fichier → Ouvrir un dossier de projet… ({{keys:Mod+O}}), Ajouter un projet dans la barre latérale, ou Ajouter un projet… dans le menu des projets de la barre de titre.
  2. Choisissez la provenance du projet :
    • Sur cet ordinateur : choisissez un dossier.
    • Cloner depuis GitHub / GitLab : choisissez l'un de vos dépôts (listés grâce à votre connexion gh ou glab) ou collez une URL, choisissez le dossier parent, et Ferret le clone puis l'ouvre.
    • Ouvrir via SSH : choisissez un hôte dans ~/.ssh/config. Le terminal et les agents s'exécutent sur la machine distante ; les relectures restent sur cet ordinateur.

Par défaut, le nom est celui du dossier. Ajouter un dossier déjà enregistré l'ouvre simplement (sur macOS et Windows, les chemins sont comparés sans tenir compte de la casse). Depuis le menu de la barre latérale, vous pouvez Renommer un projet ou le Retirer de la liste. Le retirer ne supprime jamais le dossier.

Les terminaux s'ouvrent dans le dossier du projet, et les relectures sont enregistrées sous <project>/.ferret/.

## Enregistrer des URL
  1. Ouvrez la page dans le navigateur intégré.
  2. Cliquez sur + (Enregistrer l'URL actuelle) dans la barre d'outils du navigateur. L'URL actuelle est préremplie.
  3. Saisissez un Nom et cliquez sur Enregistrer.

Seules les URL http:// et https:// sont acceptées. Si vous gardez le nom proposé, il est déduit de l'hôte :

HôteNom
localhost, 127.*, ::1, 0.0.0.0, *.localhostlocal
contient dev, develop, developmentdev
contient stg, stage, stagingstg
tout autre hôteprd
## Panneau des cibles de relecture {{clip:targets|Changer de cible de relecture et de page sans arrêter l'enregistrement.}}

En mode Retours, le panneau Cibles de relecture, à droite, liste tout ce que vous pouvez relire pour le projet actuel. Changer de cible n'arrête pas l'enregistrement. Affichez ou masquez le panneau avec Présentation → Afficher/masquer les cibles de relecture ({{keys:Mod+Shift+K}}) ou Masquer le panneau.

  • Cibles : les URL enregistrées du projet. Sous chacune se trouve l'arborescence des pages que vous avez visitées sur ce site. Les sites visités qui ne sont pas enregistrés apparaissent dans leurs propres groupes.
  • Fichiers : le dossier du projet. Un fichier s'ouvre en aperçu (Markdown et Mermaid rendus, autres textes en lecture seule), ce qui permet aussi de relire de la documentation. Le crayon (Ouvrir dans l'éditeur) l'ouvre dans l'éditeur.

Filtrer les cibles filtre à la fois les cibles, les pages et les fichiers, avec la même recherche approximative que Aller au fichier…. Dans la liste, ↑ ↓ Enter ou 1–9 changent de cible. Ouvrir une URL… ouvre une URL ponctuelle, et Enregistrer dans les URL du projet la conserve.

Les cibles proviennent de projects[].urls dans settings.json (voir l'exemple). Chaque entrée a besoin d'une url, d'une launchCommand (exécutée dans un terminal, par exemple pour lancer une application de bureau) ou d'un windowMatch (la fenêtre à enregistrer). Choisir une cible de type fenêtre en fait la source d'enregistrement : ce n'est donc pas possible pendant un enregistrement. Les pages visitées sont mémorisées par projet, sur cette machine uniquement (jusqu'à 200).

## Ouvrir et changer d'environnement

Cliquez sur une URL enregistrée pour l'ouvrir. Si la page actuelle relève d'une autre URL enregistrée, Ferret conserve le chemin, la query et le hash, et ne remplace que l'origine. Par exemple, sur http://localhost:3000/pricing?plan=pro, cliquer sur prd ouvre https://example.com/pricing?plan=pro.

La puce correspondant à la page actuelle (préfixe le plus long) est mise en évidence. Faites un clic droit sur une puce ou utilisez son icône de crayon pour la modifier ou la Supprimer. À l'ouverture d'un projet sans URL précédente, sa première URL enregistrée se charge.
