Dépannage Problèmes courants et solutions. Les messages cités sont ceux qu'affiche l'application en français. ## Installation et premier lancement

Linux : sur Ubuntu 23.10 et versions ultérieures, l'AppImage peut s'arrêter au lancement avec une erreur de sandbox, car AppArmor restreint les espaces de noms utilisateur dont se sert la sandbox d'Electron. Installez plutôt le .deb.

## La capture de l'écran ou d'une fenêtre échoue (macOS)

Message : L'enregistrement de tout l'écran ou d'une autre fenêtre nécessite l'autorisation macOS Enregistrement de l'écran.

  1. Dans la boîte de dialogue Cible d'enregistrement, cliquez sur Ouvrir les Réglages Système.
  2. Confidentialité et sécurité → Enregistrement de l'écran et de l'audio du système : activez Ferret.
  3. Redémarrez l'application, puis cliquez sur Vérifier à nouveau.

L'enregistrement du Navigateur intégré ne nécessite aucune autorisation.

Lorsque vous l'exécutez depuis les sources sur macOS, pnpm dev lance une copie renommée d'Electron, signée ad hoc, qui s'appelle aussi Ferret (scripts/prepare-dev-electron.mjs) : elle apparaît donc comme une entrée Ferret distincte dans ces listes. À sa première exécution, macOS redemande l'accès à l'enregistrement de l'écran et au micro. Il ne le redemande plus ensuite. Les versions de développement utilisent un trousseau factice (--use-mock-keychain) : il n'y a donc pas de demande du Trousseau, et les cookies et clés enregistrés dans une version de développement sont chiffrés avec une clé fixe, et non avec le vrai Trousseau. Définissez ADE_DEV_REAL_KEYCHAIN=1 pour utiliser le vrai Trousseau.

## Le microphone ne s'ouvre pas

Message : Impossible d'ouvrir le microphone. Vérifiez l'autorisation dans les réglages de votre système.

  • macOS : Réglages Système → Confidentialité et sécurité → Micro, puis activez Ferret.
  • Windows : Paramètres → Confidentialité et sécurité → Microphone, puis autorisez les applications de bureau.

Sans micro, les zones entourées au stylo créent quand même des remarques, mais sans demande orale.

## L'autre partie d'une réunion n'est pas enregistrée

Quand Enregistrer aussi l'interlocuteur est activé et que l'audio de votre ordinateur ne peut pas être enregistré, Ferret affiche l'un de ces avertissements et continue d'enregistrer votre micro, la vidéo et le stylo.

  • Ferret n'est pas autorisé à enregistrer l'audio du système. (macOS) : activez Ferret dans Réglages Système → Confidentialité et sécurité → Enregistrement de l'écran et de l'audio du système, quittez et rouvrez Ferret, puis lancez un nouvel enregistrement.
  • L'enregistrement de l'autre partie nécessite macOS 14.2 ou une version ultérieure. : mettez macOS à jour. D'ici là, seul votre micro est enregistré.
  • Windows n'a pas autorisé l'accès à l'audio du système. ou aucun périphérique de sortie audio n'a été trouvé. : activez des haut-parleurs ou un casque dans Paramètres → Système → Son (Windows) ou branchez-en, puis lancez un nouvel enregistrement.
  • l'audio du système n'est pas disponible. (Linux) : installez PulseAudio, ou pipewire-pulse si vous utilisez PipeWire.
  • L'enregistrement de l'autre partie s'est arrêté : le périphérique de sortie audio a changé ou a été déconnecté. : le reste de l'enregistrement continue sans l'autre partie. Utilisez Enregistrer la suite pour capturer le reste.

Si les paroles de l'autre partie apparaissent aussi comme les vôtres, votre micro capte vos haut-parleurs. Utilisez un casque.

## Aucun modèle sur l'appareil / whisper-cli introuvable

Message : Aucun modèle de transcription sur l'appareil trouvé. L'audio sera enregistré, et seules les remarques au stylo seront traitées.

Téléchargez un modèle dans les réglages, ou choisissez un ggml-*.bin existant. Si les réglages indiquent whisper.cpp (whisper-cli) est introuvable, installez-le (instructions), vérifiez qu'il est dans le PATH et rouvrez les réglages. Les applications empaquetées lancées depuis le Finder ou l'Explorateur peuvent ne pas voir le PATH de votre shell : installez-le donc dans un emplacement standard, comme celui de Homebrew.

Un modèle téléchargé qui échoue à la vérification sha256 est supprimé. Relancez le téléchargement.

## Terminal : node-pty n'a pas pu être chargé

Cela se produit lors d'une exécution depuis les sources lorsque node-pty a été compilé pour une autre ABI de Node ou d'Electron.

pnpm rebuild:native
## Agent introuvable / Envoyer à l'agent n'envoie rien
  • Claude Code: Introuvable (ou le nom d'un autre agent intégré), ou command not found: … dans le terminal pour un agent que vous avez ajouté : la CLI n'est pas installée ou n'est pas dans le PATH. Ferret lance les agents intégrés uniquement depuis un chemin absolu dans un dossier du PATH situé hors du projet, jamais depuis le dossier du projet. Vérifiez que la commande fonctionne dans votre terminal habituel, utilisez Installer dans Réglages → Agents, ou indiquez un chemin absolu comme Commande de cet agent.
  • L'agent attend une confirmation. Répondez dans le terminal, puis envoyez. Répondez d'abord à la question de l'agent.
  • La saisie de l'agent n'est pas encore prête. Attendez que l'agent ait fini de démarrer.
  • Le texte a été saisi mais pas envoyé. Appuyez sur Entrée dans le terminal.
  • Ouvrez d'abord un terminal.
  • Impossible d'analyser les arguments de lancement : Guillemet non fermé. Corrigez les guillemets dans les arguments de l'agent.
  • Placez … dans les arguments de lancement, pas dans la commande. ou Écrivez … dans les arguments de lancement sans guillemets ni barres obliques inverses. Écrivez cette option en texte simple dans les arguments de l'agent. Pour démarrer les agents sans demandes d'autorisation, activez Démarrer les agents sans demandes d'autorisation dans Réglages → Agents.
## L'enregistrement ne démarre pas
  • Ouvrez d'abord un dossier de projet.
  • Ouvrez d'abord une URL à relire.
  • La page ne s'est pas chargée. Ouvrez une URL qui s'affiche, puis enregistrez. Vérifiez que le serveur de développement tourne. Impossible de se connecter au serveur signifie que rien n'écoute sur ce port.
## Clé OpenAI ou endpoint non défini

Aucune clé d'API OpenAI n'est définie… ou L'endpoint de transcription (Base URL / modèle) n'est pas défini… : ajoutez-le dans les réglages, ou passez à Sur l'appareil (gratuit). L'audio de cet enregistrement est déjà sauvegardé.

## Erreurs GitHub
  • GitHub CLI (gh) introuvable. Installez gh.
  • Non connecté à GitHub. Réglages → CLI des services.
  • Aucun remote origin. ou origin n'est pas un dépôt GitHub. Vérifiez git remote -v.
  • Dépôt introuvable, ou vous n'y avez pas accès. Vérifiez gh auth status et GH_TOKEN.
