Fichiers et environnement Où Ferret conserve ses propres fichiers, et les variables d'environnement qu'il lit ou définit. ## Dossier userData

Les données de l'application se trouvent dans le dossier userData d'Electron. Son nom est figé à ade-movie (et non au nom du produit), pour que les données survivent aux changements de nom. Remplacez-le avec --user-data-dir=<path>.

OSChemin
macOS~/Library/Application Support/ade-movie/
Windows%APPDATA%\ade-movie\
Linux~/.config/ade-movie/ (ou $XDG_CONFIG_HOME/ade-movie/)
 
settings.json       # settings before 0.1.1, kept as a backup (now ~/.ferret/settings.json)
stt-keys.bin        # API keys, encrypted with safeStorage
browser-import/     # imported passwords (passwords.bin, encrypted with safeStorage) and history (history.json)
login-shell-path.json  # your login shell's PATH from the last launch, so agent tabs start without waiting
models/             # downloaded whisper models (ggml-*.bin)
accounts/claude/<id>/   # CLAUDE_CONFIG_DIR for added accounts
accounts/codex/<id>/    # CODEX_HOME for added accounts

Vos réglages ne sont pas dans ce dossier : ils se trouvent dans ~/.ferret/ (voir Configurer avec settings.json).

Un modèle que vous avez choisi vous-même peut se trouver n'importe où. L'ancien emplacement par défaut ~/.cache/ade-movie/models/ggml-small.bin est toujours vérifié.

## Variables d'environnement
VariableEffet
CLAUDE_CONFIG_DIR, CODEX_HOMEDéfinies par Ferret pour les onglets d'agent lorsqu'un compte ajouté est sélectionné
GH_TOKEN, GITHUB_TOKENUtilisées par gh avant sa propre connexion. Ferret avertit si l'une d'elles est définie
FERRET_CONFIG_DIR (ou l'ancienne MOVIE_ADE_CONFIG_DIR)Dossier de settings.json, state.json et settings.schema.json à la place de ~/.ferret
Noms indiqués dans apiKeyEnvClés d'API désignées depuis settings.json. Lues aussi depuis le .env du projet et ~/.ferret/.env
ADE_PROJECT_DIROuvre (et enregistre) ce dossier comme projet au lancement
ADE_INITIAL_URLCharge cette URL dans le navigateur intégré au lancement
ADE_WHISPER_MODELChemin absolu d'un modèle GGML à utiliser pour la transcription sur l'appareil, à la place du modèle téléchargé par défaut
ADE_TERMINAL_PREWARM0 empêche Ferret de garder un shell prêt en arrière-plan. Par défaut, le prochain onglet de shell simple l'utilise, et son invite apparaît aussitôt
FERRET_SENTRY_DSN (ou l'ancienne MOVIE_ADE_SENTRY_DSN)Destination des rapports de plantage. Vide signifie qu'aucun n'est envoyé (voir Rapports de plantage)
OPENAI_API_KEYLue depuis .env en développement uniquement (pnpm dev), jamais dans les versions empaquetées
PATHSert à trouver les commandes de vos agents (claude, codex, gemini…), gh, git, whisper-cli. Sur macOS et Linux, les emplacements de Homebrew, linuxbrew et snap sont ajoutés
