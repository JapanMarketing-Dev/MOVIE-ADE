## Comptes, CLI des services, apparence, langue
  • Comptes : voir Comptes et utilisation.
  • CLI des services : installer les CLI de services et s'y connecter. Voir CLI des services.
  • Importer depuis les navigateurs : importe les mots de passe (depuis un CSV exporté) et l'historique dans le navigateur intégré. Voir Importer les mots de passe et l'historique.
  • Apparence → Thème : Système (par défaut), Clair, Sombre.
  • Langue → Interface : Système (par défaut ; suit la langue de l'OS si Ferret la propose, l'anglais sinon) ou l'une des 14 langues : English, 日本語, 简体中文, 繁體中文, 한국어, Español, Français, Deutsch, Italiano, Português (Brasil), Русский, हिन्दी, Bahasa Indonesia, Tiếng Việt.

Depuis le pied de page : la position du terminal (à droite / en bas) et l'activation du microphone.

## settings.json

Tout ce qui précède est stocké dans ~/.ferret/settings.json (même chemin sur tous les OS), avec un JSON Schema à côté. Vous pouvez le modifier pendant que l'application tourne, à la main ou avec votre agent de code ; les changements s'appliquent immédiatement. Voir Configurer avec settings.json.
