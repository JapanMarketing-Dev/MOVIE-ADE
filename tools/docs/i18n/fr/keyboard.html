Raccourcis clavier Les raccourcis sont affichés pour l'OS sur lequel vous lisez ; utilisez le sélecteur ci-dessous pour voir l'autre. La plupart utilisent Commande sur macOS là où Windows et Linux utilisent Ctrl, et Option là où ils utilisent Alt. Quelques-uns diffèrent davantage, et les tableaux indiquent alors les deux. Source : src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts et la gestion des touches du terminal. ## Enregistrement

Changer de mode (Éditeur / Retours){{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}

## Dessiner pendant l'enregistrement
ActionmacOSWindows / Linux

Cadre{{keys-mac:B / R}}{{keys-win:B / R}}

Ces touches fonctionnent pendant l'enregistrement du navigateur intégré, lorsque la page a le focus. Elles sont ignorées pendant la saisie dans un champ de la page, et les touches de lettre ne fonctionnent que sans touche de modification : les raccourcis propres à la page continuent donc de fonctionner.

## Terminal
ActionmacOSWindows / Linux
Nouveau terminal{{keys-mac:Mod+T}}{{keys-win:Mod+T}}
Fermer le panneau / l'onglet{{keys-mac:Mod+W}}{{keys-win:Mod+W}}
Diviser à droite{{keys-mac:Mod+D|Ctrl+Shift+D}}{{keys-win:Mod+D|Ctrl+Shift+D}}
Diviser en bas{{keys-mac:Mod+Shift+D|Alt+Shift+D}}{{keys-win:Mod+Shift+D|Alt+Shift+D}}
Copier la sélection{{keys-mac:Mod+C|Ctrl+Shift+C / Ctrl+C}}{{keys-win:Mod+C|Ctrl+Shift+C / Ctrl+C}}
Coller{{keys-mac:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}{{keys-win:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}
Nouvelle ligne dans le prompt d'un agent{{keys-mac:Shift+Enter}}{{keys-win:Shift+Enter}}
Début / fin de ligne{{keys-mac:Mod+Left / Mod+Right|}}{{keys-win:Mod+Left / Mod+Right|}}
Supprimer jusqu'au début de la ligne{{keys-mac:Mod+Backspace|}}{{keys-win:Mod+Backspace|}}

Ces raccourcis fonctionnent lorsqu'un terminal a le focus. Sous Windows et Linux, Ctrl+C copie quand du texte est sélectionné et arrête la commande en cours quand rien n'est sélectionné. {{keys:Shift+Enter}} commence une nouvelle ligne pendant qu'un agent comme Claude Code ou Codex s'exécute ; dans un shell simple, il exécute la commande comme Entrée. Dans un programme plein écran qui utilise la souris (vim, tmux, un agent), maintenez Option en faisant glisser pour sélectionner du texte sur macOS.
