Raccourcis clavier Les raccourcis sont affichés pour l'OS sur lequel vous lisez ; utilisez le sélecteur ci-dessous pour voir l'autre. La plupart utilisent Commande sur macOS là où Windows et Linux utilisent Ctrl, et Option là où ils utilisent Alt. Quelques-uns diffèrent davantage, et les tableaux indiquent alors les deux. Source : src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts et la gestion des touches du terminal. ## Enregistrement
ActionmacOSWindows / Linux
Démarrer / arrêter l'enregistrement{{keys-mac:Mod+Shift+R}}{{keys-win:Mod+Shift+R}}
Changer de mode (Éditeur / Retours){{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}
Stylo tant que la touche est maintenue{{keys-mac:Alt}}{{keys-win:Alt}}
## Dessiner pendant l'enregistrement
ActionmacOSWindows / Linux
Stylo{{keys-mac:P}}{{keys-win:P}}
Cadre{{keys-mac:B / R}}{{keys-win:B / R}}
Utiliser la page (arrêter de dessiner){{keys-mac:V / Esc}}{{keys-win:V / Esc}}
Couleur suivante{{keys-mac:C}}{{keys-win:C}}
Annuler le dernier trait{{keys-mac:Mod+Z}}{{keys-win:Mod+Z}}
Rétablir{{keys-mac:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}{{keys-win:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}

Ces touches fonctionnent pendant l'enregistrement du navigateur intégré, lorsque la page a le focus. Elles sont ignorées pendant la saisie dans un champ de la page, et les touches de lettre ne fonctionnent que sans touche de modification : les raccourcis propres à la page continuent donc de fonctionner.
