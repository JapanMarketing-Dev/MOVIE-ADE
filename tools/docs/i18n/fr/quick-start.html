Démarrage rapide Installez Ferret, ouvrez votre projet et l'URL de son serveur de développement, enregistrez un premier retour et confiez-le à votre agent de code. Comptez environ cinq minutes. ## Avant de commencer {{clip:quick-start|Ouvrir une page, enregistrer, entourer en parlant, arrêter, puis envoyer les remarques à un agent.}}
  • Un agent de code qui s'exécute dans un terminal, installé et connecté : par exemple Claude Code (claude), Codex (codex) ou Gemini CLI (gemini). Ferret le lance dans son terminal intégré. Tout agent de la liste des agents pris en charge fonctionne, de même que toute autre CLI que vous ajoutez vous-même.
  • Une application web accessible par URL, par exemple un serveur de développement sur http://localhost:3000.
  • Un microphone. Un retour, c'est votre voix plus le stylo. Sans micro, les zones entourées au stylo deviennent quand même des remarques, mais sans paroles.
## 1. Installer

Téléchargez la version correspondant à votre OS depuis la page de téléchargement et ouvrez-la. La version macOS est signée avec un Developer ID et notariée par Apple : elle s'ouvre comme n'importe quelle autre application. Les versions Windows et Linux ne sont pas encore signées, leur premier lancement demande donc une étape de plus. Consultez Installation pour Windows SmartScreen, Linux et la compilation depuis les sources.

## 2. Ouvrir un projet et une URL
  1. Fichier → Ouvrir un dossier de projet… ({{keys:Mod+O}}), puis choisissez la racine de votre dépôt.
  2. Saisissez l'URL de votre serveur de développement dans la barre d'adresse du navigateur ({{keys:Mod+L}}) et appuyez sur Enter.
  3. Facultatif : cliquez sur + (Enregistrer l'URL actuelle) pour la garder comme raccourci en un clic, par exemple local, dev ou prd.

L'ouverture d'un projet démarre aussi vos agents dans des onglets de terminal, dans ce dossier. Par défaut, ce sont Claude Code et Codex ; choisissez ceux que vous utilisez dans Réglages → Agents → Démarrer à l'ouverture d'un projet (voir Réglages).

## 3. Enregistrer
  1. Cliquez sur Enregistrer dans la barre de titre, ou appuyez sur {{keys:Mod+Shift+R}}. La fenêtre passe en mode Retours.
  2. Utilisez la page normalement et dites ce qui doit changer.
  3. Maintenez {{keys:Alt}} (ou choisissez Stylo) et faites glisser pour entourer l'endroit dont vous parlez.
  4. Cliquez sur Arrêter ou appuyez de nouveau sur {{keys:Mod+Shift+R}}.

Chaque moment où vous parlez ou entourez quelque chose devient une remarque : une capture d'écran avec vos traits de stylo, la demande, vos paroles d'origine, l'URL et l'élément que vous avez désigné.

## 4. Vérifier les remarques

Une fois l'enregistrement arrêté, la fenêtre revient en mode Éditeur et ouvre l'onglet Remarques.

  • Modifiez directement un titre ou une demande.
  • Pour chaque remarque, basculez entre Envoyer et Ne pas envoyer, utilisez Fusionner avec la suivante ou Supprimer.
  • Annuler revient sur la dernière modification.
## 5. Envoyer à un agent
  1. Cliquez sur Envoyer à l'agent. L'envoi part vers l'agent de l'onglet de terminal actuel, ou vers un agent en cours d'exécution. La flèche à côté du bouton permet de choisir un agent ou un onglet précis.
  2. Si aucun agent ne tourne encore, Ferret en démarre un d'abord et envoie dès qu'il est prêt.

Ferret saisit une instruction dans l'invite de l'agent et la valide. Par défaut, elle commence ainsi :

Lisez "{{path}}" ainsi que l'image de chaque remarque dans le même dossier, puis implémentez chaque remarque marquée pour l'envoi. …

La suite demande à l'agent de vérifier chaque changement sur l'écran réel, de noter son avancement pour chaque remarque et de terminer par une liste Terminé / Non terminé. L'agent lit .ferret/reviews/<timestamp>/feedback.md et les PNG placés à côté. La vidéo n'est jamais envoyée. Vous utilisez un agent en dehors de Ferret ? Cliquez sur Copier pour l'agent et collez.

L'instruction par défaut suit la langue d'affichage. Vous pouvez la remplacer dans les réglages : voir Personnaliser l'instruction.
