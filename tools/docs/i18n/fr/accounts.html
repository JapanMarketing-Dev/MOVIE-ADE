Comptes et utilisation Passez d'une connexion Claude Code ou Codex à une autre, et suivez vos fenêtres de limite d'utilisation dans le pied de page. Ces deux fonctions ne marchent pour l'instant qu'avec Claude Code et Codex ; les autres agents continuent d'utiliser leur propre connexion comme d'habitude. ## Plusieurs comptes

Les comptes sont facultatifs. Ajoutez-en seulement si vous jonglez entre plusieurs.

  1. Ouvrez Réglages → Comptes, ou Gérer les comptes… depuis le menu d'utilisation du pied de page.
  2. Ajouter un compte lance la connexion de l'agent dans un onglet du terminal intégré.
  3. Choisissez le compte à utiliser. Les onglets en cours gardent leur compte. Les nouveaux onglets utilisent celui qui est sélectionné.

Fonctionnement : chaque compte ajouté a son propre dossier de configuration, <userData>/accounts/<agent>/<id>/. Ferret lance l'agent avec CLAUDE_CONFIG_DIR (Claude Code) ou CODEX_HOME (Codex) pointant vers ce dossier. Par défaut du système utilise vos ~/.claude / ~/.codex habituels, sans modification.

Supprimer un compte supprime son dossier de configuration. Cela ne vous déconnecte pas côté serveur.

## Utilisation dans le pied de page

Le pied de page indique la part utilisée de chaque fenêtre de limite : la fenêtre de 5 heures et la fenêtre hebdomadaire, plus la fenêtre hebdomadaire par modèle pour Claude. Les couleurs passent au jaune à 60 % et au rouge à 80 %. Les valeurs se mettent à jour toutes les 15 minutes, ou avec Rafraîchir l'utilisation.

Le niveau de détail dépend de la place disponible dans le pied de page. S'il y a de la place, il affiche des barres, les noms des fenêtres et les pourcentages. À mesure que le pied de page se rétrécit, il retire d'abord les éléments les moins utiles, jusqu'à ne garder qu'un pourcentage par agent. Cliquez sur l'utilisation pour tout voir dans une fenêtre contextuelle.

L'utilisation est récupérée directement auprès d'Anthropic (api.anthropic.com/api/oauth/usage) et de ChatGPT (chatgpt.com/backend-api/wham/usage) avec les identifiants du compte connecté.

{{shot:usage|Utilisation dans le pied de page}} ## Continuer à travailler aux limites d'utilisation

Quand un agent atteint sa limite d'utilisation, Ferret poursuit le même travail dans le même dossier de projet, pour qu'une longue tâche ne s'arrête pas à la limite. C'est activé par défaut et se règle dans Réglages → Comptes → Changement à la limite d’utilisation.

Le travail est transmis par un seul fichier du projet, .ferret/handoff.md ; cela fonctionne donc aussi bien entre comptes qu'entre agents différents. Les instructions de Envoyer à l'agent demandent à l'agent de tenir ce fichier à jour à chaque étape importante et lorsqu'il approche d'une limite d'utilisation : l'objectif, ce qui est fait, le travail restant sous forme de liste de contrôle, les fichiers modifiés, la prochaine étape, les chemins de feedback.md et des relectures concernées, et tout point d'attention. .ferret/ reste hors de git (il est ajouté à .git/info/exclude, pas à .gitignore).

  1. Ferret détecte la limite à partir du message de l'agent lui-même dans le terminal (par exemple 5-hour limit reached ∙ resets 3pm dans Claude Code, You've hit your usage limit dans Codex) ou lorsque l'utilisation affichée dans le pied de page atteint le seuil (95 % par défaut ; la plus élevée des fenêtres de 5 heures, hebdomadaire et par modèle).
  2. Avant de changer, Ferret demande à l'agent actuel de mettre à jour .ferret/handoff.md. Si l'agent ne s'y met pas (par exemple parce qu'il est déjà à sa limite), Ferret ajoute au fichier ce qu'il sait : la dernière demande, l'emplacement de feedback.md et les fichiers modifiés d'après git status.
  3. Ferret passe ensuite à un autre compte connecté du même agent, celui dont l'utilisation est la plus faible. Quand tous les comptes de l'agent sont à leur limite, le travail passe à l'agent suivant dans Ordre des agents (par défaut : Claude Code → Codex → Gemini CLI).
  4. Le nouvel agent s'ouvre dans un nouvel onglet du même projet et reçoit, dans la langue de l'application, la consigne de lire d'abord .ferret/handoff.md puis de poursuivre le travail restant.
  5. Le pied de page affiche Maintenant avec <agent> et une notification indique ce qui a changé, par exemple Codex a atteint sa limite d’utilisation, donc Claude Code a repris le travail. L'onglet qui a atteint la limite est fermé, pour qu'il ne reprenne pas la même tâche quand sa limite est réinitialisée.
