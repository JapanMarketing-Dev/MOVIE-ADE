Отправка агентам Запускайте агента для написания кода во встроенном терминале и передавайте ему ревью одним щелчком. Обычно это Claude Code и Codex, но подойдёт любой агент из списка ниже, а также CLI, добавленный вами. Можно также скопировать инструкцию для агента, работающего в другом месте. ## Работа с замечаниями

Каждая карточка во вкладке Замечания поддерживает:

  • правку заголовка и запроса прямо на месте;
  • переключатель Отправить / Не отправлять;
  • Смотреть запись (переход к этому моменту) и Заменить изображение (выбор другого кадра);
  • Подтвердить, Удалить.

Фильтр по прогрессу показывает или скрывает замечания по статусу (например, Только те, что ждут вашей проверки); Показать все сбрасывает фильтр.

Чтобы изменить порядок замечаний, перетащите маркер слева от заголовка карточки или выберите маркер и нажмите ↑ / ↓. Номера, feedback.md и то, что вы отправляете агенту, следуют новому порядку. Когда включён фильтр, порядок меняется среди видимых замечаний, а скрытые остаются на своих местах. Если ревью охватывает несколько страниц или файлов, замечания перемещаются внутри своей группы. Сортировка замечаний в заголовке переключает Вручную (порядок перетаскивания), По времени записи и По прогрессу (сначала не начатые, в конце готовые); сортировка по прогрессу сохраняет этот порядок как ручной.

В заголовке есть кнопки Отменить, Открыть папку, Копировать для агента, Обработать и Отправить агенту. Речь, которая не стала замечанием, перечислена в разделе Исключённая речь, где Вернуть как замечание возвращает её. Речь без осмысленных слов никогда не становится замечанием и тоже попадает в этот список: фразы, которые распознавание речи иногда выдумывает из тишины, например «Shh.» или «Спасибо за просмотр», слова-паразиты вроде «э-э», а также одиночное «OK» или «да» без пометки пером.

{{shot:findings|Вкладка «Замечания»}} ## Агенты во встроенном терминале

При открытии проекта Ferret запускает по одной вкладке терминала на каждого агента из Настройки → Агенты → Запуск при открытии проекта — в папке проекта. По умолчанию это Claude Code и Codex, запущенные без запросов разрешений и с включённым Claude in Chrome:

claude --dangerously-skip-permissions --chrome
codex --dangerously-bypass-approvals-and-sandbox

Вместо них можно выбрать любых агентов из списка поддерживаемых (они запускаются в порядке выбора) или ни одного.

Агенты, которых вы открываете сами, запускаются так же. Ferret также отмечает папку проекта как доверенную для Claude Code и Codex, поэтому они не спрашивают о ней. Чтобы запускать их в обычном режиме, где они спрашивают, прежде чем доверять папке, редактировать файлы или выполнять команды, выключите Настройки → Агенты → Запускать агентов без запросов разрешений. Команда и аргументы каждого агента находятся в Настройки → Агенты (Команда) и в settings.json (agents.launch) и используются ровно так, как вы их написали. Уберите там --chrome, чтобы запускать Claude Code без Claude in Chrome. Если аргументы уже задают режим разрешений (например, --permission-mode plan или --sandbox workspace-write для Codex), флаг пропуска не добавляется.

Если ни один агент не выбран, открывается обычная оболочка. Меню + открывает Новый терминал, запускает любого из ваших агентов в новой вкладке или переходит в Настройки агентов…. Его поле поиска также находит вкладки, сохранённые URL и файлы.

Перетаскивание файлов в терминал. Перетащите файлы, папки или изображения из Finder (из проводника в Windows, из файлового менеджера в Linux) на панель терминала, и их пути будут введены в эту панель через пробел, без нажатия Enter. Это работает и во время работы агента: путь к перетащенному изображению Claude Code читает как изображение. Строки, перетащенные из раздела Файлы (можно выбрать несколько сразу), работают так же: путь относителен папке проекта, пока терминал находится в ней, и абсолютный после cd в другое место. Пути с пробелами или другими специальными символами заключаются в кавычки для оболочки: '…' в zsh и bash, "…" в командной строке Windows и '…' в PowerShell.

Вкладки показывают состояние агента: Работает, Ожидает ввода, Готово (не прочитано), Простаивает. Готово (не прочитано) означает, что агент закончил, пока вы смотрели другую вкладку; состояние сменится на Простаивает, как только вы откроете эту вкладку. Боковая панель отмечает каждый проект так же, поэтому это видно без переключения проектов: движущиеся полоски, пока агент работает, вопросительный знак, пока агент ждёт вас, и галочка, когда агенты в проекте закончили, а вы ещё не открыли вкладку.

Уведомления. Включите Настройки → Агенты → Уведомлять, когда агенты закончат или им нужен я, чтобы получать системное уведомление, когда все агенты в проекте закончили или когда агент ждёт разрешения или ответа. Для вкладки, которую вы сейчас смотрите, ничего не показывается. Нажмите на уведомление, чтобы перейти в этот проект и открыть вкладку.

  • на внешней четверти края панели: Разделить влево / Разделить вправо / Разделить вверх / Разделить вниз;
  • в центре панели: Открыть как вкладку (панель выходит из разделения и становится отдельной вкладкой);

## Поддерживаемые агенты

Ferret не привязан к одному агенту. Он распознаёт перечисленных ниже агентов для написания кода: может запускать их, находить в терминале для Отправить агенту и показывать, установлены ли они. Настройки → Агенты перечисляют их с пометкой Установлен / Не найден, кнопкой Установить там, где разработчик агента публикует установщик в одну строку, а также с командой и аргументами для каждого.

{{agent-catalog}}

Нужного нет в списке? Настройки → Агенты → Добавить своего агента регистрирует любой CLI или скрипт-обёртку (название, команда и, при желании, имя процесса, по которому его распознавать); можно также добавить его в agents.customAgents в settings.json.   • Аккаунты и использование: переключение между несколькими входами и индикатор лимитов в нижней панели.
  • Обработать: работает через ваш вход в Claude Code или Codex либо через настроенный вами LLM API.
## Отправить агенту / Копировать для агента {{clip:send|Из вкладки «Замечания» — агенту во встроенном терминале кнопкой «Отправить агенту».}}
  1. Нажмите Отправить агенту. По умолчанию (Авто (текущая вкладка или запущенный агент)) замечания уходят агенту в текущей вкладке терминала или запущенному агенту. Стрелка рядом с кнопкой (Выбрать агента для отправки) позволяет выбрать конкретного агента или вкладку.
  2. Ferret записывает инструкцию в поле ввода агента и отправляет её. Следите за ходом работы в терминале.

Если ни один агент не запущен, Ferret сначала запускает его и отправляет, как только он будет готов. Пока агент ждёт ответа на запрос разрешения, ничего не отправляется. Сначала ответьте в терминале.

Копировать для агента помещает ту же инструкцию в буфер обмена для агента, работающего в другом месте (в другом терминале, IDE или приложении). Учитываются только замечания, переключённые на Отправить. Видео никогда не включается.

## Проверка приёмки моделью решений {{clip:verify|Агент исправляет замечания и проверяет каждое моделью решений, пока все не пройдут.}}

Включите эту функцию, и ваш агент для написания кода будет проверять свою работу по каждому замечанию, прежде чем сообщить «Готово». Сам Ferret ничего не оценивает: он даёт агенту модель решений (любой API, совместимый с System One) и в feedback.md поручает ему повторять цикл, пока все замечания не пройдут.

  1. Агент реализует замечания.
  2. Для каждого замечания он снимает скриншот ПОСЛЕ (с тем же viewport и состоянием страницы, что и кадр ДО) и отправляет модели решений один запрос с текстом замечания, его строкой «Готово, когда» и изображениями ДО/ПОСЛЕ.
  3. Замечание проходит, когда P(done) не ниже порога (по умолчанию 0.7) и выбран вариант done. Агент исправляет остальное и в каждом раунде заново оценивает все замечания; он останавливается, только когда все замечания проходят в одном раунде, либо по честной причине, которую обязан назвать: API недоступен, замечание вне рамок задачи или замечание застряло с неизменными оценками.
  4. Итоговый список «Готово / Не готово» включает оценки по каждому замечанию и число раундов.

Настройте это в Настройки → Модель решений и включите Добавить проверку моделью решений в инструкции агента. Пресеты лишь заполняют поля; все поля остаются редактируемыми, а Свой работает с любым совместимым API.

Для Ollama установите его (0.35.1 или новее для Clef / Clef Flash) и скачайте модель в терминале. Ferret не запускает установщики:

ollama pull clef-flash

Ключи берутся из поля ключа (сохраняется вместе с другими вашими API-ключами), из указанной вами переменной окружения (окружение приложения, .env проекта или ~/.ferret/.env) или из apiKey в settings.json. Дополнительные заголовки могут брать значения из переменных окружения через ${VAR}.

Как ключ не попадает в промпты

Агенты никогда не видят ваш ключ. Ferret запускает локальный релей на 127.0.0.1 и передаёт каждому терминалу FERRET_DECISION_URL (релей с токеном для этого терминала), FERRET_DECISION_MODEL и FERRET_DECISION_IMAGES (в течение одного выпуска задаются также старые имена MOVIE_ADE_DECISION_*). Релей добавляет ключ и заголовки и пересылает запрос без изменений, поэтому промпты, feedback.md и расшифровки сессий агентов не содержат секретов. Токен каждого терминала позволяет 500 вызовов, 30 в минуту, 20 млн токенов и 5 $ (если стоимость известна), а каждый проект — 2 000 вызовов и 20 $ в день; при достижении лимита релей отвечает 429 с причиной, а новая вкладка терминала получает новый токен. После изменения настроек модели решений токены открытых терминалов перестают действовать; терминалы, открытые после этого, используют новые настройки.

Cloudflare отличается от документации System One в двух местах (проверено на работающем API): изображения должны быть data URI (data:image/jpeg;base64,…, иначе 422 "image must be an embedded base64 data URI"), а ответ обёрнут в { "result": { … }, "success": true } (ошибки возвращаются как { "success": false, "errors": [ … ] }). Пресет Cloudflare устанавливает Кодирование изображений в data URI, агенты получают это как FERRET_DECISION_IMAGE_FORMAT, а инструкции велят им читать .result, если он есть. Релей пропускает данные в обоих направлениях без изменений. Чтобы использовать Global API Key вместо API-токена, выберите в Аутентификация значение Без ключа и добавьте заголовки X-Auth-Email: ${CLOUDFLARE_EMAIL} и X-Auth-Key: ${CLOUDFLARE_API_KEY}.

Изображения читают только Clef и Clef Flash. С текстовой моделью отключите Отправлять изображения ДО/ПОСЛЕ; тогда агент оценивает только по тексту, что менее надёжно.

Ollama и большие изображения

Ollama 0.35.0 ограничивает запросы к /v1/systemone 64 KiB, поэтому запросы со скриншотами завершаются ошибкой HTTP 413. Инструкции велят агенту уменьшать оба изображения до ширины не более 1024px в формате JPEG (качество около 70). Если 413 всё равно возникает, обновите Ollama до 0.35.1 или новее либо перейдите на Cloudflare Workers AI.

## Использование API в нижней панели

Вызовы модели решений идут через релей, поэтому Ferret может их подсчитывать. Элемент нижней панели рядом с индикатором использования агентов показывает модель решений и сегодняшние вызовы, токены и стоимость (например, clef-flash · 42 calls · 18.3k tok). Щёлкните по нему, чтобы увидеть данные за сегодня, за этот месяц, по проектам, по моделям и по видам (модель решений / распознавание / обработка), а также последние 50 вызовов.

Стоимость показывается, только если API её сообщает (Vercel AI Gateway сообщает) или если вы задали цены за 1M токенов в Настройки → Модель решений; иначе отображается «—». В ~/.ferret/usage/decision-YYYY-MM.jsonl, по одному файлу в месяц, записываются только метаданные (время, проект, модель, статус, задержка, размер, число изображений, токены, стоимость) — никогда изображения, текст или ключи.

## Поставить звезду Ferret на GitHub

После первого Отправить агенту, а также при достижении 3, 10 и 30 завершённых ревью Ferret может предложить поставить ему звезду на GitHub. Он спрашивает не более 3 раз, с перерывом не менее 3 дней, и никогда во время записи. Поставить звезду ставит звезду через ваш собственный вход в gh (или открывает GitHub, если gh недоступен), а Больше не спрашивать отключает эти предложения. Поставить звезду можно также через Справка → Поставить звезду Ferret на GitHub.

## CLI сервисов

Настройки → CLI сервисов показывает инструменты командной строки часто используемых сервисов, чтобы ваши агенты могли с ними работать. Устанавливать их не обязательно: установите только то, что нужно; Ferret работает и без них. В каждой строке видно, установлен ли инструмент и какая у него версия, есть ссылка на сайт сервиса и кнопки, которые запускают официальную команду установки или входа для вашей ОС в новой вкладке терминала:

  • Git-хостинг: GitHub (gh), GitLab (glab)
  • Хостинг и развёртывание: Vercel, Netlify, Cloudflare (wrangler), Firebase, Fly.io, Railway, Heroku
  • Облако: AWS, Google Cloud (gcloud), Azure (az)
  • Базы данных и бэкенд: Supabase, Neon, PlanetScale, Turso
  • Ошибки и мониторинг: Sentry (sentry-cli), Datadog (datadog-ci)
  • Платежи: Stripe
  • Контейнеры: Docker, kubectl
  • Мобильная разработка: Xcode Command Line Tools (Только macOS), Android Platform Tools (adb), Expo EAS, fastlane
  • Виртуальные машины: UTM (Только macOS), Lima, Multipass
  • ИИ и модели: Ollama

Если у инструмента нет официального установщика в одну строку для вашей ОС, Документация открывает его страницу установки. Когда установка завершается, список сам проверяет всё заново.
