Аккаунты и использование Переключайтесь между несколькими входами в Claude Code или Codex и следите за окнами лимитов запросов в нижней панели. Пока обе функции работают только с Claude Code и Codex; другие агенты, как обычно, используют собственный вход. ## Несколько аккаунтов

Аккаунты необязательны. Добавляйте их, только если переключаетесь между несколькими.

  1. Откройте Настройки → Аккаунты или выберите Управление аккаунтами… в меню использования в нижней панели.
  2. Добавить аккаунт запускает вход агента во вкладке встроенного терминала.
  3. Выберите аккаунт, который нужно использовать. Уже запущенные вкладки сохраняют свой аккаунт. Новые вкладки используют выбранный.

Как это работает: у каждого добавленного аккаунта своя папка конфигурации, <userData>/accounts/<agent>/<id>/. Ferret запускает агента с CLAUDE_CONFIG_DIR (Claude Code) или CODEX_HOME (Codex), указывающими на неё. Системный по умолчанию использует ваши обычные ~/.claude / ~/.codex без изменений.

Удаление аккаунта удаляет его папку конфигурации. Выход из аккаунта на сервере при этом не выполняется.

## Использование в нижней панели

Нижняя панель показывает, какая часть каждого окна лимита использована: 5-часовое окно и недельное окно, а для Claude ещё и недельное окно по каждой модели. При 60% цвет становится жёлтым, при 80% — красным. Значения обновляются каждые 15 минут или по кнопке Обновить использование.

Объём показываемых данных зависит от места в нижней панели. Если места достаточно, отображаются полосы, названия окон и проценты. По мере сужения панели сначала скрываются менее полезные части, вплоть до одного процента на агента. Щёлкните по показателю использования, чтобы увидеть всё во всплывающем окне.

Данные об использовании запрашиваются напрямую у Anthropic (api.anthropic.com/api/oauth/usage) и ChatGPT (chatgpt.com/backend-api/wham/usage) с учётными данными аккаунта, в который выполнен вход.
