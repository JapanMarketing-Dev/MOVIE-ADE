Файлы и окружение Где Ferret хранит свои файлы и какие переменные окружения он читает или задаёт. ## Папка userData

Данные приложения хранятся в папке userData Electron. Её имя зафиксировано как ade-movie (а не название продукта), поэтому данные сохраняются при переименованиях. Её можно переопределить параметром --user-data-dir=<path>.

ОСПуть
macOS~/Library/Application Support/ade-movie/
Windows%APPDATA%\ade-movie\
Linux~/.config/ade-movie/ (или $XDG_CONFIG_HOME/ade-movie/)
 
settings.json       # settings before 0.1.1, kept as a backup (now ~/.ferret/settings.json)
stt-keys.bin        # API keys, encrypted with safeStorage
browser-import/     # imported passwords (passwords.bin, encrypted with safeStorage) and history (history.json)
login-shell-path.json  # your login shell's PATH from the last launch, so agent tabs start without waiting
models/             # downloaded whisper models (ggml-*.bin)
accounts/claude/<id>/   # CLAUDE_CONFIG_DIR for added accounts
accounts/codex/<id>/    # CODEX_HOME for added accounts

Ваших настроек в этой папке нет: они находятся в ~/.ferret/ (см. Настройка через settings.json).

Модель, выбранная вами вручную, может лежать где угодно. Старое расположение по умолчанию ~/.cache/ade-movie/models/ggml-small.bin по-прежнему проверяется.

## Переменные окружения
ПеременнаяДействие
CLAUDE_CONFIG_DIR, CODEX_HOMEЗадаются Ferret для вкладок агентов, когда выбран добавленный аккаунт
GH_TOKEN, GITHUB_TOKENИспользуются gh в приоритете над его собственным входом. Ferret предупреждает, если задана любая из них
FERRET_CONFIG_DIR (или старая MOVIE_ADE_CONFIG_DIR)Папка для settings.json, state.json и settings.schema.json вместо ~/.ferret
Имена в apiKeyEnvAPI-ключи, на которые вы ссылаетесь из settings.json. Также читаются из .env проекта и ~/.ferret/.env
ADE_PROJECT_DIRПри запуске открыть (и зарегистрировать) эту папку как проект
ADE_INITIAL_URLПри запуске загрузить этот URL во встроенном браузере
ADE_WHISPER_MODELАбсолютный путь к модели GGML для распознавания на устройстве; заменяет скачанную модель по умолчанию
ADE_TERMINAL_PREWARM0 отключает заранее подготовленную в фоне оболочку. По умолчанию её получает следующая обычная вкладка оболочки, поэтому приглашение появляется сразу
FERRET_SENTRY_DSN (или старая MOVIE_ADE_SENTRY_DSN)Куда отправляются отчёты о сбоях. Пустое значение — ничего не отправляется (см. Отчёты о сбоях)
OPENAI_API_KEYЧитается из .env только при разработке (pnpm dev), никогда в собранных версиях
PATHИспользуется для поиска команд ваших агентов (claude, codex, gemini…), gh, git, whisper-cli. На macOS и Linux добавляются пути Homebrew, linuxbrew и snap
