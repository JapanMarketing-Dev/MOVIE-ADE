## settings.json

Всё перечисленное хранится в ~/.ferret/settings.json (путь одинаков во всех ОС), а рядом лежит JSON Schema. Файл можно редактировать, пока приложение работает, вручную или с помощью агента для написания кода; изменения применяются сразу. См. Настройка через settings.json.
