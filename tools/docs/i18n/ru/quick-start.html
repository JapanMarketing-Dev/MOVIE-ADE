Быстрый старт Установите Ferret, откройте проект и URL его dev-сервера, запишите один фидбэк и передайте его вашему агенту для написания кода. Это займёт около пяти минут. ## Перед началом {{clip:quick-start|Откройте страницу, начните запись, обведите место и расскажите о нём, остановите запись и отправьте замечания агенту.}}
  • Агент для написания кода, который работает в терминале, установлен и в котором выполнен вход: например, Claude Code (claude), Codex (codex) или Gemini CLI (gemini). Ferret запускает его во встроенном терминале. Подойдёт любой агент из списка поддерживаемых, а также любой другой CLI, который вы добавите сами.
  • Веб-приложение, которое открывается по URL, например dev-сервер на http://localhost:3000.
  • Микрофон. Фидбэк — это ваш голос плюс перо. Без микрофона обведённые пером места всё равно становятся замечаниями, но без слов.
## 1. Установка

Скачайте Ferret на странице загрузки и откройте его. Шаги для каждой ОС описаны в разделе Установка.

## 2. Откройте проект и URL
  1. Выберите Файл → Открыть папку проекта… ({{keys:Mod+O}}) и укажите корень репозитория.
  2. Введите URL dev-сервера в адресную строку браузера ({{keys:Mod+L}}) и нажмите Enter.
  3. По желанию нажмите + (Сохранить текущий URL), чтобы сохранить его как пресет, открываемый одним щелчком, например local, dev или prd.

При открытии проекта в этой папке также запускаются ваши агенты во вкладках терминала. По умолчанию это Claude Code и Codex; выберите нужные в Настройки → Агенты → Запуск при открытии проекта (см. Настройки).

## 3. Запись
  1. Нажмите Запись в заголовке окна или {{keys:Mod+Shift+R}}. Окно переключится в режим фидбэка.
  2. Пользуйтесь страницей как обычно и говорите, что нужно изменить.
  3. Удерживая {{keys:Alt}} (или выбрав Перо), обведите мышью место, о котором говорите.
  4. Нажмите Стоп или ещё раз {{keys:Mod+Shift+R}}.

Каждый момент, когда вы говорите или обводите, становится одним замечанием: скриншот с пометками пером, запрос, исходные слова, URL и элемент, на который вы указали.

## 4. Проверьте замечания

После остановки окно возвращается в режим редактора и открывает вкладку Замечания.

  • Заголовок или запрос можно править прямо на месте.
  • Для каждого замечания можно переключать Отправить / Не отправлять, выбрать Объединить со следующим или Удалить.
  • Отменить откатывает последнюю правку.
## 5. Отправьте агенту
  1. Нажмите Отправить агенту. Замечания уйдут агенту в текущей вкладке терминала или запущенному агенту. Стрелка рядом с кнопкой позволяет выбрать конкретного агента или вкладку.
  2. Если ни один агент ещё не запущен, Ferret сначала запустит его и отправит, как только он будет готов.

Ferret вводит одну инструкцию в поле ввода агента и отправляет её. По умолчанию она начинается так:

Прочитай "{{path}}" и изображения замечаний в той же папке, затем реализуй каждое замечание, отмеченное для отправки. …

Дальше агента просят проверить каждое изменение на реальном экране, записывать прогресс по каждому замечанию и в конце выдать список «Готово / Не готово». Агент читает .ferret/reviews/<timestamp>/feedback.md и PNG-файлы рядом с ним. Видео никогда не отправляется. Используете агента вне Ferret? Нажмите Копировать для агента и вставьте текст.

Инструкция по умолчанию зависит от языка интерфейса. Её можно заменить в настройках: см. Настройка инструкции.
