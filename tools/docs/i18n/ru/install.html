Установка Скачайте Ferret для своего компьютера и откройте его. Он работает на macOS, Windows и Linux. ## Скачивание

На странице загрузки предлагается подходящий файл для вашего компьютера. Нажмите кнопку загрузки.

## macOS

Откройте .dmg, перетащите Ferret в Applications и запустите его оттуда.

## Windows

Запустите скачанный .exe. Ferret установится и откроется, ничего выбирать не нужно. В следующий раз открывайте его из меню «Пуск» или ярлыком на рабочем столе.

Если Windows покажет Система Windows защитила ваш компьютер, нажмите Подробнее, затем Выполнить в любом случае.

## Linux

Ubuntu / Debian: дважды щёлкните .deb, чтобы установить его через центр приложений, или выполните:

sudo apt install ./Ferret-<version>-linux-amd64.deb

Затем откройте Ferret из меню приложений или выполните ferret.

Другие дистрибутивы: используйте .AppImage. Разрешите запускать его как программу (щелчок правой кнопкой → Свойства или chmod +x), затем откройте.
