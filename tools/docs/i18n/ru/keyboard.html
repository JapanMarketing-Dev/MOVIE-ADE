Сочетания клавиш Сочетания показаны для ОС, в которой вы читаете эту страницу; чтобы увидеть другую, воспользуйтесь переключателем ниже. В большинстве сочетаний на macOS используется Command там, где в Windows и Linux — Ctrl, и Option там, где — Alt. Некоторые отличаются сильнее, и в таблицах приведены оба варианта. Источник: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts, а также обработка клавиш в терминале. ## Запись

Сменить режим (редактор / фидбэк){{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}
Перо, пока клавиша удерживается{{keys-mac:Alt}}{{keys-win:Alt}}
## Рисование во время записи

Эти клавиши работают, когда вы записываете встроенный браузер и фокус находится на странице. Пока вы печатаете в поле на странице, они игнорируются, а буквенные клавиши работают только без клавиш-модификаторов, поэтому собственные сочетания клавиш страницы продолжают работать.

## Терминал
ДействиеmacOSWindows / Linux
Новый терминал{{keys-mac:Mod+T}}{{keys-win:Mod+T}}
Закрыть панель / вкладку{{keys-mac:Mod+W}}{{keys-win:Mod+W}}
Разделить вправо{{keys-mac:Mod+D|Ctrl+Shift+D}}{{keys-win:Mod+D|Ctrl+Shift+D}}
Разделить вниз{{keys-mac:Mod+Shift+D|Alt+Shift+D}}{{keys-win:Mod+Shift+D|Alt+Shift+D}}
Копировать выделенное{{keys-mac:Mod+C|Ctrl+Shift+C / Ctrl+C}}{{keys-win:Mod+C|Ctrl+Shift+C / Ctrl+C}}
Вставить{{keys-mac:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}{{keys-win:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}
Новая строка в запросе агенту{{keys-mac:Shift+Enter}}{{keys-win:Shift+Enter}}
Начало / конец строки{{keys-mac:Mod+Left / Mod+Right|}}{{keys-win:Mod+Left / Mod+Right|}}
Удалить до начала строки{{keys-mac:Mod+Backspace|}}{{keys-win:Mod+Backspace|}}

Эти сочетания работают, когда фокус находится в терминале. В Windows и Linux Ctrl+C копирует, если выделен текст, и останавливает выполняемую команду, если ничего не выделено. {{keys:Shift+Enter}} начинает новую строку, пока работает агент, например Claude Code или Codex; в обычной оболочке он выполняет команду, как Enter. В полноэкранной программе, которая использует мышь (vim, tmux, агент), на macOS удерживайте Option при перетаскивании, чтобы выделить текст.
