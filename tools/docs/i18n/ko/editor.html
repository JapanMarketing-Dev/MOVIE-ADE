에디터와 미리 보기 프로젝트 파일을 열고 편집하며, Markdown과 Mermaid를 미리 봅니다. 내장 브라우저에서 연 미리 보기는 일반 웹 페이지처럼 녹화하고 리뷰할 수 있습니다. ## 파일 열기와 편집
  • 파일(파일 트리): {{keys:Mod+Shift+E}}. 파일 이름으로 필터, 새로고침, 모두 접기가 있습니다.
  • 파일로 이동…: {{keys:Mod+P}}.
  • {{keys:Mod+S}}로 저장합니다. 수정한 파일을 닫으면 <name>의 변경 사항을 저장할까요?라고 묻고 저장, 저장 안 함, 취소 중에서 고릅니다.
  • 저장하지 않은 편집이 있는 동안 디스크의 파일이 바뀌면 디스크에서 다시 불러오기 또는 내 변경 사항 유지를 고릅니다.

에디터는 Monaco입니다. 텍스트가 아닌 파일은 대신 뷰어로 열립니다. 이미지(확대와 축소. SVG는 코드로도 표시 가능), 탐색 막대가 있는 동영상과 오디오, PDF, 그리고 그 밖의 바이너리 파일은 크기와 앞부분 바이트의 16진수 보기를 보여 줍니다. 뷰어는 읽기 전용이며, 프로젝트 폴더 밖의 파일이나 폴더 밖으로 나가는 심볼릭 링크를 통해 닿는 파일은 표시되지 않습니다.

## 파일 만들기, 이름 바꾸기, 삭제

VS Code에서처럼 파일에서 바로 파일을 다룹니다. 이름은 트리 안에서 직접 입력합니다.

  • 새 파일 / 새 폴더: 트리 위의 버튼을 누르거나, 폴더(또는 트리 아래의 빈 공간)를 마우스 오른쪽 버튼으로 클릭합니다. 새 항목은 선택한 폴더 안, 선택한 파일 옆, 또는 프로젝트의 맨 위에 만들어집니다. 새 파일은 에디터에서 열립니다.
  • 이름 바꾸기: {{keys:F2 / Enter|F2}} 또는 마우스 오른쪽 버튼 클릭. 열린 탭은 새 이름을 따라가며 저장하지 않은 편집도 유지됩니다.
  • 삭제: {{keys:Mod+Backspace / Delete|Delete}} 또는 마우스 오른쪽 버튼 클릭. Ferret이 먼저 확인한 뒤 항목을 휴지통으로 옮기므로 복원할 수 있습니다. 삭제한 파일의 탭은 닫히며, 저장하지 않은 편집이 있던 탭이 있으면 확인 화면에 그렇게 표시됩니다.
  • {{keys:Mod}}-클릭이나 {{keys:Shift}}-클릭으로 여러 항목을 선택해 한꺼번에 삭제할 수 있습니다.
  • {{keys:Esc}}는 입력 중인 이름을 취소합니다.

Ferret은 같은 이름의 기존 파일이나 폴더를 덮어쓰지 않으며, 프로젝트 폴더 밖으로 나가는 것(.., 절대 경로, 밖을 가리키는 심볼릭 링크), .git 안의 것, 그리고 일부 OS에서 쓸 수 없는 이름을 거부합니다. / \ < > : " | ? *, 제어 문자, 끝의 공백이나 점, CON이나 NUL 같은 Windows 예약 이름이 여기에 해당합니다.

## Markdown과 Mermaid 미리 보기

미리 보기는 .md, .markdown, .mdx, .mmd, .mermaid에서 사용할 수 있습니다. Mermaid는 앱에 포함되어 있으므로 다이어그램이 오프라인에서도 렌더링됩니다.

  • 옆에 미리 보기 열기: 에디터 옆에 엽니다
  • 미리 보기 열기: 내장 브라우저(ade-preview://)에서 열리므로 녹화하고 리뷰할 수 있습니다
## 녹화로 문서 리뷰하기
  1. Markdown 파일을 열고 미리 보기 열기를 클릭합니다.
  2. 평소처럼 녹화합니다. 사양서나 설계 문서를 읽어 가며 말하고, 잘못된 부분을 동그라미로 표시합니다.
  3. 중지합니다. 지적 사항에는 URL 대신 프로젝트 기준의 파일 상대 경로가 들어갑니다.
  4. 에이전트에게 보내기로 문서를 고치게 합니다.
