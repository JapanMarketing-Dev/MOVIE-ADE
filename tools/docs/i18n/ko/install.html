설치 사용하는 컴퓨터용 Ferret을 내려받아 엽니다. macOS, Windows, Linux에서 실행됩니다. ## 다운로드

다운로드 페이지가 사용하는 컴퓨터에 맞는 파일을 안내합니다. 다운로드 버튼을 클릭하세요.

## macOS

.dmg를 열고 Ferret을 Applications로 드래그한 뒤, 그곳에서 엽니다.

## Windows

내려받은 .exe를 실행합니다. 따로 선택할 것 없이 Ferret이 설치되고 열립니다. 다음부터는 시작 메뉴나 바탕 화면 바로 가기에서 엽니다.

Windows에 Windows의 PC 보호가 표시되면 추가 정보를 클릭한 다음 실행을 클릭합니다.

## Linux

Ubuntu / Debian: .deb를 더블 클릭해 소프트웨어 센터로 설치하거나, 다음을 실행합니다.

sudo apt install ./Ferret-<version>-linux-amd64.deb

그런 다음 앱 메뉴에서 Ferret을 열거나 ferret을 실행합니다.

그 밖의 배포판: .AppImage를 사용합니다. AppImage는 FUSE 2로 실행되므로, 시스템에 없다면 먼저 해당 패키지를 설치합니다: Fedora는 fuse-libs, Arch는 fuse2, openSUSE와 Debian 계열은 libfuse2. 그런 다음 .AppImage를 프로그램으로 실행할 수 있게 허용하고(마우스 오른쪽 버튼 → 속성, 또는 chmod +x) 엽니다.
