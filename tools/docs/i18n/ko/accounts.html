계정과 사용량 여러 Claude Code 또는 Codex 로그인을 전환하고, 푸터에서 사용량 제한 구간을 확인합니다. 두 기능 모두 현재는 Claude Code와 Codex에서만 작동하며, 다른 에이전트는 평소처럼 자체 로그인을 계속 사용합니다. ## 여러 계정

계정은 선택 사항입니다. 여러 계정을 전환해 쓸 때만 추가하세요.

  1. 설정 → 계정을 열거나, 푸터의 사용량 메뉴에서 계정 관리…를 엽니다.
  2. 계정 추가를 누르면 내장 터미널 탭에서 에이전트의 로그인이 시작됩니다.
  3. 사용할 계정을 고릅니다. 실행 중인 탭은 원래 계정을 유지하고, 새 탭은 선택한 계정을 사용합니다.

작동 방식: 추가한 계정마다 별도의 설정 디렉터리 <userData>/accounts/<agent>/<id>/가 만들어집니다. Ferret은 CLAUDE_CONFIG_DIR(Claude Code) 또는 CODEX_HOME(Codex)이 그곳을 가리키도록 해서 에이전트를 실행합니다. 시스템 기본값은 평소의 ~/.claude / ~/.codex를 그대로 사용합니다.

계정을 제거하면 그 설정 디렉터리가 삭제됩니다. 서버에서 로그아웃되지는 않습니다.

## 푸터의 사용량

푸터에는 각 사용량 제한 구간을 얼마나 썼는지가 표시됩니다. 5시간 구간과 주간 구간, 그리고 Claude는 모델별 주간 구간도 표시됩니다. 60%에서 노란색, 80%에서 빨간색으로 바뀝니다. 값은 15분마다 또는 사용량 새로고침을 누를 때 갱신됩니다.

표시되는 정보의 양은 푸터의 공간에 따라 달라집니다. 공간이 충분하면 막대, 구간 이름, 백분율이 표시됩니다. 푸터가 좁아질수록 덜 중요한 부분부터 숨겨지며, 마지막에는 에이전트당 백분율 하나만 남습니다. 사용량을 클릭하면 팝오버에서 모든 정보를 볼 수 있습니다.

사용량은 로그인한 계정 자체의 자격 증명으로 Anthropic(api.anthropic.com/api/oauth/usage)과 ChatGPT(chatgpt.com/backend-api/wham/usage)에서 직접 가져옵니다.

{{shot:usage|푸터의 사용량}} ## 사용 한도에 도달해도 작업 계속하기

에이전트가 사용 한도에 도달하면 Ferret은 같은 프로젝트 폴더에서 같은 작업을 이어 가므로, 긴 작업이 한도에서 멈추지 않습니다. 기본으로 켜져 있으며 설정 → 계정 → 사용 한도에서 자동 전환에서 설정합니다.

작업은 프로젝트 안의 파일 하나, .ferret/handoff.md를 통해 인계되므로 계정 사이에서도, 서로 다른 에이전트 사이에서도 똑같이 작동합니다. 에이전트에게 보내기의 지시는 단계마다, 그리고 사용 한도에 가까워졌을 때 이 파일을 최신 상태로 유지하도록 에이전트에게 요청합니다. 목표, 끝난 일, 체크리스트로 된 남은 작업, 변경한 파일, 다음 단계, 관련된 feedback.md와 리뷰 경로, 주의할 점을 적습니다. .ferret/은 git에 들어가지 않습니다(.gitignore가 아니라 .git/info/exclude에 추가됩니다).

  1. Ferret은 터미널에 나오는 에이전트 자체의 메시지(예: Claude Code의 5-hour limit reached ∙ resets 3pm, Codex의 You've hit your usage limit)나, 푸터의 사용량이 기준값(기본 95%. 5시간, 주간, 모델별 구간 중 가장 높은 값)에 도달한 것으로 한도를 알아챕니다.
  2. 전환하기 전에 Ferret은 현재 에이전트에게 .ferret/handoff.md를 업데이트하도록 요청합니다. 에이전트가 이 작업을 시작하지 않으면(예: 이미 한도에 도달한 경우) Ferret이 알고 있는 내용을 파일에 추가합니다. 마지막 요청, feedback.md의 위치, git status로 확인한 변경된 파일입니다.
  3. 그런 다음 Ferret은 같은 에이전트에 로그인한 다른 계정 중 사용량이 가장 적은 계정으로 전환합니다. 그 에이전트의 모든 계정이 한도에 도달하면 작업은 에이전트 순서(기본: Claude Code → Codex → Gemini CLI)의 다음 에이전트로 넘어갑니다.
  4. 새 에이전트는 같은 프로젝트의 새 탭에서 열리고, 앱 언어로 먼저 .ferret/handoff.md를 읽고 남은 작업을 이어 가라는 안내를 받습니다.
  5. 푸터에 지금 <agent>에서 작업 중이 표시되고, 무엇이 바뀌었는지 알림으로 알려 줍니다(예: Codex의 사용 한도로 인해 Claude Code(으)로 전환했습니다.). 한도에 도달한 탭은 닫히므로, 한도가 풀렸을 때 같은 작업을 다시 시작하지 않습니다.
