키보드 단축키 단축키는 지금 보고 있는 OS에 맞춰 표시됩니다. 다른 OS의 단축키를 보려면 아래 전환 버튼을 사용하세요. 대부분은 Windows와 Linux의 Ctrl 대신 macOS에서 Command를, Alt 대신 Option을 사용합니다. 그보다 더 다른 몇 가지는 표에 두 가지를 모두 적었습니다. 출처: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts, 터미널의 키 처리. ## 녹화
동작macOSWindows / Linux
녹화 시작 / 중지{{keys-mac:Mod+Shift+R}}{{keys-win:Mod+Shift+R}}
모드 전환(에디터 / 피드백){{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}
누르고 있는 동안 펜{{keys-mac:Alt}}{{keys-win:Alt}}
## 녹화 중 그리기
동작macOSWindows / Linux
펜{{keys-mac:P}}{{keys-win:P}}
사각형{{keys-mac:B / R}}{{keys-win:B / R}}
페이지 조작(그리기 중지){{keys-mac:V / Esc}}{{keys-win:V / Esc}}
다음 색{{keys-mac:C}}{{keys-win:C}}
마지막 표시 실행 취소{{keys-mac:Mod+Z}}{{keys-win:Mod+Z}}
다시 실행{{keys-mac:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}{{keys-win:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}

이 키는 내장 브라우저를 녹화하는 중이고 페이지에 포커스가 있을 때 작동합니다. 페이지의 입력란에 입력하는 동안에는 무시되며, 문자 키는 보조 키 없이 누를 때만 작동하므로 페이지 자체의 단축키는 그대로 쓸 수 있습니다.

## 터미널
동작macOSWindows / Linux
새 터미널{{keys-mac:Mod+T}}{{keys-win:Mod+T}}
창 / 탭 닫기{{keys-mac:Mod+W}}{{keys-win:Mod+W}}
오른쪽으로 분할{{keys-mac:Mod+D|Ctrl+Shift+D}}{{keys-win:Mod+D|Ctrl+Shift+D}}
아래로 분할{{keys-mac:Mod+Shift+D|Alt+Shift+D}}{{keys-win:Mod+Shift+D|Alt+Shift+D}}
선택 영역 복사{{keys-mac:Mod+C|Ctrl+Shift+C / Ctrl+C}}{{keys-win:Mod+C|Ctrl+Shift+C / Ctrl+C}}
붙여넣기{{keys-mac:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}{{keys-win:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}
에이전트 프롬프트에서 줄 바꿈{{keys-mac:Shift+Enter}}{{keys-win:Shift+Enter}}
줄의 처음 / 끝으로{{keys-mac:Mod+Left / Mod+Right|}}{{keys-win:Mod+Left / Mod+Right|}}
줄의 처음까지 삭제{{keys-mac:Mod+Backspace|}}{{keys-win:Mod+Backspace|}}

이 단축키는 터미널에 포커스가 있을 때 작동합니다. Windows와 Linux에서 Ctrl+C는 텍스트가 선택되어 있으면 복사하고, 선택된 것이 없으면 실행 중인 명령을 멈춥니다. {{keys:Shift+Enter}}는 Claude Code나 Codex 같은 에이전트가 실행 중일 때 새 줄을 시작하고, 일반 셸에서는 Enter처럼 명령을 실행합니다. 마우스를 쓰는 전체 화면 프로그램(vim, tmux, 에이전트)에서 macOS의 경우 Option을 누른 채 드래그하면 텍스트를 선택할 수 있습니다.
