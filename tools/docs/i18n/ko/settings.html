## settings.json

위의 모든 설정은 ~/.ferret/settings.json(모든 OS에서 같은 경로)에 저장되며, 그 옆에 JSON Schema가 있습니다. 앱이 실행 중일 때 직접 또는 코딩 에이전트로 편집할 수 있고, 변경 사항은 바로 적용됩니다. settings.json으로 설정하기를 참고하세요.
