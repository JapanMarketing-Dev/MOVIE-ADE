Archivos y entorno Dónde guarda Ferret sus propios archivos y qué variables de entorno lee o define. ## Carpeta userData

Los datos de la app están en la carpeta userData de Electron. Su nombre está fijado en ade-movie (no en el nombre del producto), así que los datos sobreviven a los cambios de nombre. Puedes cambiarla con --user-data-dir=<path>.

Sistema operativoRuta
macOS~/Library/Application Support/ade-movie/
Windows%APPDATA%\ade-movie\
Linux~/.config/ade-movie/ (o $XDG_CONFIG_HOME/ade-movie/)
 
settings.json       # settings before 0.1.1, kept as a backup (now ~/.ferret/settings.json)
stt-keys.bin        # API keys, encrypted with safeStorage
browser-import/     # imported passwords (passwords.bin, encrypted with safeStorage) and history (history.json)
login-shell-path.json  # your login shell's PATH from the last launch, so agent tabs start without waiting
models/             # downloaded whisper models (ggml-*.bin)
accounts/claude/<id>/   # CLAUDE_CONFIG_DIR for added accounts
accounts/codex/<id>/    # CODEX_HOME for added accounts

Tus ajustes no están en esta carpeta: están en ~/.ferret/ (consulta Configurar con settings.json).

Un modelo que hayas elegido tú puede estar en cualquier sitio. La antigua ubicación predeterminada ~/.cache/ade-movie/models/ggml-small.bin se sigue comprobando.

## Variables de entorno
VariableEfecto
CLAUDE_CONFIG_DIR, CODEX_HOMEFerret las define para las pestañas de agente cuando hay seleccionada una cuenta añadida
GH_TOKEN, GITHUB_TOKENgh las usa antes que su propio inicio de sesión. Ferret avisa cuando alguna está definida
FERRET_CONFIG_DIR (o la antigua MOVIE_ADE_CONFIG_DIR)Carpeta para settings.json, state.json y settings.schema.json en lugar de ~/.ferret
Nombres en apiKeyEnvClaves de API a las que apuntas desde settings.json. También se leen del .env del proyecto y de ~/.ferret/.env
ADE_PROJECT_DIRAbre (y registra) esta carpeta como proyecto al iniciar
ADE_INITIAL_URLCarga esta URL en el navegador integrado al iniciar
ADE_WHISPER_MODELRuta absoluta de un modelo GGML para la transcripción en el dispositivo, en lugar del predeterminado descargado
ADE_TERMINAL_PREWARM0 hace que Ferret deje de tener una shell preparada en segundo plano. De forma predeterminada, la siguiente pestaña de shell normal la usa, así que su prompt aparece al instante
FERRET_SENTRY_DSN (o la antigua MOVIE_ADE_SENTRY_DSN)Adónde van los informes de fallos. Vacía significa que no se envía ninguno (consulta Informes de fallos)
OPENAI_API_KEYSe lee de .env solo en desarrollo (pnpm dev), nunca en las versiones empaquetadas
PATHSe usa para encontrar los comandos de tus agentes (claude, codex, gemini…), gh, git y whisper-cli. En macOS y Linux se añaden las ubicaciones de Homebrew, linuxbrew y snap
