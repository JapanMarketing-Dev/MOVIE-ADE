Instalación avanzada Comprueba la firma de una descarga, compila Ferret desde el código fuente, obtén una versión anterior y descubre cómo funcionan las actualizaciones. Nada de esto es necesario para instalar Ferret. ## Todas las descargas

Los archivos se sirven desde Cloudflare R2, no desde GitHub Releases, y solo se conservan las 10 versiones más recientes. La página de descarga las enumera todas.

## Verificar la descarga (SHA256SUMS firmado)

Cada versión incluye un archivo SHA256SUMS y su firma SHA256SUMS.sig. La firma se hace con la clave de publicación de Ferret, que se guarda aparte del servidor de descarga, así que un instalador modificado en el servidor de descarga no puede venir con una firma válida. La clave pública no se obtiene del servidor de descarga: tómala del repositorio (build/release-signing/allowed_signers) o cópiala de aquí:

release@ferretade.dev ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIEpXERU8ST0MEOIMbzoL4zShkjIrMB4++NL3xBohKAS9

Su huella digital es SHA256:c7dvwwJQyY9qSstkmrO8JoVZ90DCaFZBAzjqV04N8zQ. Los mismos archivos se adjuntan a cada versión en GitHub. Comprueba la firma con ssh-keygen (incluido en macOS, Windows 10 y posteriores, y Linux) y luego compara el hash de tu descarga con la lista firmada:

# the download server (currently the R2 public URL; it may move to a custom domain)
BASE=https://pub-588d93b3e875464f98d6cf98dc711a0c.r2.dev
VERSION=$(curl -s $BASE/latest.json | jq -r .version)
curl -sO $BASE/releases/$VERSION/SHA256SUMS
curl -sO $BASE/releases/$VERSION/SHA256SUMS.sig

# save the public key above as allowed_signers, then:
ssh-keygen -Y verify -f allowed_signers -I release@ferretade.dev -n ferret-release -s SHA256SUMS.sig < SHA256SUMS
# → Good "ferret-release" signature for release@ferretade.dev …

# macOS
shasum -a 256 -c SHA256SUMS --ignore-missing
# Linux
sha256sum -c SHA256SUMS --ignore-missing
# Windows (PowerShell): compare with the line for your file in SHA256SUMS
Get-FileHash .\Ferret-<version>-win-x64.exe -Algorithm SHA256

No sigas si ssh-keygen no muestra Good "ferret-release" signature o si el hash no está en la lista. Buscar actualizaciones de Ferret hace la misma comprobación con la clave integrada en la app y no ofrece ninguna versión cuya firma no coincida. En macOS también puedes comprobar la firma Developer ID y la notarización con spctl -a -vv /Applications/Ferret.app. Para las versiones hasta la 0.3.0, compara con los hashes de releases/<version>/manifest.json.

## Versiones antiguas en macOS

Para las versiones hasta la 0.2.0 build 2: si macOS indica que no se puede verificar el desarrollador, cierra el diálogo, abre Ajustes del Sistema → Privacidad y seguridad, haz clic en Abrir igualmente junto al mensaje sobre Ferret y confirma con Abrir. Si dice que la app «está dañada», elimina el atributo de cuarentena:

xattr -dr com.apple.quarantine /Applications/Ferret.app
## Compilar desde el código fuente

Requiere Node.js 20+ (la CI y el desarrollo local usan la 22), pnpm y git.

git clone https://github.com/JapanMarketing-Dev/ferret.git
cd ferret
pnpm install          # postinstall prepares node-pty for Electron
pnpm dev              # run in development mode

Para empaquetar los instaladores (salida en dist/release/, configuración en electron-builder.config.cjs). La compilación de Linux solo se ejecuta en Linux.

pnpm dist:mac     # dmg (arm64, x64)
pnpm dist:win     # NSIS installers (x64, arm64)
pnpm dist:linux   # AppImage + deb (x64)

Los scripts build:<os>:dev solo generan la app sin empaquetar (--dir), lo que es más rápido para probar en local.

En Windows, pnpm install usa los binarios precompilados que incluye node-pty en lugar de recompilar (eso requeriría las herramientas de compilación de C++ de Visual Studio). Define ADE_FORCE_NATIVE_REBUILD=1 para forzar la recompilación.

Si la terminal indica que no se pudo cargar node-pty, ejecuta pnpm rebuild:native.

## Actualizaciones

Ferret busca una versión nueva al iniciarse, cada 6 horas y cuando haces clic en Buscar actualizaciones (pie de página → Actualizaciones). Obtiene latest.json del servidor de descarga (R2) y comprueba la firma del SHA256SUMS de esa versión con la clave de publicación integrada en la app. No ofrece una versión cuya firma no coincida.

Cuando encuentra una versión nueva, Ferret la descarga en segundo plano y muestra el progreso en Actualizaciones. La descarga solo se usa si su tamaño y su SHA-256 coinciden con la lista firmada. Después aparece Reiniciar y actualizar en Actualizaciones y en el pie de página. Haz clic para reiniciar con la versión nueva. Si un agente está trabajando en un terminal o hay una grabación en curso, Ferret pregunta primero; la grabación hasta ese momento se guarda antes de reiniciar.

Las builds de desarrollo (pnpm dev) no descargan en segundo plano; Descargar guarda el instalador comprobado en tu carpeta de descargas.
