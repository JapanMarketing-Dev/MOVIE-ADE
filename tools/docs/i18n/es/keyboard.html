Atajos de teclado Los atajos se muestran para el sistema operativo desde el que lees; usa el selector de abajo para ver los del otro. La mayoría usan Command en macOS donde Windows y Linux usan Ctrl, y Option donde usan Alt. Unos pocos difieren más, y las tablas muestran ambos. Fuente: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts y la gestión de teclas de la terminal. ## Grabación

Cambiar modo (Editor / Feedback){{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}
Lápiz mientras se mantiene pulsado{{keys-mac:Alt}}{{keys-win:Alt}}

Estas teclas funcionan mientras grabas el navegador integrado y la página tiene el foco. Se ignoran mientras escribes en un campo de la página, y las teclas de letras solo funcionan sin teclas modificadoras, así que los atajos propios de la página siguen funcionando.

## Terminal
AcciónmacOSWindows / Linux
Nueva terminal{{keys-mac:Mod+T}}{{keys-win:Mod+T}}
Cerrar panel / pestaña{{keys-mac:Mod+W}}{{keys-win:Mod+W}}
Dividir a la derecha{{keys-mac:Mod+D|Ctrl+Shift+D}}{{keys-win:Mod+D|Ctrl+Shift+D}}
Dividir hacia abajo{{keys-mac:Mod+Shift+D|Alt+Shift+D}}{{keys-win:Mod+Shift+D|Alt+Shift+D}}
Copiar la selección{{keys-mac:Mod+C|Ctrl+Shift+C / Ctrl+C}}{{keys-win:Mod+C|Ctrl+Shift+C / Ctrl+C}}
Pegar{{keys-mac:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}{{keys-win:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}
Nueva línea en el prompt de un agente{{keys-mac:Shift+Enter}}{{keys-win:Shift+Enter}}
Inicio / final de la línea{{keys-mac:Mod+Left / Mod+Right|}}{{keys-win:Mod+Left / Mod+Right|}}
Borrar hasta el inicio de la línea{{keys-mac:Mod+Backspace|}}{{keys-win:Mod+Backspace|}}

Funcionan mientras una terminal tiene el foco. En Windows y Linux, Ctrl+C copia cuando hay texto seleccionado y detiene el comando en ejecución cuando no hay nada seleccionado. {{keys:Shift+Enter}} empieza una línea nueva mientras se ejecuta un agente como Claude Code o Codex; en un shell normal ejecuta el comando igual que Enter. En un programa a pantalla completa que usa el ratón (vim, tmux, un agente), mantén pulsada Option mientras arrastras para seleccionar texto en macOS.
