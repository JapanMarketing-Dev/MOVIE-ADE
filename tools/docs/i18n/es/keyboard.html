Atajos de teclado Los atajos se muestran para el sistema operativo desde el que lees; usa el selector de abajo para ver los del otro. La mayoría usan Command en macOS donde Windows y Linux usan Ctrl, y Option donde usan Alt. Unos pocos difieren más, y las tablas muestran ambos. Fuente: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts y la gestión de teclas de la terminal. ## Grabación
AcciónmacOSWindows / Linux
Iniciar / detener grabación{{keys-mac:Mod+Shift+R}}{{keys-win:Mod+Shift+R}}
Cambiar modo (Editor / Feedback){{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}
Lápiz mientras se mantiene pulsado{{keys-mac:Alt}}{{keys-win:Alt}}
## Dibujar mientras grabas
AcciónmacOSWindows / Linux
Lápiz{{keys-mac:P}}{{keys-win:P}}
Recuadro{{keys-mac:B / R}}{{keys-win:B / R}}
Usar la página (dejar de dibujar){{keys-mac:V / Esc}}{{keys-win:V / Esc}}
Siguiente color{{keys-mac:C}}{{keys-win:C}}
Deshacer el último trazo{{keys-mac:Mod+Z}}{{keys-win:Mod+Z}}
Rehacer{{keys-mac:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}{{keys-win:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}

Estas teclas funcionan mientras grabas el navegador integrado y la página tiene el foco. Se ignoran mientras escribes en un campo de la página, y las teclas de letras solo funcionan sin teclas modificadoras, así que los atajos propios de la página siguen funcionando.
