Installazione Scarica Ferret per il tuo computer e aprilo. Funziona su macOS, Windows e Linux. ## Download

La pagina di download ti propone il file giusto per il tuo computer. Fai clic sul pulsante di download.

## macOS

Apri il .dmg, trascina Ferret in Applications e aprilo da lì.

## Windows

Esegui il file .exe scaricato. Ferret si installa e si apre, senza nulla da scegliere. Le volte successive, aprilo dal menu Start o dal collegamento sul desktop.

Se Windows mostra Windows ha protetto il PC, fai clic su Ulteriori informazioni, poi su Esegui comunque.

## Linux

Ubuntu / Debian: fai doppio clic sul .deb per installarlo con il gestore del software, oppure esegui:

sudo apt install ./Ferret-<version>-linux-amd64.deb

Poi apri Ferret dal menu delle applicazioni, oppure esegui ferret.

Altre distribuzioni: usa il file .AppImage. Gli AppImage funzionano con FUSE 2, quindi installa prima il relativo pacchetto se il sistema non ce l'ha: fuse-libs su Fedora, fuse2 su Arch, libfuse2 su openSUSE e sui sistemi basati su Debian. Poi consenti l'esecuzione del file .AppImage come programma (clic destro → Proprietà, oppure chmod +x) e aprilo.
