Editor e anteprima Apri e modifica i file del progetto, e visualizza l'anteprima di Markdown e Mermaid. Un'anteprima aperta nel browser integrato si può registrare e rivedere come qualsiasi pagina web. ## Aprire e modificare i file
  • File (l'albero dei file): {{keys:Mod+Shift+E}}, con Filtra per nome file, Aggiorna e Comprimi tutto.
  • Vai al file…: {{keys:Mod+P}}.
  • Trascina un file dal Finder (da Esplora file su Windows, dal tuo file manager su Linux) sulla barra delle schede o sull'editor per aprirlo. I file del progetto si aprono nell'editor o in un visualizzatore. Per portare nel progetto un file che si trova fuori, rilascialo su File, che lo copia nel progetto. Una cartella rilasciata qui si apre come progetto. I file trascinati da File si aprono allo stesso modo. Le immagini e i video rilasciati su un file Markdown aperto vengono invece incorporati nel file (vedi Incorporare immagini e video in Markdown).
  • Salva con {{keys:Mod+S}}. Chiudendo un file modificato compare Salvare le modifiche a <name>? con Salva, Non salvare e Annulla.
  • Se il file cambia sul disco mentre hai modifiche non salvate, scegli Ricarica dal disco oppure Mantieni le mie modifiche.

L'editor è Monaco. I file che non sono di testo si aprono invece in un visualizzatore: immagini (con zoom; gli SVG si possono anche mostrare come codice), video e audio con una barra di avanzamento, PDF e, per qualsiasi altro file binario, la dimensione e una vista esadecimale dei primi byte. I visualizzatori sono in sola lettura, e i file fuori dalla cartella del progetto, o raggiunti tramite un collegamento simbolico che ne esce, non vengono mostrati.

## Lavorare con i file nell'albero dei file

Lavora sui file direttamente in File, come faresti in VS Code. Fai clic destro su un elemento, oppure sullo spazio vuoto sotto l'albero per lavorare al primo livello del progetto. I nomi si digitano direttamente nell'albero.

  • Nuovo file / Nuova cartella: i pulsanti sopra l'albero, oppure clic destro. Il nuovo elemento va nella cartella selezionata, accanto al file selezionato, oppure al primo livello del progetto. Digita un nome con barre, come src/routes/index.ts, per creare anche le cartelle lungo il percorso. Un nuovo file si apre nell'editor. In una cartella vuota, File mostra Questa cartella è vuota con i pulsanti Nuovo file e Nuova cartella.
  • Taglia, Copia e Incolla: {{keys:Mod+X}}, {{keys:Mod+C}}, {{keys:Mod+V}}, oppure clic destro. Le cartelle vengono copiate con tutto il contenuto. Duplica crea una copia accanto all'originale. Se il nome è già usato, la copia si chiama name copy, poi name copy 2.
  • Trascina gli elementi su una cartella (o sullo spazio vuoto per il primo livello del progetto) per spostarli. Tieni premuto {{keys:Alt|Ctrl}} mentre rilasci per copiarli invece. File e cartelle trascinati dal Finder (da Esplora file su Windows) vengono copiati nel progetto; gli originali restano dov'erano.
  • Rinomina: {{keys:F2 / Enter|F2}}, oppure clic destro.
  • Elimina: {{keys:Mod+Backspace / Delete|Delete}}, oppure clic destro. Ferret chiede prima conferma, poi sposta l'elemento nel Cestino, così puoi ripristinarlo. Le schede dei file eliminati si chiudono; se qualcuna aveva modifiche non salvate, la conferma lo indica.
  • Annulla: {{keys:Mod+Z}} annulla l'ultima creazione, ridenominazione, spostamento, incolla o duplicazione. Gli elementi eliminati vengono ripristinati dal Cestino.
  • Copia percorso ({{keys:Alt+Mod+C|Shift+Alt+C}}) e Copia percorso relativo ({{keys:Alt+Shift+Mod+C|Ctrl+Shift+Alt+C}}) copiano il percorso negli appunti.
  • Mostra nel Finder (Mostra in Esplora file su Windows, Apri la cartella superiore su Linux): {{keys:Alt+Mod+R|Shift+Alt+R}}. Apri nel terminale apre una nuova scheda del terminale in quella cartella (per un file, nella sua cartella).
  • Per un file, Apri lo apre nell'editor e Apri con l’app predefinita lo apre nell'app che il sistema operativo usa per quel tipo.
  • Seleziona più elementi con {{keys:Mod}}-clic o {{keys:Shift}}-clic per tagliarli, copiarli, spostarli o eliminarli insieme.
  • {{keys:Esc}} annulla un nome che stai digitando.

Le schede aperte seguono un file rinominato o spostato e mantengono le modifiche non salvate. Ferret non sovrascrive un file o una cartella esistente con lo stesso nome e mantiene tutto all'interno della cartella del progetto: rifiuta .., i percorsi assoluti, i collegamenti simbolici che puntano all'esterno, tutto ciò che si trova dentro .git, lo spostamento di una cartella dentro sé stessa e i nomi che qualche sistema operativo non può usare: / \ < > : " | ? *, caratteri di controllo, uno spazio o un punto finale e i nomi riservati di Windows come CON o NUL. Una singola copia o un singolo rilascio può contenere fino a 10.000 elementi e 1 GB.

## Anteprima di Markdown e Mermaid

L'anteprima funziona per .md, .markdown, .mdx, .mmd e .mermaid. Mermaid è incluso nell'app, quindi i diagrammi vengono renderizzati anche offline.

Un file Markdown ha due viste in alto nell'editor: Sorgente e Anteprima. L'anteprima è sempre modificabile, quindi puoi scrivere direttamente al suo interno; fai clic su Sorgente per tornare al testo. Entrambe le viste mostrano lo stesso contenuto, e il salvataggio, il segno di modifiche non salvate e la conferma alla chiusura funzionano allo stesso modo.

  • Scrivi direttamente in titoli, paragrafi, elenchi, caselle di controllo, tabelle, link e testo in grassetto, corsivo o codice inline. Digitando #, -, 1. o > seguiti da uno spazio all'inizio di una riga si inizia un titolo, un elenco o una citazione.
  • Digita / all’inizio di una riga (o dopo uno spazio) per scegliere un blocco da un elenco: titoli, elenchi puntati, numerati o di controllo, una tabella, un blocco di codice, una citazione o un divisore. Ogni voce dice cosa crea e come si scrive in Markdown. Continua a digitare per filtrare, usa {{keys:Up}} {{keys:Down}} e {{keys:Enter}} per scegliere, oppure {{keys:Esc}} per lasciare la / come testo. Una tabella parte da 3 × 3 con una riga di intestazione; {{keys:Tab}} passa alla cella successiva e aggiunge una riga alla fine. Digitando / dentro una tabella puoi aggiungere o eliminare righe e colonne, oppure eliminare la tabella.
  • I blocchi di codice si modificano come sorgente, con il linguaggio indicato in un angolo. Un blocco di codice Mermaid (mermaid o mmd) mostra il diagramma per impostazione predefinita. Fai clic su Codice in alto a destra, o doppio clic sul diagramma, per modificare il sorgente; quando il cursore esce dal blocco torna il diagramma. Se il sorgente contiene un errore, viene mostrato il messaggio con Correggi il codice. I diagrammi vengono disegnati in un frame isolato (sandbox) e il Markdown salvato resta com'è stato scritto.
  • Il front matter (il blocco --- in cima) viene mostrato come testo sopra il documento e si può modificare lì.
  • Le parti che non modifichi vengono salvate esattamente come sono scritte, compresi lo stile dei titoli, i marcatori degli elenchi, le righe vuote, l'allineamento delle tabelle e i fine riga. Un blocco che modifichi mantiene il suo stile quando possibile; altrimenti quel blocco viene scritto in una forma Markdown standard, con - per gli elenchi e # per i titoli.
  • Le immagini e i video del progetto vengono mostrati. Le immagini di altri siti non vengono caricate; al loro posto viene mostrato il nome host. Il resto dell'HTML nel file viene mostrato come testo.

I file .mdx (modificati solo come sorgente), .mmd e .mermaid hanno invece un'anteprima in sola lettura:

  • Apri anteprima a lato: accanto all'editor
  • Apri anteprima: nel browser integrato (ade-preview://), così puoi registrarla e rivederla
## Incorporare immagini e video in Markdown

Trascina immagini (PNG, JPEG, GIF, WebP, SVG, AVIF) o video (MP4, WebM, MOV) su un file Markdown, in Sorgente o in Anteprima, per incorporarli nel punto in cui li rilasci.

  • I file già presenti nel progetto, compresi quelli trascinati da File, vengono collegati con un percorso relativo al file Markdown. Non viene copiato nulla.
  • I file esterni al progetto (dal Finder, dalla scrivania, da Esplora file su Windows) vengono prima copiati in una cartella accanto al file Markdown: assets, images, media o img se ne esiste già una, altrimenti una nuova cartella assets. Gli spazi nel nome diventano - e, se il nome è già usato, la copia si chiama name-2. Gli originali restano dov'erano.
  • Le immagini vengono scritte come ![name](assets/name.png) e i video come <video src="assets/name.mp4" controls></video>, che anche GitHub riproduce. Entrambi vengono mostrati in Anteprima.
  • Un'immagine può arrivare a 50 MB e un video a 500 MB, e un singolo rilascio copia fino a 50 file e 1 GB. Gli altri file rilasciati insieme si aprono nell'editor come al solito.
## Rivedere la documentazione registrando
  1. Nel pannello Target di revisione, apri il file Markdown da File. Si apre come anteprima nel browser integrato.
  2. Registra come al solito. Commenta a voce la specifica o il documento di design e cerchia ciò che non va.
  3. Ferma. Le segnalazioni fanno riferimento al percorso del file relativo al progetto invece che a un URL.
  4. Invia all'Agent per far correggere il documento.
