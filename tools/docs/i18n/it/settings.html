## Account, GitHub, aspetto, lingua
  • Account: vedi Account e utilizzo.
  • GitHub / GitLab: accesso a gh e glab. Vedi Inviare a GitHub o GitLab.
  • Strumenti CLI: installa le CLI dei servizi ed effettua l'accesso. Vedi Strumenti CLI.
  • Aspetto → Tema: Sistema (predefinito), Chiaro, Scuro.
  • Lingua → Interfaccia: Sistema (predefinito; segue la lingua del sistema operativo se Ferret la supporta, altrimenti inglese) oppure una delle 14 lingue: English, 日本語, 简体中文, 繁體中文, 한국어, Español, Français, Deutsch, Italiano, Português (Brasil), Русский, हिन्दी, Bahasa Indonesia, Tiếng Việt.

Dal footer: posizione del terminale (destra / in basso) e attivazione del microfono.

## settings.json

Tutto quanto sopra è memorizzato in ~/.ferret/settings.json (stesso percorso su ogni sistema operativo), con uno JSON Schema accanto. Puoi modificarlo mentre l'app è in esecuzione, a mano o con il tuo coding agent; le modifiche si applicano subito. Vedi Configurare con settings.json.
