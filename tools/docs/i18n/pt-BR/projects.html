Projetos e URLs Um projeto é uma pasta (normalmente a raiz do seu repositório). Cada projeto guarda as próprias URLs salvas, então local, dev e produção ficam a um clique de distância. ## Adicionar um projeto
  1. Arquivo → Abrir pasta do projeto… ({{keys:Mod+O}}), Adicionar projeto na barra lateral ou Adicionar projeto… no menu de projetos da barra de título.
  2. Escolha de onde vem o projeto:
    • Neste computador: escolha uma pasta.
    • Clonar do GitHub / GitLab: escolha um dos seus repositórios (listados pelo seu login do gh ou do glab) ou cole uma URL, escolha a pasta de destino, e o Ferret clona e abre o repositório.
    • Abrir via SSH: escolha um host do ~/.ssh/config. O terminal e os agentes rodam na máquina remota; as revisões ficam neste computador.

O nome padrão é o nome da pasta. Adicionar uma pasta já registrada apenas a abre (no macOS e no Windows, os caminhos são comparados sem diferenciar maiúsculas de minúsculas). No menu da barra lateral, você pode Renomear um projeto ou usar Remover da lista. Remover nunca exclui a pasta.

Os terminais abrem na pasta do projeto, e as revisões são salvas em <project>/.ferret/.

## Salvar URLs
  1. Abra a página no navegador integrado.
  2. Clique em + (Salvar URL atual) na barra de ferramentas do navegador. A URL atual já vem preenchida.
  3. Digite um Nome e clique em Salvar.

Só são aceitas URLs http:// e https://. Se você mantiver o nome sugerido, ele é deduzido a partir do host:

HostNome
localhost, 127.*, ::1, 0.0.0.0, *.localhostlocal

## Painel de alvos de revisão {{clip:targets|Trocando de alvo de revisão e de página sem parar a gravação.}}

No modo Feedback, o painel Alvos de revisão à direita lista tudo o que você pode revisar no projeto atual. Trocar de alvo não interrompe a gravação. Mostre ou oculte o painel com Exibir → Alternar alvos de revisão ({{keys:Mod+Shift+K}}) ou Ocultar painel.

  • Alvos: as URLs salvas do projeto. Abaixo de cada uma há uma árvore com as páginas que você visitou naquele site. Sites visitados que não estão salvos aparecem como grupos próprios.
  • Arquivos: a pasta do projeto. Um arquivo abre como prévia (Markdown e Mermaid renderizados, outros textos somente leitura), então você também pode revisar documentos. O lápis (Abrir no editor) o abre no editor.

Filtrar alvos filtra alvos, páginas e arquivos ao mesmo tempo, com a mesma busca aproximada de Ir para arquivo…. Na lista, ↑ ↓ Enter ou 1–9 trocam de alvo. Abrir URL… abre uma URL avulsa, e Salvar nas URLs do projeto a guarda.

Os alvos vêm de projects[].urls no settings.json (veja o exemplo). Cada entrada precisa de uma url, de um launchCommand (executado em um terminal, por exemplo para iniciar um app de desktop) ou de um windowMatch (a janela a gravar). Escolher um alvo de janela o define como a fonte da gravação, então isso não pode ser feito durante a gravação. As páginas visitadas são lembradas por projeto, apenas nesta máquina (até 200).

## Abrir e trocar de ambiente

Clique em uma URL salva para abri-la. Se a página atual estiver sob outra URL salva, o Ferret mantém o caminho, a query e o hash e troca só a origem. Por exemplo, em http://localhost:3000/pricing?plan=pro, clicar em prd abre https://example.com/pricing?plan=pro.

O chip que corresponde à página atual (o prefixo mais longo) fica destacado. Clique com o botão direito em um chip ou use o ícone de lápis para editá-lo ou usar Excluir. Quando um projeto abre e não há URL anterior, a primeira URL salva dele é carregada.
