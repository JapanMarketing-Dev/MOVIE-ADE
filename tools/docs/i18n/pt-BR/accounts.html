Contas e uso Alterne entre vários logins do Claude Code ou do Codex e acompanhe as janelas de limite de uso no rodapé. Por enquanto, os dois recursos funcionam só com o Claude Code e o Codex; os outros agentes continuam usando o próprio login normalmente. ## Várias contas

As contas são opcionais. Adicione-as só se você alterna entre várias.

  1. Abra Configurações → Contas ou Gerenciar contas… no menu de uso do rodapé.
  2. Adicionar conta inicia o login do agente em uma aba do terminal integrado.
  3. Escolha a conta a usar. As abas em execução mantêm a conta delas. As novas abas usam a selecionada.

Como funciona: cada conta adicionada recebe o próprio diretório de configuração, <userData>/accounts/<agent>/<id>/. O Ferret inicia o agente com CLAUDE_CONFIG_DIR (Claude Code) ou CODEX_HOME (Codex) apontando para lá. Padrão do sistema usa os seus ~/.claude / ~/.codex de sempre, sem alterações.

Remover uma conta exclui o diretório de configuração dela. Isso não encerra a sua sessão no servidor.

## Uso no rodapé

O rodapé mostra quanto de cada janela de limite de uso já foi consumido: a janela de 5 horas e a janela semanal, além da janela semanal por modelo no caso do Claude. As cores ficam amarelas em 60% e vermelhas em 80%. Os valores são atualizados a cada 15 minutos ou ao clicar em Atualizar uso.

O quanto é exibido depende do espaço no rodapé. Com espaço, ele mostra barras, nomes das janelas e porcentagens. À medida que o rodapé fica mais estreito, ele remove primeiro as partes menos úteis, até sobrar uma porcentagem por agente. Clique no uso para ver tudo em um popover.

O uso é obtido diretamente da Anthropic (api.anthropic.com/api/oauth/usage) e do ChatGPT (chatgpt.com/backend-api/wham/usage) com as próprias credenciais da conta conectada.

{{shot:usage|Uso no rodapé}} ## Continuar trabalhando nos limites de uso

Quando um agente atinge o limite de uso, o Ferret continua o mesmo trabalho na mesma pasta do projeto, então uma tarefa longa não para no limite. Isso vem ativado por padrão e é configurado em Configurações → Contas → Troca ao atingir o limite de uso.

O trabalho é passado adiante por um único arquivo no projeto, .ferret/handoff.md, então funciona tanto entre contas quanto entre agentes diferentes. As instruções de Enviar ao Agent pedem ao agente que mantenha esse arquivo atualizado a cada marco e quando estiver perto de um limite de uso: o objetivo, o que já foi feito, o trabalho restante como checklist, os arquivos que alterou, o próximo passo, os caminhos do feedback.md e da revisão relacionados, e qualquer ponto de atenção. A pasta .ferret/ fica fora do git (ela é adicionada a .git/info/exclude, não ao .gitignore).

  1. O Ferret percebe o limite pela própria mensagem do agente no terminal (por exemplo 5-hour limit reached ∙ resets 3pm no Claude Code, You've hit your usage limit no Codex) ou quando o uso mostrado no rodapé chega ao limiar (95% por padrão; o maior entre as janelas de 5 horas, semanal e por modelo).
  2. Antes de trocar, o Ferret pede ao agente atual que atualize o .ferret/handoff.md. Se o agente não começar a fazer isso (por exemplo, porque já está no limite), o Ferret adiciona ao arquivo o que sabe: o último pedido, onde está o feedback.md e os arquivos alterados segundo o git status.
  3. Em seguida, o Ferret troca para outra conta conectada do mesmo agente, a que tem o menor uso. Quando todas as contas do agente estão no limite, o trabalho passa para o próximo agente em Ordem dos agentes (padrão: Claude Code → Codex → Gemini CLI).
  4. O novo agente abre em uma nova aba no mesmo projeto e recebe, no idioma do app, a orientação de ler primeiro o .ferret/handoff.md e continuar com o trabalho restante.
  5. O rodapé mostra Agora com <agent> e um aviso diz o que mudou, por exemplo Codex atingiu o limite de uso, então Claude Code assumiu o trabalho. A aba que atingiu o limite é fechada, para que não retome a mesma tarefa quando o limite dela for restabelecido.
