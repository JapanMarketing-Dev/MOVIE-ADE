Atalhos de teclado Os atalhos são exibidos para o sistema em que você está lendo; use o seletor abaixo para ver o outro. A maioria usa Command no macOS onde o Windows e o Linux usam Ctrl, e Option onde eles usam Alt. Alguns diferem mais do que isso, e as tabelas mostram os dois. ## Terminal

Novo terminal{{keys-mac:Mod+T}}{{keys-win:Mod+T}}
Fechar painel / aba{{keys-mac:Mod+W}}{{keys-win:Mod+W}}
Dividir à direita{{keys-mac:Mod+D|Ctrl+Shift+D}}{{keys-win:Mod+D|Ctrl+Shift+D}}

Colar{{keys-mac:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}{{keys-win:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}
Nova linha no prompt de um agente{{keys-mac:Shift+Enter}}{{keys-win:Shift+Enter}}
Início / fim da linha{{keys-mac:Mod+Left / Mod+Right|}}{{keys-win:Mod+Left / Mod+Right|}}
Apagar até o início da linha{{keys-mac:Mod+Backspace|}}{{keys-win:Mod+Backspace|}}

Estes atalhos funcionam enquanto um terminal está em foco. No Windows e no Linux, Ctrl+C copia quando há texto selecionado e interrompe o comando em execução quando não há nada selecionado. {{keys:Shift+Enter}} começa uma nova linha enquanto um agente como o Claude Code ou o Codex está rodando; em um shell comum, executa o comando como o Enter. Em um programa de tela cheia que usa o mouse (vim, tmux, um agente), mantenha Option pressionado enquanto arrasta para selecionar texto no macOS.
