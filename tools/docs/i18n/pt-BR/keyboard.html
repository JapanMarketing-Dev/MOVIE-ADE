Atalhos de teclado Os atalhos são exibidos para o sistema em que você está lendo; use o seletor abaixo para ver o outro. A maioria usa Command no macOS onde o Windows e o Linux usam Ctrl, e Option onde eles usam Alt. Alguns diferem mais do que isso, e as tabelas mostram os dois. Fonte: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts, e o tratamento de teclas do terminal. ## Gravação

## Desenhar durante a gravação
AçãomacOSWindows / Linux
Caneta{{keys-mac:P}}{{keys-win:P}}
Caixa{{keys-mac:B / R}}{{keys-win:B / R}}
Usar a página (parar de desenhar){{keys-mac:V / Esc}}{{keys-win:V / Esc}}
Próxima cor{{keys-mac:C}}{{keys-win:C}}
Desfazer a última marca{{keys-mac:Mod+Z}}{{keys-win:Mod+Z}}
Refazer{{keys-mac:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}{{keys-win:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}

Essas teclas funcionam enquanto você grava o navegador integrado e a página está em foco. Elas são ignoradas enquanto você digita em um campo da página, e as teclas de letras só funcionam sem teclas modificadoras, para que os atalhos da própria página continuem funcionando.
