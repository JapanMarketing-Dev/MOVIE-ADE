Início rápido Instale o Ferret, abra seu projeto e a URL do servidor de desenvolvimento, grave um feedback e entregue-o ao seu agente de programação. Leva cerca de cinco minutos. ## Antes de começar {{clip:quick-start|Abra uma página, grave, circule e fale, pare e envie os apontamentos a um agente.}}
  • Um agente de programação que rode no terminal, instalado e com login feito: por exemplo Claude Code (claude), Codex (codex) ou Gemini CLI (gemini). O Ferret o executa no terminal integrado. Qualquer agente da lista de suportados funciona, assim como qualquer outra CLI que você mesmo adicionar.
  • Um app web que você possa abrir por URL, por exemplo um servidor de desenvolvimento em http://localhost:3000.
  • Um microfone. O feedback é a sua voz mais a caneta. Sem microfone, os círculos da caneta ainda viram apontamentos, mas sem palavras.
## 1. Instalar

Baixe o Ferret na página de download e abra-o. Os passos para cada sistema estão em Instalação.

## 2. Abrir um projeto e uma URL
  1. Arquivo → Abrir pasta do projeto… ({{keys:Mod+O}}) e escolha a raiz do seu repositório.
  2. Digite a URL do servidor de desenvolvimento na barra de endereço do navegador ({{keys:Mod+L}}) e pressione Enter.
  3. Opcional: clique em + (Salvar URL atual) para guardá-la como um atalho de um clique, como local, dev ou prd.

Abrir um projeto também inicia seus agentes em abas de terminal nessa pasta. Por padrão, são o Claude Code e o Codex; escolha os que você usa em Configurações → Agents → Iniciar ao abrir um projeto (veja Configurações).

## 3. Gravar
  1. Clique em Gravar na barra de título ou pressione {{keys:Mod+Shift+R}}. A janela muda para o modo Feedback.
  2. Use a página normalmente e diga o que deve mudar.
  3. Segure {{keys:Alt}} (ou escolha Caneta) e arraste para circular o ponto enquanto fala sobre ele.
  4. Clique em Parar ou pressione {{keys:Mod+Shift+R}} de novo.

Cada momento em que você fala ou circula vira um apontamento: uma captura de tela com as marcas da caneta, o pedido, as palavras originais, a URL e o elemento que você indicou.

## 4. Conferir os apontamentos

Depois que você para, a janela volta ao modo Editor e abre a aba Apontamentos.

  • Edite um título ou pedido ali mesmo.
  • Alterne entre Enviar / Não enviar em cada apontamento, ou use Excluir.
  • Desfazer reverte a última edição.
## 5. Enviar a um agente
  1. Clique em Enviar ao Agent. O envio vai para o agente da aba de terminal atual ou para um que esteja em execução. A seta ao lado do botão escolhe um agente ou uma aba específica.
  2. Se nenhum agente estiver em execução, o Ferret inicia um primeiro e envia assim que ele estiver pronto.

O Ferret digita uma instrução no prompt do agente e a envia. Por padrão, ela começa assim:

Leia "{{path}}" e a imagem de cada apontamento na mesma pasta e implemente todos os apontamentos marcados para envio. …

O restante pede ao agente que confira cada alteração na tela real, registre o progresso de cada apontamento e termine com uma lista de Concluído / Não concluído. O agente lê .ferret/reviews/<timestamp>/feedback.md e os PNGs ao lado dele. O vídeo nunca é enviado. Usa um agente fora do Ferret? Clique em Copiar para o Agent e cole.

O texto padrão segue o idioma da interface. Você pode substituí-lo nas Configurações: veja Personalizar a instrução.
