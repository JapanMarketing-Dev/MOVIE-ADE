Arquivos e ambiente Onde o Ferret guarda os próprios arquivos e quais variáveis de ambiente ele lê ou define. ## Pasta userData

Os dados do app ficam na pasta userData do Electron. O nome dela é fixo em ade-movie (não o nome do produto), para que os dados sobrevivam a mudanças de nome. Substitua-a com --user-data-dir=<path>.

SistemaCaminho
macOS~/Library/Application Support/ade-movie/
Windows%APPDATA%\ade-movie\
Linux~/.config/ade-movie/ (ou $XDG_CONFIG_HOME/ade-movie/)
 
settings.json       # settings before 0.1.1, kept as a backup (now ~/.ferret/settings.json)
stt-keys.bin        # API keys, encrypted with safeStorage
browser-import/     # imported passwords (passwords.bin, encrypted with safeStorage) and history (history.json)
login-shell-path.json  # your login shell's PATH from the last launch, so agent tabs start without waiting
models/             # downloaded whisper models (ggml-*.bin)
accounts/claude/<id>/   # CLAUDE_CONFIG_DIR for added accounts
accounts/codex/<id>/    # CODEX_HOME for added accounts

Suas configurações não ficam nesta pasta: elas ficam em ~/.ferret/ (veja Configurar com o settings.json).

Um modelo que você mesmo escolheu pode ficar em qualquer lugar. O antigo local padrão ~/.cache/ade-movie/models/ggml-small.bin ainda é verificado.

## Variáveis de ambiente
VariávelEfeito
CLAUDE_CONFIG_DIR, CODEX_HOMEDefinidas pelo Ferret nas abas de agentes quando uma conta adicionada está selecionada
GH_TOKEN, GITHUB_TOKENUsadas pelo gh antes do próprio login dele. O Ferret avisa quando alguma delas está definida
FERRET_CONFIG_DIR (ou o antigo MOVIE_ADE_CONFIG_DIR)Pasta para settings.json, state.json e settings.schema.json em vez de ~/.ferret
Nomes em apiKeyEnvChaves de API que você indica no settings.json. Também são lidas do .env do projeto e de ~/.ferret/.env
ADE_PROJECT_DIRAbre (e registra) esta pasta como o projeto ao iniciar
ADE_INITIAL_URLCarrega esta URL no navegador integrado ao iniciar
ADE_WHISPER_MODELCaminho absoluto de um modelo GGML a usar na transcrição no dispositivo, no lugar do padrão baixado
ADE_TERMINAL_PREWARM0 faz o Ferret deixar de manter um shell pronto em segundo plano. Por padrão, a próxima aba de shell simples o usa, e o prompt aparece na hora
FERRET_SENTRY_DSN (ou o antigo MOVIE_ADE_SENTRY_DSN)Para onde vão os relatórios de falhas. Vazio significa que nenhum é enviado (veja Relatórios de falhas)
OPENAI_API_KEYLida do .env apenas em desenvolvimento (pnpm dev), nunca nas versões empacotadas
PATHUsado para encontrar os comandos dos seus agentes (claude, codex, gemini…), gh, git e whisper-cli. No macOS e no Linux, os locais do Homebrew, do linuxbrew e do snap são adicionados
