Instalação Baixe o Ferret para o seu computador e abra-o. Ele roda em macOS, Windows e Linux. ## Download

A página de download oferece o arquivo certo para o seu computador. Clique no botão de download.

## macOS

Abra o .dmg, arraste o Ferret para Applications e abra-o a partir de lá.

## Windows

Execute o .exe baixado. O Ferret é instalado e abre, sem nada para escolher. Nas próximas vezes, abra-o pelo menu Iniciar ou pelo atalho na área de trabalho.

Se o Windows mostrar O Windows protegeu o computador, clique em Mais informações e depois em Executar assim mesmo.

## Linux

Ubuntu / Debian: clique duas vezes no .deb para instalá-lo pela central de software, ou execute:

sudo apt install ./Ferret-<version>-linux-amd64.deb

Depois, abra o Ferret pelo menu de aplicativos ou execute ferret.

Outras distribuições: use o .AppImage. Permita que ele seja executado como programa (clique com o botão direito → Propriedades, ou chmod +x) e depois abra-o.
