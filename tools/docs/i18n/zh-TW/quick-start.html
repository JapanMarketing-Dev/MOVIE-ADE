快速入門 安裝 Ferret，開啟你的專案和它的開發伺服器 URL，錄製一則意見回饋，然後交給你的程式設計 Agent。大約五分鐘即可完成。 ## 開始之前 {{clip:quick-start|開啟頁面、錄製、邊圈選邊說明、停止，然後把意見傳送給 Agent。}}
  • 一個在終端機中執行、已安裝並登入的程式設計 Agent，例如 Claude Code（claude）、Codex（codex）或 Gemini CLI（gemini）。Ferret 會在內建終端機中執行它。支援清單中的任何 Agent 都能使用，你自行加入的其他 CLI 也可以。
  • 可以用 URL 開啟的 Web App，例如在 http://localhost:3000 上的開發伺服器。
  • 麥克風。意見回饋由你的語音加上畫筆組成。沒有麥克風時，用畫筆圈選的地方仍會成為意見，但不會附上文字。
## 1. 安裝

從下載頁面下載 Ferret 並開啟。各作業系統的步驟請參閱安裝。

## 2. 開啟專案和 URL
  1. 選擇 檔案 → 開啟專案資料夾…（{{keys:Mod+O}}），然後選取儲存庫的根目錄。
  2. 在瀏覽器的 URL 列（{{keys:Mod+L}}）輸入開發伺服器的 URL，然後按 Enter。
  3. 選用：按 +（儲存目前的 URL），把它存成一鍵開啟的預設 URL，例如 local、dev 或 prd。

開啟專案時，也會在該資料夾的終端機分頁中啟動你的 Agent。預設是 Claude Code 和 Codex；要使用哪些，可在 設定 → Agent → 開啟專案時啟動 中選擇（請參閱設定）。

## 3. 錄製
  1. 按標題列中的 錄製，或按 {{keys:Mod+Shift+R}}。視窗會切換到意見模式。
  2. 像平常一樣操作頁面，同時說出需要修改的地方。
  3. 按住 {{keys:Alt}}（或選擇 畫筆）並拖曳，圈出你正在說明的位置。
  4. 按 停止，或再按一次 {{keys:Mod+Shift+R}}。

你每次說話或圈選的時刻都會成為一則意見：包含帶有畫筆標記的螢幕截圖、要求、你說的原話、URL，以及你指向的元素。

## 4. 檢查意見

停止後，視窗會回到編輯器模式，並開啟 意見 分頁。

  • 可以直接修改標題或要求。
  • 可以針對每則意見切換 傳送 / 不傳送，或使用 刪除。
  • 還原 會取消上一次的編輯。
## 5. 傳送給 Agent
  1. 按 傳送給 Agent。內容會送到目前終端機分頁中的 Agent，或送到正在執行的 Agent。按鈕旁的箭頭可以指定要傳送的 Agent 或分頁。
  2. 如果還沒有任何 Agent 在執行，Ferret 會先啟動一個，並在它就緒後立即傳送。

Ferret 會在 Agent 的輸入欄中輸入一則指示並送出。預設的指示開頭如下：

請閱讀 "{{path}}" 以及同一資料夾中每則意見的圖片，然後實作所有標記為要傳送的意見。…

後續內容會要求 Agent 在實際畫面上確認每項變更、記錄每則意見的進度，最後以「完成／未完成」清單回報。Agent 會讀取 .ferret/reviews/<timestamp>/feedback.md 及其旁邊的 PNG。影片絕不會傳送。如果使用 Ferret 以外的 Agent，請按 拷貝給 Agent 後貼上。

預設指示會依顯示語言而變。你也可以在「設定」中替換它：請參閱自訂指示。
