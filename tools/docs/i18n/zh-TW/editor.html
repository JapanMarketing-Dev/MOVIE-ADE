編輯器與預覽 開啟並編輯專案檔案，以及預覽 Markdown 與 Mermaid。在內建瀏覽器中開啟的預覽，可以像任何網頁一樣錄製並審查。 ## 開啟並編輯檔案
  • 檔案（檔案樹）：{{keys:Mod+Shift+E}}，提供 依檔名篩選、重新整理 與 全部收合。
  • 前往檔案…：{{keys:Mod+P}}。
  • 按 {{keys:Mod+S}} 儲存。關閉已修改的檔案時，會詢問 要儲存對 <name> 的變更嗎？，並提供 儲存、不儲存 與 取消。
  • 如果在你有未儲存的編輯時，檔案在磁碟上被變更，請選擇 從磁碟重新載入 或 保留我的變更。

編輯器使用 Monaco。非文字檔案會改用檢視器開啟：圖片（可放大縮小；SVG 也能以程式碼顯示）、附播放進度列的影片與音訊、PDF，其他二進位檔案則顯示檔案大小與開頭位元組的十六進位檢視。檢視器為唯讀，專案資料夾外的檔案，或經由指向資料夾外的符號連結才能到達的檔案，都不會顯示。

## 建立、重新命名與刪除檔案

可以直接在 檔案 中操作檔案，就像在 VS Code 中一樣。名稱直接在樹狀結構中輸入。

  • 新增檔案 / 新增資料夾：使用樹狀結構上方的按鈕，或在資料夾（或樹狀結構下方的空白處）按右鍵。新項目會建立在選取的資料夾中、選取的檔案旁，或專案的最上層。新檔案會在編輯器中開啟。
  • 重新命名：{{keys:F2 / Enter|F2}}，或按右鍵。已開啟的分頁會跟著新名稱，並保留未儲存的編輯。
  • 刪除：{{keys:Mod+Backspace / Delete|Delete}}，或按右鍵。Ferret 會先詢問，再把項目移到垃圾桶（Windows 上為資源回收筒），因此可以復原。已刪除檔案的分頁會關閉；如果其中有未儲存的編輯，確認訊息會提到這點。
  • 用 {{keys:Mod}}-按一下或 {{keys:Shift}}-按一下選取多個項目，即可一起刪除。
  • {{keys:Esc}} 會取消正在輸入的名稱。

Ferret 不會覆寫同名的現有檔案或資料夾，並會拒絕任何會離開專案資料夾的操作（..、絕對路徑、指向外部的符號連結）、.git 內的任何項目，以及某些作業系統無法使用的名稱：/ \ < > : " | ? *、控制字元、結尾的空格或句點，以及 CON 或 NUL 等 Windows 保留名稱。

## Markdown 與 Mermaid 預覽

預覽支援 .md、.markdown、.mdx、.mmd 與 .mermaid。Mermaid 已內建於 App 中，因此離線也能繪製圖表。

  • 在側邊開啟預覽：在編輯器旁邊
  • 開啟預覽：在內建瀏覽器中（ade-preview://），因此可以錄製並審查
## 用錄製來審查文件
  1. 開啟 Markdown 檔案，然後按 開啟預覽。
  2. 照常錄製。一邊說明規格書或設計文件，一邊圈出有問題的地方。
  3. 停止。意見會以檔案相對於專案的路徑來參照，而不是 URL。
  4. 按 傳送給 Agent，讓 Agent 修正文件。
