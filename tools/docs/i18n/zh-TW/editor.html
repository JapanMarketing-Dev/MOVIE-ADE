編輯器與預覽 開啟並編輯專案檔案，以及預覽 Markdown 與 Mermaid。在內建瀏覽器中開啟的預覽，可以像任何網頁一樣錄製並審查。 ## 開啟並編輯檔案
  • 檔案（檔案樹）：{{keys:Mod+Shift+E}}，提供 依檔名篩選、重新整理 與 全部收合。
  • 前往檔案…：{{keys:Mod+P}}。
  • 從 Finder（Windows 上為檔案總管，Linux 上為檔案管理員）把檔案拖到分頁列或編輯器上即可開啟。專案中的檔案會在編輯器或檢視器中開啟。若要把專案外的檔案帶進來，請把它放到 檔案 上，它會被複製到專案中。放到這裡的資料夾會以專案開啟。從 檔案 拖出的檔案也以相同方式開啟。
  • 按 {{keys:Mod+S}} 儲存。關閉已修改的檔案時，會詢問 要儲存對 <name> 的變更嗎？，並提供 儲存、不儲存 與 取消。
  • 如果在你有未儲存的編輯時，檔案在磁碟上被變更，請選擇 從磁碟重新載入 或 保留我的變更。

編輯器使用 Monaco。非文字檔案會改用檢視器開啟：圖片（可放大縮小；SVG 也能以程式碼顯示）、附播放進度列的影片與音訊、PDF，其他二進位檔案則顯示檔案大小與開頭位元組的十六進位檢視。檢視器為唯讀，專案資料夾外的檔案，或經由指向資料夾外的符號連結才能到達的檔案，都不會顯示。

## 在檔案樹中操作檔案

可以直接在 檔案 中操作檔案，就像在 VS Code 中一樣。在項目上按右鍵；若要在專案最上層操作，請在樹狀結構下方的空白處按右鍵。名稱直接在樹狀結構中輸入。

  • 新增檔案 / 新增資料夾：使用樹狀結構上方的按鈕，或按右鍵。新項目會建立在選取的資料夾中、選取的檔案旁，或專案的最上層。輸入含斜線的名稱（例如 src/routes/index.ts）會一併建立途中的資料夾。新檔案會在編輯器中開啟。在空的資料夾中，檔案 會顯示 此資料夾是空的，以及 新增檔案 和 新增資料夾 按鈕。
  • 剪下、複製 與 貼上：{{keys:Mod+X}}、{{keys:Mod+C}}、{{keys:Mod+V}}，或按右鍵。資料夾會連同其中的所有內容一起複製。製作副本 會在原項目旁建立一份副本。如果名稱已被使用，副本會命名為 name copy，接著是 name copy 2。
  • 把項目拖到資料夾上（拖到空白處則移到專案最上層）即可移動。放下時按住 {{keys:Alt|Ctrl}} 則改為複製。從 Finder（Windows 上為檔案總管）拖入的檔案和資料夾會被複製到專案中，原始檔案保留在原處。
  • 重新命名：{{keys:F2 / Enter|F2}}，或按右鍵。
  • 刪除：{{keys:Mod+Backspace / Delete|Delete}}，或按右鍵。Ferret 會先詢問，再把項目移到垃圾桶（Windows 上為資源回收筒），因此可以復原。已刪除檔案的分頁會關閉；如果其中有未儲存的編輯，確認訊息會提到這點。
  • 復原：{{keys:Mod+Z}} 會復原上一次的新增、重新命名、移動、貼上或製作副本。已刪除的項目會從垃圾桶還原。
  • 複製路徑（{{keys:Alt+Mod+C|Shift+Alt+C}}）與 複製相對路徑（{{keys:Alt+Shift+Mod+C|Ctrl+Shift+Alt+C}}）會把路徑放到剪貼簿。
  • 在 Finder 中顯示（Windows 上為 在檔案總管中顯示，Linux 上為 開啟所在的資料夾）：{{keys:Alt+Mod+R|Shift+Alt+R}}。在終端機中開啟 會在該資料夾（若是檔案，則為其所在資料夾）開啟新的終端機分頁。
  • 對於檔案，開啟 會在編輯器中開啟，用預設應用程式開啟 會以作業系統為該類型檔案指定的 App 開啟。
  • 用 {{keys:Mod}}-按一下或 {{keys:Shift}}-按一下選取多個項目，即可一起剪下、複製、移動或刪除。
  • {{keys:Esc}} 會取消正在輸入的名稱。

已開啟的分頁會跟著重新命名或移動的檔案，並保留未儲存的編輯。Ferret 不會覆寫同名的現有檔案或資料夾，並會把一切都限制在專案資料夾內：它會拒絕 ..、絕對路徑、指向外部的符號連結、.git 內的任何項目、把資料夾移到自身之中，以及某些作業系統無法使用的名稱：/ \ < > : " | ? *、控制字元、結尾的空格或句點，以及 CON 或 NUL 等 Windows 保留名稱。一次複製或拖放最多可包含 10,000 個項目、1 GB。

## Markdown 與 Mermaid 預覽

預覽支援 .md、.markdown、.mdx、.mmd 與 .mermaid。Mermaid 已內建於 App 中，因此離線也能繪製圖表。

  • 在側邊開啟預覽：在編輯器旁邊
  • 開啟預覽：在內建瀏覽器中（ade-preview://），因此可以錄製並審查

若要以預覽中的樣子編輯 Markdown 檔案，請按一下編輯器上方的 在預覽中編輯，按一下 原始碼 即可返回。兩者顯示相同的內容，儲存、未儲存標記與關閉時的確認也都相同。

  • 可以直接在標題、段落、清單、核取方塊、表格、連結，以及粗體、斜體或行內程式碼中輸入。在行首輸入 #、-、1. 或 > 再加一個空格，即可開始標題、清單或引言。
  • 程式碼區塊和 Mermaid 圖表以原始碼形式編輯，角落會顯示語言。圖表會在 在側邊開啟預覽 或 開啟預覽 中繪製。
  • 前置資料（最上方的 --- 區塊）會以文字顯示在文件上方，並可在那裡編輯。
  • 未變更的部分會照原樣儲存，包括標題樣式、清單符號、空行、表格對齊與換行字元。編輯過的區塊會盡量保留原本的樣式；無法保留時，該區塊會以標準 Markdown 形式寫出，清單用 -，標題用 #。
  • 專案中的圖片會顯示。不會載入其他網站的圖片，而是改為顯示其主機名稱。檔案中的 HTML 會以文字顯示。
## 用錄製來審查文件
  1. 開啟 Markdown 檔案，然後按 開啟預覽。
  2. 照常錄製。一邊說明規格書或設計文件，一邊圈出有問題的地方。
  3. 停止。意見會以檔案相對於專案的路徑來參照，而不是 URL。
  4. 按 傳送給 Agent，讓 Agent 修正文件。
