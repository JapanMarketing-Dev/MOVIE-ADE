鍵盤快速鍵 快速鍵會依你目前閱讀所用的作業系統顯示；可用下方的切換開關查看另一種。大多數快速鍵在 Windows 與 Linux 上使用 Ctrl 的地方，macOS 改用 Command；使用 Alt 的地方，macOS 改用 Option。少數快速鍵差異更大，表格中會同時列出兩者。來源：src/main/menu.ts、src/shared/browserNav.ts、src/shared/annotation.ts，以及終端機的按鍵處理。 ## 錄製
動作macOSWindows / Linux
開始 / 停止錄製{{keys-mac:Mod+Shift+R}}{{keys-win:Mod+Shift+R}}
切換模式（編輯器 / 意見）{{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}
按住時使用畫筆{{keys-mac:Alt}}{{keys-win:Alt}}
## 錄製時繪圖
動作macOSWindows / Linux

操作頁面（停止繪圖）{{keys-mac:V / Esc}}{{keys-win:V / Esc}}
下一個顏色{{keys-mac:C}}{{keys-win:C}}
復原上一個標記{{keys-mac:Mod+Z}}{{keys-win:Mod+Z}}
重做{{keys-mac:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}{{keys-win:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}

這些按鍵在錄製內建瀏覽器且頁面取得焦點時有效。在頁面上的欄位中輸入文字時會被忽略，而字母鍵只有在未按修飾鍵時才有效，因此頁面本身的快速鍵仍可照常使用。

## 終端機
動作macOSWindows / Linux
新增終端機{{keys-mac:Mod+T}}{{keys-win:Mod+T}}
關閉窗格 / 分頁{{keys-mac:Mod+W}}{{keys-win:Mod+W}}

向下分割{{keys-mac:Mod+Shift+D|Alt+Shift+D}}{{keys-win:Mod+Shift+D|Alt+Shift+D}}
拷貝選取的文字{{keys-mac:Mod+C|Ctrl+Shift+C / Ctrl+C}}{{keys-win:Mod+C|Ctrl+Shift+C / Ctrl+C}}
貼上{{keys-mac:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}{{keys-win:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}
在 Agent 的提示中換行{{keys-mac:Shift+Enter}}{{keys-win:Shift+Enter}}
移到行首 / 行尾{{keys-mac:Mod+Left / Mod+Right|}}{{keys-win:Mod+Left / Mod+Right|}}
刪除到行首{{keys-mac:Mod+Backspace|}}{{keys-win:Mod+Backspace|}}

這些快速鍵在終端機取得焦點時有效。在 Windows 與 Linux 上，有選取文字時 Ctrl+C 會拷貝，沒有選取時則會停止正在執行的指令。執行 Claude Code 或 Codex 等 Agent 時，{{keys:Shift+Enter}} 會換行；在一般的 shell 中，它會像 Enter 一樣執行指令。在使用滑鼠的全螢幕程式（vim、tmux、Agent）中，macOS 上請按住 Option 鍵再拖曳來選取文字。
