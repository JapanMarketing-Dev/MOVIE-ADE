檔案與環境 Ferret 自己的檔案存放在哪裡，以及它讀取或設定的環境變數。 ## userData 資料夾

App 資料存放在 Electron 的 userData 資料夾中。資料夾名稱固定為 ade-movie（而非產品名稱），因此即使改名，資料也會保留。可以用 --user-data-dir=<path> 覆寫。

作業系統路徑
macOS~/Library/Application Support/ade-movie/
Windows%APPDATA%\ade-movie\
Linux~/.config/ade-movie/（或 $XDG_CONFIG_HOME/ade-movie/）
 
settings.json       # settings before 0.1.1, kept as a backup (now ~/.ferret/settings.json)
stt-keys.bin        # API keys, encrypted with safeStorage
browser-import/     # imported passwords (passwords.bin, encrypted with safeStorage) and history (history.json)
login-shell-path.json  # your login shell's PATH from the last launch, so agent tabs start without waiting
models/             # downloaded whisper models (ggml-*.bin)
accounts/claude/<id>/   # CLAUDE_CONFIG_DIR for added accounts
accounts/codex/<id>/    # CODEX_HOME for added accounts

你的設定不在這個資料夾中，而是存放在 ~/.ferret/（請參閱用 settings.json 設定）。

你自行選擇的模型可以放在任何位置。舊版的預設位置 ~/.cache/ade-movie/models/ggml-small.bin 仍會被檢查。

## 環境變數
變數作用
CLAUDE_CONFIG_DIR、CODEX_HOME選擇了新增的帳號時，由 Ferret 為 Agent 分頁設定
GH_TOKEN、GITHUB_TOKENgh 會優先於它自己的登入使用這些變數。設定了其中任何一個時，Ferret 會發出警告
FERRET_CONFIG_DIR（或舊的 MOVIE_ADE_CONFIG_DIR）用來取代 ~/.ferret，存放 settings.json、state.json 與 settings.schema.json 的資料夾
apiKeyEnv 中的名稱你從 settings.json 指向的 API 金鑰。也會從專案的 .env 與 ~/.ferret/.env 讀取
ADE_PROJECT_DIR啟動時將此資料夾作為專案開啟（並登錄）
ADE_INITIAL_URL啟動時在內建瀏覽器中載入此 URL
ADE_WHISPER_MODEL本機轉錄要使用的 GGML 模型的絕對路徑，會覆寫下載的預設模型
ADE_TERMINAL_PREWARM設為 0 時，Ferret 不再在背景預先準備一個 shell。預設情況下，下一個一般的 shell 分頁會使用它，因此提示字元會立即出現
FERRET_SENTRY_DSN（或舊的 MOVIE_ADE_SENTRY_DSN）當機報告的傳送目的地。空白表示不傳送（請參閱當機報告）
OPENAI_API_KEY僅在開發環境（pnpm dev）中從 .env 讀取，打包後的版本絕不讀取
PATH用來尋找你的 Agent 指令（claude、codex、gemini…）、gh、git、whisper-cli。在 macOS 與 Linux 上，會加入 Homebrew、linuxbrew 與 snap 的位置
## 專案內的檔案
  • .ferret/reviews/<id>/：審查（請參閱資料與隱私權）。.ade-movie/reviews/ 中較舊的審查仍會被讀取
  • .git/info/exclude：第一次錄製時會加入一行 .ferret/
