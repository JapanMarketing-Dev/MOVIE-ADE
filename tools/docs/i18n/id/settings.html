## Akun, CLI layanan, tampilan, bahasa
  • Akun: lihat Akun dan penggunaan.
  • CLI layanan: instal dan masuk ke CLI layanan. Lihat CLI layanan.
  • Impor dari browser: membawa kata sandi (dari CSV yang diekspor) dan riwayat ke browser bawaan. Lihat Mengimpor kata sandi dan riwayat.
  • Tampilan → Tema: Sistem (bawaan), Terang, Gelap.
  • Bahasa → Antarmuka: Sistem (bawaan; mengikuti bahasa OS jika Ferret mendukungnya, selain itu bahasa Inggris) atau salah satu dari 14 bahasa: English, 日本語, 简体中文, 繁體中文, 한국어, Español, Français, Deutsch, Italiano, Português (Brasil), Русский, हिन्दी, Bahasa Indonesia, Tiếng Việt.

Dari footer: posisi terminal (kanan / bawah) dan sakelar mikrofon.

## settings.json

Semua pengaturan di atas disimpan di ~/.ferret/settings.json (path yang sama di setiap OS), dengan JSON Schema di sebelahnya. Anda bisa mengeditnya saat aplikasi berjalan, secara manual atau dengan agent coding Anda; perubahan langsung diterapkan. Lihat Konfigurasi dengan settings.json.
