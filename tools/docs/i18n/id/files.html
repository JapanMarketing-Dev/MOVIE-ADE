File dan lingkungan Tempat Ferret menyimpan file-nya sendiri, serta variabel lingkungan yang dibaca atau diaturnya. ## Folder userData

Data aplikasi berada di folder userData milik Electron. Namanya dipatok ke ade-movie (bukan nama produk), sehingga data tetap ada meskipun produk berganti nama. Ganti lokasinya dengan --user-data-dir=<path>.

OSPath
macOS~/Library/Application Support/ade-movie/
Windows%APPDATA%\ade-movie\
Linux~/.config/ade-movie/ (atau $XDG_CONFIG_HOME/ade-movie/)
 
settings.json       # settings before 0.1.1, kept as a backup (now ~/.ferret/settings.json)
stt-keys.bin        # API keys, encrypted with safeStorage
browser-import/     # imported passwords (passwords.bin, encrypted with safeStorage) and history (history.json)
feedback-share/     # share links you made (shares.bin; owner tokens encrypted with safeStorage)
login-shell-path.json  # your login shell's PATH from the last launch, so agent tabs start without waiting
models/             # downloaded whisper models (ggml-*.bin)
accounts/claude/<id>/   # CLAUDE_CONFIG_DIR for added accounts
accounts/codex/<id>/    # CODEX_HOME for added accounts

Pengaturan Anda tidak ada di folder ini: pengaturan berada di ~/.ferret/ (lihat Konfigurasi dengan settings.json).

Model yang Anda pilih sendiri boleh berada di mana saja. Lokasi bawaan lama ~/.cache/ade-movie/models/ggml-small.bin juga masih diperiksa.

## Variabel lingkungan
VariabelEfek
CLAUDE_CONFIG_DIR, CODEX_HOMEDiatur oleh Ferret untuk tab agent saat akun tambahan dipilih
GH_TOKEN, GITHUB_TOKENDipakai oleh gh sebelum login miliknya sendiri. Ferret memberi peringatan jika salah satunya diatur
FERRET_CONFIG_DIR (atau MOVIE_ADE_CONFIG_DIR yang lama)Folder untuk settings.json, state.json, dan settings.schema.json sebagai pengganti ~/.ferret
Nama di apiKeyEnvAPI key yang Anda rujuk dari settings.json. Juga dibaca dari .env proyek dan ~/.ferret/.env
ADE_PROJECT_DIRMembuka (dan mendaftarkan) folder ini sebagai proyek saat peluncuran
ADE_INITIAL_URLMemuat URL ini di browser bawaan saat peluncuran
ADE_WHISPER_MODELPath absolut model GGML untuk transkripsi di perangkat, menggantikan model bawaan yang diunduh
ADE_TERMINAL_PREWARM0 membuat Ferret berhenti menyiapkan satu shell di latar belakang. Secara default, tab shell biasa berikutnya memakainya sehingga prompt langsung muncul
FERRET_SENTRY_DSN (atau MOVIE_ADE_SENTRY_DSN yang lama)Tujuan laporan crash. Jika kosong, tidak ada yang dikirim (lihat Laporan crash)
OPENAI_API_KEYDibaca dari .env hanya saat pengembangan (pnpm dev), tidak pernah di build yang dipaketkan
PATHDipakai untuk menemukan perintah agent Anda (claude, codex, gemini…), gh, git, whisper-cli. Di macOS dan Linux, lokasi Homebrew, linuxbrew, dan snap ditambahkan
