Editor dan pratinjau Buka dan edit file proyek, serta pratinjau Markdown dan Mermaid. Pratinjau yang dibuka di browser bawaan dapat direkam dan ditinjau seperti halaman web lainnya. ## Membuka dan mengedit file
  • File (pohon file): {{keys:Mod+Shift+E}}, dengan Filter berdasarkan nama file, Segarkan, dan Ciutkan Semua.
  • Buka File…: {{keys:Mod+P}}.
  • Seret file dari Finder (File Explorer di Windows, pengelola file Anda di Linux) ke bilah tab atau editor untuk membukanya. File di dalam proyek terbuka di editor atau penampil. Untuk memasukkan file dari luar proyek, lepaskan di File, yang akan menyalinnya ke dalam proyek. Folder yang dilepaskan di sini dibuka sebagai proyek. File yang diseret dari File terbuka dengan cara yang sama. Gambar dan video yang dilepaskan pada file Markdown yang sedang terbuka akan disematkan ke dalamnya (lihat Menyematkan gambar dan video di Markdown).
  • Simpan dengan {{keys:Mod+S}}. Menutup file yang diubah akan menanyakan Simpan perubahan pada <name>? dengan Simpan, Jangan Simpan, dan Batal.
  • Jika file berubah di disk saat Anda memiliki edit yang belum disimpan, pilih Muat Ulang dari Disk atau Pertahankan Perubahan Saya.

Editornya adalah Monaco. File yang bukan teks dibuka di penampil: gambar (perbesar dan perkecil; SVG juga bisa ditampilkan sebagai kode), video dan audio dengan bilah posisi, PDF, dan untuk file biner lainnya, ukurannya serta tampilan hex dari byte-byte pertama. Penampil bersifat hanya-baca, dan file di luar folder proyek atau yang dicapai melalui symbolic link yang keluar dari folder tersebut tidak ditampilkan.

## Mengelola file di pohon file

Kelola file langsung di File, seperti di VS Code. Klik kanan sebuah item, atau ruang kosong di bawah pohon untuk bekerja di tingkat teratas proyek. Nama diketik langsung di dalam pohon.

  • File Baru / Folder Baru: tombol di atas pohon, atau klik kanan. Item baru masuk ke folder yang dipilih, di samping file yang dipilih, atau di tingkat teratas proyek. Ketik nama dengan garis miring, seperti src/routes/index.ts, untuk sekaligus membuat folder-folder di jalurnya. File baru terbuka di editor. Di folder kosong, File menampilkan Folder ini kosong dengan tombol File Baru dan Folder Baru.
  • Potong, Salin, dan Tempel: {{keys:Mod+X}}, {{keys:Mod+C}}, {{keys:Mod+V}}, atau klik kanan. Folder disalin beserta seluruh isinya. Duplikat membuat salinan di samping aslinya. Jika namanya sudah dipakai, salinannya diberi nama name copy, lalu name copy 2.
  • Seret item ke sebuah folder (atau ke ruang kosong untuk tingkat teratas proyek) untuk memindahkannya. Tahan {{keys:Alt|Ctrl}} saat melepaskan untuk menyalin alih-alih memindahkan. File dan folder yang diseret dari Finder (File Explorer di Windows) disalin ke dalam proyek; aslinya tetap di tempatnya.
  • Ganti Nama: {{keys:F2 / Enter|F2}}, atau klik kanan.
  • Hapus: {{keys:Mod+Backspace / Delete|Delete}}, atau klik kanan. Ferret meminta konfirmasi lebih dulu, lalu memindahkan item ke Tempat Sampah (Recycle Bin di Windows), sehingga Anda bisa memulihkannya. Tab file yang dihapus ditutup; jika ada yang memiliki edit yang belum disimpan, konfirmasinya akan menyebutkannya.
  • Urungkan: {{keys:Mod+Z}} membatalkan item baru, penggantian nama, pemindahan, penempelan, atau duplikasi terakhir. Item yang dihapus dipulihkan dari Tempat Sampah.
  • Salin Path ({{keys:Alt+Mod+C|Shift+Alt+C}}) dan Salin Path Relatif ({{keys:Alt+Shift+Mod+C|Ctrl+Shift+Alt+C}}) menaruh path ke clipboard.
  • Tampilkan di Finder (Tampilkan di File Explorer di Windows, Buka Folder Induk di Linux): {{keys:Alt+Mod+R|Shift+Alt+R}}. Buka di Terminal membuka tab terminal baru di folder tersebut (untuk file, di foldernya).
  • Untuk file, Buka membukanya di editor dan Buka di Aplikasi Bawaan membukanya di aplikasi yang dipakai OS Anda untuk jenis file tersebut.
  • Pilih beberapa item dengan {{keys:Mod}}-klik atau {{keys:Shift}}-klik untuk memotong, menyalin, memindahkan, atau menghapusnya sekaligus.
  • {{keys:Esc}} membatalkan nama yang sedang Anda ketik.

Tab yang terbuka mengikuti file yang diganti nama atau dipindahkan dan mempertahankan edit yang belum disimpan. Ferret tidak akan menimpa file atau folder yang sudah ada dengan nama yang sama, dan menjaga semuanya tetap di dalam folder proyek: Ferret menolak .., path absolut, symbolic link yang mengarah ke luar, apa pun di dalam .git, memindahkan folder ke dalam dirinya sendiri, serta nama yang tidak bisa dipakai oleh sebagian OS: / \ < > : " | ? *, karakter kontrol, spasi atau titik di akhir, dan nama yang dicadangkan Windows seperti CON atau NUL. Satu kali salin atau lepas bisa berisi hingga 10.000 item dan 1 GB.

## Pratinjau Markdown dan Mermaid

Pratinjau berfungsi untuk .md, .markdown, .mdx, .mmd, dan .mermaid. Mermaid sudah dibundel dengan aplikasi, sehingga diagram dirender secara offline.

File Markdown memiliki dua tampilan di bagian atas editor: Sumber dan Pratinjau. Pratinjau selalu bisa diedit, sehingga Anda bisa mengetik langsung di dalamnya; klik Sumber untuk kembali ke teks. Keduanya menampilkan konten yang sama, dan penyimpanan, tanda belum disimpan, serta konfirmasi saat menutup bekerja dengan cara yang sama.

  • Ketik langsung di judul, paragraf, daftar, kotak centang, tabel, tautan, serta teks tebal, miring, atau kode sebaris. Mengetik #, -, 1., atau > diikuti spasi di awal baris akan memulai judul, daftar, atau kutipan.
  • Ketik / di awal baris (atau setelah spasi) untuk memilih blok dari daftar: judul, daftar berpoin, bernomor, atau daftar periksa, tabel, blok kode, kutipan, atau pembatas. Setiap entri menjelaskan apa yang dibuat dan cara menulisnya di Markdown. Terus ketik untuk menyaring, gunakan {{keys:Up}} {{keys:Down}} dan {{keys:Enter}} untuk memilih, atau {{keys:Esc}} untuk membiarkan / sebagai teks. Tabel dimulai 3 × 3 dengan baris judul; {{keys:Tab}} pindah ke sel berikutnya dan menambah baris di akhir. Mengetik / di dalam tabel menambah atau menghapus baris dan kolom, atau menghapus tabel.
  • Blok kode diedit sebagai sumbernya, dengan bahasa ditampilkan di sudut. Blok kode Mermaid (mermaid atau mmd) menampilkan diagram secara default. Klik Kode di kanan atas, atau klik dua kali diagram, untuk mengedit sumbernya; saat kursor keluar dari blok, diagram tampil lagi. Jika sumber berisi kesalahan, pesannya ditampilkan bersama Perbaiki kode. Diagram digambar di dalam bingkai sandbox, dan Markdown yang disimpan tetap seperti yang ditulis.
  • Front matter (blok --- di bagian atas) ditampilkan sebagai teks di atas dokumen dan bisa diedit di sana.
  • Bagian yang tidak Anda ubah disimpan persis seperti yang ditulis, termasuk gaya judul, penanda daftar, baris kosong, perataan tabel, dan akhir baris. Blok yang Anda edit mempertahankan gayanya jika memungkinkan; jika tidak, blok tersebut ditulis dalam bentuk Markdown standar, dengan - untuk daftar dan # untuk judul.
  • Gambar dan video di dalam proyek ditampilkan. Gambar dari situs lain tidak dimuat; nama host-nya yang ditampilkan. HTML lain di dalam file ditampilkan sebagai teks.

File .mdx (hanya diedit sebagai sumber), .mmd, dan .mermaid memiliki pratinjau hanya-baca sebagai gantinya:

  • Buka Pratinjau di Samping: di sebelah editor
  • Buka Pratinjau: di browser bawaan (ade-preview://), sehingga Anda bisa merekam dan meninjaunya
## Menyematkan gambar dan video di Markdown

Seret gambar (PNG, JPEG, GIF, WebP, SVG, AVIF) atau video (MP4, WebM, MOV) ke file Markdown, di Sumber atau Pratinjau, untuk menyematkannya di tempat Anda melepaskannya.

  • File yang sudah ada di dalam proyek, termasuk yang diseret dari File, ditautkan dengan path relatif terhadap file Markdown. Tidak ada yang disalin.
  • File dari luar proyek (Finder, desktop, File Explorer di Windows) lebih dulu disalin ke folder di sebelah file Markdown: assets, images, media, atau img jika salah satunya sudah ada, atau folder assets baru jika tidak ada. Spasi dalam nama menjadi -, dan jika namanya sudah dipakai, salinannya diberi nama name-2. File aslinya tetap di tempatnya.
  • Gambar ditulis sebagai ![name](assets/name.png) dan video sebagai <video src="assets/name.mp4" controls></video>, yang juga bisa diputar oleh GitHub. Keduanya ditampilkan di Pratinjau.
  • Satu gambar bisa berukuran hingga 50 MB dan satu video hingga 500 MB, dan satu kali lepas bisa menyalin hingga 50 file dan 1 GB. File lain yang dilepaskan bersamanya terbuka di editor seperti biasa.
## Meninjau dokumen dengan merekam
  1. Di panel Target tinjauan, buka file Markdown dari File. File tersebut terbuka sebagai pratinjau di browser bawaan.
  2. Rekam seperti biasa. Bahas spesifikasi atau dokumen desainnya dan lingkari bagian yang salah.
  3. Berhenti. Temuan merujuk ke path file relatif terhadap proyek, bukan URL.
  4. Klik Kirim ke Agent agar dokumennya diperbaiki.
