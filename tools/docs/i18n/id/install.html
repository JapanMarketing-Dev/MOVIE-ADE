Instalasi Unduh Ferret untuk komputer Anda, lalu buka. Ferret berjalan di macOS, Windows, dan Linux. ## Unduh

Halaman unduhan menyediakan file yang sesuai untuk komputer Anda. Klik tombol unduh.

## macOS

Buka file .dmg, seret Ferret ke Applications, lalu buka dari sana.

## Windows

Jalankan file .exe yang sudah diunduh. Ferret langsung terpasang dan terbuka, tanpa ada yang perlu dipilih. Selanjutnya, buka dari menu Start atau pintasan di desktop.

Jika Windows menampilkan Windows melindungi PC Anda, klik Info selengkapnya, lalu Tetap jalankan.

## Linux

Ubuntu / Debian: klik dua kali file .deb untuk memasangnya lewat pusat perangkat lunak, atau jalankan:

sudo apt install ./Ferret-<version>-linux-amd64.deb

Setelah itu, buka Ferret dari menu aplikasi, atau jalankan ferret.

Distribusi lain: gunakan .AppImage. AppImage berjalan dengan FUSE 2, jadi pasang dulu paketnya jika sistem Anda belum memilikinya: fuse-libs di Fedora, fuse2 di Arch, libfuse2 di openSUSE dan sistem berbasis Debian. Lalu izinkan .AppImage dijalankan sebagai program (klik kanan → Properti, atau chmod +x) dan buka.

## Selanjutnya
  • Mulai cepat: buka proyek dan rekam umpan balik pertama Anda.
  • Ada yang tidak berjalan? Lihat Pemecahan masalah.
  • Untuk memeriksa tanda tangan file unduhan, membangun dari kode sumber, atau mendapatkan versi lama, lihat Instalasi lanjutan.
