Instalasi lanjutan Periksa tanda tangan file unduhan, bangun Ferret dari kode sumber, dapatkan versi lama, dan pelajari cara kerja pembaruan. Anda tidak memerlukan semua ini untuk memasang Ferret. ## Semua unduhan

File disajikan dari Cloudflare R2, bukan GitHub Releases, dan hanya 10 versi terbaru yang disimpan. Halaman unduhan mencantumkan semuanya.

OSFile
macOS (Apple silicon / Intel)Ferret-<version>-mac-arm64.dmg, Ferret-<version>-mac-x64.dmg
Windows (x64 / arm64)Ferret-<version>-win-x64.exe, Ferret-<version>-win-arm64.exe (installer)
Linux (x64)Ferret-<version>-linux-x86_64.AppImage, Ferret-<version>-linux-amd64.deb

Rilis hingga 0.1.x diterbitkan dengan nama lama, sebagai MOVIE-ADE-<version>-…. Nama Ferret-… dimulai sejak 0.2.0.

## Memverifikasi unduhan (SHA256SUMS bertanda tangan)

Setiap rilis memiliki file SHA256SUMS beserta tanda tangannya, SHA256SUMS.sig. Tanda tangan dibuat dengan kunci rilis Ferret, yang disimpan terpisah dari server unduhan, sehingga installer yang diubah di server unduhan tidak mungkin disertai tanda tangan yang valid. Kunci publiknya tidak diambil dari server unduhan: ambil dari repositori (build/release-signing/allowed_signers) atau salin dari sini:

release@ferretade.dev ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIEpXERU8ST0MEOIMbzoL4zShkjIrMB4++NL3xBohKAS9

Fingerprint-nya adalah SHA256:c7dvwwJQyY9qSstkmrO8JoVZ90DCaFZBAzjqV04N8zQ. File yang sama juga dilampirkan pada setiap rilis di GitHub. Periksa tanda tangannya dengan ssh-keygen (sudah tersedia di macOS, Windows 10 ke atas, dan Linux), lalu bandingkan hash unduhan Anda dengan daftar yang ditandatangani:

# the download server (currently the R2 public URL; it may move to a custom domain)
BASE=https://pub-588d93b3e875464f98d6cf98dc711a0c.r2.dev
VERSION=$(curl -s $BASE/latest.json | jq -r .version)
curl -sO $BASE/releases/$VERSION/SHA256SUMS
curl -sO $BASE/releases/$VERSION/SHA256SUMS.sig

# save the public key above as allowed_signers, then:
ssh-keygen -Y verify -f allowed_signers -I release@ferretade.dev -n ferret-release -s SHA256SUMS.sig < SHA256SUMS
# → Good "ferret-release" signature for release@ferretade.dev …

# macOS
shasum -a 256 -c SHA256SUMS --ignore-missing
# Linux
sha256sum -c SHA256SUMS --ignore-missing
# Windows (PowerShell): compare with the line for your file in SHA256SUMS
Get-FileHash .\Ferret-<version>-win-x64.exe -Algorithm SHA256

Hentikan jika ssh-keygen tidak mencetak Good "ferret-release" signature atau hash-nya tidak ada di daftar. Periksa Pembaruan di Ferret melakukan pemeriksaan yang sama dengan kunci yang tertanam di aplikasi dan tidak menawarkan versi yang tanda tangannya tidak cocok. Di macOS, Anda juga bisa memeriksa tanda tangan Developer ID dan notarisasi dengan spctl -a -vv /Applications/Ferret.app. Untuk rilis hingga 0.3.0, bandingkan dengan hash di releases/<version>/manifest.json.

## Versi macOS lama

Untuk versi hingga 0.2.0 build 2: jika macOS menyatakan bahwa pengembangnya tidak dapat diverifikasi, tutup dialognya, buka Pengaturan Sistem → Privasi & Keamanan, klik Tetap Buka di samping pesan tentang Ferret, lalu konfirmasi dengan Buka. Jika muncul pesan bahwa aplikasi "rusak", hapus atribut karantinanya:

xattr -dr com.apple.quarantine /Applications/Ferret.app
## Build dari kode sumber

Memerlukan Node.js 20+ (CI dan pengembangan lokal memakai 22), pnpm, dan git.

git clone https://github.com/JapanMarketing-Dev/ferret.git
cd ferret
pnpm install          # postinstall prepares node-pty for Electron
pnpm dev              # run in development mode

Untuk membuat paket installer (hasilnya di dist/release/, konfigurasinya di electron-builder.config.cjs). Build Linux hanya berjalan di Linux.

pnpm dist:mac     # dmg (arm64, x64)
pnpm dist:win     # NSIS installers (x64, arm64)
pnpm dist:linux   # AppImage + deb (x64)

Skrip build:<os>:dev hanya menghasilkan aplikasi yang belum dipaketkan (--dir), yang lebih cepat untuk pengujian lokal.

Di Windows, pnpm install memakai binary prebuilt bawaan node-pty alih-alih membangun ulang (yang memerlukan Visual Studio C++ build tools). Atur ADE_FORCE_NATIVE_REBUILD=1 untuk memaksa build ulang.

Jika terminal melaporkan bahwa node-pty tidak dapat dimuat, jalankan pnpm rebuild:native.

## Pembaruan

Ferret tidak memperbarui dirinya secara otomatis. Di footer, buka Pembaruan lalu klik Periksa Pembaruan. Ferret mengambil latest.json dari server unduhan (R2), membandingkan versinya, dan memeriksa tanda tangan SHA256SUMS versi tersebut dengan kunci rilis yang tertanam di aplikasi. Jika versi yang lebih baru tersedia, klik Unduh: Ferret mengunduh installer untuk komputer Anda, memeriksa bahwa SHA-256-nya cocok dengan SHA256SUMS yang ditandatangani, menyimpannya ke folder Unduhan, lalu menampilkannya di sana. Halaman unduhan melakukan pemeriksaan yang sama di browser Anda sebelum menyimpan file. Tidak ada yang diperiksa sampai Anda mengklik, dan tidak ada yang dipasang secara otomatis.
