Mengirim ke agent Jalankan agent coding Anda di terminal bawaan dan serahkan tinjauan kepadanya dengan satu klik. Claude Code dan Codex adalah contoh yang umum, tetapi agent mana pun dalam daftar di bawah bisa dipakai, begitu juga CLI yang Anda tambahkan sendiri. Anda juga bisa menyalin instruksi untuk agent yang berjalan di tempat lain. ## Meninjau temuan

Setiap kartu di tab Temuan mendukung:

  • Edit judul dan permintaan langsung di tempat
  • Sakelar Kirim / Jangan kirim
  • Tonton Rekaman (melompat ke waktu tersebut) dan Ganti Gambar (pilih frame lain)
  • Konfirmasi, Hapus

Saring menurut progres menampilkan atau menyembunyikan temuan berdasarkan status (misalnya Hanya temuan yang menunggu tinjauan Anda); Tampilkan semua menghapus saringan.

Untuk mengurutkan ulang temuan, seret pegangan di sebelah kiri judul kartu, atau pilih pegangan itu lalu tekan ↑ / ↓. Nomor, feedback.md, dan isi yang Anda kirim ke Agent mengikuti urutan baru. Saat saringan aktif, urutan berubah di antara temuan yang terlihat, dan temuan yang tersembunyi tetap di posisinya. Jika satu tinjauan mencakup beberapa halaman atau file, temuan berpindah di dalam kelompoknya sendiri. Urutkan temuan di header beralih antara Manual (urutan seret), Waktu rekaman, dan Progres (yang belum dimulai di awal, yang selesai di akhir); mengurutkan menurut progres menyimpan urutan itu sebagai urutan manual.

Header berisi Urungkan, Buka Folder, Salin untuk Agent, Rapikan, dan Kirim ke Agent. Ucapan yang tidak menjadi temuan dicantumkan di Ucapan yang dikecualikan, tempat Pulihkan sebagai Temuan mengembalikannya. Ucapan tanpa kata yang bermakna tidak pernah menjadi temuan dan juga dicantumkan di sana: kalimat yang terkadang dikarang transkripsi dari keheningan, seperti “Shh.” atau “Terima kasih sudah menonton”, kata pengisi seperti “eh”, serta “OK” atau “ya” saja tanpa coretan pena.

{{shot:findings|Tab Temuan}} ## Menjalankan agent di terminal bawaan

Saat proyek dibuka, Ferret memulai satu tab terminal di folder proyek untuk setiap agent yang ada di Pengaturan → Agent → Jalankan Saat Proyek Dibuka. Bawaannya adalah Claude Code dan Codex, yang dimulai tanpa permintaan izin dan dengan Claude in Chrome aktif:

claude --dangerously-skip-permissions --chrome
codex --dangerously-bypass-approvals-and-sandbox

Sebagai gantinya, pilih agent mana pun dari daftar yang didukung (agent dimulai sesuai urutan Anda memilihnya), atau tidak sama sekali.

Agent yang Anda buka sendiri dimulai dengan cara yang sama. Ferret juga menandai folder proyek sebagai tepercaya untuk Claude Code dan Codex, sehingga keduanya tidak bertanya soal folder tersebut. Untuk memulainya dalam mode normal, yaitu bertanya dulu sebelum memercayai folder, mengedit file, atau menjalankan perintah, nonaktifkan Pengaturan → Agent → Jalankan Agent tanpa permintaan izin. Perintah dan argumen setiap agent ada di Pengaturan → Agent (Perintah) dan di settings.json (agents.launch), dan dipakai persis seperti yang Anda tulis. Hapus --chrome di sana untuk memulai Claude Code tanpa Claude in Chrome. Jika argumen sudah memilih mode izin (misalnya --permission-mode plan, atau --sandbox workspace-write untuk Codex), flag lewati tidak ditambahkan.

Jika tidak ada agent yang dipilih, shell biasa yang dibuka. Menu + membuka Terminal Baru, menjalankan salah satu agent Anda di tab baru, atau melompat ke Pengaturan agent…. Kotak pencariannya juga menemukan tab, URL tersimpan, dan file.

Lepaskan file ke terminal. Seret file, folder, atau gambar dari Finder (File Explorer di Windows, pengelola file Anda di Linux) ke panel terminal, dan path-nya diketik ke panel tersebut, dipisahkan spasi, tanpa menekan Enter. Ini berfungsi sama saat agent sedang berjalan: Claude Code membaca path gambar yang dilepaskan sebagai gambar. Baris yang diseret dari File (beberapa sekaligus jika Anda memilihnya) bekerja dengan cara yang sama: path-nya relatif terhadap folder proyek selama terminal berada di dalamnya, dan absolut setelah Anda cd ke tempat lain. Path yang berisi spasi atau karakter khusus lainnya diberi kutip untuk shell: '…' di zsh dan bash, "…" di Command Prompt, dan '…' di PowerShell.

Tab menampilkan status agent: Berjalan, Menunggu input, Selesai (belum dibaca), Diam. Selesai (belum dibaca) berarti agent selesai saat Anda sedang melihat tab lain; statusnya berubah menjadi Diam begitu Anda membuka tab tersebut. Sidebar menandai setiap proyek dengan cara yang sama, sehingga Anda bisa melihatnya tanpa berpindah proyek: bilah bergerak saat agent sedang berjalan, tanda tanya saat ada agent yang menunggu Anda, dan tanda centang saat agent di sana sudah selesai dan Anda belum membuka tabnya.

Notifikasi. Aktifkan Pengaturan → Agent → Beri tahu saya saat agen selesai atau membutuhkan saya untuk mendapatkan notifikasi sistem saat semua agent di sebuah proyek sudah selesai, atau saat ada agent yang menunggu izin atau jawaban. Tidak ada yang ditampilkan untuk tab yang sedang Anda lihat. Klik notifikasi untuk beralih ke proyek tersebut dan membuka tabnya.

Ferret tidak terikat pada satu agent. Ferret mengenali agent coding di bawah ini: Ferret bisa menjalankannya, mendeteksinya di terminal untuk Kirim ke Agent, dan menampilkan apakah agent tersebut terinstal. Pengaturan → Agent mencantumkannya dengan Terinstal / Tidak ditemukan, tombol Instal jika vendornya menyediakan installer satu baris, serta perintah dan argumen untuk masing-masing.

Tidak ada di daftar? Pengaturan → Agent → Tambah Agent Kustom mendaftarkan CLI atau skrip wrapper apa pun (nama, perintah, dan opsional nama proses yang dipakai untuk mengenalinya), atau tambahkan ke agents.customAgents di settings.json. Beberapa fitur bergantung pada agent dan untuk saat ini terbatas pada Claude Code dan Codex:

  • Rapikan: berjalan dengan login Claude Code atau Codex Anda, atau dengan API LLM yang Anda konfigurasi.
## Kirim ke Agent / Salin untuk Agent {{clip:send|Dari tab Temuan ke agent di terminal bawaan dengan Kirim ke Agent.}}
  1. Klik Kirim ke Agent. Secara bawaan (Otomatis (tab saat ini atau agent yang berjalan)), instruksi dikirim ke agent di tab terminal saat ini, atau ke agent yang sedang berjalan. Gunakan panah di samping tombol (Pilih agent tujuan) untuk memilih agent atau tab tertentu.
  2. Ferret menulis instruksi ke input agent lalu mengirimkannya. Pantau progresnya di terminal.

Jika tidak ada agent yang berjalan, Ferret menjalankannya terlebih dahulu dan mengirim begitu agent siap. Tidak ada yang dikirim selama agent menunggu jawaban izin. Jawab di terminal terlebih dahulu.

Salin untuk Agent menaruh instruksi yang sama di clipboard untuk agent yang berjalan di tempat lain (terminal lain, IDE, atau aplikasi). Hanya temuan yang disetel ke Kirim yang disertakan. Videonya tidak pernah disertakan.

## Pemeriksaan penerimaan dengan model keputusan {{clip:verify|Agent memperbaiki temuan dan memeriksa masing-masing dengan model keputusan sampai semuanya lolos.}}

Aktifkan fitur ini, dan agent coding Anda akan memeriksa hasil kerjanya sendiri terhadap setiap temuan sebelum melaporkan Selesai. Ferret sendiri tidak menilai apa pun: Ferret memberi agent sebuah model keputusan (API apa pun yang kompatibel dengan System One) dan, di feedback.md, memintanya mengulang sampai setiap temuan lolos.

  1. Agent mengimplementasikan temuan.
  2. Untuk setiap temuan, agent mengambil screenshot AFTER (viewport dan status halaman yang sama dengan gambar BEFORE) dan mengirim satu permintaan berisi teks temuan, baris "Selesai jika", serta gambar BEFORE/AFTER ke model keputusan.
  3. Temuan lolos jika P(done) setidaknya sama dengan ambang batas (bawaan 0.7) dan pilihannya adalah done. Agent memperbaiki sisanya dan menilai ulang semua temuan di setiap putaran, dan hanya berhenti jika setiap temuan lolos dalam putaran yang sama, atau karena alasan jujur yang harus disebutkannya: API tidak dapat dijangkau, temuan berada di luar cakupan, atau temuan macet dengan skor yang tidak berubah.
  4. Daftar akhir Selesai / Belum selesai mencantumkan skor setiap temuan dan jumlah putarannya.

Siapkan di Pengaturan → Model keputusan lalu aktifkan Tambahkan pemeriksaan model keputusan ke instruksi agent. Preset hanya mengisi field; setiap field tetap bisa diedit, dan Kustom berfungsi dengan API kompatibel apa pun.

Untuk Ollama, instal (0.35.1 atau lebih baru untuk Clef / Clef Flash) lalu tarik modelnya di terminal. Ferret tidak menjalankan installer:

ollama pull clef-flash

Key diambil dari field key (disimpan bersama API key Anda yang lain), dari variabel lingkungan yang Anda sebutkan (lingkungan aplikasi, .env proyek, atau ~/.ferret/.env), atau dari apiKey di settings.json. Header tambahan bisa membaca nilai dari variabel lingkungan dengan ${VAR}.

Bagaimana key tidak masuk ke prompt

Agent tidak pernah melihat key Anda. Ferret menjalankan relay lokal di 127.0.0.1 dan memberi setiap terminal FERRET_DECISION_URL (relay tersebut, dengan token per terminal), FERRET_DECISION_MODEL, dan FERRET_DECISION_IMAGES (selama satu rilis, nama lama MOVIE_ADE_DECISION_* juga diatur). Relay menambahkan key dan header lalu meneruskan permintaan tanpa perubahan, sehingga prompt, feedback.md, dan transkrip agent tidak berisi rahasia apa pun. Token setiap terminal mengizinkan 500 panggilan, 30 per menit, 20 juta token, dan $5 (jika biayanya diketahui), dan setiap proyek mengizinkan 2.000 panggilan dan $20 per hari; saat batas tercapai, relay menjawab 429 beserta alasannya, dan tab terminal baru mendapat token baru. Mengubah pengaturan model keputusan mengakhiri token terminal yang sedang terbuka; terminal yang dibuka sesudahnya memakai pengaturan baru.

Cloudflare berbeda dari dokumentasi System One dalam dua hal (diperiksa terhadap API yang sebenarnya): gambar harus berupa data URI (data:image/jpeg;base64,…, jika tidak akan muncul 422 "image must be an embedded base64 data URI"), dan jawabannya dibungkus sebagai { "result": { … }, "success": true } (error dikembalikan sebagai { "success": false, "errors": [ … ] }). Preset Cloudflare mengatur Encoding gambar ke data URI, agent menerimanya sebagai FERRET_DECISION_IMAGE_FORMAT, dan instruksinya meminta agent membaca .result jika ada. Relay meneruskan kedua arah tanpa perubahan. Untuk memakai Global API Key alih-alih API token, atur Autentikasi ke Tanpa key lalu tambahkan header X-Auth-Email: ${CLOUDFLARE_EMAIL} dan X-Auth-Key: ${CLOUDFLARE_API_KEY}.

Hanya Clef dan Clef Flash yang membaca gambar. Dengan model yang hanya teks, matikan Kirim gambar BEFORE/AFTER; agent kemudian menilai hanya dari teks, yang kurang andal.

Ollama dan gambar besar

Ollama 0.35.0 membatasi permintaan /v1/systemone hingga 64 KiB, sehingga permintaan dengan screenshot gagal dengan HTTP 413. Instruksinya meminta agent mengecilkan kedua gambar menjadi lebar maksimal 1024px dalam format JPEG (kualitas sekitar 70). Jika masih mendapat 413, perbarui Ollama ke 0.35.1 atau lebih baru, atau beralih ke Cloudflare Workers AI.

## Penggunaan API di footer

Panggilan keputusan melewati relay, sehingga Ferret bisa menghitungnya. Item footer di samping meteran penggunaan agent menampilkan model keputusan serta jumlah panggilan, token, dan biaya hari ini (misalnya clef-flash · 42 calls · 18.3k tok). Klik untuk melihat rincian hari ini, bulan ini, per proyek, per model, dan per jenis (keputusan / transkripsi / merapikan), serta 50 panggilan terakhir.

Biaya hanya muncul jika API melaporkannya (Vercel AI Gateway melakukannya) atau jika Anda mengatur harga per 1 juta token di Pengaturan → Model keputusan; jika tidak, yang ditampilkan adalah "—". Hanya metadata yang dicatat (waktu, proyek, model, status, latensi, ukuran, jumlah gambar, token, biaya), tidak pernah gambar, teks, atau key, di ~/.ferret/usage/decision-YYYY-MM.jsonl, satu file per bulan.

## Menyesuaikan instruksi

Edit Pengaturan → Agent → Instruksi untuk Agent. Dua variabel akan diekspansi:

VariabelDiekspansi menjadi
{{path}}Path absolut feedback.md
{{relpath}}Path relatif terhadap proyek: .ferret/reviews/<id>/feedback.md

Biarkan kosong untuk memakai bawaan. Panjang maksimumnya 2000 karakter, dan Reset Instruksi mengembalikan bawaan. Contoh:

Read {{relpath}} and the PNGs next to it. Fix only findings marked to send, one commit per finding, then run the tests.

Pengaturan ini disimpan sebagai agentPrompt di settings.json.

## Beri bintang Ferret di GitHub

Setelah Kirim ke Agent pertama Anda, dan saat Anda mencapai 3, 10, dan 30 tinjauan yang selesai, Ferret mungkin meminta Anda memberi bintang di GitHub. Ajakan ini muncul paling banyak 3 kali, dengan jarak minimal 3 hari, dan tidak pernah saat merekam. Beri bintang di GitHub memberi bintang melalui login gh Anda sendiri (atau membuka GitHub jika gh tidak tersedia), dan Jangan tanya lagi menghentikan ajakan tersebut. Anda juga bisa memberi bintang dari Bantuan → Beri bintang Ferret di GitHub.

## CLI layanan

Pengaturan → CLI layanan menampilkan alat baris perintah dari layanan yang sering Anda pakai, agar agen Anda bisa bekerja dengannya. Memasangnya tidak wajib: pasang hanya yang Anda perlukan; Ferret tetap berjalan tanpa semuanya. Setiap baris menunjukkan apakah alat sudah terpasang beserta versinya, tautan ke situs web layanan, dan tombol yang menjalankan perintah resmi untuk memasang atau masuk sesuai OS Anda di tab terminal baru:

  • Hosting Git: GitHub (gh), GitLab (glab)
  • Hosting & deploy: Vercel, Netlify, Cloudflare (wrangler), Firebase, Fly.io, Railway, Heroku
  • Cloud: AWS, Google Cloud (gcloud), Azure (az)
  • Database & backend: Supabase, Neon, PlanetScale, Turso
  • Error & pemantauan: Sentry (sentry-cli), Datadog (datadog-ci)
  • Pembayaran: Stripe
  • Kontainer: Docker, kubectl
  • Seluler: Xcode Command Line Tools (Hanya macOS), Android Platform Tools (adb), Expo EAS, fastlane
  • Mesin virtual: UTM (Hanya macOS), Lima, Multipass
  • AI & model: Ollama

Jika suatu alat tidak memiliki installer resmi satu baris untuk OS Anda, Dokumentasi akan membuka halaman instalasinya. Daftar ini memeriksa ulang dengan sendirinya setelah instalasi selesai.
