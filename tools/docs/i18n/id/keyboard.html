Pintasan keyboard Pintasan ditampilkan untuk OS yang sedang Anda gunakan; pakai pengalih di bawah untuk melihat OS lainnya. Sebagian besar memakai Command di macOS saat Windows dan Linux memakai Ctrl, dan Option saat keduanya memakai Alt. Beberapa berbeda lebih jauh, dan tabel mencantumkan keduanya. Sumber: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts, dan penanganan tombol di terminal. ## Perekaman

Ganti Mode (Editor / Umpan Balik){{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}
Pena selama ditahan{{keys-mac:Alt}}{{keys-win:Alt}}
## Menggambar saat merekam
TindakanmacOSWindows / Linux
Pena{{keys-mac:P}}{{keys-win:P}}
Kotak{{keys-mac:B / R}}{{keys-win:B / R}}
Gunakan halaman (berhenti menggambar){{keys-mac:V / Esc}}{{keys-win:V / Esc}}
Warna berikutnya{{keys-mac:C}}{{keys-win:C}}
Urungkan coretan terakhir{{keys-mac:Mod+Z}}{{keys-win:Mod+Z}}
Ulangi{{keys-mac:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}{{keys-win:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}

Tombol-tombol ini berfungsi saat Anda merekam browser bawaan dan halaman sedang dalam fokus. Tombol diabaikan saat Anda mengetik di kolom input pada halaman, dan tombol huruf hanya berfungsi tanpa tombol pengubah, sehingga pintasan milik halaman itu sendiri tetap berfungsi.
