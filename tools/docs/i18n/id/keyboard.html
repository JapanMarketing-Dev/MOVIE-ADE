Sebagian besar memakai Command di macOS saat Windows dan Linux memakai Ctrl, dan Option saat keduanya memakai Alt. Beberapa berbeda lebih jauh, dan tabel mencantumkan keduanya. ## Terminal
TindakanmacOSWindows / Linux
Terminal Baru{{keys-mac:Mod+T}}{{keys-win:Mod+T}}
Tutup Panel / Tab{{keys-mac:Mod+W}}{{keys-win:Mod+W}}
Pisah ke Kanan{{keys-mac:Mod+D|Ctrl+Shift+D}}{{keys-win:Mod+D|Ctrl+Shift+D}}

Tempel{{keys-mac:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}{{keys-win:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}
Baris Baru di Prompt Agent{{keys-mac:Shift+Enter}}{{keys-win:Shift+Enter}}
Awal / Akhir Baris{{keys-mac:Mod+Left / Mod+Right|}}{{keys-win:Mod+Left / Mod+Right|}}
Hapus sampai Awal Baris{{keys-mac:Mod+Backspace|}}{{keys-win:Mod+Backspace|}}

Pintasan ini berfungsi saat terminal sedang dalam fokus. Di Windows dan Linux, Ctrl+C menyalin jika ada teks yang dipilih, dan menghentikan perintah yang sedang berjalan jika tidak ada yang dipilih. {{keys:Shift+Enter}} membuat baris baru saat agent seperti Claude Code atau Codex sedang berjalan; di shell biasa, tombol ini menjalankan perintah seperti Enter. Di program layar penuh yang memakai mouse (vim, tmux, agent), tahan Option sambil menyeret untuk memilih teks di macOS.
