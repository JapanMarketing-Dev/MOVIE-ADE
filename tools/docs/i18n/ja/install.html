インストール 自分のパソコン用の Ferret をダウンロードして開きます。macOS、Windows、Linux で動きます。 ## ダウンロード

ダウンロードページが、自分のパソコンに合うファイルを案内します。ダウンロードボタンを押してください。

## macOS

.dmg を開き、Ferret を Applications にドラッグして、そこから開きます。

## Windows

ダウンロードした .exe を実行します。選ぶものは無く、Ferret がインストールされてそのまま開きます。次からはスタートメニューかデスクトップのショートカットから開きます。

Windows が Windows によって PC が保護されました と出したら、詳細情報 を押してから 実行 を押します。

## Linux

Ubuntu / Debian: .deb をダブルクリックしてソフトウェアセンターで入れるか、次を実行します。

sudo apt install ./Ferret-<version>-linux-amd64.deb

そのあと、アプリのメニューから Ferret を開くか、ferret を実行します。

ほかのディストリビューション: .AppImage を使います。プログラムとして実行できるようにして（右クリック → プロパティ、または chmod +x）から開きます。

## 次に
  • クイックスタート: プロジェクトを開き、最初のフィードバックを録ります。
  • うまくいかないときはトラブルシューティングを見てください。
  • ダウンロードの署名の確認、ソースからのビルド、古い版の入手はインストールの詳細にあります。
