クイックスタート Ferret を入れ、プロジェクトと開発サーバーの URL を開き、フィードバックを1回録画して、コーディングエージェントに渡します。5分ほどで終わります。 ## 始める前に {{clip:quick-start|ページを開いて録画し、ペンで囲みながら話し、止めて、指摘をエージェントへ送る。}}
  • ターミナルで動くコーディングエージェント（インストールしてサインイン済みのもの）。たとえば Claude Code（claude）、Codex（codex）、Gemini CLI（gemini）など。Ferret は内蔵のターミナルでそれを動かします。対応している一覧のエージェントならどれでも使え、自分で足した CLI も使えます。
  • URL で開ける Web アプリ。たとえば http://localhost:3000 の開発サーバー。
  • マイク。フィードバックは声とペンで伝えます。マイクが無くてもペンで囲んだところは指摘になりますが、言葉は付きません。
## 1. インストール

ダウンロードページから自分の OS 用のファイルを取って開きます。macOS 版は Developer ID で署名され Apple の公証を受けているので、ほかのアプリと同じように開けます。Windows 版と Linux 版はまだコード署名が無いため、初回の起動で確認の手順が1つ増えます。Windows の SmartScreen、Linux、ソースからのビルドはインストールを見てください。

## 2. プロジェクトと URL を開く
  1. ファイル → プロジェクトフォルダを開く…（{{keys:Mod+O}}）で、リポジトリのルートを選びます。
  2. ブラウザの URL バー（{{keys:Mod+L}}）に開発サーバーの URL を入れて Enter を押します。
  3. 必要なら +（表示中のURLを登録）を押し、local・dev・prd のようにワンクリックで開ける URL として残します。

プロジェクトを開くと、そのフォルダのターミナルのタブでエージェントも起動します。最初の設定では Claude Code と Codex です。使うものは 設定 → Agent → プロジェクトを開いたら起動 で選べます（設定を参照）。

## 3. 録画する
  1. タイトルバーの 録画 を押すか、{{keys:Mod+Shift+R}} を押します。ウィンドウがフィードバックモードに切り替わります。
  2. いつもどおりページを操作しながら、直してほしいことを話します。
  3. {{keys:Alt}} を押したまま（または ペン を選んで）ドラッグし、話している場所を囲みます。
  4. 停止 を押すか、もう一度 {{keys:Mod+Shift+R}} を押します。

話したり囲んだりした場面がそれぞれ1件の指摘になります。ペンの跡が入ったスクリーンショット、依頼、話した言葉そのもの、URL、指した要素が1件にまとまります。

## 4. 指摘を確かめる

止めるとウィンドウはエディタモードに戻り、指摘 タブが開きます。

  • 題名や依頼はその場で直せます。
  • 指摘ごとに 送信する / 送信しない を切り替えたり、次とまとめる、削除 ができます。
  • 元に戻す で直前の編集を取り消せます。
## 5. エージェントに送る
  1. Agentへ送信 を押します。いま開いているターミナルのタブのエージェントか、動いているエージェントに届きます。ボタンの横の矢印で、送り先のエージェントやタブを選べます。
  2. エージェントがまだ動いていなければ、Ferret が先に起動し、準備ができしだい送ります。

Ferret はエージェントの入力欄に指示を1つ書き込んで送信します。最初の設定では、指示は次のように始まります。

"{{path}}" と、同じフォルダにある各指摘の画像を読み、送信対象の指摘をすべて実装してください。…

続きでは、変えた画面を実際に見て確かめること、指摘ごとの進み具合を書くこと、最後に「完了／未完了」の一覧で報告することを頼みます。エージェントは .ferret/reviews/<timestamp>/feedback.md と、その横の PNG を読みます。動画は送りません。Ferret の外で動くエージェントを使うときは、Agent向けにコピー を押して貼り付けます。

最初の指示は画面の言語に合わせて変わります。設定で差し替えることもできます。指示を変えるを見てください。
