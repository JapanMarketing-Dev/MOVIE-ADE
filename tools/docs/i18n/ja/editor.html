エディタとプレビュー プロジェクトのファイルを開いて編集し、Markdown と Mermaid をプレビューします。内蔵のブラウザで開いたプレビューは、ほかの Web ページと同じように録画してレビューできます。 ## ファイルを開いて編集する
  • ファイル（ファイルツリー）: {{keys:Mod+Shift+E}}。ファイル名で絞り込む、再読込、すべて畳む があります。
  • ファイルを名前で開く…: {{keys:Mod+P}}。
  • Finder（Windows ではエクスプローラー、Linux ではファイルマネージャー）からファイルをタブバーかエディタにドラッグすると開きます。プロジェクト内のファイルはエディタかビューアで開きます。プロジェクトの外のファイルを取り込むには、ファイル にドロップします。プロジェクトにコピーされます。ここにドロップしたフォルダはプロジェクトとして開きます。ファイル からドラッグしたファイルも同じように開きます。
  • {{keys:Mod+S}} で保存します。変更したファイルを閉じると <name> の変更を保存しますか？ と尋ねられ、保存、保存しない、キャンセル を選べます。
  • 保存していない編集がある間にディスク上のファイルが変わったときは、ディスクの内容を読み込む か 自分の変更を残す を選びます。

エディタは Monaco です。テキストでないファイルは代わりにビューアで開きます。画像（拡大・縮小でき、SVG はコードとしても表示可能）、シークバー付きの動画と音声、PDF、そのほかのバイナリファイルはサイズと先頭のバイトの 16 進表示です。ビューアは読み取り専用で、プロジェクトのフォルダの外にあるファイルや、フォルダの外へ出るシンボリックリンクの先にあるファイルは表示しません。

## ファイルツリーでファイルを扱う

VS Code と同じように、ファイル の中でそのままファイルを扱えます。項目を右クリックします。プロジェクトの一番上で操作するときは、ツリーの下の空いた所を右クリックします。名前はツリーの中で直接入力します。

  • 新しいファイル / 新しいフォルダ: ツリーの上のボタンか右クリック。新しい項目は、選んでいるフォルダの中、選んでいるファイルの隣、またはプロジェクトの一番上にできます。src/routes/index.ts のようにスラッシュを含む名前を入力すると、途中のフォルダも作ります。新しいファイルはエディタで開きます。空のフォルダでは、ファイル に このフォルダは空です と、新しいファイル と 新しいフォルダ のボタンが出ます。
  • 切り取り、コピー、貼り付け: {{keys:Mod+X}}、{{keys:Mod+C}}、{{keys:Mod+V}} か右クリック。フォルダは中身ごとコピーします。複製 は元の隣にコピーを作ります。名前がすでに使われているときは、コピーの名前は name copy、その次は name copy 2 になります。
  • 項目をフォルダの上（プロジェクトの一番上なら空いた所）にドラッグすると移動します。ドロップするときに {{keys:Alt|Ctrl}} を押していると、移動ではなくコピーします。Finder（Windows ではエクスプローラー）からドラッグしてきたファイルやフォルダはプロジェクトにコピーされ、元のものはそのまま残ります。
  • 名前を変更: {{keys:F2 / Enter|F2}} か右クリック。
  • 削除: {{keys:Mod+Backspace / Delete|Delete}} か右クリック。Ferret は先に確認してから、項目をゴミ箱（Windows ではごみ箱）へ移すので、元に戻せます。削除したファイルのタブは閉じます。保存していない編集があったときは、確認の画面にそう出ます。
  • 元に戻す: {{keys:Mod+Z}} で、直前の新規作成、名前の変更、移動、貼り付け、複製を取り消します。削除した項目はゴミ箱から戻します。
  • パスをコピー（{{keys:Alt+Mod+C|Shift+Alt+C}}）と 相対パスをコピー（{{keys:Alt+Shift+Mod+C|Ctrl+Shift+Alt+C}}）は、パスをクリップボードに入れます。
  • Finder で表示（Windows では エクスプローラーで表示、Linux では 含まれているフォルダを開く）: {{keys:Alt+Mod+R|Shift+Alt+R}}。ターミナルで開く は、そのフォルダ（ファイルならそのファイルがあるフォルダ）で新しいターミナルのタブを開きます。
  • ファイルでは、開く でエディタで開き、既定のアプリで開く で OS がその種類のファイルに使うアプリで開きます。
  • {{keys:Mod}}-クリックか {{keys:Shift}}-クリックで複数の項目を選ぶと、まとめて切り取り、コピー、移動、削除できます。
  • {{keys:Esc}} で入力中の名前を取り消します。

開いているタブは、名前を変えたり移動したりしたファイルに付いていき、保存していない編集も残ります。Ferret は同じ名前の既存のファイルやフォルダを上書きせず、すべてをプロジェクトのフォルダの中に収めます。..、絶対パス、外を指すシンボリックリンク、.git の中のもの、フォルダをそれ自身の中へ移すこと、どれかの OS で使えない名前（/ \ < > : " | ? *、制御文字、末尾の空白やドット、CON や NUL などの Windows の予約名）は受け付けません。1回のコピーやドロップで扱えるのは 10,000 項目、1 GB までです。

## Markdown と Mermaid のプレビュー

プレビューできるのは .md、.markdown、.mdx、.mmd、.mermaid です。Mermaid はアプリに同梱しているので、オフラインでも図を描けます。

  • プレビューを横に並べる: エディタの隣に表示
  • プレビューを開く: 内蔵のブラウザ（ade-preview://）で表示。録画してレビューできます

Markdown ファイルをプレビューの見た目のまま編集するには、エディタの上の プレビューで編集 を押します。戻るには ソース を押します。どちらも同じ内容を表示し、保存、未保存の印、閉じるときの確認も同じように働きます。

  • 見出し、段落、リスト、チェックボックス、表、リンク、太字、斜体、インラインコードにそのまま入力できます。行の先頭で #、-、1.、> に続けて空白を入力すると、見出し、リスト、引用になります。
  • コードブロックと Mermaid の図はソースのまま編集し、隅に言語が出ます。図は プレビューを横に並べる か プレビューを開く で描かれます。
  • フロントマター（先頭の --- のブロック）は文書の上にテキストとして出て、そこで編集できます。
  • 変更していない部分は、見出しの書き方、リストの記号、空行、表の揃え、改行コードも含めて、書かれたとおりに保存します。編集したブロックはできるだけ元の書き方を保ち、保てないときはそのブロックを標準的な Markdown の形（リストは -、見出しは #）で書きます。
  • プロジェクト内の画像は表示します。ほかのサイトの画像は読み込まず、代わりにホスト名を表示します。ファイル内の HTML はテキストとして表示します。
## ドキュメントを録画でレビューする
  1. Markdown のファイルを開き、プレビューを開く を押します。
  2. いつもどおり録画します。仕様書や設計書を読みながら話し、おかしいところを囲みます。
  3. 止めます。指摘には URL の代わりに、プロジェクトからのファイルの相対パスが入ります。
  4. Agentへ送信 で、ドキュメントを直してもらいます。
