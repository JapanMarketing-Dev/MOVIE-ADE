ファイルと環境変数 Ferret が自分のファイルを置く場所と、読んだり設定したりする環境変数です。 ## userData フォルダ

アプリのデータは Electron の userData フォルダにあります。フォルダ名は製品名ではなく ade-movie に固定しているので、名前が変わってもデータは残ります。--user-data-dir=<path> で場所を変えられます。

OSパス
macOS~/Library/Application Support/ade-movie/
Windows%APPDATA%\ade-movie\
Linux~/.config/ade-movie/（または $XDG_CONFIG_HOME/ade-movie/）
 
settings.json       # settings before 0.1.1, kept as a backup (now ~/.ferret/settings.json)
stt-keys.bin        # API keys, encrypted with safeStorage
browser-import/     # imported passwords (passwords.bin, encrypted with safeStorage) and history (history.json)
feedback-share/     # share links you made (shares.bin; owner tokens encrypted with safeStorage)
login-shell-path.json  # your login shell's PATH from the last launch, so agent tabs start without waiting
models/             # downloaded whisper models (ggml-*.bin)
accounts/claude/<id>/   # CLAUDE_CONFIG_DIR for added accounts
accounts/codex/<id>/    # CODEX_HOME for added accounts

設定はこのフォルダにはありません。~/.ferret/ にあります（settings.json で設定するを参照）。

自分で選んだモデルはどこに置いてもかまいません。以前の既定の場所 ~/.cache/ade-movie/models/ggml-small.bin も引き続き探します。

## 環境変数
変数働き
CLAUDE_CONFIG_DIR, CODEX_HOME追加したアカウントを選んでいるとき、Ferret がエージェントのタブに設定します
GH_TOKEN, GITHUB_TOKENgh が自分のログインより優先して使います。どちらかが設定されていると Ferret が警告します
FERRET_CONFIG_DIR（または以前の MOVIE_ADE_CONFIG_DIR）~/.ferret の代わりに settings.json、state.json、settings.schema.json を置くフォルダ
apiKeyEnv に書いた名前settings.json から指す API キー。プロジェクトの .env と ~/.ferret/.env からも読みます
ADE_PROJECT_DIR起動時にこのフォルダをプロジェクトとして開きます（登録もします）
ADE_INITIAL_URL起動時にこの URL を内蔵ブラウザで開きます
ADE_WHISPER_MODEL端末内の文字起こしに使う GGML モデルの絶対パス。ダウンロードした既定のモデルより優先します
ADE_TERMINAL_PREWARM0 にすると、Ferret がシェルを1つ裏で用意しておくのをやめます。既定では次に開く素のシェルのタブがそれを使うので、プロンプトがすぐに出ます
FERRET_SENTRY_DSN（または以前の MOVIE_ADE_SENTRY_DSN）クラッシュレポートの送り先。空なら何も送りません（クラッシュレポートを参照）
OPENAI_API_KEY開発時（pnpm dev）だけ .env から読みます。配布用のビルドでは読みません
PATHエージェントのコマンド（claude、codex、gemini…）、gh、git、whisper-cli を探すのに使います。macOS と Linux では Homebrew、linuxbrew、snap の場所も足します
## プロジェクトの中
  • .ferret/reviews/<id>/: レビュー（データとプライバシーを参照）。.ade-movie/reviews/ にある以前のレビューも読みます
  • .git/info/exclude: 最初の録画のときに .ferret/ の1行を足します
