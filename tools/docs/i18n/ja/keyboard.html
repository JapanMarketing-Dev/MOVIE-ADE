キーボードショートカット ショートカットは、いま読んでいる OS のものを表示します。もう一方は下の切り替えで見られます。たいていは、Windows と Linux の Ctrl が macOS では Command に、Alt が Option になるだけです。それ以上に違うものもいくつかあり、表には両方を載せています。出典: src/main/menu.ts、src/shared/browserNav.ts、src/shared/annotation.ts、ターミナルのキー処理。 ## 録画
操作macOSWindows / Linux
録画を開始 / 停止{{keys-mac:Mod+Shift+R}}{{keys-win:Mod+Shift+R}}
モードを切り替える（エディタ / フィードバック）{{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}
押している間だけペン{{keys-mac:Alt}}{{keys-win:Alt}}
## 録画中に描く
操作macOSWindows / Linux
ペン{{keys-mac:P}}{{keys-win:P}}
四角の枠{{keys-mac:B / R}}{{keys-win:B / R}}
ページを操作する（描くのをやめる）{{keys-mac:V / Esc}}{{keys-win:V / Esc}}
次の色{{keys-mac:C}}{{keys-win:C}}
最後の書き込みを取り消す{{keys-mac:Mod+Z}}{{keys-win:Mod+Z}}
やり直す{{keys-mac:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}{{keys-win:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}

これらのキーは、内蔵ブラウザを録画していて、ページにフォーカスがあるときに効きます。ページの入力欄で文字を打っている間は無視されます。また、文字のキーは修飾キーなしのときだけ効くので、ページ自身のショートカットはそのまま使えます。
