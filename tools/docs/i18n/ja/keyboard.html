キーボードショートカット ショートカットは、いま読んでいる OS のものを表示します。もう一方は下の切り替えで見られます。たいていは、Windows と Linux の Ctrl が macOS では Command に、Alt が Option になるだけです。それ以上に違うものもいくつかあり、表には両方を載せています。出典: src/main/menu.ts、src/shared/browserNav.ts、src/shared/annotation.ts、ターミナルのキー処理。 ## 録画
操作macOSWindows / Linux
録画を開始 / 停止{{keys-mac:Mod+Shift+R}}{{keys-win:Mod+Shift+R}}
モードを切り替える（エディタ / フィードバック）{{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}
押している間だけペン{{keys-mac:Alt}}{{keys-win:Alt}}
## 録画中に描く
操作macOSWindows / Linux
ペン{{keys-mac:P}}{{keys-win:P}}
四角の枠{{keys-mac:B / R}}{{keys-win:B / R}}
ページを操作する（描くのをやめる）{{keys-mac:V / Esc}}{{keys-win:V / Esc}}
次の色{{keys-mac:C}}{{keys-win:C}}
最後の書き込みを取り消す{{keys-mac:Mod+Z}}{{keys-win:Mod+Z}}
やり直す{{keys-mac:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}{{keys-win:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}

これらのキーは、内蔵ブラウザを録画していて、ページにフォーカスがあるときに効きます。ページの入力欄で文字を打っている間は無視されます。また、文字のキーは修飾キーなしのときだけ効くので、ページ自身のショートカットはそのまま使えます。

## ターミナル
操作macOSWindows / Linux
新しいタブ{{keys-mac:Mod+T}}{{keys-win:Mod+T}}
閉じる（ペイン／タブ）{{keys-mac:Mod+W}}{{keys-win:Mod+W}}
右に分割{{keys-mac:Mod+D|Ctrl+Shift+D}}{{keys-win:Mod+D|Ctrl+Shift+D}}
下に分割{{keys-mac:Mod+Shift+D|Alt+Shift+D}}{{keys-win:Mod+Shift+D|Alt+Shift+D}}
選択範囲をコピー{{keys-mac:Mod+C|Ctrl+Shift+C / Ctrl+C}}{{keys-win:Mod+C|Ctrl+Shift+C / Ctrl+C}}
ペースト{{keys-mac:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}{{keys-win:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}
エージェントへの入力で改行{{keys-mac:Shift+Enter}}{{keys-win:Shift+Enter}}
行頭 / 行末へ{{keys-mac:Mod+Left / Mod+Right|}}{{keys-win:Mod+Left / Mod+Right|}}
行頭まで削除{{keys-mac:Mod+Backspace|}}{{keys-win:Mod+Backspace|}}

どれもターミナルにフォーカスがあるときに効きます。Windows と Linux では、文字を選んでいるときの Ctrl+C はコピーになり、何も選んでいないときは実行中のコマンドを止めます。{{keys:Shift+Enter}} は、Claude Code や Codex などのエージェントが動いている間は改行になり、ふつうのシェルでは Enter と同じくコマンドを実行します。マウスを使う全画面のプログラム（vim、tmux、エージェント）の中で文字を選ぶには、macOS では Option を押しながらドラッグします。
