कीबोर्ड शॉर्टकट शॉर्टकट उसी OS के लिए दिखाए जाते हैं जिस पर आप यह पढ़ रहे हैं; दूसरे OS के शॉर्टकट देखने के लिए नीचे का स्विच इस्तेमाल करें। ज़्यादातर शॉर्टकट में जहाँ Windows और Linux पर Ctrl होता है, वहाँ macOS पर Command होता है, और जहाँ Alt होता है वहाँ Option। कुछ शॉर्टकट इससे ज़्यादा अलग हैं, और तालिकाओं में दोनों दिए गए हैं। स्रोत: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts, और टर्मिनल की key handling। ## रिकॉर्डिंग

ये शॉर्टकट तब काम करते हैं जब किसी टर्मिनल पर focus हो। Windows और Linux पर Ctrl+C, टेक्स्ट चुना हो तो कॉपी करता है, और कुछ भी चुना न हो तो चल रही command को रोक देता है। {{keys:Shift+Enter}} तब नई लाइन शुरू करता है जब Claude Code या Codex जैसा कोई agent चल रहा हो; सामान्य shell में यह Enter की तरह command चला देता है। माउस इस्तेमाल करने वाले full-screen program (vim, tmux, कोई agent) में macOS पर टेक्स्ट चुनने के लिए drag करते समय Option दबाए रखें।
