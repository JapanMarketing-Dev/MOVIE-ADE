अकाउंट और usage कई Claude Code या Codex logins के बीच बदलें, और फ़ुटर में अपनी rate-limit windows पर नज़र रखें। फ़िलहाल ये दोनों फ़ीचर सिर्फ़ Claude Code और Codex के साथ काम करते हैं; दूसरे agents हमेशा की तरह अपना ही login इस्तेमाल करते रहते हैं। ## कई अकाउंट

अकाउंट वैकल्पिक हैं। इन्हें सिर्फ़ तभी जोड़ें जब आप कई अकाउंट के बीच बदलते हों।

  1. Settings → अकाउंट खोलें, या फ़ुटर के usage मेन्यू से अकाउंट प्रबंधित करें…।
  2. अकाउंट जोड़ें बिल्ट-इन टर्मिनल टैब में agent का login शुरू करता है।
  3. इस्तेमाल करने वाला अकाउंट चुनें। चल रहे टैब अपना अकाउंट रखते हैं। नए टैब चुना गया अकाउंट इस्तेमाल करते हैं।

यह कैसे काम करता है: जोड़े गए हर अकाउंट को अपनी config directory मिलती है, <userData>/accounts/<agent>/<id>/। Ferret agent को CLAUDE_CONFIG_DIR (Claude Code) या CODEX_HOME (Codex) के साथ उसी directory की ओर इशारा करते हुए launch करता है। सिस्टम डिफ़ॉल्ट आपकी सामान्य ~/.claude / ~/.codex को बिना बदले इस्तेमाल करता है।

अकाउंट हटाने से उसकी config directory डिलीट हो जाती है। इससे server पर आप sign out नहीं होते।

## फ़ुटर में usage

फ़ुटर दिखाता है कि हर rate-limit window का कितना हिस्सा इस्तेमाल हो चुका है: 5 घंटे की window और साप्ताहिक window, साथ में Claude के लिए हर मॉडल की साप्ताहिक window। 60% पर रंग पीला और 80% पर लाल हो जाता है। मान हर 15 मिनट में, या usage रिफ़्रेश करें पर रिफ़्रेश होते हैं।

कितना दिखता है, यह फ़ुटर में उपलब्ध जगह पर निर्भर करता है। जगह हो तो यह bars, window के नाम और प्रतिशत दिखाता है। फ़ुटर जितना संकरा होता है, यह कम काम के हिस्से पहले हटाता जाता है, यहाँ तक कि हर agent के लिए सिर्फ़ एक प्रतिशत बचता है। सब कुछ एक popover में देखने के लिए usage पर क्लिक करें।

Usage सीधे Anthropic (api.anthropic.com/api/oauth/usage) और ChatGPT (chatgpt.com/backend-api/wham/usage) से, साइन इन किए गए अकाउंट के अपने credentials के साथ लाया जाता है।
