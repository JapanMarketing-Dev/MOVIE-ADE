इंस्टॉल करें Ferret macOS, Windows और Linux के लिए एक डेस्कटॉप ऐप है। macOS build पर Developer ID से हस्ताक्षर है और Apple ने उसे notarize किया है। Windows और Linux builds पर अभी code signing नहीं है, इसलिए ये OS पहली बार चलाने से पहले आपसे पुष्टि माँगते हैं। ## डाउनलोड

डाउनलोड पेज से अपने OS और CPU के लिए फ़ाइल लें। फ़ाइलें GitHub Releases से नहीं, बल्कि Cloudflare R2 से दी जाती हैं, और सिर्फ़ 10 सबसे नए versions रखे जाते हैं।

OSफ़ाइलें
macOS (Apple silicon / Intel)Ferret-<version>-mac-arm64.dmg, Ferret-<version>-mac-x64.dmg
Windows (x64 / arm64)Ferret-<version>-win-x64.exe, Ferret-<version>-win-arm64.exe (NSIS installer)
Linux (x64)Ferret-<version>-linux-x86_64.AppImage, Ferret-<version>-linux-amd64.deb

0.1.x तक के releases पुराने नाम से, MOVIE-ADE-<version>-… के रूप में प्रकाशित हुए थे। Ferret-… नाम 0.2.0 से शुरू होते हैं।

Ferret macOS, Windows और Linux को सपोर्ट करता है। Windows और Linux builds पर अभी code signing नहीं है, इसलिए पहली बार चलाने पर पुष्टि माँगी जाती है (नीचे दिए कदम देखें)।

## डाउनलोड की जाँच करें (हस्ताक्षरित SHA256SUMS)

हर release में एक SHA256SUMS फ़ाइल और उसका हस्ताक्षर SHA256SUMS.sig होता है। हस्ताक्षर Ferret की release key से बनाया जाता है, जो डाउनलोड server से अलग रखी जाती है, इसलिए डाउनलोड server पर बदला गया installer किसी मान्य हस्ताक्षर के साथ नहीं आ सकता। Public key डाउनलोड server से नहीं ली जाती: इसे repository (build/release-signing/allowed_signers) से लें या यहाँ से कॉपी करें:

release@ferretade.dev ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIEpXERU8ST0MEOIMbzoL4zShkjIrMB4++NL3xBohKAS9

इसका fingerprint SHA256:c7dvwwJQyY9qSstkmrO8JoVZ90DCaFZBAzjqV04N8zQ है। यही फ़ाइलें GitHub पर हर release के साथ भी जुड़ी होती हैं। ssh-keygen (macOS, Windows 10 और बाद के versions, और Linux में शामिल) से हस्ताक्षर जाँचें, फिर अपने डाउनलोड के hash की तुलना हस्ताक्षरित सूची से करें:

# the download server (currently the R2 public URL; it may move to a custom domain)
BASE=https://pub-588d93b3e875464f98d6cf98dc711a0c.r2.dev
VERSION=$(curl -s $BASE/latest.json | jq -r .version)
curl -sO $BASE/releases/$VERSION/SHA256SUMS
curl -sO $BASE/releases/$VERSION/SHA256SUMS.sig

# save the public key above as allowed_signers, then:
ssh-keygen -Y verify -f allowed_signers -I release@ferretade.dev -n ferret-release -s SHA256SUMS.sig < SHA256SUMS
# → Good "ferret-release" signature for release@ferretade.dev …

# macOS
shasum -a 256 -c SHA256SUMS --ignore-missing
# Linux
sha256sum -c SHA256SUMS --ignore-missing
# Windows (PowerShell): compare with the line for your file in SHA256SUMS
Get-FileHash .\Ferret-<version>-win-x64.exe -Algorithm SHA256

अगर ssh-keygen Good "ferret-release" signature न दिखाए या hash सूची में न हो, तो आगे न बढ़ें। Ferret का अपडेट जाँचें ऐप में बनी key से यही जाँच करता है और ऐसा कोई version नहीं सुझाता जिसका हस्ताक्षर मेल न खाए। macOS पर आप spctl -a -vv /Applications/Ferret.app से Developer ID हस्ताक्षर और notarization भी जाँच सकते हैं। Windows और Linux installers पर अभी Microsoft या किसी Linux distribution का code signing नहीं है। 0.3.0 तक के releases हस्ताक्षर शुरू होने से पहले प्रकाशित हुए थे, और उनमें सिर्फ़ releases/<version>/manifest.json में बिना हस्ताक्षर वाले hashes हैं।

## macOS
  1. .dmg खोलें और Ferret.app को /Applications में drag करें।
  2. इसे चलाएँ। ऐप पर Developer ID से हस्ताक्षर है और Apple ने इसे notarize किया है (ticket stapled है), इसलिए यह बिना किसी चेतावनी के खुलता है।

हस्ताक्षर खुद जाँचने के लिए:

spctl -a -vv /Applications/Ferret.app
# accepted
# source=Notarized Developer ID

सिर्फ़ पुराने versions (0.2.0 build 2 और उससे पहले) पर हस्ताक्षर नहीं था। उनके लिए macOS कहता है कि developer की पुष्टि नहीं की जा सकती: dialog बंद करें, System Settings → Privacy & Security खोलें, Ferret वाले संदेश के बगल में Open Anyway पर क्लिक करें, और Open से पुष्टि करें। अगर यह कहे कि ऐप "is damaged", तो quarantine attribute हटा दें:

xattr -dr com.apple.quarantine /Applications/Ferret.app
## Windows
  1. Ferret-<version>-win-<arch>.exe चलाएँ।
  2. जब SmartScreen "Windows protected your PC" दिखाए, तो More info पर क्लिक करें, फिर Run anyway पर।
  3. इंस्टॉल फ़ोल्डर चुनें। Installer एक डेस्कटॉप shortcut बनाता है।
## Linux

AppImage:

chmod +x Ferret-<version>-linux-x86_64.AppImage
./Ferret-<version>-linux-x86_64.AppImage

Debian / Ubuntu:

sudo apt install ./Ferret-<version>-linux-amd64.deb

deb पैकेज ferret package और command इंस्टॉल करता है।

Ubuntu 23.10 और बाद के versions पर AppImage launch के समय sandbox error के साथ रुक सकता है, क्योंकि AppArmor उन user namespaces को सीमित करता है जिनका इस्तेमाल Electron का sandbox करता है। इसके बजाय .deb इंस्टॉल करें; यह sandbox helper सेट कर देता है।

## Source से build करें

इसके लिए Node.js 20+ (CI और local development में 22 इस्तेमाल होता है), pnpm और git चाहिए।

git clone https://github.com/JapanMarketing-Dev/ferret.git
cd ferret
pnpm install          # postinstall prepares node-pty for Electron
pnpm dev              # run in development mode

Installers पैकेज करने के लिए (output dist/release/ में, config electron-builder.config.cjs में)। Linux build सिर्फ़ Linux पर चलता है।

pnpm dist:mac     # dmg (arm64, x64)
pnpm dist:win     # NSIS installers (x64, arm64)
pnpm dist:linux   # AppImage + deb (x64)

build:<os>:dev scripts सिर्फ़ एक unpacked ऐप (--dir) बनाते हैं, जो local testing के लिए ज़्यादा तेज़ है।

Windows पर pnpm install दोबारा build करने के बजाय node-pty के साथ आने वाली prebuilt binaries इस्तेमाल करता है (दोबारा build करने के लिए Visual Studio C++ build tools चाहिए होते)। ज़बरदस्ती rebuild करने के लिए ADE_FORCE_NATIVE_REBUILD=1 सेट करें।

अगर टर्मिनल बताए कि node-pty load नहीं हो सका, तो pnpm rebuild:native चलाएँ।

## अपडेट

Ferret अपने-आप अपडेट नहीं होता। फ़ुटर में अपडेट खोलें और अपडेट जाँचें पर क्लिक करें। यह डाउनलोड server (R2) से latest.json लाता है, versions की तुलना करता है, और डाउनलोड पेज का लिंक देता है। 0.4.0 से यह उस version की SHA256SUMS का हस्ताक्षर भी ऐप में बनी release key से जाँचता है, और ऐसा कोई version नहीं सुझाता जिसका हस्ताक्षर सत्यापित न हो सके। जब तक आप क्लिक नहीं करते, कुछ भी जाँचा नहीं जाता, और कुछ भी अपने-आप इंस्टॉल नहीं होता।
