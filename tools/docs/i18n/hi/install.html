इंस्टॉल करें अपने कंप्यूटर के लिए Ferret डाउनलोड करें और खोलें। यह macOS, Windows और Linux पर चलता है। ## डाउनलोड

डाउनलोड पेज आपके कंप्यूटर के लिए सही फ़ाइल देता है। डाउनलोड बटन पर क्लिक करें।

## macOS

.dmg खोलें, Ferret को Applications में drag करें, और वहीं से उसे खोलें।

## Windows

डाउनलोड की गई .exe चलाएँ। Ferret इंस्टॉल होकर खुल जाता है, कुछ भी चुनना नहीं पड़ता। अगली बार इसे Start menu या डेस्कटॉप shortcut से खोलें।

अगर Windows Windows protected your PC दिखाए, तो More info पर क्लिक करें, फिर Run anyway पर।

## Linux

Ubuntu / Debian: .deb पर double-click करके उसे अपने software center से इंस्टॉल करें, या यह चलाएँ:

sudo apt install ./Ferret-<version>-linux-amd64.deb

फिर Ferret को अपने ऐप मेन्यू से खोलें, या ferret चलाएँ।

दूसरे distributions: .AppImage इस्तेमाल करें। उसे program के रूप में चलने की अनुमति दें (right-click → Properties, या chmod +x), फिर उसे खोलें।
