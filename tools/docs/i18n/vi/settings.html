## Tài khoản, GitHub, giao diện, ngôn ngữ
  • Tài khoản: xem Tài khoản và mức sử dụng.
  • GitHub / GitLab: đăng nhập gh và glab. Xem Gửi lên GitHub hoặc GitLab.
  • Công cụ CLI: cài đặt và đăng nhập CLI của các dịch vụ. Xem Công cụ CLI.
  • Giao diện → Chủ đề: Hệ thống (mặc định), Sáng, Tối.
  • Ngôn ngữ → Giao diện: Hệ thống (mặc định; theo ngôn ngữ của hệ điều hành nếu Ferret có ngôn ngữ đó, nếu không thì dùng tiếng Anh) hoặc một trong 14 ngôn ngữ: English, 日本語, 简体中文, 繁體中文, 한국어, Español, Français, Deutsch, Italiano, Português (Brasil), Русский, हिन्दी, Bahasa Indonesia, Tiếng Việt.

Từ footer: vị trí terminal (bên phải / bên dưới) và nút bật/tắt microphone.

## settings.json

Mọi cài đặt ở trên được lưu trong ~/.ferret/settings.json (cùng đường dẫn trên mọi hệ điều hành), kèm một JSON Schema bên cạnh. Bạn có thể sửa tệp này khi ứng dụng đang chạy, bằng tay hoặc nhờ coding agent; thay đổi được áp dụng ngay. Xem Cấu hình bằng settings.json.
