Bắt đầu nhanh Cài Ferret, mở dự án và URL dev server của nó, ghi một lần góp ý rồi giao cho coding agent của bạn. Mất khoảng năm phút. ## Trước khi bắt đầu {{clip:quick-start|Mở một trang, ghi, khoanh vùng và nói, dừng, rồi gửi các góp ý cho agent.}}
  • Một coding agent chạy trong terminal, đã cài đặt và đăng nhập: ví dụ Claude Code (claude), Codex (codex) hoặc Gemini CLI (gemini). Ferret chạy nó trong terminal tích hợp. Bất kỳ agent nào trong danh sách được hỗ trợ đều dùng được, kể cả CLI khác do bạn tự thêm.
  • Một ứng dụng web mở được bằng URL, ví dụ dev server tại http://localhost:3000.
  • Một microphone. Góp ý gồm giọng nói của bạn cùng với bút. Không có mic thì các vòng khoanh bằng bút vẫn thành góp ý, nhưng không có lời nói kèm theo.
## 1. Cài đặt

Tải Ferret từ trang tải xuống rồi mở nó. Các bước cho từng hệ điều hành có ở trang Cài đặt.

## 2. Mở dự án và URL
  1. Chọn Tệp → Mở thư mục dự án… ({{keys:Mod+O}}) và chọn thư mục gốc của repository.
  2. Nhập URL dev server vào thanh URL của trình duyệt ({{keys:Mod+L}}) rồi nhấn Enter.
  3. Tùy chọn: bấm + (Lưu URL hiện tại) để giữ nó làm preset mở bằng một cú bấm, như local, dev hoặc prd.

Khi mở dự án, các agent của bạn cũng được khởi động trong các tab terminal tại thư mục đó. Mặc định là Claude Code và Codex; chọn những agent bạn dùng trong Cài đặt → Agent → Khởi chạy khi mở dự án (xem Cài đặt).

## 3. Ghi
  1. Bấm Ghi trên thanh tiêu đề, hoặc nhấn {{keys:Mod+Shift+R}}. Cửa sổ chuyển sang chế độ Feedback.
  2. Dùng trang như bình thường và nói điều cần thay đổi.
  3. Giữ {{keys:Alt}} (hoặc chọn Bút) rồi kéo để khoanh vùng chỗ bạn đang nói đến.
  4. Bấm Dừng hoặc nhấn lại {{keys:Mod+Shift+R}}.

Mỗi lúc bạn nói hoặc khoanh vùng sẽ thành một góp ý: ảnh chụp màn hình có nét bút, yêu cầu, lời nói gốc, URL và phần tử bạn đã chỉ vào.

## 4. Kiểm tra các góp ý

Sau khi dừng, cửa sổ trở về chế độ Editor và mở tab Góp ý.

  • Sửa tiêu đề hoặc yêu cầu ngay tại chỗ.
  • Chuyển Gửi / Không gửi cho từng góp ý, hoặc Xóa.
  • Hoàn tác hủy lần sửa gần nhất.
## 5. Gửi cho agent
  1. Bấm Gửi cho Agent. Nội dung được gửi tới agent trong tab terminal hiện tại, hoặc tới một agent đang chạy. Mũi tên cạnh nút cho phép chọn một agent hoặc tab cụ thể.
  2. Nếu chưa có agent nào chạy, Ferret khởi động một agent trước rồi gửi ngay khi nó sẵn sàng.

Ferret nhập một chỉ dẫn vào ô nhập của agent và gửi đi. Mặc định, chỉ dẫn bắt đầu như sau:

Đọc "{{path}}" và hình ảnh của từng góp ý trong cùng thư mục, rồi triển khai mọi góp ý được đánh dấu để gửi. …

Phần còn lại yêu cầu agent kiểm tra từng thay đổi trên màn hình thực tế, ghi tiến độ cho từng góp ý, và kết thúc bằng danh sách Xong / Chưa xong. Agent đọc .ferret/reviews/<timestamp>/feedback.md và các tệp PNG bên cạnh. Video không bao giờ được gửi. Dùng agent bên ngoài Ferret? Bấm Sao chép cho Agent rồi dán.

Chỉ dẫn mặc định đi theo ngôn ngữ hiển thị. Bạn có thể thay nó trong Cài đặt: xem Tùy chỉnh chỉ dẫn.

## Bước tiếp theo
  • Khái niệm: các chế độ, góp ý và những gì agent nhận được
  • Chuyển văn bản và chi phí: tải model whisper miễn phí chạy trên máy, hoặc dùng endpoint của riêng bạn
