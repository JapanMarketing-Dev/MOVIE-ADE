Cài đặt Ferret là ứng dụng desktop cho macOS, Windows và Linux. Bản macOS được ký bằng Developer ID và được Apple notarize. Bản Windows và Linux chưa được ký mã, nên các hệ điều hành này sẽ yêu cầu bạn xác nhận ở lần khởi động đầu tiên. ## Tải xuống

Lấy tệp cho hệ điều hành và CPU của bạn từ trang Tải xuống. Các tệp được phân phối từ Cloudflare R2, không phải GitHub Releases, và chỉ 10 phiên bản gần nhất được giữ lại.

Hệ điều hànhTệp
macOS (Apple silicon / Intel)Ferret-<version>-mac-arm64.dmg, Ferret-<version>-mac-x64.dmg
Windows (x64 / arm64)Ferret-<version>-win-x64.exe, Ferret-<version>-win-arm64.exe (trình cài đặt NSIS)
Linux (x64)Ferret-<version>-linux-x86_64.AppImage, Ferret-<version>-linux-amd64.deb

Các bản phát hành đến 0.1.x được công bố dưới tên cũ, dạng MOVIE-ADE-<version>-…. Tên Ferret-… bắt đầu từ 0.2.0.

Ferret hỗ trợ macOS, Windows và Linux. Bản Windows và Linux chưa được ký mã, nên lần khởi động đầu tiên sẽ yêu cầu bạn xác nhận (xem các bước bên dưới).

## Xác minh tệp tải về (SHA256SUMS có chữ ký)

Mỗi bản phát hành có tệp SHA256SUMS và chữ ký của nó SHA256SUMS.sig. Chữ ký được tạo bằng khóa phát hành của Ferret, khóa này được giữ tách biệt khỏi server tải xuống, nên một trình cài đặt bị thay đổi trên server tải xuống không thể đi kèm chữ ký hợp lệ. Khóa công khai không được lấy từ server tải xuống: hãy lấy nó từ repository (build/release-signing/allowed_signers) hoặc sao chép từ đây:

release@ferretade.dev ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIEpXERU8ST0MEOIMbzoL4zShkjIrMB4++NL3xBohKAS9

Dấu vân tay của nó là SHA256:c7dvwwJQyY9qSstkmrO8JoVZ90DCaFZBAzjqV04N8zQ. Các tệp tương tự cũng được đính kèm vào mỗi bản phát hành trên GitHub. Kiểm tra chữ ký bằng ssh-keygen (có sẵn trong macOS, Windows 10 trở lên và Linux), rồi so sánh hash của tệp bạn tải về với danh sách đã ký:

# the download server (currently the R2 public URL; it may move to a custom domain)
BASE=https://pub-588d93b3e875464f98d6cf98dc711a0c.r2.dev
VERSION=$(curl -s $BASE/latest.json | jq -r .version)
curl -sO $BASE/releases/$VERSION/SHA256SUMS
curl -sO $BASE/releases/$VERSION/SHA256SUMS.sig

# save the public key above as allowed_signers, then:
ssh-keygen -Y verify -f allowed_signers -I release@ferretade.dev -n ferret-release -s SHA256SUMS.sig < SHA256SUMS
# → Good "ferret-release" signature for release@ferretade.dev …

# macOS
shasum -a 256 -c SHA256SUMS --ignore-missing
# Linux
sha256sum -c SHA256SUMS --ignore-missing
# Windows (PowerShell): compare with the line for your file in SHA256SUMS
Get-FileHash .\Ferret-<version>-win-x64.exe -Algorithm SHA256

Hãy dừng lại nếu ssh-keygen không in ra Good "ferret-release" signature hoặc hash không có trong danh sách. Kiểm tra cập nhật của Ferret cũng kiểm tra như vậy bằng khóa được tích hợp trong ứng dụng, và không đề xuất phiên bản có chữ ký không khớp. Trên macOS, bạn cũng có thể kiểm tra chữ ký Developer ID và notarization bằng spctl -a -vv /Applications/Ferret.app. Trình cài đặt Windows và Linux chưa được Microsoft hay một bản phân phối Linux ký mã. Các bản phát hành đến 0.3.0 được công bố trước khi bắt đầu ký, và chỉ có các hash chưa ký trong releases/<version>/manifest.json.

## macOS
  1. Mở tệp .dmg và kéo Ferret.app vào /Applications.
  2. Khởi động ứng dụng. Ứng dụng được ký bằng Developer ID và được Apple notarize (ticket đã được staple), nên mở mà không có cảnh báo.

Để tự kiểm tra chữ ký:

spctl -a -vv /Applications/Ferret.app
# accepted
# source=Notarized Developer ID

Chỉ với các phiên bản cũ (0.2.0 build 2 trở về trước): các bản này chưa được ký. Với chúng, macOS báo không thể xác minh nhà phát triển: đóng hộp thoại, mở System Settings → Privacy & Security, bấm Open Anyway cạnh thông báo về Ferret, rồi xác nhận bằng Open. Nếu macOS báo ứng dụng "is damaged" (bị hỏng), hãy gỡ thuộc tính quarantine:

xattr -dr com.apple.quarantine /Applications/Ferret.app
## Windows
  1. Chạy Ferret-<version>-win-<arch>.exe.
  2. Khi SmartScreen hiện "Windows protected your PC" (Windows đã bảo vệ PC của bạn), bấm More info (Thêm thông tin), rồi Run anyway (Vẫn chạy).
  3. Chọn thư mục cài đặt. Trình cài đặt tạo một lối tắt trên desktop.
## Linux

AppImage:

chmod +x Ferret-<version>-linux-x86_64.AppImage
./Ferret-<version>-linux-x86_64.AppImage

Debian / Ubuntu:

sudo apt install ./Ferret-<version>-linux-amd64.deb

Gói deb cài đặt package và lệnh ferret.

Trên Ubuntu 23.10 trở lên, AppImage có thể dừng khi khởi động với lỗi sandbox, vì AppArmor hạn chế các user namespace mà sandbox của Electron sử dụng. Hãy cài .deb thay thế; gói này thiết lập sẵn trình trợ giúp sandbox.

## Build từ mã nguồn

Cần Node.js 20 trở lên (CI và môi trường phát triển cục bộ dùng 22), pnpm và git.

git clone https://github.com/JapanMarketing-Dev/ferret.git
cd ferret
pnpm install          # postinstall prepares node-pty for Electron
pnpm dev              # run in development mode

Để đóng gói trình cài đặt (đầu ra trong dist/release/, cấu hình trong electron-builder.config.cjs). Bản build Linux chỉ chạy được trên Linux.

pnpm dist:mac     # dmg (arm64, x64)
pnpm dist:win     # NSIS installers (x64, arm64)
pnpm dist:linux   # AppImage + deb (x64)

Các script build:<os>:dev chỉ tạo ứng dụng chưa đóng gói (--dir), nhanh hơn khi kiểm thử cục bộ.

Trên Windows, pnpm install dùng các binary dựng sẵn đi kèm node-pty thay vì build lại (việc đó sẽ cần Visual Studio C++ build tools). Đặt ADE_FORCE_NATIVE_REBUILD=1 để buộc build lại.

Nếu terminal báo không tải được node-pty, hãy chạy pnpm rebuild:native.

## Cập nhật

Ferret không tự động cập nhật. Ở chân trang, mở Cập nhật và bấm Kiểm tra cập nhật. Ứng dụng lấy latest.json từ server tải xuống (R2), so sánh phiên bản và đưa liên kết tới trang tải xuống. Từ 0.4.0, nó còn kiểm tra chữ ký của SHA256SUMS cho phiên bản đó bằng khóa phát hành tích hợp trong ứng dụng, và không đề xuất phiên bản có chữ ký không xác minh được. Không có gì được kiểm tra cho đến khi bạn bấm, và không có gì được cài đặt tự động.
