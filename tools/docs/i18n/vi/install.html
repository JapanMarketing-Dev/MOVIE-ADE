Cài đặt Tải Ferret cho máy tính của bạn rồi mở nó. Ferret chạy trên macOS, Windows và Linux. ## Tải xuống

Trang tải xuống đưa ra đúng tệp cho máy tính của bạn. Bấm nút tải xuống.

## macOS

Mở tệp .dmg, kéo Ferret vào Applications, rồi mở nó từ đó.

## Windows

Chạy tệp .exe đã tải về. Ferret tự cài đặt và mở ra, bạn không cần chọn gì. Những lần sau, mở Ferret từ menu Start hoặc lối tắt trên desktop.

Nếu Windows hiện Windows protected your PC (Windows đã bảo vệ PC của bạn), bấm More info (Thêm thông tin), rồi Run anyway (Vẫn chạy).

## Linux

Ubuntu / Debian: nhấp đúp vào tệp .deb để cài bằng trình quản lý phần mềm, hoặc chạy:

sudo apt install ./Ferret-<version>-linux-amd64.deb

Sau đó mở Ferret từ menu ứng dụng, hoặc chạy ferret.

Các bản phân phối khác: dùng tệp .AppImage. AppImage chạy bằng FUSE 2, nên nếu hệ thống chưa có thì hãy cài gói của nó trước: fuse-libs trên Fedora, fuse2 trên Arch, libfuse2 trên openSUSE và các hệ thống dựa trên Debian. Sau đó cho phép tệp .AppImage chạy như một chương trình (nhấp chuột phải → Properties, hoặc chmod +x) rồi mở nó.
