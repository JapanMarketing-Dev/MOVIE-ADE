Dateien und Umgebung Wo Ferret seine eigenen Dateien ablegt und welche Umgebungsvariablen es liest oder setzt. ## Ordner userData

Die App-Daten liegen im userData-Ordner von Electron. Sein Name ist fest auf ade-movie gesetzt (nicht auf den Produktnamen), damit die Daten Umbenennungen überstehen. Mit --user-data-dir=<path> können Sie ihn überschreiben.

BetriebssystemPfad
macOS~/Library/Application Support/ade-movie/
Windows%APPDATA%\ade-movie\
Linux~/.config/ade-movie/ (oder $XDG_CONFIG_HOME/ade-movie/)
 
settings.json       # settings before 0.1.1, kept as a backup (now ~/.ferret/settings.json)
stt-keys.bin        # API keys, encrypted with safeStorage
browser-import/     # imported passwords (passwords.bin, encrypted with safeStorage) and history (history.json)
feedback-share/     # share links you made (shares.bin; owner tokens encrypted with safeStorage)
login-shell-path.json  # your login shell's PATH from the last launch, so agent tabs start without waiting
models/             # downloaded whisper models (ggml-*.bin)
accounts/claude/<id>/   # CLAUDE_CONFIG_DIR for added accounts
accounts/codex/<id>/    # CODEX_HOME for added accounts

Ihre Einstellungen liegen nicht in diesem Ordner, sondern in ~/.ferret/ (siehe Mit settings.json konfigurieren).

Ein selbst ausgewähltes Modell kann an beliebiger Stelle liegen. Der frühere Standardort ~/.cache/ade-movie/models/ggml-small.bin wird weiterhin geprüft.

## Umgebungsvariablen
VariableWirkung
CLAUDE_CONFIG_DIR, CODEX_HOMEVon Ferret für Agent-Tabs gesetzt, wenn ein hinzugefügtes Konto ausgewählt ist
GH_TOKEN, GITHUB_TOKENVon gh vor der eigenen Anmeldung verwendet. Ferret warnt, wenn eine davon gesetzt ist
FERRET_CONFIG_DIR (oder das alte MOVIE_ADE_CONFIG_DIR)Ordner für settings.json, state.json und settings.schema.json anstelle von ~/.ferret
Namen in apiKeyEnvAPI-Schlüssel, auf die Sie in settings.json verweisen. Werden auch aus der .env des Projekts und aus ~/.ferret/.env gelesen
ADE_PROJECT_DIRDiesen Ordner beim Start als Projekt öffnen (und registrieren)
ADE_INITIAL_URLDiese URL beim Start im integrierten Browser laden
ADE_WHISPER_MODELAbsoluter Pfad eines GGML-Modells für die Transkription auf dem Gerät; hat Vorrang vor dem heruntergeladenen Standardmodell
ADE_TERMINAL_PREWARM0 verhindert, dass Ferret im Hintergrund eine Shell bereithält. Standardmäßig nutzt der nächste einfache Shell-Tab sie, sodass seine Eingabeaufforderung sofort erscheint
FERRET_SENTRY_DSN (oder das alte MOVIE_ADE_SENTRY_DSN)Ziel der Absturzberichte. Leer bedeutet, dass keine gesendet werden (siehe Absturzberichte)
OPENAI_API_KEYWird nur in der Entwicklung (pnpm dev) aus .env gelesen, nie in paketierten Builds
PATHDient zum Finden der Befehle Ihrer Agents (claude, codex, gemini…), von gh, git und whisper-cli. Unter macOS und Linux werden die Orte von Homebrew, linuxbrew und snap ergänzt
