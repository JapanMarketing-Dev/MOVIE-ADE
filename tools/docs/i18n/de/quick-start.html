Schnellstart Installieren Sie Ferret, öffnen Sie Ihr Projekt und die URL seines Dev-Servers, nehmen Sie ein Feedback auf und übergeben Sie es Ihrem Coding-Agent. Das dauert etwa fünf Minuten. ## Bevor Sie beginnen {{clip:quick-start|Seite öffnen, aufnehmen, einkreisen und sprechen, stoppen und die Befunde an einen Agent senden.}}
  • Ein Coding-Agent, der im Terminal läuft, installiert und angemeldet ist: zum Beispiel Claude Code (claude), Codex (codex) oder Gemini CLI (gemini). Ferret führt ihn in seinem integrierten Terminal aus. Jeder Agent aus der Liste der unterstützten Agents funktioniert, ebenso jede andere CLI, die Sie selbst hinzufügen.
  • Eine Web-App, die Sie per URL öffnen können, z. B. ein Dev-Server unter http://localhost:3000.
  • Ein Mikrofon. Feedback besteht aus Ihrer Stimme und dem Stift. Ohne Mikrofon werden Stiftmarkierungen trotzdem zu Befunden, haben dann aber keinen Text.
## 1. Installieren

Laden Sie Ferret von der Download-Seite herunter und öffnen Sie es. Die Schritte für jedes Betriebssystem stehen unter Installation.

## 2. Projekt und URL öffnen
  1. Wählen Sie Ablage → Projektordner öffnen … ({{keys:Mod+O}}) und dann das Stammverzeichnis Ihres Repositorys.
  2. Geben Sie die URL Ihres Dev-Servers in die URL-Leiste des Browsers ein ({{keys:Mod+L}}) und drücken Sie Enter.
  3. Optional: Klicken Sie auf + (Aktuelle URL speichern), um sie als Voreinstellung für einen Klick zu behalten, etwa local, dev oder prd.

Beim Öffnen eines Projekts starten außerdem Ihre Agents in Terminal-Tabs in diesem Ordner. Standardmäßig sind das Claude Code und Codex; wählen Sie die gewünschten unter Einstellungen → Agents → Beim Öffnen eines Projekts starten aus (siehe Einstellungen).

## 3. Aufnehmen
  1. Klicken Sie in der Titelleiste auf Aufnehmen oder drücken Sie {{keys:Mod+Shift+R}}. Das Fenster wechselt in den Feedback-Modus.
  2. Bedienen Sie die Seite wie gewohnt und sagen Sie, was sich ändern soll.
  3. Halten Sie {{keys:Alt}} gedrückt (oder wählen Sie Stift) und ziehen Sie, um die Stelle einzukreisen, über die Sie gerade sprechen.
  4. Klicken Sie auf Stopp oder drücken Sie erneut {{keys:Mod+Shift+R}}.

Jeder Moment, in dem Sie sprechen oder einkreisen, wird zu einem Befund: ein Screenshot mit Ihren Stiftmarkierungen, die Anfrage, Ihre ursprünglichen Worte, die URL und das Element, auf das Sie gezeigt haben.

## 4. Befunde prüfen

Nach dem Stoppen kehrt das Fenster in den Editor-Modus zurück und öffnet den Tab Befunde.

  • Bearbeiten Sie Titel oder Anfrage direkt an Ort und Stelle.
  • Schalten Sie pro Befund zwischen Senden / Nicht senden um oder nutzen Sie Löschen.
  • Widerrufen macht die letzte Bearbeitung rückgängig.
## 5. An einen Agent senden
  1. Klicken Sie auf An Agent senden. Die Befunde gehen an den Agent im aktuellen Terminal-Tab oder an einen laufenden Agent. Mit dem Pfeil neben der Schaltfläche wählen Sie einen bestimmten Agent oder Tab.
  2. Läuft noch kein Agent, startet Ferret zuerst einen und sendet, sobald er bereit ist.

Ferret tippt eine Anweisung in die Eingabe des Agents und schickt sie ab. Standardmäßig beginnt sie so:

Lies "{{path}}" und das Bild zu jedem Befund im selben Ordner und setze dann jeden zum Senden markierten Befund um. …

Im Rest wird der Agent gebeten, jede Änderung auf dem tatsächlichen Bildschirm zu prüfen, seinen Fortschritt pro Befund festzuhalten und mit einer Liste „Erledigt“ / „Nicht erledigt“ abzuschließen. Der Agent liest .ferret/reviews/<timestamp>/feedback.md und die PNGs daneben. Das Video wird nie gesendet. Sie verwenden einen Agent außerhalb von Ferret? Klicken Sie auf Für Agent kopieren und fügen Sie den Text ein.

Die Standardanweisung folgt der Anzeigesprache. Sie können sie in den Einstellungen ersetzen: siehe Anweisung anpassen.
