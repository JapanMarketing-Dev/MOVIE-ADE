Installation Laden Sie Ferret für Ihren Computer herunter und öffnen Sie es. Es läuft unter macOS, Windows und Linux. ## Download

Die Download-Seite bietet die passende Datei für Ihren Computer an. Klicken Sie auf die Download-Schaltfläche.

## macOS

Öffnen Sie die .dmg, ziehen Sie Ferret nach Applications und öffnen Sie es von dort.

## Windows

Führen Sie die heruntergeladene .exe aus. Ferret wird installiert und geöffnet, ohne dass Sie etwas auswählen müssen. Beim nächsten Mal öffnen Sie es über das Startmenü oder die Verknüpfung auf dem Desktop.

Wenn Windows Der Computer wurde durch Windows geschützt anzeigt, klicken Sie auf Weitere Informationen und dann auf Trotzdem ausführen.

## Linux

Ubuntu / Debian: Doppelklicken Sie auf das .deb, um es mit Ihrer Softwareverwaltung zu installieren, oder führen Sie aus:

sudo apt install ./Ferret-<version>-linux-amd64.deb

Öffnen Sie Ferret dann über Ihr Anwendungsmenü oder führen Sie ferret aus.

Andere Distributionen: Verwenden Sie das .AppImage. AppImages laufen mit FUSE 2. Installieren Sie daher zuerst dessen Paket, falls es auf Ihrem System fehlt: fuse-libs unter Fedora, fuse2 unter Arch, libfuse2 unter openSUSE und Debian-basierten Systemen. Erlauben Sie dann, das .AppImage als Programm auszuführen (Rechtsklick → Eigenschaften oder chmod +x), und öffnen Sie es.
