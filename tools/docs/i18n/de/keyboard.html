Tastenkürzel Die Tastenkürzel werden für das Betriebssystem angezeigt, auf dem Sie lesen; mit dem Umschalter unten sehen Sie das jeweils andere. Die meisten verwenden unter macOS Command, wo Windows und Linux Strg (Ctrl) verwenden, und Option, wo dort Alt steht. Einige unterscheiden sich stärker; die Tabellen führen dann beide auf. Quelle: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts, und die Tastenverarbeitung des Terminals. ## Aufnahme
AktionmacOSWindows / Linux
Aufnahme starten/stoppen{{keys-mac:Mod+Shift+R}}{{keys-win:Mod+Shift+R}}
Modus wechseln (Editor / Feedback){{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}
Stift, solange gedrückt{{keys-mac:Alt}}{{keys-win:Alt}}
## Zeichnen während der Aufnahme
AktionmacOSWindows / Linux
Stift{{keys-mac:P}}{{keys-win:P}}
Rahmen{{keys-mac:B / R}}{{keys-win:B / R}}
Seite bedienen (Zeichnen beenden){{keys-mac:V / Esc}}{{keys-win:V / Esc}}
Nächste Farbe{{keys-mac:C}}{{keys-win:C}}
Letzte Markierung widerrufen{{keys-mac:Mod+Z}}{{keys-win:Mod+Z}}
Wiederholen{{keys-mac:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}{{keys-win:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}

Diese Tasten funktionieren, während Sie den integrierten Browser aufnehmen und die Seite den Fokus hat. Während Sie in ein Feld auf der Seite tippen, werden sie ignoriert, und die Buchstabentasten wirken nur ohne Zusatztasten, sodass die eigenen Tastenkürzel der Seite weiter funktionieren.
