Tastenkürzel Die Tastenkürzel werden für das Betriebssystem angezeigt, auf dem Sie lesen; mit dem Umschalter unten sehen Sie das jeweils andere. Die meisten verwenden unter macOS Command, wo Windows und Linux Strg (Ctrl) verwenden, und Option, wo dort Alt steht. Einige unterscheiden sich stärker; die Tabellen führen dann beide auf. Quelle: src/main/menu.ts, src/shared/browserNav.ts, src/shared/annotation.ts, und die Tastenverarbeitung des Terminals. ## Aufnahme

Modus wechseln (Editor / Feedback){{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}
Stift, solange gedrückt{{keys-mac:Alt}}{{keys-win:Alt}}

Diese Tasten funktionieren, während Sie den integrierten Browser aufnehmen und die Seite den Fokus hat. Während Sie in ein Feld auf der Seite tippen, werden sie ignoriert, und die Buchstabentasten wirken nur ohne Zusatztasten, sodass die eigenen Tastenkürzel der Seite weiter funktionieren.

AktionmacOSWindows / Linux
Neues Terminal{{keys-mac:Mod+T}}{{keys-win:Mod+T}}
Bereich/Tab schließen{{keys-mac:Mod+W}}{{keys-win:Mod+W}}

Einsetzen{{keys-mac:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}{{keys-win:Mod+V|Ctrl+V / Ctrl+Shift+V / Shift+Insert}}
Neue Zeile im Prompt eines Agents{{keys-mac:Shift+Enter}}{{keys-win:Shift+Enter}}
Zeilenanfang / Zeilenende{{keys-mac:Mod+Left / Mod+Right|}}{{keys-win:Mod+Left / Mod+Right|}}
Bis zum Zeilenanfang löschen{{keys-mac:Mod+Backspace|}}{{keys-win:Mod+Backspace|}}

Diese Tastenkürzel funktionieren, während ein Terminal den Fokus hat. Unter Windows und Linux kopiert Ctrl+C, wenn Text markiert ist, und stoppt den laufenden Befehl, wenn nichts markiert ist. {{keys:Shift+Enter}} beginnt eine neue Zeile, während ein Agent wie Claude Code oder Codex läuft; in einer normalen Shell führt es den Befehl wie Enter aus. In einem Vollbildprogramm, das die Maus verwendet (vim, tmux, ein Agent), halten Sie unter macOS beim Ziehen die Wahltaste gedrückt, um Text zu markieren.
