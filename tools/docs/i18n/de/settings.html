## settings.json

Alle oben genannten Einstellungen werden in ~/.ferret/settings.json gespeichert (auf jedem Betriebssystem derselbe Pfad), daneben liegt ein JSON Schema. Sie können die Datei bearbeiten, während die App läuft, von Hand oder mit Ihrem Coding-Agent; Änderungen werden sofort übernommen. Siehe Mit settings.json konfigurieren.
