安装 下载适合你电脑的 Ferret 并打开。它可在 macOS、Windows 和 Linux 上运行。 ## 下载

下载页面会提供适合你电脑的文件。点击下载按钮即可。

## macOS

打开 .dmg，将 Ferret 拖到 Applications，然后从那里打开。

## Windows

运行下载的 .exe。Ferret 会自动安装并打开，无需做任何选择。之后可以从开始菜单或桌面快捷方式打开它。

如果 Windows 显示 Windows 已保护你的电脑，请点击 更多信息，然后点击 仍要运行。

## Linux

Ubuntu / Debian：双击 .deb，用软件中心安装；或者运行：

sudo apt install ./Ferret-<version>-linux-amd64.deb

然后从应用菜单打开 Ferret，或运行 ferret。

其他发行版：使用 .AppImage。AppImage 依赖 FUSE 2 运行，如果系统中还没有，请先安装对应的软件包：Fedora 上是 fuse-libs，Arch 上是 fuse2，openSUSE 和基于 Debian 的系统上是 libfuse2。然后允许 .AppImage 作为程序运行（右键 → 属性，或 chmod +x），再打开它。
