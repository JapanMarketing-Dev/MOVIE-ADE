键盘快捷键 快捷键按你当前阅读所用的操作系统显示；可用下方的开关查看另一种。大多数快捷键在 macOS 上用 Command，对应 Windows 和 Linux 上的 Ctrl；用 Option 对应 Alt。少数快捷键差别更大，表中会同时列出两种。来源：src/main/menu.ts、src/shared/browserNav.ts、src/shared/annotation.ts 以及终端的按键处理。 ## 录制
操作macOSWindows / Linux
开始 / 停止录制{{keys-mac:Mod+Shift+R}}{{keys-win:Mod+Shift+R}}
切换模式（编辑器 / 反馈）{{keys-mac:Mod+Shift+M}}{{keys-win:Mod+Shift+M}}
按住时使用画笔{{keys-mac:Alt}}{{keys-win:Alt}}
## 录制时绘制
操作macOSWindows / Linux
画笔{{keys-mac:P}}{{keys-win:P}}
方框{{keys-mac:B / R}}{{keys-win:B / R}}
操作网页（停止绘制）{{keys-mac:V / Esc}}{{keys-win:V / Esc}}
下一个颜色{{keys-mac:C}}{{keys-win:C}}
撤销上一个标记{{keys-mac:Mod+Z}}{{keys-win:Mod+Z}}
重做{{keys-mac:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}{{keys-win:Mod+Shift+Z|Ctrl+Shift+Z / Ctrl+Y}}

这些按键在录制内置浏览器且页面获得焦点时有效。在页面的输入框中打字时它们会被忽略，而且字母键只在不按修饰键时有效，因此页面自身的快捷键仍可正常使用。

## 终端
操作macOSWindows / Linux

删除到行首{{keys-mac:Mod+Backspace|}}{{keys-win:Mod+Backspace|}}

这些快捷键在终端获得焦点时有效。在 Windows 和 Linux 上，选中文本时 Ctrl+C 会拷贝，未选中任何内容时会停止正在运行的命令。当 Claude Code 或 Codex 等 Agent 正在运行时，{{keys:Shift+Enter}} 会换行；在普通 shell 中，它和 Enter 一样会执行命令。在使用鼠标的全屏程序（vim、tmux、Agent）中，在 macOS 上按住 Option 再拖动即可选择文本。
