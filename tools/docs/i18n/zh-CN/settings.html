## settings.json

以上所有设置都保存在 ~/.ferret/settings.json（所有操作系统路径相同），旁边还有一个 JSON Schema。应用运行时也可以编辑它，手动编辑或让你的编码 Agent 编辑都可以；更改会立即生效。参见用 settings.json 配置。
