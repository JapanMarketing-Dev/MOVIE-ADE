快速开始 安装 Ferret，打开项目及其开发服务器 URL，录制一条反馈，再交给你的编码 Agent。大约需要五分钟。 ## 开始之前 {{clip:quick-start|打开页面并录制，一边用画笔圈出位置一边讲解，停止后把反馈发送给 Agent。}}
  • 一个在终端中运行、已安装并登录的编码 Agent，例如 Claude Code（claude）、Codex（codex）或 Gemini CLI（gemini）。Ferret 会在内置终端中运行它。支持列表中的任何 Agent 都可以使用，你自己添加的其他 CLI 也可以。
  • 一个可以通过 URL 打开的 Web 应用，例如运行在 http://localhost:3000 的开发服务器。
  • 一个麦克风。反馈由你的语音和画笔组成。没有麦克风时，用画笔圈出的位置仍会成为反馈，只是不带文字。
## 1. 安装

从下载页面下载 Ferret 并打开。各操作系统的步骤请参阅安装。

## 2. 打开项目和 URL
  1. 选择 文件 → 打开项目文件夹…（{{keys:Mod+O}}），然后选中你的仓库根目录。
  2. 在浏览器的地址栏（{{keys:Mod+L}}）中输入开发服务器的 URL，然后按 Enter。
  3. 可选：点击 +（保存当前 URL），将其保存为可一键打开的预设，例如 local、dev 或 prd。

打开项目时，Ferret 还会在该文件夹的终端标签页中启动你的 Agent。默认是 Claude Code 和 Codex；可以在 设置 → Agent → 打开项目时启动 中选择你要用的 Agent（参阅设置）。

## 3. 录制
  1. 点击标题栏中的 录制，或按 {{keys:Mod+Shift+R}}。窗口会切换到反馈模式。
  2. 像平常一样操作页面，同时说出需要修改的地方。
  3. 按住 {{keys:Alt}}（或选择 画笔）并拖动，圈出你正在讲的位置。
  4. 点击 停止，或再次按 {{keys:Mod+Shift+R}}。

你每次说话或圈画的时刻都会成为一条反馈：包括带有画笔标记的截图、修改请求、你的原话、URL，以及你所指的元素。

## 4. 检查反馈

停止后，窗口会回到编辑器模式，并打开 反馈 标签页。

  • 可以直接修改标题或请求内容。
  • 可以为每条反馈切换 发送 / 不发送，或选择 与下一条合并、删除。
  • 撤销 会撤回上一次编辑。
## 5. 发送给 Agent
  1. 点击 发送给 Agent。反馈会发送给当前终端标签页中的 Agent，或某个正在运行的 Agent。按钮旁的箭头可以指定 Agent 或标签页。
  2. 如果还没有 Agent 在运行，Ferret 会先启动一个，并在它就绪后立即发送。

Ferret 会在 Agent 的输入框中输入一条指令并提交。默认情况下，指令的开头如下：

阅读 "{{path}}" 以及同一文件夹中每条反馈对应的图片，然后实现所有标记为发送的反馈。…

后续内容会要求 Agent 在实际界面上确认每处修改、逐条记录进度，并在最后给出“已完成 / 未完成”列表。Agent 会读取 .ferret/reviews/<timestamp>/feedback.md 及其旁边的 PNG 图片。视频永远不会被发送。如果使用 Ferret 之外的 Agent，请点击 拷贝给 Agent 然后粘贴。

默认指令会跟随界面语言。你可以在设置中替换它：参阅自定义指令。
