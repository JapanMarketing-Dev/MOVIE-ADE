账户与用量 在多个 Claude Code 或 Codex 登录之间切换，并在底部栏查看速率限制窗口的用量。这两项功能目前只支持 Claude Code 和 Codex；其他 Agent 照常使用各自的登录。 ## 多个账户

账户是可选的。只有需要在多个账户之间切换时才需要添加。

  1. 打开 设置 → 账户，或从底部栏的用量菜单中选择 管理账户…。
  2. 添加账户 会在内置终端标签页中启动该 Agent 的登录流程。
  3. 选择要使用的账户。正在运行的标签页保持原来的账户，新标签页使用所选账户。

工作原理：每个添加的账户都有自己的配置目录 <userData>/accounts/<agent>/<id>/。Ferret 启动 Agent 时，会将 CLAUDE_CONFIG_DIR（Claude Code）或 CODEX_HOME（Codex）指向该目录。系统默认 则原样使用你平常的 ~/.claude / ~/.codex。

移除账户会删除其配置目录，但不会在服务器端注销登录。

## 底部栏中的用量

底部栏显示每个速率限制窗口已用的比例：5 小时窗口和每周窗口，Claude 还有按模型计算的每周窗口。达到 60% 时颜色变黄，达到 80% 时变红。数值每 15 分钟刷新一次，也可以点击 刷新用量 立即刷新。

显示多少内容取决于底部栏的空间。空间充足时会显示进度条、窗口名称和百分比。底部栏越窄，越先省略不太重要的部分，最少只显示每个 Agent 一个百分比。点击用量可以在弹出框中查看全部内容。

用量直接从 Anthropic（api.anthropic.com/api/oauth/usage）和 ChatGPT（chatgpt.com/backend-api/wham/usage）获取，使用的是已登录账户自身的凭据。

{{shot:usage|底部栏中的用量}} ## 达到用量上限时继续工作

当 Agent 达到用量上限时，Ferret 会在同一个项目文件夹中继续同一项工作，因此长任务不会因上限而中断。此功能默认开启，可在 设置 → 账户 → 达到用量上限时自动切换 中设置。

工作通过项目中的一个文件 .ferret/handoff.md 交接，因此在账户之间和不同 Agent 之间都同样适用。发送给 Agent 的指示会要求 Agent 在每个阶段以及接近用量上限时更新该文件：目标、已完成的内容、以清单列出的剩余工作、修改过的文件、下一步、相关的 feedback.md 和审查路径，以及需要注意的事项。.ferret/ 不会进入 git（它被添加到 .git/info/exclude，而不是 .gitignore）。

  1. Ferret 会根据终端中 Agent 自己输出的消息（例如 Claude Code 的 5-hour limit reached ∙ resets 3pm、Codex 的 You've hit your usage limit），或底部栏的用量达到阈值（默认 95%；取 5 小时、每周和按模型的额度中最高的一个）来判断已达到上限。
  2. 切换之前，Ferret 会请当前 Agent 更新 .ferret/handoff.md。如果 Agent 没有开始处理（例如它已经达到上限），Ferret 会把自己掌握的信息写入该文件：最后的请求、feedback.md 的位置，以及 git status 中显示的已修改文件。
  3. 然后，Ferret 会切换到同一 Agent 已登录的其他账户中用量最低的那个。当该 Agent 的所有账户都达到上限时，工作会转到 Agent 顺序（默认：Claude Code → Codex → Gemini CLI）中的下一个 Agent。
  4. 新的 Agent 会在同一项目的新标签页中打开，并以应用显示语言收到提示：先阅读 .ferret/handoff.md，再继续剩余的工作。
  5. 底部栏会显示 当前使用 <agent>，并有通知说明发生了什么变化（例如 Codex 已达到用量上限，已切换到 Claude Code。）。达到上限的标签页会被关闭，因此在其上限恢复后不会再次接手同一项任务。
