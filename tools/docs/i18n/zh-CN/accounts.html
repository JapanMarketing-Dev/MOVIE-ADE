账户与用量 在多个 Claude Code 或 Codex 登录之间切换，并在底部栏查看速率限制窗口的用量。这两项功能目前只支持 Claude Code 和 Codex；其他 Agent 照常使用各自的登录。 ## 多个账户

账户是可选的。只有需要在多个账户之间切换时才需要添加。

  1. 打开 设置 → 账户，或从底部栏的用量菜单中选择 管理账户…。
  2. 添加账户 会在内置终端标签页中启动该 Agent 的登录流程。
  3. 选择要使用的账户。正在运行的标签页保持原来的账户，新标签页使用所选账户。

工作原理：每个添加的账户都有自己的配置目录 <userData>/accounts/<agent>/<id>/。Ferret 启动 Agent 时，会将 CLAUDE_CONFIG_DIR（Claude Code）或 CODEX_HOME（Codex）指向该目录。系统默认 则原样使用你平常的 ~/.claude / ~/.codex。

移除账户会删除其配置目录，但不会在服务器端注销登录。

## 底部栏中的用量

底部栏显示每个速率限制窗口已用的比例：5 小时窗口和每周窗口，Claude 还有按模型计算的每周窗口。达到 60% 时颜色变黄，达到 80% 时变红。数值每 15 分钟刷新一次，也可以点击 刷新用量 立即刷新。

显示多少内容取决于底部栏的空间。空间充足时会显示进度条、窗口名称和百分比。底部栏越窄，越先省略不太重要的部分，最少只显示每个 Agent 一个百分比。点击用量可以在弹出框中查看全部内容。

用量直接从 Anthropic（api.anthropic.com/api/oauth/usage）和 ChatGPT（chatgpt.com/backend-api/wham/usage）获取，使用的是已登录账户自身的凭据。
