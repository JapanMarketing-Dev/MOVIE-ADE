文件与环境变量 Ferret 自己的文件存放在哪里，以及它读取或设置的环境变量。 ## userData 文件夹

应用数据存放在 Electron 的 userData 文件夹中。其名称固定为 ade-movie（而不是产品名），因此产品改名后数据仍会保留。可以用 --user-data-dir=<path> 指定其他位置。

操作系统路径
macOS~/Library/Application Support/ade-movie/
Windows%APPDATA%\ade-movie\
Linux~/.config/ade-movie/（或 $XDG_CONFIG_HOME/ade-movie/）
 
settings.json       # settings before 0.1.1, kept as a backup (now ~/.ferret/settings.json)
stt-keys.bin        # API keys, encrypted with safeStorage
models/             # downloaded whisper models (ggml-*.bin)
accounts/claude/<id>/   # CLAUDE_CONFIG_DIR for added accounts
accounts/codex/<id>/    # CODEX_HOME for added accounts

你的设置不在这个文件夹中，而是在 ~/.ferret/ 中（参见用 settings.json 配置）。

你自己选择的模型可以放在任何位置。旧的默认位置 ~/.cache/ade-movie/models/ggml-small.bin 仍会被检查。

## 环境变量
变量作用
CLAUDE_CONFIG_DIR、CODEX_HOME选择了添加的账户时，由 Ferret 为 Agent 标签页设置
GH_TOKEN、GITHUB_TOKENgh 会优先于自身的登录使用它们。设置了其中任何一个时，Ferret 会发出警告
FERRET_CONFIG_DIR（或旧的 MOVIE_ADE_CONFIG_DIR）用于存放 settings.json、state.json 和 settings.schema.json 的文件夹，替代 ~/.ferret
apiKeyEnv 中的名称你在 settings.json 中指定的 API 密钥。也会从项目的 .env 和 ~/.ferret/.env 中读取
ADE_PROJECT_DIR启动时将此文件夹作为项目打开（并登记）
ADE_INITIAL_URL启动时在内置浏览器中加载此 URL
ADE_WHISPER_MODEL用于本机转写的 GGML 模型的绝对路径，优先于下载的默认模型
FERRET_SENTRY_DSN（或旧的 MOVIE_ADE_SENTRY_DSN）崩溃报告的发送目标。为空时不发送（参见崩溃报告）
OPENAI_API_KEY仅在开发时（pnpm dev）从 .env 读取，打包后的版本从不读取
PATH用于查找你的 Agent 命令（claude、codex、gemini…）、gh、git、whisper-cli。在 macOS 和 Linux 上，会追加 Homebrew、linuxbrew 和 snap 的位置
## 项目内部
  • .ferret/reviews/<id>/：审查（参见数据与隐私）。.ade-movie/reviews/ 中较旧的审查仍会被读取
  • .git/info/exclude：首次录制时添加一行 .ferret/
