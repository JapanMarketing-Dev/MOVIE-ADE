编辑器与预览 打开并编辑项目文件，预览 Markdown 和 Mermaid。在内置浏览器中打开的预览可以像任何网页一样录制和审查。 ## 打开和编辑文件
  • 文件（文件树）：{{keys:Mod+Shift+E}}，提供 按文件名筛选、刷新 和 全部折叠。
  • 转到文件…：{{keys:Mod+P}}。
  • 用 {{keys:Mod+S}} 保存。关闭已修改的文件时会询问 要保存对 <name> 的更改吗？，可选 保存、不保存 和 取消。
  • 如果你有未保存的编辑时文件在磁盘上被更改，可选择 从磁盘重新载入 或 保留我的更改。

编辑器使用 Monaco。非文本文件会改用查看器打开：图片（可放大缩小；SVG 也可以显示为代码）、带进度条的视频和音频、PDF，其他二进制文件则显示其大小和开头字节的十六进制视图。查看器是只读的；项目文件夹之外的文件，以及经由指向项目外的符号链接访问的文件，都不会显示。

## Markdown 和 Mermaid 预览

预览支持 .md、.markdown、.mdx、.mmd 和 .mermaid。Mermaid 随应用一起打包，因此离线也能渲染图表。

  • 在侧边打开预览：在编辑器旁边打开
  • 打开预览：在内置浏览器（ade-preview://）中打开，因此可以录制和审查
## 通过录制审查文档
  1. 打开一个 Markdown 文件，点击 打开预览。
  2. 照常录制。一边讲解规格或设计文档，一边圈出有问题的地方。
  3. 停止。反馈引用的是该文件相对于项目的路径，而不是 URL。
  4. 点击 发送给 Agent，让它修改文档。
