编辑器与预览 打开并编辑项目文件，预览 Markdown 和 Mermaid。在内置浏览器中打开的预览可以像任何网页一样录制和审查。 ## 打开和编辑文件
  • 文件（文件树）：{{keys:Mod+Shift+E}}，提供 按文件名筛选、刷新 和 全部折叠。
  • 转到文件…：{{keys:Mod+P}}。
  • 从访达（Windows 上为文件资源管理器，Linux 上为文件管理器）把文件拖到标签栏或编辑器上即可打开。项目中的文件会在编辑器或查看器中打开。要把项目外的文件带进来，请把它放到 文件 上，它会被复制到项目中。放到这里的文件夹会作为项目打开。从 文件 拖出的文件也以同样方式打开。图片和视频放到已打开的 Markdown 文件上时，则会嵌入到该文件中（参见在 Markdown 中嵌入图片和视频）。
  • 用 {{keys:Mod+S}} 保存。关闭已修改的文件时会询问 要保存对 <name> 的更改吗？，可选 保存、不保存 和 取消。
  • 如果你有未保存的编辑时文件在磁盘上被更改，可选择 从磁盘重新载入 或 保留我的更改。

编辑器使用 Monaco。非文本文件会改用查看器打开：图片（可放大缩小；SVG 也可以显示为代码）、带进度条的视频和音频、PDF，其他二进制文件则显示其大小和开头字节的十六进制视图。查看器是只读的；项目文件夹之外的文件，以及经由指向项目外的符号链接访问的文件，都不会显示。

## 在文件树中处理文件

可以像在 VS Code 中一样，直接在 文件 中处理文件。右键点击某一项即可；要在项目顶层操作，请右键点击树下方的空白处。名称直接在树中输入。

  • 新建文件 / 新建文件夹：使用树上方的按钮，或右键点击。新项目会放在所选文件夹中、所选文件旁边，或项目的顶层。输入带斜杠的名称（例如 src/routes/index.ts）会一并创建途中的文件夹。新建的文件会在编辑器中打开。在空文件夹中，文件 会显示 此文件夹为空，以及 新建文件 和 新建文件夹 按钮。
  • 剪切、复制 和 粘贴：{{keys:Mod+X}}、{{keys:Mod+C}}、{{keys:Mod+V}}，或右键点击。文件夹会连同其中的所有内容一起复制。创建副本 会在原项目旁边创建一个副本。如果名称已被占用，副本会命名为 name copy，然后是 name copy 2。
  • 把项目拖到某个文件夹上（拖到空白处则移到项目顶层）即可移动。放下时按住 {{keys:Alt|Ctrl}} 则改为复制。从访达（Windows 上为文件资源管理器）拖入的文件和文件夹会被复制到项目中，原文件保留在原处。
  • 重命名：{{keys:F2 / Enter|F2}}，或右键点击。
  • 删除：{{keys:Mod+Backspace / Delete|Delete}}，或右键点击。Ferret 会先确认，然后把项目移到废纸篓（Windows 上为回收站），因此可以恢复。已删除文件的标签页会关闭；如果其中有未保存的编辑，确认对话框会提示。
  • 撤销：{{keys:Mod+Z}} 撤销上一次新建、重命名、移动、粘贴或创建副本。已删除的项目会从废纸篓中恢复。
  • 复制路径（{{keys:Alt+Mod+C|Shift+Alt+C}}）和 复制相对路径（{{keys:Alt+Shift+Mod+C|Ctrl+Shift+Alt+C}}）会把路径放到剪贴板上。
  • 在访达中显示（Windows 上为 在文件资源管理器中显示，Linux 上为 打开所在的文件夹）：{{keys:Alt+Mod+R|Shift+Alt+R}}。在终端中打开 会在该文件夹（如果是文件，则为其所在文件夹）中打开一个新的终端标签页。
  • 对于文件，打开 会在编辑器中打开它，用默认应用打开 会用操作系统为该类型文件指定的应用打开它。
  • 用 {{keys:Mod}}-点击或 {{keys:Shift}}-点击选择多个项目，可以一起剪切、复制、移动或删除。
  • {{keys:Esc}} 取消正在输入的名称。

已打开的标签页会跟随被重命名或移动的文件，并保留未保存的编辑。Ferret 不会覆盖已存在的同名文件或文件夹，并且会把一切都限制在项目文件夹内：它会拒绝 ..、绝对路径、指向外部的符号链接、.git 内的任何内容、把文件夹移到其自身内部，以及某些操作系统无法使用的名称：/ \ < > : " | ? *、控制字符、末尾的空格或句点，以及 CON、NUL 等 Windows 保留名称。一次复制或拖放最多可包含 10,000 个项目、1 GB。

## Markdown 和 Mermaid 预览

预览支持 .md、.markdown、.mdx、.mmd 和 .mermaid。Mermaid 随应用一起打包，因此离线也能渲染图表。

Markdown 文件在编辑器顶部有两种视图：源代码 和 预览。预览始终可以编辑，因此可以直接在其中输入；点击 源代码 即可回到文本。两者显示相同的内容，保存、未保存标记和关闭时的确认也都一样。

  • 可以直接在标题、段落、列表、复选框、表格、链接以及粗体、斜体或行内代码中输入。在行首输入 #、-、1. 或 > 加一个空格，即可开始标题、列表或引用。
  • 在行首（或空格之后）输入 /，即可从列表中选择块：标题、项目符号列表、编号列表或清单、表格、代码块、引用或分隔线。每一项都会说明它生成什么，以及在 Markdown 中如何书写。继续输入可以筛选，用 {{keys:Up}} {{keys:Down}} 和 {{keys:Enter}} 选择，或按 {{keys:Esc}} 将 / 保留为文字。表格初始为带表头行的 3 × 3；{{keys:Tab}} 移到下一个单元格，在末尾会添加一行。在表格中输入 / 可以添加或删除行和列，或删除整个表格。
  • 代码块按源代码编辑，并在角落显示语言。Mermaid 代码块（mermaid 或 mmd）默认显示图表。点击右上角的 代码 或双击图表即可编辑源代码；光标移出代码块后会重新显示图表。源代码有错误时，会显示错误信息和 修改代码。图表在沙盒框架中绘制，保存的 Markdown 保持原样。
  • 前置元数据（顶部的 --- 块）以文本形式显示在文档上方，可以在那里编辑。
  • 未修改的部分会按原样保存，包括标题样式、列表标记、空行、表格对齐和换行符。编辑过的块会尽量保留原有样式；无法保留时，该块会以标准 Markdown 形式写出，列表用 -，标题用 #。
  • 项目中的图片和视频会显示。不会加载其他网站的图片，而是显示其主机名。文件中的其他 HTML 会以文本形式显示。

.mdx 文件（仅以源代码形式编辑）、.mmd 和 .mermaid 文件则改用只读预览：

  • 在侧边打开预览：在编辑器旁边打开
  • 打开预览：在内置浏览器（ade-preview://）中打开，因此可以录制和审查
## 在 Markdown 中嵌入图片和视频

把图片（PNG、JPEG、GIF、WebP、SVG、AVIF）或视频（MP4、WebM、MOV）拖到 Markdown 文件上（源代码 或 预览 均可），即可将其嵌入到放下的位置。

  • 已在项目中的文件（包括从 文件 拖出的文件）会以相对于该 Markdown 文件的路径链接，不会复制任何内容。
  • 项目外的文件（来自访达、桌面，或 Windows 上的文件资源管理器）会先被复制到 Markdown 文件旁边的文件夹中：如果已有 assets、images、media 或 img，就复制到其中，否则新建一个 assets 文件夹。名称中的空格会变成 -，如果名称已被占用，副本会命名为 name-2。原文件保留在原处。
  • 图片写作 ![name](assets/name.png)，视频写作 <video src="assets/name.mp4" controls></video>，GitHub 也能播放。两者都会在 预览 中显示。
  • 单个图片最大 50 MB，单个视频最大 500 MB，一次拖放最多复制 50 个文件、共 1 GB。一起放下的其他文件会照常在编辑器中打开。
## 通过录制审查文档
  1. 在 审查对象 面板中，从 文件 打开 Markdown 文件。它会在内置浏览器中以预览形式打开。
  2. 照常录制。一边讲解规格或设计文档，一边圈出有问题的地方。
  3. 停止。反馈引用的是该文件相对于项目的路径，而不是 URL。
  4. 点击 发送给 Agent，让它修改文档。
